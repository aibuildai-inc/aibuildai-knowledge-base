## How this list was built

Nine channels ran at 2026-08-11: curated lists, three forms of GitHub code search, GitHub topic search, GitHub README search, the Hugging Face method-tag census, arXiv, and pyproject probes. They put 2210 repositories in the index. A library earned a card when training code was measured in it, it was not archived and had been pushed within a year, two independent channels found it, and it was large enough that a reader could plausibly pick it; two named lists bend the size and staleness rules for a library that is the only way to do something.

**The list is not saturated, and that is measured.** GitHub code search reports far more results than it will hand over: across the channels here 71,654 results were counted and never returned. Every channel still contributed libraries no other channel found, and the curated-list channel alone brought in 500 of them, which a saturated list would not show. Use the repository's own README and the search method in the cards for anything newer.
