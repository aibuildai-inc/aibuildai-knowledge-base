# Magpie-Align/Magpie-Qwen2.5-Pro-300K-Filtered

https://huggingface.co/datasets/Magpie-Align/Magpie-Qwen2.5-Pro-300K-Filtered

300,000 English instruction-response pairs self-synthesized by prompting Qwen2.5-72B-Instruct, quality-filtered down from a 1M-example raw pool to the 300K examples with the longest responses and best automatic-quality scores.

**Magpie-Align/Magpie-Qwen2.5-Pro-300K-Filtered** is built by the Magpie-Align team using the Magpie self-synthesis method introduced in "Magpie: Alignment Data Synthesis from Scratch by Prompting Aligned LLMs with Nothing" [1]: the method extracts instructions from an aligned model by feeding it only the chat-template prefix up to the user-turn placeholder and letting the model's autoregressive decoding fill in a plausible user query, then generates the matching response from the same model [1]. The dataset's own card states this specific release was "generated by Qwen/Qwen2.5-72B-Instruct using Magpie" [2], and its own navigation table labels the release's downstream use as "SFT" [2]. **The dataset repository carries no license tag, no `cardData.license` field, and the fetched card text contains no license text; treat licensing as undetermined until confirmed on the live repo (see Licence below).**

**Use it for**: SFT chat training - the `conversations` column is a ready-made list of `{from, value}` turns, and the same content is duplicated in flat `instruction`/`response` string columns [3][4]. Map to the SFT method card.

**Licence**: not stated on the dataset's own card - no `license` Hub tag, no `cardData.license` key, and no "MIT" text anywhere in the fetched README, despite the corpus screening row for this dataset recording an "MIT" body mention; that mention does not hold up against the fetched card text and is not repeated here as fact [2][5]. The upstream Magpie codebase on GitHub does carry an MIT `LICENSE` file, but that covers the code, not this data repository [6]. Gated: false, private: false [5].

**Shape**: 300,000 rows, one split (`train`), one config (`default`) [3][4].

**Hold out**: nothing - no source read for this card (README, screening row, or Hub metadata) flags an evaluation-set overlap or contamination risk for this release [2][7].

**Origin**: built by Magpie-Align; instructions and responses are both generated by Qwen/Qwen2.5-72B-Instruct, with per-example labels added by three auxiliary models named in the card - task category, difficulty and input-quality labels by meta-llama/Meta-Llama-3-8B-Instruct, a safety tag by meta-llama/Meta-Llama-Guard-2-8B, and a reward score by sfairXC/FsfairX-LLaMA3-RM-v0.1 [2][3]. Hub API at the check date: `downloads` 1,451, `downloadsAllTime` 7,340, `likes` 14 [5].

**Trained-on-by**: khulaifi95/Llama-3.1-8B-Reason-Blend-888k, a fine-tune of meta-llama/Llama-3.1-8B-Instruct, lists this dataset among its declared training datasets via its model-card tags, alongside four other datasets; three GGUF quantizations of that same model carry the same tag but are re-packagings, not independent training runs [8]. Drramishaheen/HPD, a small gpt2-based model with zero recorded downloads and likes at the check date, also declares this dataset among its training datasets [8]. No larger or better-known model's training recipe naming this dataset was found.

**Introduced by**: [1] (Xu et al.) introduces the Magpie method; this specific 300K-row release has no paper of its own - the dataset card [2] is what documents it.

## Quality

- The card's Filter Setups list the exact automatic filters applied to reach this 300K-row release: input quality "good" or higher, instruction reward at or above -5, removal of repetitive or incomplete instructions (its example is one ending in ":"), removal of instructions mentioning "Alibaba", then selection of the 300K examples with the longest responses out of the larger raw pool [2].
- Input-quality, difficulty, and task-category labels come from meta-llama/Meta-Llama-3-8B-Instruct acting as a judge; the safety tag comes from meta-llama/Meta-Llama-Guard-2-8B; the reward score comes from sfairXC/FsfairX-LLaMA3-RM-v0.1 [2].
- Of the 20 rows served at offset 0 by the datasets-server first-rows endpoint, all 20 carry `language: "EN"` and all 20 carry `input_quality: "good"`, with `instruct_reward` ranging from 3.82 to 9.57 in that sample [9]. This is a 20-row sample at offset 0 only and does not establish the language or quality mix of the full 300,000 rows.
- No source states a measured duplicate rate, an annotator-agreement figure (there are no human annotators - all labels are model-generated per the card [2]), or a benchmark-contamination check for this release.

## Where it came from

Built by Magpie-Align. Instructions are extracted from Qwen/Qwen2.5-72B-Instruct by feeding the model only its chat-template prefix up to the user-turn placeholder, following the Magpie method in [1]; the same model then generates the response to each extracted instruction, and the card describes the release as "generated by Qwen/Qwen2.5-72B-Instruct using Magpie" [2]. The larger raw pool of 1M such conversations is filtered down to this 300K-row release using the automatic filters listed in Quality above - input quality, instruction reward, repetition/incompleteness removal, an "Alibaba"-mention removal, then selection by longest response - all applied without further human review, per the card [2].
