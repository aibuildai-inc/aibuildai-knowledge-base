# microsoft/orca-math-word-problems-200k

200,035 grade-school math word problems, each a `question`/`answer` string pair, with every answer's step-by-step solution generated by Azure GPT-4-Turbo.

**microsoft/orca-math-word-problems-200k** is Microsoft's synthetic math word-problem dataset introduced in "Orca-Math: Unlocking the potential of SLMs in Grade School Math" [1]: a seed set of ~36,217 problems pulled from the Lila benchmark's train/validation splits was expanded through a multi-agent pipeline in which one agent generates new problems from a seed problem and another pair of agents (Suggester and Editor) iteratively increases problem difficulty, with GPT-4-Turbo generating both the expanded questions and their worked-solution answers; a further 6,216 problems were added separately from DMath's training set, kept only where GPT-4-Turbo's computed solution matched DMath's gold answer, without going through that same multi-agent expansion [1]. **The paper states it never used the GSM8K test split, or any other benchmark's test split, as training data or as generation seeds** [1]; it also ran its own contamination check between this train set and the GSM8K test set (1,319 questions) and found only 8 test questions with n-gram (Jaccard, n=1) overlap above its 0.5 threshold, calling this negligible [1]. It lives at https://huggingface.co/datasets/microsoft/orca-math-word-problems-200k .

**Use it for**: reasoning-trace SFT - each `answer` is a full worked solution, not a bare final number, so it trains a model to produce step-by-step math reasoning; maps to the SFT method card. No usage-shape restriction beyond the standard "hold out the eval set you'll score against" caution below.

**Licence**: MIT (`cardData.license` is `"mit"`, tag `license:mit`), ungated (`"gated": false`, `"private": false`) [2]. No further catch stated.

**Shape**: 200,035 rows, one config (`default`), one split (`train`), two string columns (`question`, `answer`) [2][3].

**Hold out**: the GSM8K test set (1,319 questions) before scoring on GSM8K - not because this dataset's own rows overlap it (the paper's own check found only 8 near-duplicates out of 1,319, treated as negligible [1]), but because GSM8K is the standard grade-school-math benchmark this data is shaped to feed, so anyone using it for training and then scoring on GSM8K should hold that benchmark's test split out of any of their own retraining or selection loops. No source flags any other eval-set overlap.

**Origin**: built by Microsoft; the questions are synthetically expanded by a multi-agent GPT-4-Turbo pipeline from human-authored seed problems, and every answer is a GPT-4-Turbo generation [1]. Hub API at the check date: `downloads` 13,389, `downloadsAllTime` 137,343, `likes` 494 [2].

**Trained-on-by**: the origin paper's own Orca-Math-7B (Mistral-7B fine-tuned on this set) [1]; on the Hub, models tagged as using this dataset (`datasets:microsoft/orca-math-word-problems-200k`) include dphn/Dolphin3.0-Llama3.1-8B, dphn/dolphin-2.9-llama3-8b, and Weyaxi/Einstein-v6.1-Llama3-8B [4].

**Introduced by**: [1] (Mitra, Khanpour, Rosset, Awadallah).

## Quality

- The paper reports the deciding downstream number: training Mistral-7B by Supervised Fine-Tuning alone on this dataset reaches 81.50% pass@1 on GSM8K, versus 86.81% when that SFT model is further trained with iterative preference learning on top (a separate, later-stage process not part of this dataset) [1].
- The paper's own contamination check (TF-IDF cosine similarity to shortlist candidates, then Jaccard n-gram overlap at n=1) found 8 of the 1,319 GSM8K test questions above its 0.5 overlap threshold when compared against the full train set, and 7 when compared against only the original seed problems; at n≥2 the overlap count is zero [1]. No source states a duplicate-row rate or an annotator-agreement figure, since annotation here is entirely GPT-4-Turbo generation rather than human labeling.
- The dataset card states no personal or sensitive information is present ("None") and that the data is English-only, math word problems only [6].
- The dataset card's stated Out-of-Scope Use: "not intended for use in educational systems or organizations" [6].

## Where it came from

Built and released by Microsoft. The seed set of ~36,217 problems was collected from the Lila benchmark's train and validation splits, which aggregate problems from NumGLUE, AddSub, ALGES, ASDiv, DRAW, GSM8K's own train split, MATHQA, MultiArith, SingleOp, SingleEQ, and SVAMP [1]. Two agent pipelines then expanded this seed set with GPT-4-Turbo: an "Ask Me Anything" agent that rewrites a seed problem into a statement and generates one new question per number in it (yielding 120,445 new problems), and a "Suggester & Editor" pair of agents that iteratively rewrites a problem to increase its difficulty over multiple rounds [1]. Separately, a further 6,216 problems were sourced from DMath's 7,943-problem training set, kept where GPT-4-Turbo's computed solution matched DMath's gold answer, without passing through the Ask-Me-Anything or Suggester-and-Editor expansion [1]. GPT-4-Turbo also generated the worked-solution answer for every question in the released set [6].
