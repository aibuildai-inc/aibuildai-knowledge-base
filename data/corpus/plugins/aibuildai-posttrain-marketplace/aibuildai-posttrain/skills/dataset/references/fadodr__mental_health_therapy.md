# fadodr/mental_health_therapy

12,258 single-turn mental-health counseling instruction/input/output rows, mixing real counselor forum answers with ChatGPT-written synthetic discussions, split into a fixed 8,580-row train and 3,678-row test set.

**fadodr/mental_health_therapy** is a Hub-only compilation (no accompanying paper) built by user `fadodr`, who describes it as combining real counseling conversation from the CounselChat forum with synthetic discussion generated by ChatGPT, drawn from three named upstream repositories - `nbertagnolli/counsel-chat`, `Amod/mental_health_counseling_conversations`, and `ShenLab/MentalChat16K` - and "cleaned to make it anonymized and remove convo that is not relevant" [1]. Rows are shaped as `instruction`/`input`/`output` triplets: a fixed counseling-assistant system instruction, a client message as `input`, and a counselor-style reply as `output` [2], the standard Alpaca-style single-turn SFT layout. **One of the three named upstream sources, `Amod/mental_health_counseling_conversations`, is released under a non-commercial RAIL-D licence with a mandatory-donation clause for commercial use [3]; this repository's own front matter and Hub tag both read `license: mit` regardless [1][4], and no source here reconciles the two.**

**Use it for**: single-turn SFT chat fine-tuning on counseling-style question/answer pairs - map `input` to the user turn and `output` to the assistant turn, ignoring or folding in the fixed `instruction` string as a system prompt; this is the same instruction/input/output shape the SFT method card expects. Flag the RAIL-D-vs-MIT licence conflict above before any commercial use.

**Licence**: `license: mit` in the repo's `cardData` and Hub tags, ungated [1][4]. The catch: this MIT label covers only this repository's own re-release; one of its three stated upstream sources carries RAIL-D terms requiring a paid donation for commercial use, and no source addresses whether that restriction survives the merge [3].

**Shape**: 12,258 rows, one config (`default`), two splits - `train` 8,580 and `test` 3,678 - three string columns (`instruction`, `input`, `output`) [5][2].

**Hold out**: `test` (3,678 rows); train on `train` (8,580 rows) [5]. No source here flags overlap with a named evaluation benchmark.

**Origin**: mixed - real CounselChat forum answers from licensed counselors plus ChatGPT-written synthetic discussions, compiled and anonymized by `fadodr` from the three upstream repositories named above [1]. Hub API at the check date: `downloads` 128, `likes` 17 [4].

**Trained-on-by**: at least six public fine-tunes on the Hub declare this dataset in their tags, found by filtering the Hub's model list for `dataset:fadodr/mental_health_therapy` [6]: `therealcyberlord/MindGem-9b-bnb-4bit` (Gemma-2-9B via unsloth/trl), `zbt566666/qwen2.5-7b-mental-therapy-lora-sft` (Qwen2.5-7B LoRA SFT), `help2opensource/Qwen3-4B-Instruct-2507_mental_health_therapy` (Qwen3-4B LoRA), and `alibidaran/Zigroo-Mental_consultant2-merged` (Qwen3-8B, mixed with four other counseling datasets) [6].

**Introduced by**: no paper - the dataset card [1].

## Neighbors

Three named upstream sources feed this compilation, and each is independently on the Hub with a different schema; all row counts below were read live at the check date [7][8][9].

- `nbertagnolli/counsel-chat` - the raw CounselChat scrape this repo draws its real-counselor answers from: 2,775 rows, 10 columns (`questionID`, `questionTitle`, `questionText`, `topic`, `therapistInfo`, `therapistURL`, `answerText`, `upvotes`, `views`, plus a link column), MIT-licensed, not anonymized (therapist names retained) [7][10].
- `Amod/mental_health_counseling_conversations` - a two-column (`Context`/`Response`) reformatting of counseling Q&A pairs from public counseling sites, 3,512 rows, no predefined splits, released under RAIL-D with a commercial-use donation clause [8][3].
- `ShenLab/MentalChat16K` - 16,084 rows in the same `instruction`/`input`/`output` schema as this repository, combining 9,775 GPT-3.5-Turbo synthetic counseling conversations ("Synthetic Data 10K") with 6,338 Mistral-7B-summarized real clinical-trial interview transcripts ("Interview Data 6K"), MIT-licensed, introduced by Xu et al., "MentalChat16K: A Benchmark Dataset for Conversational Mental Health Assistance" [9][11].

This repository's 12,258 rows are fewer than the roughly 22,000-row sum of the three sources, consistent with its own claim of having removed irrelevant conversations [1]; no source states the exact per-source row breakdown that survived into this release, so pick this compilation only when the pre-cleaned, pre-split 8,580/3,678 shape is what is wanted, and go to the named source directly for its full row set or original schema.

## Where it came from

Built by Hub user `fadodr` by combining and cleaning rows from three named upstream repositories: real CounselChat forum answers by licensed counselors (via `nbertagnolli/counsel-chat`, itself scraped from counselchat.com on 2022-04-01 [10]), further real counseling Q&A (via `Amod/mental_health_counseling_conversations` [8]), and ChatGPT-written synthetic counseling discussions (via `ShenLab/MentalChat16K`'s GPT-3.5-Turbo-generated synthetic half [9]). The card states the result was "cleaned to make it anonymized and remove convo that is not relevant" but does not state a per-source row count, a cleaning script, or a train/test split rule [1].
