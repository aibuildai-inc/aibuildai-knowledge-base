# mlabonne/MedText

1,412 clinical-vignette / diagnosis-and-treatment pairs, one config, one `train` split, ~494 KB of Parquet - a column-renamed re-release of the BI55/MedText dataset.

**mlabonne/MedText** is a copy of BI55/MedText's shuffled `medtext_2` file with the two columns renamed from `Prompt`/`Completion` to `instruction`/`output`; row 0 of both repositories' `train` split carries the identical vitamin-D-toxicity vignette text [1][2]. The upstream card describes the underlying data as original patient-presentation and diagnosis/treatment material that was "converted into uniform datapoints using GPT-4," with three doctors judging a 10-example sample "textbook quality" [1]. mlabonne/MedText's own README carries no description, no license field, and no citation - only the Hugging Face `datasets`-library autogenerated header [2]. It lives at https://huggingface.co/datasets/mlabonne/MedText . **The upstream card licenses the content CC BY 4.0 [1]; this repository states no license of its own [2], so treat licensing as unresolved rather than assuming the upstream grant carries over automatically.**

**Use it for**: instruction-response SFT - the two columns (`instruction`, `output`) are plain instruction/output pairs, not a chat-templated or multi-turn format; map directly to the SFT method card's single-turn instruction format. No preference, reasoning-trace, or reward-model structure is present.

**Licence**: not stated on this repository (`cardData` and body both carry no `license` field) [2]; the upstream BI55/MedText repository that supplies the content is tagged `cc-by-4.0` [3]. Ungated, public (`"gated": false`, `"private": false`) [4].

**Shape**: 1,412 rows, one config (`default`), one split (`train`); two string columns, `instruction` and `output` [5][6].

**Hold out**: nothing found - no source states or implies this dataset overlaps a known evaluation set. This is limited to what the fetched sources cover (the two dataset cards and the row-0 comparison above), not a broader contamination sweep.

**Origin**: built by user mlabonne as a reformatted re-upload of BI55/MedText [1][2]; the underlying content is original clinical material converted into datapoints by GPT-4, per the upstream card [1]. Hub API at the check date: 149 `downloads`, 1,439 `downloadsAllTime`, 8 `likes` [4].

**Trained-on-by**: no model card was found citing `mlabonne/MedText` by name via the Hub's dataset-filter search. Several models cite the upstream `BI55/MedText` as training data instead: Locutusque/gpt2-large-medical (fine-tuned on MedText plus PubMedQA) [7], therealcyberlord/TinyLlama-1.1B-Medical (fine-tuned on a combined BI55/MedText and MedQuad set for 1,000 steps) [8], and 13 further medical fine-tunes and GGUF conversions returned by the same filter [9].

**Introduced by**: no paper - the upstream BI55/MedText dataset card [1]; this repository's own card gives no description [2].

## Quality

- The only quality signal on either card is upstream's self-reported spot check: 10 random examples were shown to three doctors (two involved in building the set, one uninvolved), who all rated them "textbook quality" [1]. That is a 10-of-1,412-row sample, not a dataset-wide measurement.
- The upstream card states the set deliberately includes "noise/data pollution" content - dismissal of non-medical questions, requests for more information when data is insufficient, contradictory or irrelevant details, and misleading-symptom cases - by design, to train a model to decline low-confidence answers [1].
- No source states a measured duplicate rate or contamination rate for either repository; none is invented here.
- This repository's own README carries no quality statement of any kind [2].

## Where it came from

This repository's own card states nothing about provenance beyond the autogenerated schema header [2]. The content traces to BI55/MedText, whose card states the data is original patient-presentation and diagnosis/treatment material "converted into uniform datapoints using GPT-4," covering the 100 most common diseases and 30 most common injury types presenting to hospitals, plus deliberately included edge cases (insufficient-information refusals, misleading symptoms, AI-capability disclaimers) meant to reduce hallucination and overconfidence [1]. The upstream card describes this specific file as "the shuffled version of medtext_1," randomized to prevent the model from learning category order [1]. A 10-example subset was reviewed by three doctors, who rated it "textbook quality" [1].
