# allenai/ai2_arc

7,787 four-choice, grade-school science exam questions, split into an Easy set and a harder Challenge set, each with its own train/validation/test partition.

**allenai/ai2_arc** packages the AI2 Reasoning Challenge (ARC), introduced by Clark et al. in "Think you have Solved Question Answering? Try ARC, the AI2 Reasoning Challenge" [1], as a Hugging Face dataset with two configs, `ARC-Challenge` and `ARC-Easy`. It lives at https://huggingface.co/datasets/allenai/ai2_arc . The paper defines the Challenge set as exactly those questions that both an information-retrieval solver and a PMI (pointwise mutual information) solver answered incorrectly, with the Easy set holding the rest [1]; each row is a natural-language multiple-choice science question with an `id`, `question`, a `choices` list of `{text, label}` options, and an `answerKey` naming the correct label. **`test` in both configs is the ARC benchmark split used to report and compare scores; `train` and `validation` are safe to train on, `test` is not.**

**Use it for**: multiple-choice reasoning-trace or direct-answer SFT on the `train` (and optionally `validation`) rows of either config, formatted as a question with its `choices` and the `answerKey`-selected option as the target; not a preference-pair or reward-model format. See the SFT method card. Do not eval-contaminate any run that reports ARC scores by including `test` rows in training.

**Licence**: cc-by-sa-4.0 (`cardData.license` and the `license:cc-by-sa-4.0` repo tag), ungated (`"gated": false`) [2]. The one catch: the README's own "Licensing Information" section is unfilled ("More Information Needed"), so the SPDX id comes only from the repo metadata, not from body prose [3].

**Shape**: 7,787 rows across two configs, each with `train`/`test`/`validation` splits: `ARC-Challenge` 1,119/1,172/299, `ARC-Easy` 2,251/2,376/570 [4][5].

**Hold out**: `ARC-Challenge/test` (1,172 rows) and `ARC-Easy/test` (2,376 rows) - together 3,548 of the 7,787 rows - because both are the ARC benchmark test split; train on the remaining `train`+`validation` rows (1,119+299 and 2,251+570) [6].

**Origin**: released by the Allen Institute for AI (AI2); questions were written for use in human standardized testing and collected/found rather than generated by a model [1][3]. Hub API at the check date: `downloads` 466,533, `downloadsAllTime` 13,521,375, `likes` 379 [2].

**Trained-on-by**: UnifiedQA fine-tunes a single T5-based QA model across 17 multiple-choice/extractive/abstractive QA datasets including ARC (both the easy and challenge subsets, citing Clark et al. 2018), and reports a 13-point gain over fine-tuned T5 alone on ARC-challenge from this multi-dataset training [7].

**Introduced by**: [1] (Clark et al.).

## Quality

- The paper's own baseline results (Table 6) are the deciding number for how hard the Challenge set is: on the Challenge test partition, the "Guess-all (random)" baseline scores 25.02%, and every tested solver (IR using the ARC Corpus, TupleInference, DecompAttn, DGEM-OpenIE, BiDAF, TableILP, DGEM) scores between 20.26% and 27.11%, clustered around that random-guess score, which the paper reports as none significantly outperforming random guessing [1]. The same baselines score far above random on the Easy test partition (e.g. IR using the ARC Corpus reaches 62.55% there, against a 25.02% random baseline) [1].
- The Challenge/Easy split itself is a quality-control construction, not a random sample: a question lands in Challenge only if both an IR solver and a PMI (pointwise mutual information) solver answered it incorrectly, so Challenge is selected to be adversarial to those two baselines [1].
- The README's Dataset Structure section documents no missing-value, duplicate-rate, or annotation-agreement figures for this release, and states no other quality caveats; none is invented here [3].
- Questions are described as genuine, natural grade-school science questions "authored for human tests," and the paper calls this collection "the largest public-domain set of this kind" of that size (7,787 questions) at time of release [1].

## Load it

Both configs are needed to get all 7,787 rows; each is loaded separately, train and validation only, holding out test. Pin the revision this card's numbers were read at (the shortlist's own commit) [2]:

```python
import datasets

REV = "210d026faf9955653af8916fad021475a3f00453"
challenge_train = datasets.load_dataset("allenai/ai2_arc", "ARC-Challenge", revision=REV, split="train")       # 1,119 rows
challenge_val    = datasets.load_dataset("allenai/ai2_arc", "ARC-Challenge", revision=REV, split="validation") # 299 rows
easy_train       = datasets.load_dataset("allenai/ai2_arc", "ARC-Easy", revision=REV, split="train")           # 2,251 rows
easy_val         = datasets.load_dataset("allenai/ai2_arc", "ARC-Easy", revision=REV, split="validation")      # 570 rows
```

**Trap**: `load_dataset("allenai/ai2_arc")` with no config name fails - a config (`ARC-Challenge` or `ARC-Easy`) is required, and the two configs must be loaded and concatenated separately if the full question set is wanted [2]. Loading `split="test"` from either config pulls in the ARC benchmark split named in Hold out above; do not add it to a training mix.

## Where it came from

Built and released by the Allen Institute for AI. The questions are natural, grade-school-level science questions originally written for human standardized testing, collected rather than authored by the AI2 team or a model [1]. The paper partitions the full question set into Challenge and Easy by running an IR (information-retrieval) solver and a PMI (pointwise mutual information) solver over every question: any question either solver answered correctly goes to Easy, and the remainder - answered incorrectly by both - forms Challenge [1]. Alongside the question sets, the paper also releases the ARC Corpus, a 14-million-sentence science text corpus meant to support retrieval-based solving of these questions, and reference implementations of three neural baseline models; neither the corpus nor the baseline code is part of this Hub repository's `ARC-Challenge`/`ARC-Easy` configs [1][3].
