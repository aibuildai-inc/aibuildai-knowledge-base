# Magpie-Align/Magpie-Qwen2.5-Math-Pro-300K-v0.1

300,000 math-leaning instruction-response pairs, both sides self-generated by Qwen2.5-Math-72B-Instruct through the Magpie extraction method, unfiltered ("raw") and carrying per-row quality/difficulty/safety annotations.

**Magpie-Align/Magpie-Qwen2.5-Math-Pro-300K-v0.1** is built by the Magpie-Align team using the Magpie method from "Magpie: Alignment Data Synthesis from Scratch by Prompting Aligned LLMs with Nothing" [1]: Magpie exploits the fact that an aligned, instruction-tuned model will complete a user turn on its own when fed only the chat template up to that turn, which lets it synthesize instructions without any seed prompts or human writing, and the same model then answers its own instructions [1]. This release runs that method entirely with Qwen2.5-Math-72B-Instruct [2], and the dataset card's own sibling-dataset table describes it as "300K Raw conversations built with Qwen2.5 Math 72B Instruct" [2] - unlike two sibling Qwen2/Qwen2.5 releases from the same team, whose table entries say they "Apply a filter and select 300K high quality conversations" [2], this release carries no stated filtering step. **Both the instructions and the responses come from one 72B model instruct-tuned on math, so the ceiling on correctness, difficulty calibration, and style is that model's own capability, not a separate teacher or human check.**

**Use it for**: reasoning-trace SFT (instruction plus a full worked solution) via the `instruction`/`response` fields or the equivalent `conversations` list, mapping to the SFT method card's chat format; no preference pairs or reward-model fields beyond a scalar per-row reward are present. No stated usage restriction beyond the self-generation ceiling above; **using it to train and distribute a model may separately require the "Built with Qwen" attribution carried by the generating model's own license, not this dataset's** [3].

**Licence**: no `license` field in this repo's card metadata and no license tag on the repo [4]; the dataset card body states no license either [2]. The one catch: the data is entirely Qwen2.5-Math-72B-Instruct output, and that model is released under a custom "Qwen" license (not MIT, not Apache) that requires any AI model trained on its outputs and then distributed to display "Built with Qwen" or "Improved using Qwen" [3] - a downstream condition worth carrying even though it is not this repository's own license field.

**Shape**: 300,000 rows, one split (`train`), one config (`default`), 25 columns [5][6].

**Hold out**: not stated - no source for this dataset names an evaluation set it may overlap; nothing found to flag as a contamination risk here or elsewhere on this card.

**Origin**: built by Magpie-Align; every row's `model` field reads `Qwen/Qwen2.5-Math-72B-Instruct`, confirming both instruction and response are that one model's own generations, with no separate human or model judge in the generation loop itself (see Quality for the auxiliary annotator models) [7]. Hub API at the check date: `downloads` 222 (last 30 days), `downloadsAllTime` 2,507, `likes` 2 [4][8].

**Trained-on-by**: none found - a Hub model search for this dataset's name returned no results, and the repository's only discussion is an automated bot pull request adding language metadata, not a training report [9][10].

**Introduced by**: [1] (Xu et al.); this specific Qwen2.5-Math-72B-Instruct generation is documented only in the dataset's own card, not in the paper, which predates Qwen2.5 [1][2].

## Quality

- The card documents `input_quality` ('very poor' to 'excellent'), `difficulty` ('very easy' to 'very hard'), a safety tag from meta-llama/Meta-Llama-Guard-2-8B, and a scalar reward from a named reward model as per-row fields, but states no aggregate statistic (mean, distribution, pass rate) over the 300,000 rows [2].
- Reading the 36 rows the datasets-server first-rows endpoint serves at offset 0 of `train`: all 36 have `model` equal to `Qwen/Qwen2.5-Math-72B-Instruct`; 35 are tagged `llama_guard_2` "safe" and one carries an empty string; `task_category` splits 25 Math, 8 Information seeking, 3 Coding & Debugging (some rows carry more than one category via `other_task_category`); `input_quality` splits 29 good, 5 average, 1 excellent, 1 poor; `language` is 35 "EN" and 1 "LA" [7]. This sample shows the "Math-Pro" name does not mean every row is task-tagged Math, and gives no basis for a rate claim beyond these 36 rows.
- `task_category_generator`, `difficulty_generator`, and `quality_generator` all read `meta-llama/Meta-Llama-3-8B-Instruct` in the sampled rows - the quality and difficulty labels are a separate 8B model's judgment of the 72B-generated pair, not a human check [7].
- The dataset's own card states no measured duplicate rate; the `repeat_count` and `min_neighbor_distance`/`min_similar_uuid` columns exist precisely so a user can filter near-duplicates, but the card gives no dataset-wide figure for how many rows they would remove [2].

## Where it came from

Built by the Magpie-Align team using the Magpie self-synthesis method [1]: an aligned, instruction-tuned model is fed only its own chat template up to the user-turn marker, and its auto-regressive completion of that partial template becomes a synthetic instruction; the same model is then prompted with that instruction to produce the response [1]. Here the model performing both roles is Qwen2.5-Math-72B-Instruct, per the `model` column on every sampled row and the dataset card's "Dataset Details" section [2][7]. The auxiliary per-row labels - task category, difficulty, input quality, and their explanations - are added afterward by a separate model, `meta-llama/Meta-Llama-3-8B-Instruct`, and the safety tag by `meta-llama/Meta-Llama-Guard-2-8B`, per the card's "Available Labels" section and the sampled rows' `*_generator` fields [2][7]. The reward field comes from `sfairXC/FsfairX-LLaMA3-RM-v0.1` per the card and the sampled row [2][7].
