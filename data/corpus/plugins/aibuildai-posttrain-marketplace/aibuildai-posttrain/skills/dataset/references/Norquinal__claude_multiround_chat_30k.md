# Norquinal/claude_multiround_chat_30k

32,170 synthetic multi-turn chat conversations - three chained human/Claude instruction-response turns per conversation, 96,510 total instructions - generated by Claude and filtered to remove overt alignment/refusal text.

**Norquinal/claude_multiround_chat_30k** was built by the Hugging Face user Norquinal by generating 50,000 instruction/response pairs with Claude and then chaining two additional Claude-generated follow-up instructions onto each base instruction, for 150,000 instructions total, before removing conversations that carried "blatant alignment" text; 32,170 conversations (96,510 instructions) remain in the released file [1]. The dataset card names no paper: the source here is the dataset's own README [1]. It lives at https://huggingface.co/datasets/Norquinal/claude_multiround_chat_30k . Each row is a `conversations` list of `{from, value}` turns alternating `human`/`gpt`, i.e. ShareGPT-style multi-turn dialogue, so it serves multi-turn SFT chat training. **The dataset's own README says nothing about removed content beyond "instances of blatant alignment removed" [1] - it does not name what was filtered or how, so a user who needs unfiltered assistant refusals for a safety-training run should treat this corpus as pre-filtered against that behavior, not neutral.**

**Use it for**: multi-turn SFT chat training - the `conversations` column already holds full human/gpt turn sequences, mapping directly to the SFT method card's chat format (list of role-tagged turns) with no `extract_prompt`-style reshaping needed. The "blatant alignment removed" filtering [1] means this is not a source for training or evaluating refusal/alignment behavior.

**Licence**: not stated. The dataset card carries no licence field (`cardData` is empty) and the README text contains no licence statement [1][2]; the repository is ungated (`"gated": false`) [2].

**Shape**: 32,170 rows, one config (`default`), one split (`train`), two columns (`id` string, `conversations` list of `{from, value}` structs) [3][4].

**Hold out**: nothing found. No source - the README, the Hub record, or the neighbor trail - names an evaluation-set overlap or contamination risk for this corpus [1][2][5].

**Origin**: built by Norquinal; the instructions and responses were generated by an Anthropic Claude model, then algorithmically filtered by the builder for alignment-flagged content [1]. Hub API at the check date: `downloads` 132, `downloadsAllTime` 3,432, `likes` 70 [2].

**Trained-on-by**: PygmalionAI's Pygmalion-2 7B and 13B chat models list this dataset in their training mix, alongside PIPPA, OpenOrca, airoboros-gpt4-1.4.1, and databricks-dolly-15k [6]; Mythalion-13B, a merge built on Pygmalion-2, inherits the same listed mix [7]. The Hub's models-by-dataset filter lists 63 repositories tagged as using this dataset as of the check date; 30 of them are Pygmalion-2/Mythalion itself or quantized/renamed re-packagings of it (TheBloke's GPTQ/GGUF/AWQ builds and similar), and the other 33 are independent repositories this card did not verify individually, spanning several unrelated families - seven `xiaol/*` RWKV models (two of them named `RWKV-claude-*`), six `LoneStriker/Skywork-13B-Airo-Claude-Pippa-Puffin` quantizations, three `open-llama-3b-claude-30k` repackagings, two `Echo-3B` repos, two `Luminaura-RP-13B` repos, three `Luminia-8B-RP` repos, three `Minueza-2-96M-Instruct-Variant-03` repos, and several singles (e.g. `FunkEngine/SchweinZwei-13b`, `Or4cl3/1nsfw`, `Doctor-Shotgun/smol_llama-220M-GQA-32k-theta-sft`, `svyatsharov/Role-play-ai`) [8].

## Where it came from

Built by the Hugging Face user Norquinal. The instructions and responses were synthetically generated using Claude with a method the builder describes as "multi-instruct": a base instruction plus two chained follow-up instructions per conversation, covering STEM, Arts & Humanities, Social Knowledge, and General Knowledge topics [1]. The builder started from 50,000 base instruction/response pairs (150,000 instructions after chaining follow-ups) and removed conversations containing "blatant alignment" text, leaving the 32,170 conversations (96,510 instructions) served today [1]. No paper documents the generation or filtering pipeline; the README is the only source [1].
