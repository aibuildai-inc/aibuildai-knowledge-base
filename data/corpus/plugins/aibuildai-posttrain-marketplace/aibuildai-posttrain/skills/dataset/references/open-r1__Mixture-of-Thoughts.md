# open-r1/Mixture-of-Thoughts

349,317 distinct DeepSeek-R1 reasoning traces over math, code, and science, formatted as two-turn user/assistant chat messages with a `<think>` block; served under four configs, one of which ("all") is only the union of the other three.

**Mixture-of-Thoughts** is Hugging Face's Open R1 project's curated SFT corpus, distilled from [DeepSeek-R1](https://huggingface.co/deepseek-ai/DeepSeek-R1) and used to train [open-r1/OpenR1-Distill-7B](https://huggingface.co/open-r1/OpenR1-Distill-7B), which the dataset's own card describes as replicating the reasoning of deepseek-ai/DeepSeek-R1-Distill-Qwen-7B [1]. It has no dedicated origin paper; its own card is the only description of how it was built, and its curation methodology explicitly follows the domain-independent mixture-optimisation approach of the Phi-4-reasoning technical report [2][1]. It lives at https://huggingface.co/datasets/open-r1/Mixture-of-Thoughts .

**The math domain (93,733 rows, from the `default` subset of open-r1/OpenR1-Math-220k) and the code domain (83,070 rows, from the non-decontaminated `solutions`/`solutions_w_editorials` subsets of open-r1/codeforces-cots) carry no stated decontamination against AIME 2025 or other competition benchmarks, unlike sibling subsets in the same open-r1 family that are explicitly decontaminated against exactly that benchmark [3]. The science domain (172,514 rows, from nvidia/Llama-Nemotron-Post-Training-Dataset) is synthetic data whose upstream card warns that a distributed model trained on it may inherit Llama 3.1/3.3 Community License Agreement redistribution obligations [4].**

**Use it for**: reasoning-trace SFT - each row is a ready two-message (`user`, `assistant`) chat pair where the assistant turn contains a `<think>...</think>` reasoning block followed by the final answer; maps directly onto a chat-format SFT loader (the `messages` column already matches the standard chat SFT shape, no `extract_prompt`-style conversion needed). See the SFT method card. Before a scored run against AIME 2024/2025, GPQA Diamond, MATH-500, or LiveCodeBench, decontaminate the math and code domains yourself, per the restriction above.

**Licence**: not stated for the combined release - no `license:` field in the YAML metadata and no `license` tag on the repo [5]; the README states no license for Mixture-of-Thoughts itself [1]. The three upstream sources carry different licenses: OpenR1-Math-220k is Apache-2.0 [6], codeforces-cots is CC-BY-4.0 with an ODC-BY note [7], and Llama-Nemotron-Post-Training-Dataset is CC-BY-4.0 with the redistribution catch above [4].

**Shape**: 349,317 distinct rows across three domain configs (`code` 83,070, `math` 93,733, `science` 172,514), each with one `train` split; a fourth config, `all`, is the union of those three (349,317 rows again) and is not additional data [8][9].

**Hold out**: no test split exists to hold out - every config serves only `train` [9]. The contamination risk instead runs the other way: math and code rows are not stated to be decontaminated against AIME 2025/2024, GPQA Diamond, MATH-500, or LiveCodeBench, so a reader scoring on those benchmarks should decontaminate the `math` and `code` configs before using them, mirroring the decontamination the open-r1 org already ships for a sibling codeforces-cots subset [3].

**Origin**: built by the Hugging Face Open R1 project from three existing datasets; every reasoning trace was generated by DeepSeek-R1 (science-domain prompts pre-processed with a mix of models, filtered to exclude Qwen-processed ones) [1]. Hub API at the check date: `downloads` 10,463, `likes` 326 [5].

**Trained-on-by**: open-r1/OpenR1-Distill-7B, the Open R1 project's own SFT model, plus several third-party quantized/GGUF mirrors of it (e.g. `mlx-community/OpenR1-Distill-7B-4bit`, `prithivMLmods/OpenR1-Distill-7B-F32-GGUF`) [10][1].

**Introduced by**: no paper - the dataset card [1]; its curation methodology is attributed to the Phi-4-reasoning technical report [2].

Rows and bytes per config (`cardData.dataset_info` in the README, cross-checked against the datasets-server size endpoint) [1][8]:

`all` is not a fourth slice of data: its 349,317 rows are exactly `code` + `math` + `science` combined, confirmed by sampling the first ten rows of `all/train` and finding their `source` values split across `open-r1/codeforces-cots`, `open-r1/OpenR1-Math-220k`, and `nvidia/Llama-Nemotron-Post-Training-Dataset` [9]. So loading `all` and any one domain config together duplicates rows; the dataset's true size is 349,317 distinct examples, not the datasets-server total of 698,634 rows served across all four configs [8]. Every config shares three columns: `messages` (a list of `{content, role}` structs), `num_tokens` (int64), and `source` (string) [1][11]. `num_tokens` is stated per row but the README states no corpus-wide average; the ten `all/train` rows sampled ranged from 1,062 to 22,185 tokens [9].

## Quality

- Each row's `source` column names the upstream dataset it was drawn from; sampling the first ten rows of `all/train`, `code/train`, and `math/train`, and the first 37 rows of `science/train` (the datasets-server first-rows response sizes), confirms `code` rows all carry `source="open-r1/codeforces-cots"`, `math` rows all carry `source="open-r1/OpenR1-Math-220k"`, and `science` rows all carry `source="nvidia/Llama-Nemotron-Post-Training-Dataset"` [9].
- The README states that in the Open R1 team's own ablations, training on OpenR1-Math-220k's `default` and `extended` subsets together gave the best results, and `default` alone beat `extended` alone; they chose `default` alone for the final mixture anyway, trading the modest extra performance of the combined subsets for a smaller dataset [1].
- The README states the code traces mix C++ and Python R1 completions because C++ traces scored better on the IOI 2024 benchmark while Python traces scored better on LiveCodeBench, and that combining all four codeforces-cots subsets (`solutions`, `solutions_py`, `solutions_w_editorials`, `solutions_w_editorials_py`) gave the best LiveCodeBench result in their ablation [1].
- The README states the science subset was reduced from Llama-Nemotron's 483k-row `science` split (as it stood when Mixture-of-Thoughts was curated) to 172,514 rows by keeping only traces where no Qwen model was used for prompt pre-processing [1]. The Llama-Nemotron card, read live at the check date, currently reports its `science` split at 708,920 rows [4] - a live-endpoint count, not the figure Mixture-of-Thoughts was built from, since Llama-Nemotron is an independently versioned, still-updated dataset.
- No source states a measured contamination rate, near-duplicate rate, or human-verification pass rate for Mixture-of-Thoughts itself. OpenR1-Math-220k's README states its own traces are verified with Math-Verify for most samples and a Llama-3.3-70B-Instruct judge for 12% of samples, with every problem guaranteed at least one correct-answer trace [6]; no equivalent verification-rate statement exists for the code or science domains.

**Trap**: loading `all` together with any of `code`, `math`, or `science` and concatenating them duplicates every row, since `all` already contains them; pick either `all` alone or the three domain configs together, never both [1][9].

## Where it came from

Built by Hugging Face's Open R1 project by combining and filtering three existing datasets, each with DeepSeek-R1-generated reasoning traces [1]:

- **math** (93,733 rows): the `default` subset of open-r1/OpenR1-Math-220k, itself built by prompting DeepSeek-R1 for solutions to problems drawn from NuminaMath 1.5 [6]. NuminaMath 1.5's own source breakdown includes a 5,872-problem `amc_aime` category [13], the likely origin of the AIME-overlap risk flagged above, though neither the OpenR1-Math-220k nor Mixture-of-Thoughts cards state a decontamination step against AIME.
- **code** (83,070 rows): the `solutions` and `solutions_w_editorials` subsets of open-r1/codeforces-cots, built by prompting DeepSeek-R1 to solve Codeforces competitive-programming problems, with and without a human-written editorial provided as context [1][7]. codeforces-cots separately ships `_decontaminated` variants of these same subsets, built by 8-gram overlap filtering against AIME24, AIME25, GPQA Diamond, MATH-500, and LiveCodeBench [3]; Mixture-of-Thoughts uses the non-decontaminated originals [1].
- **science** (172,514 rows): the `science` split of nvidia/Llama-Nemotron-Post-Training-Dataset, filtered by the Open R1 team to exclude rows where a Qwen model was used for prompt pre-processing [1]. That upstream dataset's synthetic completions come from a mix of models including DeepSeek-R1 and several Qwen-2.5 variants, and its card warns that a distributed model trained on it may inherit Llama 3.1/3.3 Community License Agreement obligations [4].

## Appendix: screening record

### Screening verdict

Usable for reasoning-trace SFT, with a decontamination step owed before any scored run against AIME-family or the other listed benchmarks. Two facts decide it, both established above: the dataset itself has no held-out split and no stated decontamination for its math and code domains, while a sibling codeforces-cots subset in the same family is explicitly decontaminated against exactly the benchmarks a reader would score against [3] - the pattern the screening row's flag names.
