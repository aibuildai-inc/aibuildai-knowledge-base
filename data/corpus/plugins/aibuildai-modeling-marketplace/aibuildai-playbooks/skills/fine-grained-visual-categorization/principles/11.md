## Principle 11: Combine k-NN and Logit Predictions for Metric Learning to Balance Precision and Recall

*Consensus: 1st place Happy Whale mixed k-NN and logits with ratio 0.5 (no pseudo-labels) to 0.8 (after pseudo-labels); 3rd place used similar mixing.*

ArcFace models produce both: (1) embeddings for k-NN retrieval (similarity-based), (2) logits from the classifier head (softmax-based). k-NN is better for rare classes (fewer false positives), but logits are better for frequent classes (more training data). Mix them with a tunable ratio.

**Why this matters:** k-NN relies on distance in embedding space and is robust to class imbalance (finds the nearest neighbor regardless of class size). But logits leverage the classifier's learned class priors (frequent classes get higher scores). In long-tail distributions, k-NN over-predicts rare classes (because it ignores priors), and logits over-predict frequent classes. Mixing balances this.

**When to use:** Use when: (1) you are using ArcFace/CosFace with both a metric learning head and a classifier head, (2) your dataset is long-tailed (k-NN alone degrades on frequent classes), (3) you have a validation set to tune the mixing ratio (try 0.3 to 0.8 for k-NN weight).

**When NOT to use:** Skip if you are using pure k-NN without a classifier (no logits to mix). Skip if your dataset is balanced (k-NN and logits agree, so mixing adds complexity without benefit). Do not mix if you have only one of the two (pure classification or pure metric learning).

**How to reason about it:**
At inference, compute both: (1) k-NN similarity scores (cosine similarity to training embeddings, aggregated by class), (2) classifier logits (from the ArcFace head, without margins). Normalize both to [0, 1]. Compute weighted average: final_score = alpha * knn_score + (1 - alpha) * logit_score. Tune alpha on validation: start with 0.5, grid search [0.3, 0.5, 0.7, 0.9]. After pseudo-labeling, increase alpha (k-NN benefits more from added test samples).

```python
# At training: ArcFace with both metric learning and classification
class ArcFaceModel(nn.Module):
    def __init__(self, backbone, n_classes, embedding_dim=512):
        super().__init__()
        self.backbone = backbone
        self.gem_pool = GeM(p=3)
        self.bn_neck = nn.BatchNorm1d(embedding_dim)  # for metric learning
        self.arcface = ArcFaceHead(embedding_dim, n_classes, s=30, m=0.3)
    
    def forward(self, x, labels=None):
        features = self.backbone(x)
        embeddings = self.gem_pool(features).flatten(1)  # for k-NN
        normalized_embeddings = self.bn_neck(embeddings)  # for classification
        if labels is not None:
            logits = self.arcface(normalized_embeddings, labels)
            return logits, embeddings
        else:
            return embeddings

# At inference: mix k-NN and logits
def predict_mixed(model, test_image, train_embeddings, train_labels, alpha=0.5):
    # Get test embedding
    test_emb = model(test_image)  # (embedding_dim,)
    
    # k-NN scores
    similarities = F.cosine_similarity(test_emb.unsqueeze(0), train_embeddings)  # (n_train,)
    knn_scores = torch.zeros(n_classes)
    for cls in range(n_classes):
        cls_mask = train_labels == cls
        if cls_mask.any():
            knn_scores[cls] = similarities[cls_mask].max()  # max similarity for this class
    knn_scores = (knn_scores - knn_scores.min()) / (knn_scores.max() - knn_scores.min())  # normalize to [0,1]
    
    # Logit scores (classifier head without margins)
    logits = model.arcface.forward_without_margin(test_emb)  # implement this to get raw logits
    logit_scores = torch.softmax(logits, dim=0)
    
    # Mix
    final_scores = alpha * knn_scores + (1 - alpha) * logit_scores
    return final_scores.topk(5)  # top-5 predictions
```
