## Principle 5: Leverage Domain-Specific External Data and Pretraining Over Generic ImageNet

*Consensus: Mixed evidence - iWildCam 2021 (3rd) added iNaturalist images for shared classes and Flower Classification (1st) added external flower datasets, but Flower (1st) found iNaturalist and OpenImages data lowered accuracy; validate each external source*

ImageNet pretraining teaches generic object features (edges, textures, parts), but fine-grained tasks benefit more from models pretrained on related domains. Use publicly available domain-specific models (such as iNaturalist for species) or self-supervised pretraining on unlabeled data from the same domain.

**Why this matters:** Fine-grained distinctions rely on domain-specific features: petal shapes, whale skin markings, fabric textures. A model pretrained on the same domain has already learned these feature types, reducing the effective learning task from 'learn features + learn classes' to 'learn classes'.

**When to use:** Use when: (1) a domain-specific pretrained model exists (check TensorFlow Hub, Hugging Face, competition forums), (2) you have access to large unlabeled data from the same domain (use self-supervised learning like SimCLR), (3) your domain is far from ImageNet (medical, satellite, microscopy).

**When NOT to use:** Do not skip ImageNet pretraining entirely unless you have >100k domain samples. Do not use domain models trained on different resolutions or input formats without checking compatibility. Some domain models (NoisyStudent on ImageNet) are still generic; prioritize true domain match.

**How to reason about it:**
Search for '[domain] pretrained model' (e.g., 'plant classification pretrained', 'wildlife pretrained'). Check TensorFlow Hub, Hugging Face, and past Kaggle competitions in the same domain. If found, benchmark it against ImageNet: train two models (one from each init) for 10 epochs and compare validation. If no domain model exists but you have unlabeled domain data, run SimCLR or MoCo for self-supervised pretraining. The effort threshold: if you have >10k unlabeled images, self-supervised pretraining (1-2 weeks) is worth it.
