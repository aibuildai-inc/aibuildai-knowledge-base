## Principle 10: Apply Multi-Scale Test-Time Augmentation with Horizontal Flipping and Multi-Crop

*Consensus: 9 of the 44 writeups mention TTA; typical setup is a horizontal flip plus a few crops or slight rotations.*

At inference, predict on multiple augmented versions of each test image (original, horizontally flipped, multi-crop) and average the predictions. This smooths out noise and improves robustness to minor variations.

**Why this matters:** Fine-grained features may appear in different parts of the image or be sensitive to orientation. Horizontal flip doubles the effective test set and is nearly free (2x inference time). Multi-crop (5-10 overlapping crops) captures features at different positions and scales.

**When to use:** Always use horizontal flip TTA (cheap, and it usually helps). Add multi-crop (4-10 crops) if: (1) discriminative features are localized and may be cropped out by a single center crop, (2) you have spare inference time (10x TTA = 10x slower). Add slight rotations (±5-10 degrees) for datasets with random orientation.

**When NOT to use:** Skip rotations if your domain has a canonical orientation (plants always upright, text always horizontal). Skip multi-crop if your images are already tightly cropped to the subject. Do not TTA with heavy augmentations (strong color jitter, cutout) that were not in training (train-test mismatch).

**How to reason about it:**
Start with horizontal flip TTA (original + flipped = 2x). If you have time, add 5-crop TTA (center crop + 4 corner crops). If images are high-resolution (>768), add 10-crop (overlapping patches). Average predictions across all augmentations. For metric learning, average the embeddings before k-NN retrieval (not the k-NN results).

```python
def predict_with_tta(model, image, n_crops=5):
    preds = []
    
    # Original + horizontal flip
    preds.append(model(image))
    preds.append(model(torch.flip(image, dims=[-1])))  # horizontal flip
    
    # Multi-crop TTA (5-crop: center + 4 corners)
    if n_crops >= 5:
        h, w = image.shape[-2:]
        crop_size = int(0.9 * min(h, w))  # 90% crop
        crops = [
            image[..., :crop_size, :crop_size],  # top-left
            image[..., :crop_size, -crop_size:],  # top-right
            image[..., -crop_size:, :crop_size],  # bottom-left
            image[..., -crop_size:, -crop_size:],  # bottom-right
            center_crop(image, crop_size)  # center
        ]
        for crop in crops:
            crop_resized = F.interpolate(crop, size=image.shape[-2:])
            preds.append(model(crop_resized))
    
    # Average predictions
    return torch.stack(preds).mean(dim=0)
```
