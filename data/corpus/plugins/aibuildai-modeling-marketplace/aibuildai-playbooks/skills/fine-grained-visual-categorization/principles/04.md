## Principle 4: Handle Long-Tail Distribution with Staged Training: Frequent Classes First, Then All Classes

*Consensus: 1st place Humpback trained first on classes with more than 10 samples, then on all samples with most of the network frozen.*

Datasets with thousands of classes where many classes have only a few samples converge slowly or poorly when trained jointly from scratch. Train on the frequent classes first (1st place Humpback: classes with more than 10 samples) until validation plateaus, then add the rare classes, optionally initializing their classifier weights via weight imprinting (copy the average embedding of their samples), and fine-tune.

**Why this matters:** Rare classes have insufficient gradient signal to learn discriminative features when competing with thousands of other classes. Training frequent classes first teaches the backbone generalizable features (shape, texture, markings). Weight imprinting gives rare-class classifiers a warm start in the right embedding region instead of random initialization.

**When to use:** Use when: (1) you have thousands of classes, (2) the class frequency ratio is >100:1, (3) you are using a linear classifier (not pure metric learning). Typical split: classes above a sample-count cutoff in stage 1, all classes in stage 2.

**When NOT to use:** Skip for balanced datasets or <1000 classes (train end-to-end). Skip if you are using pure metric learning with k-NN (no classifier to imprint). Skip if your rare classes have >20 samples each (joint training works).

**How to reason about it:**
Count classes by frequency. If >50% of classes have <10 samples and the top 10% of classes hold >70% of the data, you need staged training. Stage 1: train only on classes with >N samples (1st place Humpback used N=10) until validation plateaus. Stage 2: optionally imprint rare-class weights, then train on all samples with most of the backbone frozen (1st place Humpback fixed all but the last two layers). Stage 3 (optional): unfreeze all, train end-to-end with balanced sampling or class-weighted loss.

```python
# Stage 1: train on frequent classes only
frequent_classes = [c for c, count in class_counts.items() if count > 10]
train_subset = train_data[train_data['label'].isin(frequent_classes)]
model.train_on_subset(train_subset, epochs=stage1_epochs)  # until validation plateaus

# Stage 2 (optional): weight imprinting for rare classes
backbone.eval()
for rare_class in rare_classes:
    samples = train_data[train_data['label'] == rare_class]
    embeddings = [backbone(img) for img in samples]
    # Initialize classifier weight as mean embedding
    classifier.weight[rare_class] = torch.stack(embeddings).mean(dim=0)

# Train on all samples with most of the backbone frozen
for param in backbone.parameters():
    param.requires_grad = False
for param in backbone.last_blocks.parameters():  # e.g. the last two layers
    param.requires_grad = True
train(model, epochs=stage2_epochs)

# Stage 3 (optional): unfreeze and train end-to-end
for param in backbone.parameters():
    param.requires_grad = True
train(model, epochs=stage3_epochs, sampler='balanced')  # sample equally from all classes
```
