## Principle 2: Apply Sub-Center ArcFace with Dynamic Margins for Long-Tailed Individual ID

*Consensus: 1st place Happy Whale used sub-center ArcFace with class-frequency-based dynamic margins; 4th, 6th, 10th, and 36th place Happy Whale also used dynamic margins.*

Standard ArcFace treats all classes equally, but fine-grained datasets have extreme imbalance (some individuals have 100+ images, others have 3). Sub-center ArcFace (k=2 or more centers per class) handles intra-class variation, and dynamic margins (larger margins for frequent classes) prevent the model from overfitting to head classes.

**Why this matters:** Frequent classes dominate the gradient and push rare-class embeddings into narrow regions. Dynamic margins force the model to learn tighter boundaries for common classes, leaving more embedding space for rare ones. Sub-centers model intra-class modes (e.g., different viewing angles of the same whale).

**When to use:** Use when: (1) class frequency spans 2+ orders of magnitude, (2) you are using ArcFace/CosFace for metric learning, (3) some classes have multiple distinct visual modes. Tune the margin schedule (linear, sqrt, log of class frequency) on validation.

**When NOT to use:** Skip for balanced datasets (standard ArcFace works). Skip when you have <10 samples per class across the board (no head to regularize). Do not add sub-centers if your intra-class variance is low (each class has one consistent appearance).

**How to reason about it:**
Plot class frequency distribution. If the ratio between the most and least frequent class is >10, dynamic margins help. If within-class you see distinct clusters (frontal vs side views, day vs night images), add sub-centers. Start with margins proportional to sqrt(class_count), tune with Optuna or grid search.
