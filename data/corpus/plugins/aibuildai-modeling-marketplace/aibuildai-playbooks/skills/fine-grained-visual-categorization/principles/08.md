## Principle 8: Use GeM Pooling Instead of Global Average Pooling to Emphasize Salient Features

*Consensus: 1st place Happy Whale, 3rd place Happy Whale use GeM pooling with p=3.*

Global Average Pooling (GAP) treats all spatial locations equally, but fine-grained distinctions often rely on small salient regions (a unique marking, a texture patch). Generalized Mean (GeM) pooling with p>1 upweights locations with higher activations, focusing on discriminative features.

**Why this matters:** Fine-grained features are localized: a whale's unique fluke pattern, a notch in a dorsal fin, a small pattern on a garment. GAP dilutes these by averaging with irrelevant background activations. GeM with p=3 gives high-activation regions 3x more weight, amplifying discriminative signals.

**When to use:** Use for tasks where: (1) the discriminative feature is localized (markings, textures, small objects), (2) you are using a CNN backbone with spatial feature maps, (3) you are doing metric learning or retrieval (GeM is standard in image retrieval). Typical p values: 3-4. Some solutions make p learnable.

**When NOT to use:** Skip for whole-image classification where all regions matter equally (scene classification). Skip for Transformer backbones (ViT, Swin) which already use attention-based pooling (the [CLS] token or global attention aggregates discriminatively). Skip if your images are already tightly cropped to the subject (a product photo where the item fills the frame).

**How to reason about it:**
If your images have background or the subject is <50% of the image area, use GeM. Replace `nn.AdaptiveAvgPool2d` with GeM pooling. Start with p=3 (from Happy Whale 1st place). Optionally, make p a learnable parameter initialized at 3. Monitor validation: if p drifts toward 1, GeM is not helping (revert to GAP). If p stays at 3-4, keep it.

```python
import torch.nn as nn
import torch.nn.functional as F

class GeM(nn.Module):
    def __init__(self, p=3, eps=1e-6):
        super().__init__()
        self.p = nn.Parameter(torch.ones(1) * p)  # learnable p
        self.eps = eps
    
    def forward(self, x):
        # x: (batch, channels, height, width)
        # GeM: (mean(x^p))^(1/p)
        return F.avg_pool2d(x.clamp(min=self.eps).pow(self.p), 
                            (x.size(-2), x.size(-1))).pow(1. / self.p)
```
