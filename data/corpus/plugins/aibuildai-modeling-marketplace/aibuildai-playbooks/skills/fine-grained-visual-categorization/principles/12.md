## Principle 12: Set Learning Rate for Classification Head 5-10x Higher Than Backbone

*Consensus: 1st place Happy Whale set the ArcFace head learning rate 10x the backbone learning rate and reported a significant gain.*

When fine-tuning a pretrained backbone, the backbone weights are already near-optimal for feature extraction, but the classification/metric-learning head is randomly initialized. Use a higher learning rate for the head to enable it to adapt quickly without disrupting backbone features.

**Why this matters:** A single global learning rate forces a compromise: high LR for the head (fast convergence) but risks breaking pretrained backbone features, or low LR for the backbone (stable) but the head converges too slowly. Separate LRs let both components learn at their optimal rate.

**When to use:** Always use when fine-tuning a pretrained model (ImageNet, domain-specific, self-supervised). Typical ratio: 5-10x. If backbone LR is 1e-4, head LR is 5e-4 to 1e-3. Tune on validation if unsure (try 5x, 10x, 20x).

**When NOT to use:** Skip if training from scratch (both backbone and head are random; use the same LR). Skip if using a very small backbone LR (<1e-5; the head LR may become numerically unstable at 10x).

**How to reason about it:**
Split your model parameters into two groups: backbone and head. Assign different learning rates to each group in the optimizer. Start with head_lr = 10 * backbone_lr (from Happy Whale 1st place). Monitor training: if the head converges in <5 epochs but validation accuracy is still rising, increase the head LR further. If training diverges, reduce the head LR.

```python
# Separate learning rates for backbone and head
backbone_params = model.backbone.parameters()
head_params = list(model.arcface.parameters()) + list(model.bn_neck.parameters())

backbone_lr = 1e-4
head_lr = 10 * backbone_lr  # 10x higher

optimizer = torch.optim.AdamW([
    {'params': backbone_params, 'lr': backbone_lr},
    {'params': head_params, 'lr': head_lr}
])

# Alternative: use different weight decay for head (common in metric learning)
optimizer = torch.optim.AdamW([
    {'params': backbone_params, 'lr': 1e-4, 'weight_decay': 1e-4},
    {'params': head_params, 'lr': 1e-3, 'weight_decay': 0}  # no weight decay for head
])

scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=50)
```
