## Principle 6: Apply Pseudo-Labeling Iteratively with Confidence Filtering for Test Set Leverage

*Consensus: 1st-3rd place Happy Whale, 1st place Humpback, 2nd place Happy Whale all use 2-5 rounds of pseudo-labeling with thresholds 0.4-0.8.*

Fine-grained tasks often have test sets significantly larger than training (Happy Whale: 15k train, 27k test). High-confidence test predictions can be added to training as pseudo-labels, retrained, and iterated. Each round improves the model, enabling lower thresholds in subsequent rounds.

**Why this matters:** Test images provide free supervision when the model is confident. In long-tailed distributions, pseudo-labeling disproportionately helps rare classes (which had few training samples) by adding confident test examples. Iterative refinement: round 1 adds only very confident predictions; round 2 uses the improved model to add medium-confidence predictions.

**When to use:** Use when: (1) test set is large (>50% of training size), (2) you can submit multiple times to validate pseudo-labels (public LB feedback), (3) initial model achieves >80% accuracy (low-confidence pseudo-labels are noise). Iterate 2-5 rounds; stop when gains plateau.

**When NOT to use:** Skip if test set is small or you have only 1-2 submissions (cannot validate threshold choice). Do not use pseudo-labels for k-NN retrieval index (1st place Happy Whale found this harmful; pseudo-labels improve the model, not the reference set). Do not add pseudo-labels with confidence <0.4 in early rounds (noise dominates).

**How to reason about it:**
After training your initial model, predict on the test set with softmax probabilities (for classification) or k-NN similarity scores (for metric learning). Set a high threshold (0.7-0.9) for round 1: only predictions with max_prob > threshold are added as pseudo-labels. Retrain from ImageNet or the previous checkpoint, validate on a held-out set. If validation improves, submit; if public LB improves, iterate. Round 2: lower threshold to 0.5-0.7. Round 3: 0.4-0.5. Stop when the LB score drops or plateaus. Remove pseudo-labels that conflict with the validation set (high similarity to a validation image but different pseudo-label).

```python
# Round 1: high-confidence pseudo-labeling
initial_model.eval()
test_preds = initial_model.predict(test_loader)  # shape: (N, n_classes)
max_probs, pseudo_labels = test_preds.max(dim=1)

# Filter by confidence threshold
```
