## Principle 9: Apply Graph-Based Post-Processing to Enforce Consistency

*Consensus: 3rd Shopee (clustering), 2nd Shopee (betweenness), 14th Shopee (clique), Quora transitivity*

Model matches as a graph (nodes=items, edges=predicted matches). Apply constraints: remove edges with high betweenness centrality (likely bridging wrong clusters), or cluster via agglomerative methods until average cluster size matches target.

**Why this matters:** Predicted matches often violate transitivity or create implausible clusters. Graph algorithms exploit global structure: if A-B and B-C are matches but A-C is weak, likely one edge is wrong. Removing such edges improves precision. Typical gain: +0.001-0.002.

**When to use:** When the task is grouping items into clusters (product matching, duplicate detection) and the metric rewards precision. When initial predictions have many false-positive edges connecting wrong clusters.

**When NOT to use:** When the metric is ranking (not clustering), graph structure is irrelevant. If clusters are naturally noisy (not cliques), enforcing transitivity may hurt. Skip if post-processing on CV shows no gain or reduces recall too much.

**How to reason about it:**
Build graph: nodes = items, edges = predicted matches with weight = similarity/probability. IF task = clustering: run agglomerative clustering on distances (1 - similarity) until avg cluster size ≈ expected. IF task = pruning: iteratively remove edge with highest betweenness centrality (bridges two clusters) until no edge connects components smaller than threshold. Validate on CV.

```python
import networkx as nx
from sklearn.cluster import AgglomerativeClustering

# Betweenness pruning
G = nx.Graph()
for i, j, sim in predicted_edges:
    G.add_edge(i, j, weight=sim)

while avg_cluster_size(G) > target_size:
    betweenness = nx.edge_betweenness_centrality(G)
    edge_to_remove = max(betweenness, key=betweenness.get)
    G.remove_edge(*edge_to_remove)
```
