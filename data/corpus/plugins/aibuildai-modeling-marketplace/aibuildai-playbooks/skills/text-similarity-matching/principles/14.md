## Principle 14: Optimize for the Actual Metric, Not Proxy Losses

*Consensus: Shopee solutions tuned match thresholds directly on F1; Quora solutions rescaled predictions or resampled training data to the lower duplicate rate of the test set for log loss*

When possible, use a loss function aligned with the evaluation metric (log loss under the test class balance, F1-optimized thresholds for F1 metric). For non-differentiable metrics, optimize end-to-end then tune post-processing to the metric.

**Why this matters:** Training with one objective and evaluating on another creates a mismatch: the model optimizes the wrong objective. Under log loss, a model calibrated to the training positive rate is penalized when the test positive rate is different, so rescaling probabilities to the test rate improves the score directly. For F1, threshold tuning on the real metric closes the gap.

**When to use:** When the metric is differentiable (log loss, MSE) or can be approximated (soft F1). When the metric is non-standard (custom ranking), train a proxy (ranking loss, pairwise BCE) then heavily tune post-processing.

**When NOT to use:** When the metric is standard classification (logloss, AUC), train and test class balance match, and cross-entropy is fine. If custom loss functions destabilize training, fall back to BCE/MSE and tune thresholds.

**How to reason about it:**
IF metric = log loss and the test positive rate differs from train: rescale predicted probabilities to the test rate, and apply the same rescaling to out-of-fold predictions before stacking. IF metric = MSE/MAE: use MSE/MAE loss. IF metric = F1: train with BCE, tune threshold to maximize F1 on validation. IF metric = ranking: use pairwise ranking loss or listwise (if feasible), then tune post-processing on the ranking metric.

```python
import numpy as np

# Prior shift correction for log loss (train and test positive rates differ)
def rescale_to_prior(p, train_rate, test_rate):
    a = test_rate / train_rate
    b = (1 - test_rate) / (1 - train_rate)
    return a * p / (a * p + b * (1 - p))

# F1-optimized threshold tuning (post-training)
from sklearn.metrics import f1_score

def find_best_threshold(y_true, y_pred_proba):
    best_f1 = 0
    best_thresh = 0.5
    for thresh in np.arange(0.1, 0.9, 0.01):
        y_pred = (y_pred_proba > thresh).astype(int)
        f1 = f1_score(y_true, y_pred, average='micro')
        if f1 > best_f1:
            best_f1 = f1
            best_thresh = thresh
    return best_thresh
```
