## Principle 11: Handle Language/Domain Diversity with Specialized Components

*Consensus: Shopee Indonesian language specialization was a recurring pattern in the source writeups.*

When data spans multiple languages or domains, either (a) use multilingual pretrained models, (b) train separate models per language/domain and route at inference, or (c) add domain identifier as explicit context.

**Why this matters:** Language-specific models (e.g., Indonesian BERT for Shopee) outperform multilingual on in-language data but fail on others. Multilingual models close the gap across languages but underperform specialists. Routing or ensembling both captures best of both worlds.

**When to use:** When data contains multiple languages (multilingual product titles, titles that mix two languages). When domain context (such as product category) strongly affects similarity.

**When NOT to use:** When one language dominates >95% of data, specialize on that language. If domain/language detection is unreliable, routing may introduce more errors than it fixes.

**How to reason about it:**
DETECT language/domain (explicit field or fasttext classifier). IF one language dominates training: train specialist on it + multilingual fallback for others. IF languages are balanced: ensemble specialist models per language, weighted by detection confidence. ALWAYS include domain context (e.g., product category) in input text if available—models learn domain-specific similarity.

```python
# Domain/language-aware input formatting
def build_input(row):
    domain_text = category_to_text(row['category'])  # Map category code to description
    return f"{row['title']} [SEP] {domain_text}"

# Ensemble specialists with multilingual fallback
import fasttext
lang_detector = fasttext.load_model('lid.176.bin')

def predict(text, models):
    lang = lang_detector.predict(text)[0][0].replace('__label__', '')
    if lang in models['specialist']:
        return models['specialist'][lang].predict(text)
    else:
        return models['multilingual'].predict(text)
```
