## Principle 3: Use Metric Learning (ArcFace/Triplet) for Embedding Quality

*Consensus: 18/21 Shopee solutions, appearing in other multimodal tasks*

Train encoders with ArcFace or triplet loss to learn embeddings optimized for cosine similarity matching, rather than classification softmax.

**Why this matters:** Standard classification heads optimize for separating classes, not for measuring similarity. Metric learning forces embeddings of the same entity to cluster tightly and different entities to separate, directly optimizing what you'll measure at inference (cosine distance).

**When to use:** When the task is retrieval or matching based on embedding similarity. Essential for multimodal tasks (image+text), product matching, duplicate detection. Use when you'll perform kNN search or threshold-based matching at inference.

**When NOT to use:** When predicting a continuous similarity score end-to-end (a direct regression head may be simpler). If the dataset is small (<10k samples), triplet mining may be unstable.

**How to reason about it:**
IF task = find duplicates/matches → use metric learning. IF task = score similarity 0-1 → try both metric learning + ranking and direct regression, compare CV. For ArcFace: tune margin (0.5-1.0 for images, 0.3-0.8 for text), use gradient clipping and warmup to stabilize training. Start margin low (0.2) and increase gradually if convergence is unstable.

```python
import torch.nn as nn
import torch.nn.functional as F

class ArcFaceHead(nn.Module):
    def __init__(self, in_features, num_classes, s=30, m=0.5):
        super().__init__()
        self.s = s  # scale
        self.m = m  # margin
        self.weight = nn.Parameter(torch.randn(num_classes, in_features))
        
    def forward(self, embeddings, labels):
        # Normalize embeddings and weights
        embeddings = F.normalize(embeddings)
        weights = F.normalize(self.weight)
        cosine = F.linear(embeddings, weights)
        # Add arc margin to target class
        theta = torch.acos(torch.clamp(cosine, -1+1e-7, 1-1e-7))
        target_logits = torch.cos(theta + self.m)
        one_hot = F.one_hot(labels, num_classes)
        output = (one_hot * target_logits + (1 - one_hot) * cosine) * self.s
        return output
```
