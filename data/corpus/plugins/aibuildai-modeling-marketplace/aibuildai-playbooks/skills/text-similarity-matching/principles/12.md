## Principle 12: Leverage Domain-Specific Features as Ensemble Signals

*Consensus: Shopee (perceptual hash, image size), Avito (location, price), Quora (qid overlap)*

Extract task-specific features beyond embeddings: perceptual hash for images, Levenshtein distance for text, price/location for ads, qid frequency for questions. Use as stage-2 classifier features.

**Why this matters:** Domain features capture signals embeddings miss: duplicate images often have identical perceptual hashes even if pixel-perfect different; price differences flag non-duplicates; rare qids suggest test-specific anomalies. These add precision to recall-focused embeddings.

**When to use:** When structured metadata exists (price, location, image dimensions, timestamps). In stage-2 classifiers where you can afford feature engineering. When domain knowledge suggests specific signals (e.g., identical image hash → almost certainly duplicate).

**When NOT to use:** For stage-1 retrieval where speed matters—compute only for candidate pairs. If features are mostly missing or noisy, they add little. Skip if stage-2 model trained without them performs equally well.

**How to reason about it:**
IDENTIFY domain-specific signals: perceptual hash, Levenshtein/edit distance, metadata overlap (category, brand), graph properties (qid frequency, PageRank). COMPUTE for candidate pairs in stage-2. ADD to classifier alongside embedding distances. INSPECT feature importance—if domain features rank high, they're pulling their weight.

```python
import imagehash
from PIL import Image
from Levenshtein import distance

# Perceptual hash for images
def phash_similarity(img1_path, img2_path):
    hash1 = imagehash.phash(Image.open(img1_path))
    hash2 = imagehash.phash(Image.open(img2_path))
    return 1 - (hash1 - hash2) / 64.0  # normalize to [0,1]

# Text edit distance
def text_similarity(text1, text2):
    lev_dist = distance(text1, text2)
    max_len = max(len(text1), len(text2))
    return 1 - lev_dist / max_len if max_len > 0 else 1.0
```
