## Principle 4: Employ Two-Stage Pipeline: Retrieval Then Classification

*Consensus: 12/21 Shopee solutions, 3rd place Shopee, multiple Quora solutions*

Stage 1: Use embeddings + kNN to retrieve candidate pairs. Stage 2: Train a classifier (LightGBM, XGBoost, or GNN) on pairwise features (distance, rank, graph properties) to refine predictions.

**Why this matters:** Embeddings alone miss fine-grained signal. A second-stage model can learn when to trust image vs text similarity, calibrate thresholds per product type, and exploit graph structure (e.g., transitivity: if A matches B and B matches C, A likely matches C).

**When to use:** When you have multimodal data or multiple embedding sources. When the metric is F1/precision-recall (not ranking), allowing threshold tuning. When graph features (PageRank, betweenness) or pairwise statistics (rank, density) add predictive power.

**When NOT to use:** When inference time is tight and you can't afford pairwise feature computation. If a single well-tuned embedding + threshold already achieves competitive scores, the complexity may not pay off. Skip if stage-2 CV shows no gain over stage-1.

**How to reason about it:**
RETRIEVE candidates with high recall (low threshold) from embeddings. EXTRACT features: cosine distances (image, text, combined), rank of match, neighborhood density, graph metrics. TRAIN classifier on sampled pairs (downsample negatives to ~5-10% positive rate). THRESHOLD classifier output by CV-optimized F1.

```python
# Stage 1: Retrieve candidates via kNN
import faiss
index = faiss.IndexFlatIP(embedding_dim)  # cosine similarity
index.add(embeddings)
distances, indices = index.search(embeddings, k=50)

# Stage 2: Build pairwise features
features = []
for i in range(len(embeddings)):
    for j, dist in zip(indices[i], distances[i]):
        features.append({
            'img_dist': img_distances[i, j],
            'text_dist': text_distances[i, j],
            'rank': np.where(indices[i] == j)[0][0],
            'pagerank_i': pagerank[i],
            'pagerank_j': pagerank[j],
            'label': int(labels[i] == labels[j])
        })

# Train LightGBM classifier
import lightgbm as lgb
clf = lgb.LGBMClassifier()
clf.fit(X_train, y_train, sample_weight=1/group_size**0.4)  # downweight large groups
```
