## Principle 5: Fuse Multimodal Signals at Multiple Levels

*Consensus: 15/21 Shopee solutions*

For image+text tasks, combine modalities in three ways: (1) separate image matches, (2) separate text matches, (3) concatenated embedding matches. Union all three match sets.

**Why this matters:** Different modalities capture different aspects: images detect visual duplicates even with different text, text catches semantic matches with different photos. Concatenating embeddings finds items where BOTH agree moderately. Unioning all three maximizes recall: accept if ANY signal is strong.

**When to use:** Any multimodal matching task (product matching, ad deduplication with images+text). When modalities are complementary—neither alone achieves high recall.

**When NOT to use:** When one modality dominates (e.g., text-only questions, image-only retrieval). If union hurts precision and you're optimized for precision > recall, consider intersection or weighted voting instead.

**How to reason about it:**
Generate three similarity matrices: S_img, S_text, S_concat (where S_concat uses normalized concatenation of img and text embeddings). Apply threshold to each: M_img = S_img > t_img, M_text = S_text > t_text, M_concat = S_concat > t_concat. Union: M_final = M_img ∪ M_text ∪ M_concat. Tune thresholds jointly by CV or LB. Interpret: union accepts items that image strongly suggests OR text strongly suggests OR both moderately suggest.

```python
# Normalize and concatenate embeddings
img_emb_norm = F.normalize(img_embeddings, dim=1)
text_emb_norm = F.normalize(text_embeddings, dim=1)
comb_emb = F.normalize(torch.cat([img_emb_norm, text_emb_norm], dim=1), dim=1)

# Compute three similarity matrices
S_img = img_emb_norm @ img_emb_norm.T
S_text = text_emb_norm @ text_emb_norm.T
S_comb = comb_emb @ comb_emb.T

# Threshold and union
matches_img = (S_img > threshold_img)
matches_text = (S_text > threshold_text)
matches_comb = (S_comb > threshold_comb)
matches_final = matches_img | matches_text | matches_comb
```
