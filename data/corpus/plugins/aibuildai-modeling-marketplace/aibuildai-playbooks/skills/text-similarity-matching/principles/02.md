## Principle 2: Use the Other Items Tied to the Same Anchor as Features

*Consensus: Quora solutions built features from the other questions each question was paired with (common neighbors, node degree, component size)*

When many rows share an anchor (the same question, product group, or device), give the model what is known about the other items tied to that anchor, summarized as features: how many items each side is linked to, and how many they share.

**Why this matters:** Items that share an anchor are correlated, and a pair model that reads one row at a time cannot see that. In Quora Question Pairs, top solutions built a graph with questions as nodes and pairs as edges, then used node degree, common neighbors, and connected component size as features; one writeup reports that its graph features gave a significant gain.

**When to use:** When the data has a clear anchor-target structure with multiple targets per anchor (question pairs, product variants, device-cookie links). Strongest when targets under the same anchor exhibit semantic clustering.

**When NOT to use:** When targets are independent, or when test rows share no anchor with any other row. If anchor-target pairs are 1:1, this doesn't apply. Skip if CV experiments show no gain.

**How to reason about it:**
Group rows by anchor and collect the related items. Exclude the current item from its own list. Compute counts and overlaps: how many items each side is linked to, how many linked items the two sides share, and how large the connected group is. Build the graph from train and test pairs together when test pairs are available, as the Quora 1st place solution did.

```python
# Related items as graph features for a tree model
from collections import defaultdict
pairs = pd.concat([train[['q1', 'q2']], test[['q1', 'q2']]])
neighbors = defaultdict(set)
for a, b in zip(pairs['q1'], pairs['q2']):
    neighbors[a].add(b)
    neighbors[b].add(a)

df['q1_degree'] = df['q1'].map(lambda q: len(neighbors[q]))
df['q2_degree'] = df['q2'].map(lambda q: len(neighbors[q]))
df['common_neighbors'] = [len(neighbors[a] & neighbors[b]) for a, b in zip(df['q1'], df['q2'])]
```
