## Principle 6: Refine Embeddings with Iterative Neighborhood Blending

*Consensus: 1st Shopee, 7th/8th Shopee adopted Query Expansion / DBA variants*

After initial kNN search, iteratively blend each item's embedding with a weighted sum of its neighbors' embeddings, then re-run kNN. Repeat 2-3 times.

**Why this matters:** Initial embeddings may place true matches just outside the threshold. Blending with neighbors (which are likely the same cluster) pulls embeddings toward cluster centroids, tightening clusters and making borderline matches clearer. Typical gain: 0.75 → 0.79.

**When to use:** After you have decent embeddings from metric learning. When kNN retrieval is the main matching mechanism. Particularly effective on product/image matching where visual clusters are tight.

**When NOT to use:** If your embeddings are already very clean (high initial precision/recall), the gain may be marginal. Skip if inference time is critical and you can't afford multiple kNN passes. Not applicable to pairwise scoring tasks that output a continuous similarity score rather than a cluster.

**How to reason about it:**
Run kNN with a lenient threshold to get initial neighborhoods. For each item, compute new_emb = normalize(Σ similarity_i * neighbor_emb_i). Normalize the blended embedding. Re-run kNN on blended embeddings with a tighter threshold. Repeat 1-2 more times. Tune thresholds at each stage jointly (but stages 2-3 thresholds matter most).

```python
def blend_neighborhood(embeddings, match_indices, similarities):
    new_emb = embeddings.copy()
    for i in range(len(embeddings)):
        neighbor_embs = embeddings[match_indices[i]]
        weights = similarities[i].reshape(-1, 1)
        new_emb[i] = (neighbor_embs * weights).sum(axis=0)
    return normalize(new_emb, axis=1)

def iterative_neighborhood_blending(emb, thresholds):
    for thresh in thresholds:
        match_idx, sims = knn_search_threshold(emb, thresh)
        emb = blend_neighborhood(emb, match_idx, sims)
    return emb

# Example: 3-stage INB
thresholds = [0.0, 0.3, 0.35]  # stage1 uses min-2 rule, stages 2-3 tuned

```
