## Principle 10: Ensemble with Model Diversity, Not Just Architecture Variety

*Consensus: Recurring among solutions discussing ensembling (Quora, Shopee).*

Diversify ensembles by varying loss functions (ArcFace vs triplet vs regression), input processing (with/without related-item features), augmentation strategies, and CV strategies—not just model architectures.

**Why this matters:** Two models of the same architecture trained with different losses (for example BCE vs contrastive loss) learn different error patterns and ensemble better than two architectures trained the same way. Diversity in HOW you train matters more than WHAT architecture you use.

**When to use:** When building final ensembles for competition submissions. When a single model class (e.g., one text encoder family) is clearly best and you want to ensemble multiple variants of it.

**When NOT to use:** Early experimentation when you're still finding the best single model—focus on that first. If you already have 10+ diverse models and adding more shows no gain, you've saturated ensemble capacity.

**How to reason about it:**
DIVERSIFY across: (1) Loss function (BCE, MSE, contrastive, ArcFace). (2) Input format (with/without related-item features, different text preprocessing). (3) Training strategy (different LR, different data sampling). (4) CV splits (GroupKFold vs StratifiedGroupKFold, different seeds). WEIGHT models by validation performance or learn weights via linear regression on OOF predictions.

```python
# Train diverse models
models = [
    train_model(loss='mse', input_format='with_related', cv='groupkfold'),
    train_model(loss='contrastive', input_format='with_related', cv='stratified_groupkfold'),
    train_model(loss='bce', input_format='baseline', cv='groupkfold', augment=True),
    train_model(loss='mse', input_format='cleaned_text', cv='groupkfold'),
]

# Learn ensemble weights via linear regression on OOF
from sklearn.linear_model import Ridge
oof_preds = np.column_stack([m.predict_oof() for m in models])
ridge = Ridge(alpha=1.0)
ridge.fit(oof_preds, y_train)
weights = ridge.coef_

# Ensemble test predictions
test_preds = np.column_stack([m.predict(test) for m in models])
```
