### Overview





### Models

#### Train/validation split

GroupKfold(5 folds) with stratification by distribution of number of samples in label_group



#### Image model

Backbone : NFNet-F0 with GeM pooling (p=3(fixed) for training, p=4 for inference)
Input size : 420x420
Epochs : 30
Optimizer : madgrad(momentum=0.9, weight_decay=1e-5) [1]
Learning rate scheduler : cosine annealing (1e-5 --> 1e-8)
Distance : cosine similarity
Loss : multi-similarity loss (alpha=2, beta=50, base=0.5) with XBM(memory_size=1024) [2]
Batch size : 32, mini-batch is generated by randomly sampling pairs of images in same label_group
Data augmentation : Rotate, ColorJitter, RandomBrightnessContrast, RandomGamma, HorizontalFlip, CoarseDropout



#### Text model

Backbone : DistilBERT ([distilbert-base-indonesian](https://huggingface.co/cahya/distilbert-base-indonesian))
Epochs : 30
Optimizer : madgrad(momentum=0.9, weight_decay=1e-5)
Learning rate scheduler : cosine annealing (1e-4 --> 1e-8)
Distance : cosine similarity
Loss : multi-similarity loss (alpha=2, beta=50, base=0.5)
Miner : multi-similarity miner (epsilon=0.1)
Batch size : 256, mini-batch is generated by randomly sampling pairs of titles in same label_group
Data augmentation : OneOf([random_delete, random_swap, random_swap+random_delete, random_swap*2]) at p=0.1

- random_delete : randomly delete a word if len(title) > 2
- random_swap   : randomly swap two words if len(title) > 2

### Threshold for private LB

I plotted number of images vs best threshold curve and observed exponential decay of best threshold as number of images is getting bigger, so I decresed threshold for final submission. But this worsened private LB score (0.762, 0.757). If I didn't change threshold tuned in public LB, my model could get 0.765.



### What worked

#### Common in image/text model

- Multi-similarity loss (better than CircleLoss(2nd best), TripletLoss, ArcFace, CosFace, SphereFace, ProxyAnchor and SupConLoss)
- Smart mini-batch generation as explained above
- madgrad optimizer (better than SGD-momentum, Adam and RAdam)
- alpha query expansion
The distributions of true/false positives before/after alpha-QE on validation set are as below.

- relax threshold if number of matches < 2
- soft-voting (concat all embeddings over 5 folds, better than hard-voting) 
If each embedding is L2-normalized, the cosine similarity of concatenated embeddings is equal to the simple mean of cosine similarities of each embedding. 



#### Image model

- NFNet-F0 (better than EfficientNets and larger NFNets(F1, F2))
- GeM pooling (p=3 for training, p=4 for inference)
- Cross-Batch memory (XBM)
  This improved convergence by up to 5 times faster and pushed CV from 0.82x to 0.83x.

#### Text model

- DistilBERT (better than BERT)
- Text data augmentation



### What didn't work

#### Common in image/text model

- Stochastic weight averaging (improved only CV)
- Tuning weight_decay in madgrad optimizer (improved only CV)
- Cosine annealing with warm-up
- Applying ROBUST scaler to embeddings as in [3]
- [k reciprocal re-ranking](https://github.com/zhunzhong07/person-re-ranking) / [GNN re-ranking](https://github.com/Xuanmeng-Zhang/gnn-re-ranking)
- Other cosine similarity-like metrics (correlation (de-meaned cosine similarity), adjusted cosine similarity)
- Merging label_groups of samples with same phash but different label_group
- Jointed embedding (concat image/text embedding --> FC layer)
- Adaptive thresholding that optimzes expected row-wise F1 (improved only CV)

#### Image model

- RandAugment
- Combined global descriptor (improved only CV) [4]
  combination of GeM and GMP was best.
- Applying Mixup/CutMix/ResizeMix to pair of images in same label_group to augment data.
- Swin transformer(base), ECA-NFNet-L1 (improved only CV)
- External data (Stanford online products dataset)

#### Text model

- Title length-dependent augmentation probability [5]
- XBM (I guess BS=256 is large enough and effect of XBM is limited)
- Concatenating last layer's CLS and 2nd-to-last layer's CLS (improved only CV)
  I tried concat, average, average with trainable blending weight, concat was best.
- Differential entropy loss (improved only CV) [6]
