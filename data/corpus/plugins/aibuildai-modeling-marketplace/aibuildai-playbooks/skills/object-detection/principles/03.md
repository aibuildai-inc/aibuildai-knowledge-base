## Principle 3: Apply Heavy Augmentation with Mixing Techniques for Small Datasets

*Consensus: Nearly all top solutions used mosaic, mixup, or cutmix; mosaic was the most common, followed by mixup. The 1st place Global Wheat solution gained +0.03 mAP from custom mosaic alone.*

Use mosaic (4-image grid), mixup (blend two images), and cutmix (paste regions) to create synthetic training diversity, especially when your dataset is <10k images or has high class imbalance.

**Why this matters:** These techniques force the model to detect objects in unusual contexts and scales, improving generalization. Mosaic places objects in diverse spatial arrangements within a single image, teaching the model to handle occlusions and varying scales. Mixup/cutmix reduce overfitting by creating soft boundaries and preventing the model from memorizing specific backgrounds.

**When to use:** Default to mosaic + (mixup OR cutmix) for datasets <10k images. Increase mosaic probability (0.5-1.0) when objects are small or densely packed. Use cutmix over mixup when you need hard box edges (standard detection). Apply background-mix (paste objects onto empty images) when background variety is limited.

**When NOT to use:** Reduce or disable for very large datasets (>100k images) where diversity is already high—computational cost may outweigh gains. Disable mosaic if your task requires preserving strict spatial relationships (e.g., structured layouts, document detection). Avoid mixing when border artifacts matter (e.g., crops of wheat heads at image edges, as noted in 2nd place Global Wheat solution).

**How to reason about it:**
Check dataset size and object density. If <10k images or <50 objects per image on average, enable mosaic at p=0.5+. If objects are <10% of image area, mosaic helps by creating denser scenes. Validate by training with/without: if validation loss plateaus early without mixing, or if model struggles with crowded scenes, mixing helps. Monitor edge artifacts—if mosaic creates unrealistic box cutoffs, reduce probability or filter boxes near tile boundaries.

import albumentations as A

def mosaic_augmentation(images, boxes, p=0.5):
    """4-image mosaic that preserves border objects by careful cropping."""
    if np.random.rand() > p:
        return images[0], boxes[0]
    
    # Sample 4 images
    indices = np.random.choice(len(images), 4, replace=False)
    mosaic_img = np.zeros((1024, 1024, 3), dtype=np.uint8)
    mosaic_boxes = []
    
    # Place images in 2x2 grid, adjusting boxes
    for i, idx in enumerate(indices):
        x_offset = (i % 2) * 512
        y_offset = (i // 2) * 512
        mosaic_img[y_offset:y_offset+512, x_offset:x_offset+512] = images[idx][:512, :512]
        # Translate boxes and filter those cut by borders
        for box in boxes[idx]:
            new_box = [box[0]+x_offset, box[1]+y_offset, box[2], box[3]]
            if is_valid_box(new_box, x_offset, y_offset, 512):  # custom border logic
                mosaic_boxes.append(new_box)
    
    return mosaic_img, mosaic_boxes
