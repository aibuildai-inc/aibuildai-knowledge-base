## Principle 11: Add a Classification Head to Re-Score Detections for Multi-Class Datasets with Class Imbalance

*Consensus: Several RSNA Aneurysm top solutions detected candidate regions first and then classified them (15th place: Faster R-CNN RoIs into a Transformer; 9th place: YOLO outputs into meta-classifiers). Great Barrier Reef 1st place: classification re-scoring boosted CV from 0.716 to 0.73+.*

Train a separate classification model on detected bounding boxes to re-score or filter detections, especially when detector confidence is poorly calibrated across classes or when false positives are class-specific.

**Why this matters:** Object detectors optimize for localization and classification jointly, often leading to poorly calibrated class probabilities, especially for rare classes. A dedicated classifier trained on crops of detected boxes can learn class-specific features without the localization burden, improving precision by filtering false positives and recall by rescuing low-confidence true positives.

**When to use:** Apply to multi-class datasets (>5 classes) with severe class imbalance (rarest class <5% of samples). Essential when detector confidence doesn't correlate with classification accuracy—check by plotting confidence vs actual precision per class. Use as post-processing: crop detector boxes, classify with a strong CNN, and re-score or filter based on classification output. Train classifier on OOF detector predictions to match test-time distribution.

**When NOT to use:** Skip for single-class detection or when detector class confidence is already well-calibrated. Avoid if adding another model violates runtime constraints. Not useful when false positives are primarily localization errors (wrong IoU) rather than misclassification—check confusion matrix.

**How to reason about it:**
Analyze detector errors: are false positives scattered across classes or concentrated in specific classes? If the latter, a classifier can filter them. Train classifier on crops of OOF detector predictions with IoU >threshold (e.g., 0.3-0.5) to learn what distinguishes true positives from false positives. Use multi-label classification if boxes can have overlapping classes. Validate that re-scoring improves mAP per class, especially for rare classes. Consider using classification output as features in a second-stage model rather than hard filtering.

        """
        crops = []
        for box in boxes:
