## Principle 12: Clean Training Data by Removing or Correcting Obvious Annotation Errors

*Consensus: Several top solutions mentioned data cleaning. Global Wheat 1st place removed boxes <10px and fixed oversized boxes. Great Barrier Reef 9th place relabeled inconsistent/missing labels.*

Identify and remove or correct annotation errors in the training data: boxes that are too small, too large, cut objects in half, or are inconsistent across similar images. Prioritize fixing errors that affect model convergence over chasing marginal improvements.

**Why this matters:** Annotation noise directly degrades model performance, especially for high-IoU metrics. Tiny boxes (<10px) are often annotation artifacts that create impossible training targets. Oversized boxes teach the model to predict loose boundaries. Inconsistent labels (same object annotated differently across frames) confuse temporal models. Removing egregious errors often improves CV more than adding augmentations.

**When to use:** Always inspect a sample of training data manually (50-100 images). Look for: (1) boxes smaller than smallest realistic object, (2) boxes much larger than object, (3) boxes cutting objects at image edges, (4) duplicates or overlapping boxes for the same object, (5) clear misclassifications. Remove clear errors; correct if pattern is systematic (e.g., all boxes 10% too large). Especially critical for metrics with high IoU thresholds (>0.6).

**When NOT to use:** Don't over-clean if annotation style is consistent even if imperfect—model can learn it. Avoid removing ambiguous cases unless you have domain expertise. Don't spend days on marginal cleaning; fix obvious errors first, then move to modeling. Skip if data is expert-labeled with clear quality control.

**How to reason about it:**
Compute box statistics: area distribution, aspect ratios, boxes per image. Flag outliers (e.g., area <100px² or >50% of image). Manually inspect flagged cases. For edge-cut boxes, decide policy: remove, expand to full object (if other crops show it), or keep if intentional. For video data, check consistency: does the same object have wildly different box sizes across frames? If yes, propagate corrections or remove inconsistent frames. Validate that cleaning improves CV before trusting it.

# Detect and fix annotation errors
import pandas as pd
import numpy as np

def clean_annotations(df, min_box_size=10, max_box_size_ratio=0.9, 
                      img_width=1024, img_height=1024):
    """
    Remove or fix common annotation errors.
    
    Args:
        df: DataFrame with columns ['image_id', 'bbox', 'label']
        min_box_size: minimum width/height in pixels
        max_box_size_ratio: maximum box area as fraction of image area
        img_width, img_height: image dimensions
    """
    cleaned = []
    removed = {'too_small': 0, 'too_large': 0, 'invalid': 0}
    
    for idx, row in df.iterrows():
        x, y, w, h = row['bbox']
        
        # Fix: Remove tiny boxes (likely errors)
        if w < min_box_size or h < min_box_size:
            removed['too_small'] += 1
            continue
        
        # Fix: Remove oversized boxes (likely errors or background)
        area_ratio = (w * h) / (img_width * img_height)
        if area_ratio > max_box_size_ratio:
            removed['too_large'] += 1
            continue
        
        # Fix: Clip boxes to image boundaries
        if x < 0 or y < 0 or x + w > img_width or y + h > img_height:
            x = max(0, x)
            y = max(0, y)
            w = min(w, img_width - x)
            h = min(h, img_height - y)
            
            # Remove if clipping made box invalid
            if w < min_box_size or h < min_box_size:
                removed['invalid'] += 1
                continue
            
            row['bbox'] = [x, y, w, h]
        
        cleaned.append(row)
    
    print(f"Removed: {removed['too_small']} too small, "
          f"{removed['too_large']} too large, "
          f"{removed['invalid']} invalid")
    print(f"Kept: {len(cleaned)}/{len(df)} ({len(cleaned)/len(df):.1%})")
    
    return pd.DataFrame(cleaned)
