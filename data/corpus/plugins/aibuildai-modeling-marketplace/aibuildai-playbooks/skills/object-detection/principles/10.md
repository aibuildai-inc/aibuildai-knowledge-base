## Principle 10: Tune NMS IoU Threshold Lower Than Default for Dense or Overlapping Objects

*Consensus: Several solutions in dense-object competitions lowered NMS IoU threshold. Great Barrier Reef solutions commonly used 0.3-0.4 for clustered starfish.*

Reduce the NMS (Non-Maximum Suppression) IoU threshold from the typical 0.5 to 0.3-0.4 when objects are densely packed or frequently overlap, allowing high-confidence boxes to suppress nearby predictions more aggressively.

**Why this matters:** Default NMS (IoU ≥ 0.5) assumes objects are well-separated. For dense objects (wheat heads, cells, clustered animals), correct boxes from the same object often have IoU <0.5 with each other. A high NMS threshold keeps duplicate predictions, hurting precision. Conversely, very low thresholds (0.2) risk suppressing nearby distinct objects. The optimal threshold depends on object density and evaluation metric sensitivity to false positives.

**When to use:** Apply when objects frequently overlap or cluster (e.g., wheat heads touch, starfish cluster). Essential when precision matters more than recall (mAP metric vs F-beta with beta >1). Validate by plotting IoU distributions of predicted boxes—if many true boxes have 0.3-0.5 IoU with each other, lower NMS threshold. Tune on validation set, not train.

**When NOT to use:** Keep default (0.5) for well-separated objects or when recall is critical (F2 metric weights recall 2x more than precision). Don't go below 0.3 unless objects are extremely dense—risk suppressing true nearby objects. If using WBF for ensembling, NMS is less critical since WBF merges rather than suppresses.

**How to reason about it:**
Analyze ground truth box overlaps: compute pairwise IoU between all GT boxes in the same image. If >20% of box pairs have IoU >0.3, objects are dense. Test NMS thresholds 0.3, 0.4, 0.5 on validation and compare mAP/F2. Lower thresholds should increase precision (fewer duplicates) but may decrease recall (suppress nearby objects). Choose the threshold that maximizes your competition metric. For multi-class detection, consider per-class thresholds if density varies by class.
