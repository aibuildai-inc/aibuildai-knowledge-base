## Principle 14: Use Test-Time Augmentation (TTA) with Geometric Transforms, Not Just Flips

*Consensus: Most top solutions used TTA beyond horizontal flip. Global Wheat 1st place: HFlip + VFlip + Rotate90 gave +0.01 mAP. Great Barrier Reef 2nd place: 11 TTA combinations (scales + rotations) improved ensemble diversity.*

Apply test-time augmentation with diverse geometric transforms (horizontal/vertical flips, 90° rotations, multi-scale) and average predictions using WBF. Go beyond simple horizontal flips for rotationally-invariant tasks.

**Why this matters:** TTA creates an implicit ensemble by testing the model's predictions under different views of the same image. Geometric transforms (flips, rotations) are nearly free in object detection since you just transform boxes back. Multi-scale TTA is especially powerful because different scales reveal different object sizes, improving detection across size ranges. WBF merges diverse TTA predictions better than averaging.

**When to use:** Always apply horizontal flip TTA as baseline. Add vertical flip + 90° rotations for tasks with no canonical orientation (aerial, microscopy, natural scenes like wheat). Use multi-scale TTA (0.8x, 1.0x, 1.2x) when object sizes vary widely. Balance: more TTA = better performance but slower inference. For code competitions with tight time budgets, prioritize 2-3 effective transforms over exhaustive combinations.

**When NOT to use:** Skip vertical flip and rotations if data has canonical orientation (driving scenes, document analysis, faces). Avoid excessive TTA (>8 transforms) if inference time is constrained and marginal gains are small. Don't use TTA blindly—validate that each transform improves CV; some may hurt if they create unrealistic views.

**How to reason about it:**
Identify natural symmetries in your task. If rotating 90° produces realistic images, include Rotate90. If objects appear at any scale, add multi-scale (0.8x, 1.0x, 1.25x). Start with HFlip as baseline, add one transform at a time, and measure CV improvement per transform. Use WBF to merge TTA predictions—it handles the coordinate transforms automatically and fuses boxes better than naive averaging. For video data, apply TTA per-frame and then apply tracking.

```python
# Comprehensive TTA with geometric transforms
import cv2
import numpy as np
from ensemble_boxes import weighted_boxes_fusion

def tta_predict(model, image, transforms=['hflip', 'vflip', 'rot90'], 
                scales=[1.0], iou_thr=0.5):
    """
    Test-time augmentation with geometric transforms and multi-scale.
    
    Args:
        model: detection model
        image: (H, W, C) image
        transforms: list of transforms to apply
        scales: list of scale factors
        iou_thr: WBF IoU threshold
    """
    h, w = image.shape[:2]
    all_boxes, all_scores, all_labels = [], [], []
    
    for scale in scales:
        # Scale image
        if scale != 1.0:
            img = cv2.resize(image, None, fx=scale, fy=scale)
        else:
            img = image.copy()
        
        # Original prediction
        boxes, scores, labels = predict_and_normalize(model, img)
        all_boxes.append(boxes)
        all_scores.append(scores)
        all_labels.append(labels)
        
        # Apply transforms
        if 'hflip' in transforms:
            img_hflip = cv2.flip(img, 1)
            boxes, scores, labels = predict_and_normalize(model, img_hflip)
            boxes[:, [0, 2]] = 1 - boxes[:, [2, 0]]  # flip x coordinates
            all_boxes.append(boxes)
            all_scores.append(scores)
            all_labels.append(labels)
        
        if 'vflip' in transforms:
            img_vflip = cv2.flip(img, 0)
            boxes, scores, labels = predict_and_normalize(model, img_vflip)
            boxes[:, [1, 3]] = 1 - boxes[:, [3, 1]]  # flip y coordinates
            all_boxes.append(boxes)
            all_scores.append(scores)
            all_labels.append(labels)
        
        if 'rot90' in transforms:
            img_rot90 = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)
            boxes, scores, labels = predict_and_normalize(model, img_rot90)
            # Rotate boxes back: (x, y) -> (1-y, x) in normalized coords
            boxes_rot = boxes.copy()
            boxes_rot[:, [0, 1, 2, 3]] = np.stack([
                1 - boxes[:, 3], boxes[:, 0],  # new xmin, ymin
                1 - boxes[:, 1], boxes[:, 2]   # new xmax, ymax
            ], axis=1)
            all_boxes.append(boxes_rot)
            all_scores.append(scores)
            all_labels.append(labels)
    
    # Merge all predictions with WBF
    boxes, scores, labels = weighted_boxes_fusion(
        all_boxes, all_scores, all_labels,
        iou_thr=iou_thr, skip_box_thr=0.3
    )
    
    # Denormalize to image coordinates
    boxes[:, [0, 2]] *= w
    boxes[:, [1, 3]] *= h
    
    return boxes, scores, labels

def predict_and_normalize(model, img):
    """Run model and normalize boxes to [0, 1]."""
    boxes, scores, labels = model.predict(img)
    h, w = img.shape[:2]
    boxes[:, [0, 2]] /= w
    boxes[:, [1, 3]] /= h
    return boxes, scores, labels
```
