## Principle 9: Use Tiled Training and Inference for Small or Densely Packed Objects

*Consensus: 4/6 solutions in competitions with very small objects (<50px mean) used tiling. Great Barrier Reef 9th place: 320px tiles improved F2 by +0.014 vs full-image training. Global Wheat 30th place: quadrant detection with overlap boosted mAP +0.03.*

Split large images into overlapping tiles for training and inference, then stitch predictions together. Train on tiles to increase effective resolution and object density; infer on tiles to handle memory constraints and improve small object recall.

**Why this matters:** Small objects occupy few pixels and match few anchors, making them hard to detect when trained at downsampled full-image resolution. Tiling increases relative object size and creates more positive anchors per image. For inference, tiling allows using higher effective resolution than GPU memory permits for full images, improving localization precision.

**When to use:** Apply when mean object size is <50px or when objects are densely clustered (>10 per 512px region). Essential for high-resolution images (>2048px) where downsampling loses critical detail. Use overlapping tiles (25-50% overlap) to avoid cutting objects at tile boundaries. Train on tiles if you have large images with sparse objects—this creates more 'positive' training samples per image.

**When NOT to use:** Skip if objects are large (>200px) and images fit in memory at full resolution—tiling adds complexity without benefit. Avoid excessive tiling (>4x4 grid) as it multiplies inference time and can create boundary artifacts. Don't tile when spatial context beyond local neighborhoods matters (e.g., scene-level relationships).

**How to reason about it:**
Calculate mean object size and image resolution. If objects are <5% of image size and resolution >1024px, test tiling. Choose tile size to make objects 10-20% of tile (e.g., 50px objects → 320-512px tiles). Use 25-50% overlap; discard boxes within margin pixels of tile edges during training (or use soft margins). For inference, run full-image + tiled predictions and ensemble with WBF to combine. Validate on CV that tiling improves small object recall without degrading overall mAP.

```python
# Tiled training and inference
import numpy as np

def create_tiles(image, boxes, tile_size=512, overlap=0.25, margin=50):
    """
    Split image into overlapping tiles for training.
    
    Args:
        image: (H, W, C) image
        boxes: [N, 4] bounding boxes in [x, y, w, h] format
        tile_size: size of each tile
        overlap: fraction of overlap between adjacent tiles
        margin: discard boxes within this many pixels of tile edge
    """
    h, w = image.shape[:2]
    stride = int(tile_size * (1 - overlap))
    
    tiles, tile_boxes = [], []
    
    for y in range(0, h - tile_size + 1, stride):
        for x in range(0, w - tile_size + 1, stride):
            # Extract tile
            tile = image[y:y+tile_size, x:x+tile_size]
            
            # Find boxes within this tile (with margin)
            tile_box_list = []
            for box in boxes:
                bx, by, bw, bh = box
                # Check if box center is in tile (excluding margin)
                cx, cy = bx + bw/2, by + bh/2
                if (x + margin < cx < x + tile_size - margin and 
                    y + margin < cy < y + tile_size - margin):
                    # Translate box to tile coordinates
                    new_box = [bx - x, by - y, bw, bh]
                    tile_box_list.append(new_box)
            
            if len(tile_box_list) > 0:  # Only keep tiles with objects
                tiles.append(tile)
                tile_boxes.append(tile_box_list)
    
    return tiles, tile_boxes

# Inference: stitch tiles with WBF
def infer_with_tiles(model, image, tile_size=512, overlap=0.25):
    h, w = image.shape[:2]
    stride = int(tile_size * (1 - overlap))
    
    all_boxes, all_scores, all_labels = [], [], []
    
    for y in range(0, h - tile_size + 1, stride):
        for x in range(0, w - tile_size + 1, stride):
            tile = image[y:y+tile_size, x:x+tile_size]
            boxes, scores, labels = model.predict(tile)
            
            # Translate boxes to full image coordinates
            boxes[:, [0, 2]] += x
            boxes[:, [1, 3]] += y
            
            all_boxes.append(boxes)
            all_scores.append(scores)
            all_labels.append(labels)
    
    # Merge overlapping detections with WBF
    from ensemble_boxes import weighted_boxes_fusion
    boxes, scores, labels = weighted_boxes_fusion(
        all_boxes, all_scores, all_labels, iou_thr=0.5
    )
    
    return boxes, scores, labels
```
