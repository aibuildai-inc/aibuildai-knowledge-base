## Principle 8: Apply Temporal Tracking for Video Sequences to Boost Confidence of Persistent Objects

*Consensus: Nearly all video-based competition top solutions used tracking. Great Barrier Reef 1st place: 'attention area' tracking boosted CV by +0.01. 3rd place: tracking low-confidence boxes via trajectory improved recall without adding false positives.*

For video data, track object trajectories across frames and propagate high-confidence detections to boost low-confidence detections in the same track. Don't add missing boxes via Kalman filter; instead, re-score existing low-confidence boxes based on track history.

**Why this matters:** Video sequences have high temporal coherence—an object present in frame N is very likely present in frames N±k. Models sometimes detect an object but with low confidence due to blur, occlusion, or lighting. Tracking allows you to trust these marginal detections when they appear consistently across frames, improving recall without increasing false positives from hallucinated boxes.

**When to use:** Essential for video-based detection (underwater, surveillance, autonomous driving). Most effective when model has good recall (detects objects) but inconsistent confidence (boxes fluctuate above/below threshold). Use simple trackers first (IoU matching, centroid distance); only add Kalman filters if objects move significantly between frames. Apply after initial detection, before final NMS.

**When NOT to use:** Skip for static images or when frames are independent. Avoid Kalman filter-based box prediction if camera moves erratically or objects appear/disappear abruptly—predicted boxes at wrong locations harm more than help. If model confidence is already stable (low variance across frames), tracking adds little value.

**How to reason about it:**
Plot confidence scores across frames for the same object. If they fluctuate (e.g., 0.9, 0.3, 0.8, 0.2), tracking can stabilize. Implement simple 'attention area' tracking: for boxes with confidence >threshold_high in frame N, boost all boxes in frame N+k with IoU >0.5 to the max confidence seen in their track. Tune threshold_high (typically 0.6-0.8) and temporal window (3-10 frames) on CV. Validate that tracking improves metric—F2/recall should increase without precision drop.

```python
# Attention-area tracking (Great Barrier Reef 1st place approach)
def attention_area_tracking(frame_predictions, conf_high=0.7, conf_low=0.01, 
                            iou_threshold=0.5, boost_factor=1.0):
    """
    Boost confidence of low-conf boxes that overlap with high-conf boxes from previous frames.
    
    Args:
        frame_predictions: list of (boxes, scores) for each frame in sequence
        conf_high: threshold to mark boxes as 'attention areas'
        conf_low: threshold for boxes to consider boosting
        iou_threshold: IoU overlap to link boxes across frames
        boost_factor: how much to boost (1.0 = set to max track confidence)
    """
    tracked_predictions = []
    attention_areas = []  # high-confidence boxes from previous frames
    
    for frame_idx, (boxes, scores) in enumerate(frame_predictions):
        boosted_scores = scores.copy()
        
        # Identify high-confidence 'attention areas' in this frame
        high_conf_mask = scores >= conf_high
        attention_areas.append(boxes[high_conf_mask])
        
        # Boost low-confidence boxes that overlap with recent attention areas
        low_conf_mask = (scores >= conf_low) & (scores < conf_high)
        for i, (box, score) in enumerate(zip(boxes[low_conf_mask], scores[low_conf_mask])):
            # Check IoU with attention areas from previous 3 frames
            for prev_areas in attention_areas[-3:]:
                if len(prev_areas) == 0:
                    continue
                ious = compute_iou(box, prev_areas)  # [N] array of IoUs
                max_iou = ious.max()
                
                if max_iou > iou_threshold:
                    # Boost confidence
                    boost = conf_high * boost_factor
                    boosted_scores[low_conf_mask][i] = max(score, boost)
                    break
        
        tracked_predictions.append((boxes, boosted_scores))
    
    return tracked_predictions
```
