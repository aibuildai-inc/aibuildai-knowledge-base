## Principle 13: For 3D or Volumetric Detection, Use Coarse-to-Fine Pipelines to Manage Computational Cost

*Consensus: 3/3 top solutions in 3D medical imaging (RSNA Aneurysm, BYU Flagellar Motors) used multi-stage coarse-to-fine. RSNA 1st place: low-res localization → high-res ROI segmentation → classification saved 60% inference time.*

For 3D volumetric data, first run a fast low-resolution model to locate regions of interest (ROI), then apply expensive high-resolution models only within those ROIs. Use the coarse stage to filter out easy negatives.

**Why this matters:** 3D detection is computationally expensive—processing full volumes at high resolution is often infeasible. Most 3D volumes are mostly background (e.g., medical scans). A coarse pass at low resolution (1mm isotropic) can quickly identify candidate regions, allowing high-resolution models (0.5mm) to focus on <10% of the volume, drastically reducing compute while maintaining recall.

**When to use:** Essential for 3D medical imaging, microscopy, or any volumetric detection where objects occupy <20% of volume. Use when full-resolution inference exceeds time/memory budget. Train coarse model first, then use its ROI predictions to extract training patches for fine model. Typical cascade: coarse localization (fast, low-res) → fine segmentation (slow, high-res, ROI-only) → optional classification (features from both stages).

**When NOT to use:** Skip if objects fill most of the volume or if low-resolution loses critical detail (e.g., very small objects relative to coarse voxel size). Avoid if coarse model has poor recall—missed ROIs can't be recovered by fine model. Not needed if single-stage model already fits in budget.

**How to reason about it:**
Estimate compute budget and object sparsity. If objects occupy <30% of volume and full-res inference is >2x budget, coarse-to-fine helps. Design coarse model to prioritize recall (few false negatives) over precision—it's a filter, not the final answer. Use ROI extraction with generous margins (10-20mm) to avoid cutting objects. Fine model should be trained on realistic ROI crops, not just ground-truth-centered patches. Validate that two-stage mAP matches single-stage performance while being faster.

# Coarse-to-fine 3D detection pipeline
import numpy as np

class CoarseToFinePipeline:
    """
    Two-stage 3D detection: coarse localization → fine ROI processing.
    Based on RSNA Aneurysm 1st place approach.
    """
    def __init__(self, coarse_model, fine_model, roi_size=(140, 140, 140), 
                 coarse_spacing=(1.0, 1.0, 1.0), fine_spacing=(0.5, 0.5, 0.5)):
        self.coarse_model = coarse_model
        self.fine_model = fine_model
        self.roi_size = roi_size
        self.coarse_spacing = coarse_spacing
        self.fine_spacing = fine_spacing
    
    def predict(self, volume, original_spacing):
        # Stage 1: Coarse localization at low resolution
        volume_coarse = resample_volume(volume, original_spacing, self.coarse_spacing)
        coarse_mask = self.coarse_model.predict(volume_coarse)  # binary mask
        
        # Extract ROI centroid
        if coarse_mask.sum() == 0:
            return None  # no detection
        
        # Use DBSCAN to find largest connected component
        from sklearn.cluster import DBSCAN
        coords = np.argwhere(coarse_mask > 0.5)
        clustering = DBSCAN(eps=10, min_samples=50).fit(coords)
        largest_cluster = np.argmax(np.bincount(clustering.labels_[clustering.labels_ >= 0]))
        roi_center = coords[clustering.labels_ == largest_cluster].mean(axis=0)
        
        # Stage 2: Fine-resolution inference on ROI
        # Extract ROI with margins
        roi = extract_roi(volume, roi_center, self.roi_size, original_spacing, 
                         target_spacing=self.fine_spacing)
        
        # Run fine model
        fine_predictions = self.fine_model.predict(roi)
        
        # Map predictions back to original volume coordinates
        # (coordinate transformation logic here)
        
        return fine_predictions

def resample_volume(volume, original_spacing, target_spacing):
    """Resample 3D volume to target spacing using scipy."""
    from scipy.ndimage import zoom
    zoom_factors = [o / t for o, t in zip(original_spacing, target_spacing)]
    return zoom(volume, zoom_factors, order=1)

def extract_roi(volume, center, roi_size, original_spacing, target_spacing):
    """Extract and resample ROI around center point."""
    # Convert ROI size from mm to voxels in original spacing
    roi_voxels = [int(s / sp) for s, sp in zip(roi_size, original_spacing)]
    
    # Extract ROI
    slices = [slice(max(0, int(c - r/2)), int(c + r/2)) 
             for c, r in zip(center, roi_voxels)]
    roi = volume[slices]
    
    # Resample to target spacing
    return resample_volume(roi, original_spacing, target_spacing)
