## Principle 10: Engineer Target Transformations When Direct Prediction Fails

*Consensus: 1st CMI predicted PCIAT_Total→sii; 1st equity-HCT normalized rank within efs groups; 1st Parkinson's used classification instead of regression*

If direct regression fails, transform the target: predict a proxy variable and convert, predict normalized ranks instead of absolute values, or reframe regression as classification with post-processed class selection.

**Why this matters:** Raw targets may be noisy, skewed, or have poor dynamic range. The underlying progression may be more predictable than the measured value. Normalized rank removes scale/offset issues.

**When to use:** When regression achieves poor CV. When you have a correlated proxy variable with less noise. When targets have outliers or heavy tails. When the metric cares about ranking more than absolute values.

**When NOT to use:** When direct prediction works well. When the metric heavily penalizes any transformation error. When no proxy variable exists.

**How to reason about it:**
If regression CV is poor, check: is there a related variable (e.g., total score vs severity class) that's easier to predict? Can you predict rank instead of value and scale back? Can you frame it as classification (bin continuous target) and use class probabilities? Try all three and compare CV.

```python
# Option 1: Predict proxy then convert
y_proxy = df['PCIAT_Total']  # More continuous, less noisy
model.fit(X, y_proxy)
y_pred_proxy = model.predict(X_test)
# Convert using thresholds
y_pred_sii = pd.cut(y_pred_proxy, bins=[0, 30, 40, 50, 100], 
                    labels=[0, 1, 2, 3])

# Option 2: Predict normalized rank
for group in df['group'].unique():
    mask = df['group'] == group
    df.loc[mask, 'rank_target'] = df.loc[mask, 'outcome'].rank() / mask.sum()

model.fit(X, df['rank_target'])

# Option 3: Regression as classification
```
