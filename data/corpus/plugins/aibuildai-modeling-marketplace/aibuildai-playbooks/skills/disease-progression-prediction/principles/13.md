## Principle 13: Build Interpretable Features from Actigraphy Time-Series

*Consensus: All CMI top solutions extracted summary statistics; 4th place found 'longest inactivity streaks'*

For wearable sensor time-series (accelerometry, heart rate), extract domain-relevant summary statistics (day/night means, longest streaks, variability) rather than feeding raw sequences to deep models.

**Why this matters:** Raw time-series from wearables are high-dimensional and noisy. Summary statistics capture the patterns clinicians look for: sleep disruption (night activity), sedentary behavior (inactivity streaks), daily rhythms. With small sample sizes, these outperform end-to-end sequence models.

**When to use:** When you have wearable sensor data with <1000 subjects. When clinical literature identifies specific patterns (activity/inactivity, day/night differences). When time-series are irregular or have many missing periods.

**When NOT to use:** When you have 10,000+ subjects and can train LSTMs/Transformers. When the signal is in fine-grained temporal patterns that summaries would destroy.

**How to reason about it:**
Identify clinically relevant contrasts: day vs night, active vs sedentary, weekday vs weekend. Create separate masks and compute statistics (mean, std, max, percentiles) within each. Extract streak features (longest continuous high/low period). Use PCA if dimensionality is still too high. Compare summary-based model CV to raw sequence model.

```python
# Extract actigraphy summary features
import pandas as pd

# Separate day/night using time_of_day
day_mask = (df['time_of_day'].dt.hour >= 6) & (df['time_of_day'].dt.hour < 22)
night_mask = ~day_mask

features = {}
for col in ['enmo', 'anglez', 'light']:
    features[f'{col}_day_mean'] = df.loc[day_mask, col].mean()
    features[f'{col}_night_mean'] = df.loc[night_mask, col].mean()
    features[f'{col}_day_std'] = df.loc[day_mask, col].std()

# Longest inactivity streak (enmo ~ 0)
inactive = (df['enmo'] < 0.01).astype(int)
streaks = inactive.groupby((inactive != inactive.shift()).cumsum()).sum()
features['max_inactivity_streak'] = streaks.max()

# PCA for dimensionality reduction
from sklearn.decomposition import PCA
pca = PCA(n_components=15)
features_pca = pca.fit_transform(pd.DataFrame([features]))
```
