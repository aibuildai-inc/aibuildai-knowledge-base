## Principle 8: Handle Missing Data with Domain-Driven Imputation

*Consensus: 2nd/4th CMI solutions explicitly modeled missingness; multiple solutions treated NaN as informative*

Missing medical data is rarely random—tests are skipped for clinical reasons. Impute with domain knowledge (KNN using demographic features, sub-models per feature) or treat missingness as a distinct category rather than filling blindly.

**Why this matters:** Default mean/median imputation destroys the signal in missing patterns. A missing CGAS score may indicate the patient wasn't severe enough to warrant the test—this is information. Imputing it with the mean erases this distinction.

**When to use:** When missing rates differ by outcome. When certain tests are only administered to specific patient subgroups. When missingness is systematic, not random.

**When NOT to use:** When missing rates are <5% and uniform across outcomes. When data is missing completely at random (rare in medical data).

**How to reason about it:**
Check missing rate by outcome class. If class 0 has 10% missing for feature X but class 1 has 60% missing, missingness is informative—add a 'feature_X_missing' indicator and consider treating NaN as a category. For important features, train a sub-model (KNN, linear regression) using correlated features to impute. For less important features with random missingness, leave as NaN if your model handles it (CatBoost, LightGBM).

```python
# Check if missingness is informative
for col in df.columns:
    missing_by_class = df.groupby('outcome')[col].apply(
        lambda x: x.isna().mean()
    )
    if (missing_by_class.max() - missing_by_class.min()) > 0.2:
        # Add missing indicator
        df[f'{col}_was_missing'] = df[col].isna().astype(int)

# Domain-driven imputation example
from sklearn.neighbors import KNeighborsRegressor

# Use demographics to impute physical measurements
impute_features = ['age', 'sex', 'bmi']
knn = KNeighborsRegressor(n_neighbors=5)
mask = df['waist'].notna()
knn.fit(df.loc[mask, impute_features], df.loc[mask, 'waist'])
df.loc[~mask, 'waist'] = knn.predict(df.loc[~mask, impute_features])
```
