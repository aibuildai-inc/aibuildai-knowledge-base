## Principle 14: Validate Train-Test Distribution Shifts

*Consensus: Parkinson's solutions noted test set differences*

Medical competition test sets often differ from train: collected at different times, different sites, or with protocol changes. Features that work on train may be unavailable or have different meanings in test.

**Why this matters:** A feature that leaks ground truth on train (computed from a later measurement of the target) may not exist in test the same way. Temporal splits mean test patients are later in study, potentially with different characteristics. Features that boost CV but hurt LB are usually distribution shifts.

**When to use:** Always check train vs test distributions for all features. When the competition description mentions data collected over time or from multiple sites. When public LB contradicts CV.

**When NOT to use:** When train and test are IID samples from the same source. When the competition explicitly states no temporal or site splits.

**How to reason about it:**
Plot feature distributions in train vs test sample. Are means/variances similar? For temporal data, check if test has different visit patterns than train. If a feature's meaning depends on a value that is unavailable in test, it's a leak. Remove or redefine features with train-test mismatches.

```python
# Check train-test distribution shifts
import matplotlib.pyplot as plt
from scipy import stats

for col in X_train.columns:
    train_vals = X_train[col].dropna()
    test_vals = X_test[col].dropna()
    
    # KS test for distribution difference
    ks_stat, p_value = stats.ks_2samp(train_vals, test_vals)
    
    if p_value < 0.01:  # Significant difference
        print(f'{col}: train mean={train_vals.mean():.2f}, '
              f'test mean={test_vals.mean():.2f}, p={p_value:.4f}')
        
        # Visualize
        plt.figure()
        plt.hist(train_vals, alpha=0.5, label='train', bins=30)
        plt.hist(test_vals, alpha=0.5, label='test', bins=30)
        plt.title(f'{col} distribution shift')
        plt.legend()
        plt.show()
```
