## Principle 4: Build Robust CV for Small, Noisy Data

*Consensus: All top-3 CMI solutions used 100+ repeated folds; all Parkinson's/ICR solutions used group/stratified CV*

With <500 samples, single-split CV is unstable (±0.05 score variance). Repeated stratified group K-fold with 20-100 repeats stabilizes CV and reveals true model differences. Group by patient ID to prevent leakage.

**Why this matters:** Model selection on unstable CV picks the luckiest split, not the best model. Repeated CV averages out split variance. Grouping by patient prevents the same patient's visits from appearing in both train and validation.

**When to use:** Always for medical time-series with <1000 patients. Increase repeats until CV variance across seeds <0.01. Stratify by outcome AND critical metadata (race, disease subtype) when fairness matters.

**When NOT to use:** When you have >10,000 independent samples, single 5-fold suffices. Don't use repeated CV for hyperparameter search (too slow)—use it for final model selection only.

**How to reason about it:**
Run CV with 5 different seeds. If scores vary >0.03, you need repeated folds. Check: does a patient's data appear in both train and validation? If yes, switch to GroupKFold. For final selection, run 100 repeats without fixing seed and check distribution of scores.

```python
from sklearn.model_selection import RepeatedStratifiedKFold, GroupKFold

# For classification with patient groups
y_stratify = df['outcome'].astype(str) + '|' + df['metadata'].astype(str)
rkf = RepeatedStratifiedKFold(n_splits=5, n_repeats=100, random_state=None)

# For time-series, group by patient
gkf = GroupKFold(n_splits=5)
for train_idx, val_idx in gkf.split(X, y, groups=df['patient_id']):
    # Ensure no patient in both splits
    assert len(set(df.loc[train_idx, 'patient_id']) & 
               set(df.loc[val_idx, 'patient_id'])) == 0
```
