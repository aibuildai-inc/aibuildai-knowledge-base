## Principle 7: Apply Data Augmentation for Tabular Small Data

*Consensus: 3/3 top CMI solutions, multiple ICR solutions used augmentation*

Add Gaussian noise to features (matched to target for regression), randomly impute NaNs, or create synthetic samples.

**Why this matters:** Small datasets lead to brittle models that memorize exact values. Noise forces models to learn robust patterns. Matched noise (adding same noise to input and target regression) prevents the model from learning the noise itself.

**When to use:** When train size <1000. When you see high train score but low validation. For tabular data with continuous features. NaN augmentation when many features have missingness.

**When NOT to use:** When features are categorical IDs. When noise would destroy the signal (very precise measurements). When you have >5000 samples.

**How to reason about it:**
Identify continuous features. Add Gaussian noise with σ = 0.1-0.2× feature std. For regression, add the SAME noise to the target to prevent learning the noise. For NaN augmentation, randomly set 20% of already-missing columns to NaN. Combine augmented data with original data.

```python
# Gaussian noise augmentation for regression
noise_level = 0.15
X_aug = X.copy()
y_aug = y.copy()

for col in continuous_cols:
    noise = np.random.normal(0, X[col].std() * noise_level, len(X))
    X_aug[col] += noise
    
    # If col contributes to target, add proportional noise to target
    if col == target_col:
        y_aug += noise  # Match input noise to target

# Combine original and augmented
X_train = pd.concat([X, X_aug])
y_train = pd.concat([y, y_aug])
```
