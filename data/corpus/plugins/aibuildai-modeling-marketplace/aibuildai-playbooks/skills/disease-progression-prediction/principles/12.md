## Principle 12: Quantile Binning to Handle Noisy Continuous Features

*Consensus: 1st CMI applied quantile binning to 'a good chunk of features'; multiple solutions discretized features*

Bin noisy continuous features into quantiles (5-10 bins) rather than using raw values. This reduces the impact of measurement error and outliers while preserving rank information.

**Why this matters:** Medical measurements have inherent noise (instrument precision, patient state). A patient with BMI 24.1 vs 24.3 may be indistinguishable, but the model treats them as different. Binning groups similar values and forces the model to learn robust thresholds.

**When to use:** When continuous features have high measurement noise. When scatter plots show weak continuous relationships but clear threshold effects. When raw continuous features hurt CV but domain knowledge says they should help.

**When NOT to use:** When features are precisely measured and continuous relationships are strong. When you have >10,000 samples and can estimate smooth functions reliably.

**How to reason about it:**
Identify noisy continuous features (medical measurements, survey responses). Create 5-10 quantile bins. Test if binned version improves CV over continuous. If yes, replace or add binned version as additional features. Be cautious with test-time binning—use train quantiles only.

```python
from sklearn.preprocessing import KBinsDiscretizer

# Quantile binning for noisy features
binner = KBinsDiscretizer(n_bins=10, encode='ordinal', strategy='quantile')

noisy_features = ['BMI', 'blood_pressure', 'heart_rate']
for col in noisy_features:
    # Fit on train only
    binned = binner.fit_transform(X_train[[col]])
    X_train[f'{col}_binned'] = binned
    
    # Apply same bins to test
    X_test[f'{col}_binned'] = binner.transform(X_test[[col]])

# Can keep both continuous and binned versions
```
