## Principle 6: Use Simple Models with Strong Regularization

*Consensus: 5th Parkinson's used 2-feature linear/isotonic; 1st equity-HCT found optimal depth=2 for XGB/LGB*

With <500 samples, simple models (linear, depth-2 trees, small NNs with high dropout) generalize better than complex ones. The 5th place Parkinson's solution used only 2 features: patient group and month.

**Why this matters:** Complex models memorize noise in small datasets. Depth-2 trees can't learn spurious interactions. High dropout (0.5-0.75) forces networks to learn robust patterns. The winning equity-HCT solution found depth=2 was optimal—unprecedented but correct for the data size.

**When to use:** When train samples <1000. When you see huge CV-LB gap (overfitting). When adding features or depth consistently hurts validation.

**When NOT to use:** When you have 10,000+ samples and can verify complex interactions hold out. When domain knowledge confirms real feature interactions exist.

**How to reason about it:**
Start simple: linear model or depth-2 tree. Does adding depth/features improve holdout? If not, stay simple. For NNs, if <500 samples, use dropout ≥0.5 and <3 layers. If depth-2 trees beat depth-6, your data lacks reliable interactions—don't force complexity.

# Simple but robust models for small data
from sklearn.linear_model import Ridge
import lightgbm as lgb

# Option 1: Ridge regression with strong regularization
model_ridge = Ridge(alpha=10.0)

# Option 2: Shallow tree with high regularization
model_lgb = lgb.LGBMRegressor(
    max_depth=2,  # Force simplicity
    num_leaves=4,
    min_child_samples=20,  # Require sufficient support
    reg_alpha=1.0,
    reg_lambda=1.0
)
