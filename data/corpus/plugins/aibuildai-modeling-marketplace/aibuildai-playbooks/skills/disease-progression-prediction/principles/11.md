## Principle 11: Separate Model Types by Task Structure

*Consensus: 1st equity-HCT trained separate classifier/regressor*

For complex tasks (survival with censoring, multi-target progression), train separate specialized models and merge rather than forcing one model to do everything. Classifier for event occurrence, regressor for time-to-event.

**Why this matters:** A model predicting both whether an event happens AND when it happens must learn two different patterns. Separating them allows each model to specialize. The merge function can weight them based on prediction context.

**When to use:** For survival analysis (event + time). When targets have discrete and continuous components. When different data types (imaging vs tabular) predict different aspects.

**When NOT to use:** When a single target is predicted. When models would use identical features and one joint model achieves better CV than separated models.

**How to reason about it:**
Identify if your task has multiple components: classification + regression, multiple timescales, or different data modalities. Train separate models for each. Design a merge function (weighted average, conditional selection) and optimize merge parameters on CV. Check if merged model beats single joint model.

```python
# Survival analysis: separate event and time models
# Classifier: P(event occurs)
cls_model = LGBMClassifier()
cls_model.fit(X, y_event)
p_event = cls_model.predict_proba(X_test)[:, 1]

# Regressor: normalized rank of time (only on event=1 samples)
mask_event = y_event == 1
reg_model = LGBMRegressor()
reg_model.fit(X[mask_event], y_time_rank[mask_event])
p_time_rank = reg_model.predict(X_test)

# Merge function (tune a, b, c on validation)
def merge_predictions(p_event, p_time_rank, a=2.0, b=1.5, c=0.5):
    # High event probability → high risk score
    # Low time rank (early event) → high risk score
    risk = (p_event ** a) * (1 - c * (p_time_rank ** b))
    return risk

final_prediction = merge_predictions(p_event, p_time_rank)
```
