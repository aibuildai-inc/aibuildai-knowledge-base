## Principle 9: Optimize Hyperparameters with Optuna for Gradient Boosting

*Consensus: Mentioned in 10+ solutions. Optuna was the most common hyperparameter optimization tool across TPS competitions.*

Use automated hyperparameter optimization (Optuna, Hyperopt) to tune gradient boosting models. Focus on key parameters: learning_rate, num_leaves, max_depth, min_child_samples, subsample, colsample_bytree.

**Why this matters:** Gradient boosting is sensitive to hyperparameters, and manual tuning is time-consuming. Optuna efficiently searches the space using Bayesian optimization. The cat-in-the-dat 1st place solution used Optuna to tune logistic regression's C parameter, improving from 0.808 to 0.8085.

**When to use:** For XGBoost, LightGBM, CatBoost: always run Optuna with 50-100 trials. Define search ranges based on defaults: learning_rate [0.01, 0.1], num_leaves [20, 100], max_depth [3, 10]. Use CV score as the objective. For linear models, tune regularization strength (alpha, C). For neural networks, tune learning rate, dropout, layer sizes.

**When NOT to use:** Don't over-optimize on the public LB (risk overfitting). Don't spend >20% of your time on hyperparameter tuning if feature engineering hasn't been explored. Default hyperparameters for GBDT are often good enough; Optuna gives a 0.5-2% boost, while good features can give 5-10%.

**How to reason about it:**
After basic feature engineering, run Optuna to find good hyperparameters. Use CV score as the objective, not LB score. Start with wide search ranges, then narrow after the first 50 trials. Focus on parameters that affect overfitting (learning_rate, regularization, depth) before less important ones (subsample, colsample). Check if the improvement justifies the complexity.

```python
import optuna
from lightgbm import LGBMClassifier
from sklearn.model_selection import cross_val_score

def objective(trial):
    params = {
        'n_estimators': trial.suggest_int('n_estimators', 100, 1000),
        'learning_rate': trial.suggest_loguniform('learning_rate', 0.01, 0.3),
        'num_leaves': trial.suggest_int('num_leaves', 20, 100),
        'max_depth': trial.suggest_int('max_depth', 3, 10),
        'min_child_samples': trial.suggest_int('min_child_samples', 5, 100),
        'subsample': trial.suggest_uniform('subsample', 0.6, 1.0),
        'colsample_bytree': trial.suggest_uniform('colsample_bytree', 0.6, 1.0),
    }
    model = LGBMClassifier(**params, random_state=42)
    score = cross_val_score(model, X_train, y_train, cv=5, scoring='roc_auc').mean()
    return score

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=100)
```
