## Principle 7: Use Stratified CV for Imbalanced or Multiclass Tasks

*Consensus: Mentioned in 12+ solutions across classification tasks. Standard practice for all top solutions in imbalanced competitions.*

For classification, use StratifiedKFold to ensure each fold has the same class distribution as the full dataset. For time series, use GroupKFold to prevent temporal leakage.

**Why this matters:** Random CV can create folds with very different class distributions, leading to unreliable and high-variance CV scores. This is especially problematic for imbalanced datasets or multiclass with rare classes. Stratified CV ensures every fold is representative. For time series, GroupKFold prevents future data from leaking into the past.

**When to use:** Always use StratifiedKFold for classification tasks. For time series, use GroupKFold with time-based groups (year, quarter, month). For regression with skewed targets, consider binning the target and using StratifiedKFold on the bins. Use 5-10 folds; more folds = lower bias but higher variance.

**When NOT to use:** Don't use StratifiedKFold for regression (no classes to stratify). Don't use random KFold for time series (creates temporal leakage). Don't use TimeSeriesSplit if you need multiple folds on limited data (it's cumulative, so early folds have very little data).

**How to reason about it:**
Ask: Is this a classification task? Use StratifiedKFold. Is there a time dimension? Use GroupKFold with time groups. Is the target highly imbalanced? Check that each fold has at least a few samples of each class. For multiclass, ensure rare classes aren't missing from folds. The goal is representative folds that mimic the train/test distribution.
