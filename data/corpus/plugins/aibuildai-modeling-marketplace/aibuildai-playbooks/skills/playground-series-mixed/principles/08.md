## Principle 8: Apply Heavy Regularization for Small or Sparse Datasets

*Consensus: The dont-overfit-ii winners all used regularization. Multiple small-sample TPS solutions emphasized L1/L2 penalties.*

For datasets with few samples (n<1000) or many features (p>n), use strong regularization (L1/L2 penalties, dropout, early stopping) to prevent overfitting.

**Why this matters:** Small datasets memorize easily. The dont-overfit-ii competition had 250 training samples with 300 features—winners used L1 penalties, feature selection, and coefficient shrinkage. Without regularization, models fit noise and fail to generalize.

**When to use:** When n<1000 or p>n, start with strong regularization. For linear models, use Ridge (L2) or Lasso (L1) with cross-validated alpha selection. For neural networks, use dropout (0.3-0.5), L2 weight decay, and early stopping. For tree models, increase min_samples_leaf, reduce max_depth. The dont-overfit-ii 2nd place solution capped small coefficients to zero (abs(coef)<0.04 → 0) to avoid fitting noise.

**When NOT to use:** Large datasets (n>10k) with p<<n don't need extreme regularization, though some is still beneficial. If CV shows underfitting (train and val scores both poor), reduce regularization strength.

**How to reason about it:**
Ask: What is my n/p ratio? If p>n, I'm in the overfitting regime—use strong L1 (Lasso) for feature selection. If n is small (<1000), use L2 (Ridge) to shrink coefficients. For neural networks on small data, always use dropout and early stopping. Tune regularization strength via CV: try alphas from 1e-4 to 1e2 in log scale, pick the one with best CV.

```python
# Ridge regression with CV to find best alpha
from sklearn.linear_model import RidgeCV

alphas = np.logspace(-4, 2, 50)  # 1e-4 to 1e2
ridge = RidgeCV(alphas=alphas, cv=5)
ridge.fit(X_train, y_train)
print(f'Best alpha: {ridge.alpha_:.4f}')

# Lasso for feature selection (sets some coefficients to 0)
from sklearn.linear_model import LassoCV
lasso = LassoCV(alphas=alphas, cv=5, max_iter=10000)
lasso.fit(X_train, y_train)
selected_features = np.where(lasso.coef_ != 0)[0]
print(f'Selected {len(selected_features)} / {len(lasso.coef_)} features')
```
