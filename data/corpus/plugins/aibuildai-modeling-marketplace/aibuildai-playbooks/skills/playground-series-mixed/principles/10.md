## Principle 10: Build Ensemble Diversity Through Preprocessing and Model Families

*Consensus: The Otto 1st place used 33 diverse base models; TPS Sep-2021 2nd place used 115 models with different preprocessing.*

Effective ensembles require diversity: different model families (linear, tree-based, neural networks), different preprocessing (scaling methods, encoding strategies), different features, different random seeds.

**Why this matters:** Ensembling identical or highly correlated models provides minimal gain. Diversity allows the ensemble to correct each model's errors. The Otto winner used RandomForest, Logistic, ExtraTrees, kNN, NeuralNets, XGBoost, etc. The TPS Sep-2021 2nd place: 'Models were trained with different parameters and features, creating a large level 1.'

**When to use:** Create diversity by: (1) Model families—mix linear (Logistic, Ridge), tree (XGBoost, LightGBM, CatBoost, RF), neural (MLP, TabNet). (2) Preprocessing—try StandardScaler, RobustScaler, MinMaxScaler, no scaling; one-hot vs ordinal vs target encoding. (3) Features—different feature subsets, different engineered features. (4) Hyperparameters—different depths, learning rates. (5) Random seeds—train same model with 3-5 seeds.

**When NOT to use:** Don't add models that are near-duplicates (same architecture, same hyperparameters, same seed). Don't add models with poor individual CV scores (<baseline) unless they provide unique errors. Don't add >50 models to a level-1 ensemble without checking that the meta-model isn't overfitting.

**How to reason about it:**
Ask: Are my base models making different mistakes? Check correlation of predictions—if all correlations >0.95, you lack diversity. Aim for correlations in 0.7-0.9 range. Diversity sources ranked by impact: (1) model family > (2) features > (3) preprocessing > (4) hyperparameters > (5) random seeds. Add 5-10 diverse base models, check ensemble CV, then add more if it keeps improving.
