## Principle 6: Invest in Domain-Specific Feature Engineering Over Model Tuning

*Consensus: 10+ time series solutions emphasized this. The TPS Jan-2022 winner spent most effort on holiday/seasonal features, not hyperparameters.*

For time series and domain-rich tasks, manually engineered features (holidays, Fourier terms, lag features) often matter more than model choice or hyperparameter tuning.

**Why this matters:** Time series playground competitions often have strong seasonal/holiday patterns. Linear models with good features outperform GBDTs with weak features. The TPS Jan-2022 winner: 'Why not gradient boosting? If you use gradient boosting and don't engineer the features yourself, you give up control. With linear regression you analyze residuals and create an Easter holiday which starts exactly on Good Friday and lasts ten days.'

**When to use:** For time series: create Fourier features for seasonality, one-hot or duration features for holidays, trend features (linear, polynomial), lag features for autoregression. Analyze residuals to find missing patterns. For tabular: create interaction features (product/ratio of top features), aggregations (group-level statistics), polynomial features for nonlinear relationships. Use feature importance from a simple model to guide which interactions to try.

**When NOT to use:** Don't blindly create all possible interactions (combinatorial explosion). Don't add features that don't improve CV. The TPS May-2021 winner: 'Nothing worked for me here. I tried PCA, clustering, featuretools but all led to either horrible overfitting or poor local cv so I did not pursue feature engineering much.' Some datasets have minimal feature engineering opportunity—test quickly and move on if CV doesn't improve.

**How to reason about it:**
Start with domain knowledge: for time series, what seasonal patterns exist? (weekly, monthly, yearly). What holidays matter? For tabular, what interactions make business sense? Then validate with data: plot target vs time to see seasonality, use feature importance to find top features, create interactions of top 5-10 features, validate each addition with CV. The Jan-2022 winner analyzed residuals to find that Easter needed a 10-day holiday window, Midsummer affected only Norway, etc.

```python
# Time series: Fourier features for seasonality
import numpy as np

def add_fourier_features(df, date_col, period, order=3):
    t = (df[date_col] - df[date_col].min()).dt.days
    for i in range(1, order + 1):
        df[f'sin_{period}_{i}'] = np.sin(2 * np.pi * i * t / period)
        df[f'cos_{period}_{i}'] = np.cos(2 * np.pi * i * t / period)
    return df

# Add yearly and weekly seasonality
df = add_fourier_features(df, 'date', period=365.25, order=3)  # yearly
df = add_fourier_features(df, 'date', period=7, order=2)  # weekly
```
