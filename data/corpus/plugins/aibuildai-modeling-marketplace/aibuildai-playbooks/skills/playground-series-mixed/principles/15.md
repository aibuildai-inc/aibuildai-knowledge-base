## Principle 15: Apply Pseudo-Labeling Cautiously with Confidence Thresholding

*Consensus: 3 solutions used pseudo-labeling successfully, but emphasized careful thresholding and validation.*

Pseudo-labeling uses confident predictions on test/unlabeled data as additional training data. Select only high-confidence predictions (e.g., top/bottom 5% probabilities) and retrain. Validate that it improves CV.

**Why this matters:** Pseudo-labeling can exploit test distribution information and boost performance. The TPS Nov-2021 winner: 'used 5% of the data as pseudo label and retrained a simple NN ~LB 0.75070.' However, it risks propagating errors—if your model is wrong on the pseudo-labeled samples, you reinforce those errors. The TPS Apr-2021 winner used swap noise with pseudo-labeling to mitigate overfitting.

**When to use:** For binary classification, pseudo-label test samples with predictions <0.05 or >0.95 (high confidence). Add them to training data and retrain. For multiclass, use samples with max(probability) > 0.9. Always validate on held-out CV that pseudo-labeling improves performance—if CV degrades, it's overfitting.

**When NOT to use:** Don't pseudo-label if your model is weak (CV AUC < 0.70 for binary classification). Don't use all test data (creates overfitting). Don't skip CV validation. Don't use pseudo-labeling as a primary strategy—it's a 0.5-1% boost at best, risky if CV isn't monitored.

**How to reason about it:**
Ask: Is my base model strong? (CV AUC > 0.75 for binary). Then predict on test, select top 5% and bottom 5% most confident predictions. Add these to train with their pseudo-labels. Retrain and check CV—if CV improves, keep it; if not, discard. Iterate: re-pseudo-label with the new model, select top 5%, retrain. Stop when CV stops improving.

```python
# Pseudo-labeling for binary classification
import numpy as np

# Get test predictions from a strong base model
test_preds = model.predict_proba(X_test)[:, 1]

# Select high-confidence samples (top/bottom 5%)
conf_threshold = 0.05
high_conf_mask = (test_preds < conf_threshold) | (test_preds > 1 - conf_threshold)
pseudo_X = X_test[high_conf_mask]
pseudo_y = (test_preds[high_conf_mask] > 0.5).astype(int)

# Combine with training data
X_combined = np.vstack([X_train, pseudo_X])
y_combined = np.hstack([y_train, pseudo_y])

# Retrain and validate on CV
model_pl = clone(model).fit(X_combined, y_combined)
cv_score_pl = cross_val_score(model_pl, X_train, y_train, cv=5).mean()
print(f'Pseudo-labeling CV: {cv_score_pl:.5f}')
```
