## Principle 3: Match Categorical Encoding to Model Architecture

*Consensus: 5/5 top cat-in-the-dat solutions used this principle. Tree-based models used ordinal encoding, linear models used one-hot or target encoding.*

Choose encoding strategies based on your model family: one-hot encoding for linear models, ordinal/label encoding for tree-based models, target encoding cautiously for both.

**Why this matters:** Tree-based models (GBDT, RF) naturally handle ordinal encodings via splits and don't need one-hot expansion. Linear models need numeric representations where distance matters—one-hot preserves independence, target encoding captures target correlation. The 1st place cat-in-the-dat solution: 'Ordinal Encoding ord features, One Hot Encoding other features, Using logistic regression.' Mixing encodings within the same model dilutes signal.

**When to use:** For linear models (Logistic, Ridge, Lasso): one-hot encode low-cardinality categoricals (<10 levels), target-encode or embed high-cardinality. For tree models (XGBoost, LightGBM, CatBoost): use ordinal/label encoding. CatBoost can handle native categorical features directly. For high-cardinality features (>100 levels), consider target encoding with CV to avoid leakage, or frequency encoding.

**When NOT to use:** Don't use one-hot encoding for tree models with high-cardinality features (creates sparse, deep trees). Don't use target encoding without proper CV-based encoding (leaks target into features). Don't use ordinal encoding for truly nominal features in linear models unless you also include interaction terms.

**How to reason about it:**
Ask: Does my model care about distance between categories? (Linear models: yes, trees: no). How many unique values does this feature have? (Low cardinality → one-hot is safe; high cardinality → target/frequency encoding). Is there a natural order? (Ordinal features: encode the order; nominal features: one-hot or target encode). The cat-in-the-dat 2nd place solution found that 'nothing other than one hot encoders was significant' for their linear approach, but also discovered ordinal tricks that exploited the known lexical ordering.
