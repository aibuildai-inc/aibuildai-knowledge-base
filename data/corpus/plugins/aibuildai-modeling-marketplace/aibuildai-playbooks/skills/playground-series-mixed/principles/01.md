## Principle 1: Start Simple and Add Complexity Only When Justified by CV

*Consensus: Mentioned in 15+ top solutions across different competition types. Simple models (logistic regression, linear models) won multiple competitions outright.*

Begin with baseline linear models or simple tree ensembles before exploring complex architectures. Many competitions are won by logistic regression with good feature engineering or lightly-tuned gradient boosting.

**Why this matters:** Playground datasets are often engineered to have clean signals that simple models capture well. Complex models risk overfitting synthetic artifacts or small sample sizes. The 1st place cat-in-the-dat solution used only logistic regression with one-hot encoding; the 1st place TPS Jan-2022 used Ridge regression with careful feature engineering.

**When to use:** Always start here. For categorical-heavy tasks, try logistic regression with different encodings. For time series, try linear models with seasonal features. For small datasets (n<1000), heavily regularized linear models often outperform deep learning.

**When NOT to use:** Skip directly to complex models only if: (1) simple baselines completely fail (CV AUC<0.55 for binary classification), (2) you've already exhausted feature engineering on simple models, or (3) the task explicitly requires sequence/image understanding.

**How to reason about it:**
Ask: What is the simplest model that could capture this pattern? Does adding complexity improve CV by a meaningful margin (>0.5% for AUC, >1% for RMSE)? Am I adding complexity to fix a modeling problem or a feature engineering problem? The decision tree: Logistic/Linear → Regularized Linear (Ridge/Lasso) → Single GBDT → Ensemble of GBDTs → Neural Networks → Complex stacking. Move right only when the current stage plateaus on CV.

# Start with regularized logistic regression
from sklearn.linear_model import LogisticRegressionCV
from sklearn.preprocessing import StandardScaler

# Try multiple regularization strengths via CV
model = LogisticRegressionCV(
    Cs=10,  # Test 10 regularization strengths
    cv=5,
    scoring='roc_auc',
    max_iter=1000,
    random_state=42
)
# Only move to GBDT if this underperforms
