## Principle 11: Use Simple Meta-Models for Stacking

*Consensus: 15+ solutions used Ridge, Lasso, or Logistic regression as meta-models. Complex meta-models were rare and often underperformed.*

Stack base model predictions using simple linear meta-models (Ridge, Lasso, Logistic Regression with Logits) rather than complex models. Optionally stack predictions twice (level-2 → level-3).

**Why this matters:** Meta-models train on OOF predictions, which is already a small dataset (size=n_train). Complex meta-models overfit. Simple linear models find optimal weights. The TPS Sep-2021 2nd place: 'Linear models worked best (L1, L2, Elastic Net regression). After experimentation, Elastic Net seemed to have the best CV score.' The TPS May-2021 winner used Ridge for meta-model stacking.

**When to use:** Collect OOF predictions from 5-20 diverse base models. Train a Ridge or ElasticNet meta-model on these OOFs. For classification, use LogisticRegression or Ridge with log-transformed targets. Optionally, feed the meta-model predictions into another Ridge model (level-3). Use CV on the meta-model too.

**When NOT to use:** Don't use complex meta-models (deep neural networks, heavily-tuned GBDTs) unless you have >50 diverse base models and large n_train. Don't stack without CV—you need OOF predictions, not in-sample predictions (creates leakage).

**How to reason about it:**
Stacking works by learning optimal weights for base models. Linear meta-models provide this with minimal overfitting. Ask: Do I have diverse base models? (Check correlation <0.95). Do I have proper OOF predictions? (No leakage). Then train Ridge/Lasso on OOFs, use CV to check meta-model isn't overfitting. If meta-model CV < best base model CV, stacking failed—need more diversity.

```python
from sklearn.linear_model import RidgeCV
import numpy as np

# Collect OOF predictions from base models
# Each model should produce OOF preds on the same CV folds
oof_preds = np.column_stack([oof_lgbm, oof_xgb, oof_catboost, oof_lr, oof_nn])

# Train meta-model (Ridge)
meta_model = RidgeCV(alphas=np.logspace(-3, 3, 50), cv=5)
meta_model.fit(oof_preds, y_train)

# Get test predictions from base models, then meta-predict
test_preds = np.column_stack([test_lgbm, test_xgb, test_catboost, test_lr, test_nn])
final_preds = meta_model.predict(test_preds)
```
