## Principle 4: Leverage Original Datasets for Synthetic Competitions

*Consensus: Mentioned in 8+ TPS writeups. The playground-series-s6e5 winner explicitly used original data with sample weights.*

When the competition dataset is synthetic (generated from a real dataset), use the original dataset to augment training, understand feature relationships, and validate that synthetic artifacts aren't misleading.

**Why this matters:** Synthetic generation introduces artifacts (e.g., slightly different feature distributions, correlations smoothed out). The original dataset provides ground truth for feature importance and interactions. However, blindly adding original data can hurt if distributions differ significantly. The s6e5 winner: 'modulating the impact of the original via sample weights - weights between 0.5 and 1 seemed to produce pretty much the same score.'

**When to use:** When the competition description links to an original dataset. First, run adversarial validation to check train/original similarity. If adversarial AUC < 0.6, the datasets are similar enough to combine. Use the original dataset as: (1) extra training rows with lower sample weights (0.5-1.0), (2) a validation set to check if your model generalizes, (3) a source for feature engineering ideas.

**When NOT to use:** If adversarial validation shows AUC > 0.7 (datasets are very different), don't naively concatenate. If a specific feature has very different distribution (check per-feature adversarial AUC), consider dropping that feature or training separate models. The s6e5 winner found 'Driver' had high adversarial AUC and benefited from training models without it.

**How to reason about it:**
Run adversarial validation: train a classifier to distinguish competition train from original data. If it can't (AUC~0.5), distributions are similar. Check per-feature adversarial AUC to find problematic features. If overall AUC < 0.6: add original data with sample_weight=0.5-1.0. If 0.6-0.7: train separate models or use original only for feature engineering ideas. If >0.7: treat as a different dataset.
