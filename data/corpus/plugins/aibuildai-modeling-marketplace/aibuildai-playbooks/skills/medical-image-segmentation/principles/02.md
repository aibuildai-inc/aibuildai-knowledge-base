## Principle 2: Match Train Resolution to Test Physical Scale, Not Pixel Count

*Consensus: The competitions whose test resolution differed from training (blood vessel, organ segmentation) emphasize this*

When train and test data have different voxel sizes (um/pixel), adjust training to simulate the test resolution so models learn scale-invariant features.

**Why this matters:** A vessel that occupies 12 pixels at 50um/voxel will occupy only 10 pixels at 63um/voxel. If you train only at the finer resolution, the model overfits to that scale and fails on coarser test data. The metric penalizes boundary errors, so even 1-2 pixel shifts from scale mismatch cause large score drops.

**When to use:** When: (a) train and test voxel sizes differ (check metadata or organizer announcements), (b) the competition provides multiple resolutions in training data, (c) you observe train-test shake (high public LB, low private LB) correlated with resolution differences.

**When NOT to use:** Skip if train and test resolutions are identical, or if your backbone has strong scale invariance (e.g., multi-scale feature pyramids with extensive scale augmentation already cover the gap).

**How to reason about it:**
1. Compute scale ratio: test_um / train_um (e.g., 63/50 = 1.26). 2. If ratio > 1, test is coarser: augment with downscaling centered at the ratio (scale_limit=(-0.45, 0.05) for 0.8× center). 3. At inference, optionally resize test images TO train resolution, predict, then resize predictions BACK (3D interpolation, not 2D per-slice). 4. Validate this on a held-out high-res subset downsampled to test resolution.

```python
# Simulate coarser test resolution during training
import albumentations as A
train_res, test_res = 50.0, 63.08  # um/voxel
scale_factor = test_res / train_res  # 1.26 (test is coarser)

# Center augmentation around test scale
aug = A.ShiftScaleRotate(
    scale_limit=(-0.45, 0.05),  # Range: [0.55, 1.05] centered at ~0.8
    # This simulates test being 1.26x coarser
    p=0.95
)

# Inference: resize to train resolution, predict, resize back
import torch.nn.functional as F
def predict_with_rescale(model, test_vol, scale_factor):
    # test_vol shape: (D, H, W)
    D, H, W = test_vol.shape
    vol_scaled = F.interpolate(
        test_vol[None, None], 
        size=(int(D*scale_factor), int(H*scale_factor), int(W*scale_factor)),
        mode='trilinear'
    ).squeeze()
    preds_scaled = model(vol_scaled)
    preds = F.interpolate(
        preds_scaled[None, None],
        size=(D, H, W),
        mode='trilinear'
    ).squeeze()
    return preds
```
