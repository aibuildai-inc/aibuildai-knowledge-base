## Principle 8: Optimize Thresholds Per-Class and Per-Metric Using Validation Data

*Consensus: Most source competitions with multi-class or complex metrics*

Do not use a single global threshold (e.g., 0.5) for binarizing predictions. Search for optimal per-class thresholds on validation data that maximize the competition metric.

**Why this matters:** Different classes have different optimal thresholds due to class imbalance, annotation quality, or model confidence calibration. A lung structure may peak at 0.6 while kidney peaks at 0.3. The competition metric (Dice, mAP, surface Dice) is non-differentiable, so you must search thresholds post-training.

**When to use:** When: (a) multi-class segmentation with per-class scoring, (b) metrics include precision-recall trade-offs (mAP, F-score), (c) you observe that changing threshold from 0.5 significantly changes validation score. Search over [0.1, 0.9] in 0.05 steps.

**When NOT to use:** Skip per-class optimization if: single binary class, metric is pure Dice (often peaks near 0.5 for balanced data), or validation is too small to reliably estimate optimal thresholds (<50 samples per class).

**How to reason about it:**
1. Generate soft predictions (probabilities) on validation set. 2. For each class, sweep threshold from 0.1 to 0.9 in steps of 0.05. 3. At each threshold, compute competition metric (Dice, surface Dice, mAP). 4. Select threshold that maximizes metric for that class. 5. Validate stability: ensure metric doesn't drop >0.01 with ±0.05 threshold change (wide plateau = robust). 6. For binary tasks with empty/non-empty classification, use a two-threshold scheme: high threshold for classification (is there any object?), low threshold for segmentation (where is it?).

```python
# Per-class threshold search
import numpy as np
from sklearn.metrics import f1_score

def find_optimal_thresholds(val_preds, val_masks, class_names, metric_fn):
    """
    val_preds: (N, C, H, W) soft probabilities
    val_masks: (N, C, H, W) binary ground truth
    metric_fn: function(pred_binary, mask) -> score
    """
    optimal_thresholds = {}
    for class_idx, class_name in enumerate(class_names):
        best_threshold, best_score = 0.5, 0
        for threshold in np.arange(0.1, 0.95, 0.05):
            preds_binary = (val_preds[:, class_idx] > threshold).astype(int)
            score = metric_fn(preds_binary, val_masks[:, class_idx])
            if score > best_score:
                best_score = score
                best_threshold = threshold
        optimal_thresholds[class_name] = best_threshold
        print(f"{class_name}: threshold={best_threshold:.2f}, score={best_score:.4f}")
    return optimal_thresholds

# Two-threshold scheme for binary with empty detection
def predict_with_two_thresholds(pred_prob, top_threshold=0.7, bottom_threshold=0.3, min_area=2000):
    # Classification: is there any object?
    classification_mask = pred_prob > top_threshold
    if classification_mask.sum() < min_area:
        return np.zeros_like(pred_prob)  # Predict empty
    # Segmentation: use lower threshold
    return (pred_prob > bottom_threshold).astype(int)
```
