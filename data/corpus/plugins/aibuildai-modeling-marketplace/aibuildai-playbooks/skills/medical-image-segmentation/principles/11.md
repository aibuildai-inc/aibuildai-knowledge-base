## Principle 11: Post-Process Predictions With Connected Components and Morphological Operations

*Consensus: 7/7 competitions use post-processing; effect varies by metric*

After generating soft predictions, apply morphological operations (opening, closing), remove small connected components, and fill holes to clean up masks and align with anatomical priors.

**Why this matters:** Neural networks produce noisy predictions with small false positives and fragmented true positives. Morphological operations smooth boundaries and remove noise. For metrics that penalize false positives (precision-heavy mAP), removing small objects helps. For Dice, filling holes in true positives improves recall.

**When to use:** When: (a) predictions have salt-and-pepper noise (many tiny components), (b) metric penalizes small false positives (mAP, precision), (c) targets are known to be large and connected (organs, not scattered cells). Apply after thresholding: (1) remove components smaller than N pixels, (2) morphological opening (erode+dilate) to remove noise, (3) morphological closing (dilate+erode) to fill gaps.

**When NOT to use:** Skip if: (a) targets are truly small and scattered (removing small components loses true positives), (b) aggressive post-processing hurts validation score (always validate), (c) metric is pure Dice and your predictions are already clean.

**How to reason about it:**
1. Threshold predictions to binary masks. 2. Label connected components (scipy.ndimage.label or cv2.connectedComponents). 3. Compute size of each component; remove those <min_size (search min_size on validation: try [50, 100, 500, 1000]). 4. Apply morphological opening with small kernel (3×3 or 5×5) to remove noise. 5. Apply morphological closing to fill holes. 6. For instance segmentation: use weighted boxes fusion or NMS to merge overlapping predictions. 7. Validate each step: does it improve metric on validation?

```python
# Post-processing pipeline
import cv2
from scipy.ndimage import label, binary_opening, binary_closing

def postprocess_mask(pred_prob, threshold=0.4, min_size=100, kernel_size=3):
    # 1. Threshold
    mask = (pred_prob > threshold).astype(np.uint8)
    
    # 2. Morphological opening (remove noise)
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (kernel_size, kernel_size))
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
    
    # 3. Remove small connected components
    labeled, num_components = label(mask)
    for component_id in range(1, num_components + 1):
        component_size = (labeled == component_id).sum()
        if component_size < min_size:
            mask[labeled == component_id] = 0
    
    # 4. Morphological closing (fill holes)
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)
    
    return mask

# For instance segmentation: merge overlapping boxes
from ensemble_boxes import weighted_boxes_fusion

def merge_instance_predictions(predictions_list, iou_threshold=0.5):
    # predictions_list: list of (boxes, scores, masks) from different models/TTA
    boxes_list, scores_list, masks_list = [], [], []
    for boxes, scores, masks in predictions_list:
        boxes_list.append(boxes)
        scores_list.append(scores)
        masks_list.append(masks)
    
    # Weighted boxes fusion
    merged_boxes, merged_scores, merged_masks = weighted_boxes_fusion(
        boxes_list, scores_list, masks_list,
        iou_thr=iou_threshold, skip_box_thr=0.01
    )
    return merged_boxes, merged_scores, merged_masks
```
