## Principle 12: Increase Effective Resolution With Interpolation or Intelligent Cropping

*Consensus: Several high-resolution competitions (blood vessels, organs)*

When targets contain small structures, increase resolution by: (a) upsampling input before model, predicting, then downsampling output, or (b) using intelligent sliding-window crops focused on non-empty regions.

**Why this matters:** Small vessels or nuclei occupy only 5-10 pixels at standard resolution (512×512). Upsampling to 1024×1024 or training on 1024 crops directly doubles their pixel representation, making them easier to detect. However, this increases memory 4× and compute 4-8×, so it must be done strategically.

**When to use:** When: (a) targets include structures <10 pixels in diameter, (b) you have false negatives on small objects in validation, (c) you can afford 2-4× longer training (use mixed-resolution: train mostly at 512, fine-tune at 1024). Use interpolation trick (upsample → predict → downsample) for inference if memory is tight.

**When NOT to use:** Skip if: (a) targets are large (>50 pixels), (b) memory/time constraints are severe, (c) your backbone already has multi-scale features (FPN, U-Net decoder) that handle small objects.

**How to reason about it:**
1. Measure target object sizes in pixels. If 50%+ are <10 pixels, consider higher resolution. 2. Option A (full high-res): train U-Net at 1024×1024 instead of 512×512. Use crops from 1024 images or resize 512→1024. Requires 4× memory → reduce batch size or use gradient accumulation. 3. Option B (interpolation trick): wrap model in upscale/downscale: input 512 → upsample to 1024 → model → downsample to 512. This increases compute but not memory (model stays at native resolution). 4. Option C (intelligent cropping): use sliding window with large overlap (50%) focused on non-empty regions (detect with low-res pass first).

```python
# Option B: Interpolation wrapper (from 5th place blood vessel solution)
import torch.nn.functional as F

class UnetUpscale(nn.Module):
    def __init__(self, base_model, upscale_factor=2):
        super().__init__()
        self.model = base_model
        self.upscale_factor = upscale_factor
    
    def forward(self, x):
        # x shape: (B, C, H, W) at base resolution
        H, W = x.shape[2:]
        # Upsample input
        x_upscaled = F.interpolate(
            x, size=(H * self.upscale_factor, W * self.upscale_factor),
            mode='bilinear', align_corners=False
        )
        # Predict at high resolution
        pred_upscaled = self.model(x_upscaled)
        # Downsample output back to original resolution
        pred = F.interpolate(
            pred_upscaled, size=(H, W),
            mode='bilinear', align_corners=False
        )
        return pred

# Option C: Intelligent sliding window
from monai.inferers import sliding_window_inference

def predict_with_sliding_window(model, image, roi_size=512, overlap=0.5):
    # First pass: low-res to find non-empty regions
    image_lowres = F.interpolate(image, scale_factor=0.5, mode='bilinear')
    mask_lowres = model(image_lowres) > 0.1  # Rough mask
    
    # Crop around non-empty regions with sliding window
    predictions = sliding_window_inference(
        inputs=image,
        roi_size=(roi_size, roi_size),
        sw_batch_size=4,
        predictor=model,
        overlap=overlap,
        mode='gaussian'  # Gaussian blending at overlaps
    )
    return predictions
```
