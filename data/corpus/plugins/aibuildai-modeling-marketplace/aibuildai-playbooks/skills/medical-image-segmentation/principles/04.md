## Principle 4: Select Loss Functions That Align With the Evaluation Metric

*Consensus: Most source competitions; combinations dominate single losses*

Combine multiple loss terms that directly optimize for the competition metric: Dice for overlap, boundary-weighted losses for surface metrics, focal for class imbalance.

**Why this matters:** Dice coefficient evaluates overlap, but surface Dice penalizes boundary errors. BCE alone produces blurry edges. Focal loss handles extreme class imbalance (99% background in some datasets). A single loss rarely captures all metric nuances; combinations provide complementary gradients.

**When to use:** Always use combinations. For Dice metric: BCE + Dice. For surface Dice or boundary-sensitive metrics: add boundary loss (weight edges 2-5×) or custom surface-aware loss. For instance segmentation with IoU thresholds: add focal (alpha=0.25, gamma=2) to handle hard examples.

**When NOT to use:** Avoid complex custom losses if you cannot validate their benefit on a reliable holdout. Do not add boundary losses if your metric is pure Dice without boundary weighting.

**How to reason about it:**
1. Read metric definition: Dice? Surface Dice? IoU at multiple thresholds? 2. Base loss = BCE (pixel-wise) + Dice (global overlap). 3. If metric includes boundary: add boundary loss weighted 2-5× (compute edge pixels via morphological operations). 4. If severe class imbalance (>95% background): add focal loss. 5. Tune weights via grid search on validation: try (BCE:Dice:Boundary) = (1:1:0), (1:1:2), (1:3:5). 6. For surface metrics, consider implementing the metric itself as a differentiable loss.

```python
# Combo loss for surface Dice metric
import torch
import torch.nn.functional as F

class BoundarySurfaceLoss(nn.Module):
    def __init__(self, bce_weight=1.0, dice_weight=1.0, boundary_weight=2.0):
        super().__init__()
        self.bce_w = bce_weight
        self.dice_w = dice_weight
        self.boundary_w = boundary_weight
    
    def forward(self, preds, targets):
        # BCE
        bce = F.binary_cross_entropy_with_logits(preds, targets)
        
        # Dice
        preds_sigmoid = torch.sigmoid(preds)
        intersection = (preds_sigmoid * targets).sum()
        dice_loss = 1 - (2 * intersection + 1) / (preds_sigmoid.sum() + targets.sum() + 1)
        
        # Boundary-weighted BCE (dilate mask to get boundary region)
        from scipy.ndimage import binary_dilation
        boundaries = binary_dilation(targets.cpu().numpy(), iterations=2) ^ targets.cpu().numpy()
        boundaries = torch.from_numpy(boundaries).to(targets.device)
        boundary_bce = F.binary_cross_entropy_with_logits(
            preds, targets, reduction='none'
        )
        boundary_loss = (boundary_bce * (1 + self.boundary_w * boundaries)).mean()
        
        return self.bce_w * bce + self.dice_w * dice_loss + self.boundary_w * boundary_loss
```
