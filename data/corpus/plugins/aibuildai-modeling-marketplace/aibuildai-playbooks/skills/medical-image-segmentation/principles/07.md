## Principle 7: Ensemble Multi-Scale TTA and Multi-Axis Predictions for Robust Inference

*Consensus: 7/7 competitions use TTA; multi-axis inference recurs in the 3D blood vessel competition*

At inference, augment test images with flips/rotations (TTA), predict at multiple scales, and for 3D data, predict along x/y/z axes independently, then ensemble all predictions.

**Why this matters:** Medical structures are orientation-agnostic, so horizontal/vertical flips and 90° rotations are free augmentation. Multi-scale inference captures objects at different resolutions (small vessels vs large organs). Multi-axis inference for 3D data averages out anisotropic artifacts and improves small-object detection (a vessel missed on one axis is caught on another).

**When to use:** Always. Standard TTA: h-flip, v-flip, 90°/180°/270° rotations (D4 group, 8 variants). Multi-scale: 3 scales spanning 0.8×-1.2× of training size. Multi-axis: for any 3D data, even if using 2.5D models (slice along x, y, z axes).

**When NOT to use:** Skip TTA only if inference time is severely limited (<1 min) and single-model performance is sufficient. Skip multi-scale if your training already covers wide scale augmentation and test scale is known. Do not skip multi-axis for 3D data—it consistently improves scores.

**How to reason about it:**
1. Implement TTA with 8-fold D4 transforms (identity, h-flip, v-flip, rot90/180/270, h-flip+rot90, v-flip+rot90). 2. For each transform, predict and inverse-transform the prediction back to original orientation, then average. 3. Add multi-scale: resize test image to [0.8×, 1.0×, 1.2×] of training size, predict, resize predictions back to original, average. 4. For 3D: reslice volume along each axis (XY, XZ, YZ planes), apply 2D model, merge predictions by averaging or taking max. 5. Final ensemble: average all TTA × scale × axis predictions.

```python
# D4 TTA for 2D
import cv2
def predict_with_tta(model, image):
    preds = []
    for flip_code in [None, 0, 1]:  # None, h-flip, v-flip
        for k in range(4):  # 0, 90, 180, 270 degrees
            img_aug = image.copy()
            if flip_code is not None:
                img_aug = cv2.flip(img_aug, flip_code)
            img_aug = np.rot90(img_aug, k)
            pred = model(img_aug)
            # Inverse transform
            pred = np.rot90(pred, -k)
            if flip_code is not None:
                pred = cv2.flip(pred, flip_code)
            preds.append(pred)
    return np.mean(preds, axis=0)

# Multi-scale + multi-axis for 3D
def predict_3d_multiscale_multiaxis(model, volume):
    scales = [0.8, 1.0, 1.2]
    axes = ['xy', 'xz', 'yz']
    all_preds = []
    for scale in scales:
        vol_resized = resize_volume(volume, scale)
        for axis in axes:
            slices = reslice_volume(vol_resized, axis)
            preds_axis = [model(s) for s in slices]
            preds_3d = reconstruct_volume(preds_axis, axis)
            preds_3d = resize_volume(preds_3d, 1.0/scale)  # Back to original
            all_preds.append(preds_3d)
    return np.mean(all_preds, axis=0)
```
