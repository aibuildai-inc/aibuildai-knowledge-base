## Principle 9: Use Instance Segmentation When Objects Must Be Individually Counted or Tracked

*Consensus: 3/3 instance segmentation competitions (cells, nuclei)*

Choose instance segmentation (Mask R-CNN, YOLOX) over semantic segmentation (U-Net) when the task requires distinguishing individual objects, counting them, or when metric penalizes merged instances.

**Why this matters:** Semantic segmentation produces a single mask per class, merging touching objects. Instance segmentation assigns each object a unique ID. If the metric is mAP@IoU thresholds or counts individual cells, merged objects count as one false positive and multiple false negatives, destroying your score.

**When to use:** When: (a) metric is mAP, instance-wise IoU, or object count, (b) targets are discrete objects (cells, nuclei, organs) that can touch/overlap, (c) you need to track objects across frames. Use Mask R-CNN for <1000 objects/image, YOLOX/YOLO for >1000 small objects, or U-Net + watershed post-processing as a lightweight alternative.

**When NOT to use:** Use semantic segmentation when: (a) metric is per-pixel Dice without instance distinction, (b) targets are non-discrete (vessels, tissue regions), (c) objects are so densely packed that bounding boxes are not meaningful.

**How to reason about it:**
1. Check metric definition: does it say 'instance', 'mAP', 'per-object'? Yes → instance segmentation. 2. Count typical objects per image: <100 → Mask R-CNN (box-based), >1000 → YOLOX or semantic + watershed. 3. If choosing semantic + watershed: predict (a) mask, (b) instance centers (3×3 patches), (c) boundary map. At inference, watershed from centers on (mask - boundary). 4. For Mask R-CNN: focus on box detector quality (mAP@bbox often predicts mAP@mask); use strong backbones (ConvNeXt, EfficientNet); pretrain on similar data (e.g., LIVECell for cells).

import cv2
from scipy.ndimage import label

def unet_to_instances(model, image):
    # Model outputs: (mask, centers, boundary)
    mask, centers, boundary = model(image)
    
    # Threshold
    mask_binary = (mask > 0.4).astype(np.uint8)
    centers_binary = (centers > 0.5).astype(np.uint8)
    
    # Find seeds from centers (connected components with area ~9)
    seeds, _ = label(centers_binary)
    
    # Watershed from seeds on (mask - boundary)
    distance = mask - boundary
    instances = cv2.watershed(distance, seeds)
    
    return instances
