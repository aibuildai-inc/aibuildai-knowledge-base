## Principle 6: Validate on Splits That Match Test Distribution, Not Random Folds

*Consensus: Most source competitions; random folds caused overfitting in several cases*

Create validation splits that mirror test set characteristics: same resolution, annotation quality, organ/cell type, or imaging protocol. Avoid random splits when test has known distributional differences.

**Why this matters:** A random fold averages over all domains, giving inflated CV scores when test is from a single domain. If test is kidney at 63um and validation is mixed kidneys at 50um, you'll overestimate performance. Validation must be a proxy for the private test to guide model selection and hyperparameter tuning.

**When to use:** Always. Specifically: (a) if test resolution is disclosed, validate on that resolution or downsample validation data to match, (b) if test is a specific organ/cell type, validate on that type only, (c) if test is from a different protocol (HuBMAP vs HPA), validate on a HuBMAP-only fold.

**When NOT to use:** Random folds are acceptable only if train and test are IID from the same distribution with no disclosed differences.

**How to reason about it:**
1. List known test characteristics (resolution, organ, stain, annotation density). 2. Filter training data to create a validation set matching those characteristics. 3. If insufficient data for a clean split, simulate test conditions: downsample high-res to test resolution, apply test-stain normalization. 4. If no info on test: use stratified folds by metadata (organ, patient, resolution). 5. Monitor public LB vs CV correlation: if LB improves but CV doesn't, your validation is misaligned.

```python
# Example: validate on test-like subset
train_data = load_data()

# Disclosed: private test is kidney at 63um, dense annotations
val_candidates = [
    sample for sample in train_data 
    if sample.organ == 'kidney' 
    and sample.resolution_um == 50.0  # Closest to 63
    and sample.annotation_density > 0.9  # Dense like test
]

# If needed, downsample to match test resolution
val_data = [downsample_to_63um(s) for s in val_candidates]
train_data = [s for s in train_data if s not in val_candidates]

# Alternative: if no metadata, stratify by multiple factors
from sklearn.model_selection import StratifiedKFold
stratify_key = train_data['organ'] + '_' + train_data['resolution_bin']
folds = StratifiedKFold(n_splits=5).split(train_data, stratify_key)
```
