## Principle 3: Use Pseudo-Labeling to Refine Sparse Annotations or Bridge Domain Gaps

*Consensus: 5/7 competitions, especially those with sparse/mixed-quality labels*

Train on densely-labeled data, generate predictions on sparse/unlabeled data, then retrain with combined real + pseudo labels to improve coverage and domain adaptation.

**Why this matters:** Medical annotations are expensive and often incomplete (e.g., 65% of a kidney annotated). Pseudo-labels fill gaps and provide weak supervision. They also help bridge domain shifts (e.g., different organs, stains, or protocols) by letting the model self-teach on target-domain data.

**When to use:** When: (a) training data is partially annotated (sparse labels explicitly mentioned), (b) external data exists from similar but not identical domains, (c) test distribution differs from train (different organ, stain, or protocol). Apply iteratively: densely-labeled → pseudo on sparse → retrain → pseudo on external → final train.

**When NOT to use:** Skip if: all training data is densely and accurately labeled, your initial model has low confidence (<0.6 Dice) on validation, or pseudo labels risk amplifying systematic errors (e.g., class imbalance).

**How to reason about it:**
1. Train baseline on dense labels only. 2. Generate pseudo labels on sparse data; threshold by confidence (start conservative: 0.8+) or match known annotation density (e.g., if 65% annotated, select top 65% by pixel count). 3. Retrain with dense + pseudo, using soft labels (probabilities) or lower loss weight for pseudo. 4. Validate that pseudo-added model beats dense-only on a dense holdout. 5. Iterate: use improved model for next round of pseudo labels with stricter thresholds (0.95).

```python
# Multi-stage pseudo-labeling
# Stage 1: train on dense data
model_v1 = train(data=dense_data)

# Stage 2: pseudo-label sparse data
pseudo_masks = []
for img in sparse_data:
    pred = model_v1.predict(img)  # Soft probabilities
    # Threshold by confidence OR match known annotation %
    if sparse_data.annotation_pct == 0.65:
        threshold = np.percentile(pred, 35)  # Keep top 65%
    else:
        threshold = 0.8
    pseudo_masks.append((pred > threshold).astype(float))

# Stage 3: retrain with weighted loss
model_v2 = train(
    data=dense_data + sparse_data,
    masks=dense_masks + pseudo_masks,
    weights=[1.0]*len(dense_data) + [0.65]*len(sparse_data)  # Lower weight for pseudo
)

# Stage 4: iterate with stricter threshold
pseudo_masks_v2 = [model_v2.predict(img) > 0.95 for img in external_data]
model_final = train(dense + sparse + external, ...)
```
