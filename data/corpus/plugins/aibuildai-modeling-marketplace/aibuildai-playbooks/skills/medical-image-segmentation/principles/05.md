## Principle 5: Apply Domain-Specific Stain/Intensity Normalization to Bridge Protocol Gaps

*Consensus: Competitions with multi-protocol data (HPA vs HuBMAP, different stains)*

When training and test images come from different acquisition protocols or staining methods, normalize images to a common color/intensity space or augment heavily on intensity to force invariance.

**Why this matters:** Histology images vary wildly by stain (H&E vs PAS vs DAB), scanner, and lab protocol. Models trained on one stain fail on another because color distributions differ. Stain normalization (Reinhard, Vahadane) transforms images to a reference appearance, making the model protocol-agnostic.

**When to use:** When: (a) train and test come from different consortia/labs/protocols (e.g., HPA vs HuBMAP), (b) training data includes multiple staining methods, (c) heavy intensity augmentation alone doesn't close the gap (validate on cross-protocol splits).

**When NOT to use:** Skip if all data is from a single imaging protocol (e.g., all X-rays from one scanner type). Also skip if targets are independent of appearance (e.g., shape-based cell detection may not need it).

**How to reason about it:**
1. Identify if train/test protocols differ (read data description, check histograms). 2. During training: randomly apply stain normalization (Reinhard/Vahadane) to HPA images using a HuBMAP reference, so model sees both domains. 3. During inference on HuBMAP test: normalize to HPA reference (reverse direction) and average predictions with un-normalized. 4. Pair this with heavy intensity augmentation (RandomBrightnessContrast, RandomGamma, p=1.0). 5. Validate on a cross-stain split: train on stain A, test on stain B.

```python
# Stain normalization with staintools
import staintools

# Training: normalize HPA to HuBMAP reference
hubmap_ref = staintools.LuminosityStandardizer.standardize(hubmap_image)
normalizer = staintools.StainNormalizer(method='vahadane')
normalizer.fit(hubmap_ref)

def augment_with_stain(hpa_image):
    if np.random.rand() < 0.5:
        # Normalize to HuBMAP appearance
        return normalizer.transform(hpa_image)
    else:
        # Keep original
        return hpa_image

# Inference: ensemble normalized + original
import albumentations as A
intensity_aug = A.Compose([
    A.RandomBrightnessContrast(p=1.0),
    A.RandomGamma(p=0.8),
])

def predict_with_stain_ensemble(model, test_image, hpa_ref):
    # Original prediction
    pred_orig = model(test_image)
    
    # Normalize to HPA and predict
    normalizer_inv = staintools.StainNormalizer(method='vahadane')
    normalizer_inv.fit(hpa_ref)
    test_normalized = normalizer_inv.transform(test_image)
    pred_norm = model(test_normalized)
    
    return (pred_orig + pred_norm) / 2
```
