## Principle 7: Use Measurement Uncertainty Without Throwing Away Most Labels

*Consensus: 5/5 top Ribonanza solutions used filtering, sampling, masking, or weighting based on signal-to-noise and per-position errors.*

Treat experimental quality as graded information. Mask irrecoverable positions, but retain moderately noisy sequences through error-aware loss weights, quality-weighted sampling, or a noisy-to-clean fine-tuning curriculum.

**Why this matters:** Whole-sequence filtering discards reliable positions because of a few bad measurements. Conversely, treating every assay value as exact causes noisy profiles and overrepresented clusters to dominate gradients.

**When to use:** Use uncertainty-aware training when the dataset supplies reactivity errors, read counts, signal-to-noise, or quality filters. It is particularly useful when clean data are scarce.

**When NOT to use:** Do not assume one universal weighting formula. Some Ribonanza solutions found direct loss weighting weaker than quality-weighted sampling, while others benefited from inverse-error weights. If uncertainty estimates are poorly calibrated, aggressive weights can suppress useful signal.

**How to reason about it:**
Inspect uncertainty at both sequence and position level. Compare: clean-only training, position masking, sequence sampling, and broad-data pretraining followed by clean-data fine-tuning. Select using a clean validation set because that best approximates the scored population.

```python
def masked_uncertainty_loss(pred, target, error, valid, eps=1e-3):
    # Customize clipping after checking calibration of the supplied errors.
    weight = 1.0 / (error.clamp_min(eps).sqrt() + 0.1)
    weight = weight.clamp(max=10.0) * valid
    return (weight * (pred - target).abs()).sum() / weight.sum().clamp_min(1.0)
```
