## Principle 12: Route Models and Compute Per Target

*Consensus: 8/9 reviewed leading 3D solutions used length-, template-, runtime-, or confidence-dependent routing; Part 2 pipelines made this especially explicit under the eight-hour notebook limit.*

Treat inference as a budgeted decision system. Route each target according to template confidence, sequence length, chain complexity, model memory limits, and remaining runtime, with fast fallbacks that always produce a valid submission.

**Why this matters:** 3D inference cost grows sharply with length and diffusion samples, while model strengths are heterogeneous. Uniformly running the most expensive model wastes budget on easy template-rich targets and may leave hard or long targets unfinished.

**When to use:** Use routing in code competitions, mixed-length datasets, and ensembles containing TBM plus large diffusion or refinement models. Chunk only when the model cannot process the whole molecule and overlap alignment is validated.

**When NOT to use:** Avoid routing from unstable public-LB heuristics alone. Hard thresholds can create discontinuities, and chunking can destroy global tertiary contacts; a full-length template may be preferable for very long RNAs.

**How to reason about it:**
Estimate cost and expected gain for every target-model pair, reserve a safety margin, and solve a simple benefit-per-second allocation. Cache template search and embeddings, parallelize independent targets, and write an intermediate valid submission before expensive refinement.

```python
def route(target, budget):
    plan = ["fast_template"]  # valid fallback first
    if target.template_confidence < 0.8 and target.length <= budget.neural_max_len:
        plan.append("neural_generator")
    if target.length <= budget.refiner_max_len and budget.seconds_left > target.refine_cost:
        plan.append("template_conditioned_refiner")
    if target.length > budget.neural_max_len:
        plan.append("validated_chunking_or_tbm_only")
    return plan
```
