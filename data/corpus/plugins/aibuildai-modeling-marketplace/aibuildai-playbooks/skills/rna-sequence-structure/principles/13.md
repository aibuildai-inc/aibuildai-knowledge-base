## Principle 13: Post-Process According to Candidate Provenance and the Metric

*Consensus: All leading TBM pipelines repaired gaps and local geometry, while several neural-model writeups reported that extra coordinate constraints or averaging made predictions worse.*

Repair template-transferred coordinates with chain-aware interpolation, realistic consecutive-residue distances, light smoothing, and confidence-scaled constraints. For neural outputs, prefer validity checks and candidate selection over aggressive geometry rewriting or coordinate averaging.

**Why this matters:** Template gaps create broken backbones, but a strong neural generator has already learned molecular geometry and can be damaged by generic smoothing. Averaging two aligned but distinct folds can produce a structure that resembles neither and scores worse under best-of-five TM-score.

**When to use:** Use geometry repair after coordinate transfer, truncation, chunk stitching, or missing-residue filling. Use Kabsch alignment before comparing candidates, and clip coordinates only as required by the submission format.

**When NOT to use:** Do not average coordinate candidates merely because they are individually strong; average only a tight structural cluster validated to represent the same conformation. Do not add fake bonds across chain breaks or heavily refine a high-confidence template.

**How to reason about it:**
Tag every candidate by provenance. TBM candidates receive confidence-scaled repair; chunked candidates receive overlap alignment and blending; neural candidates receive collapse/clash checks and little else. Evaluate post-processing with the exact competition metric, not visual smoothness.

```python
def postprocess(candidate):
    if candidate.source == "template_transfer":
        xyz = fill_alignment_gaps(candidate.xyz, candidate.chain_ids)
        return light_geometry_repair(xyz, strength=1 - candidate.confidence)
    if candidate.source == "chunked_neural":
        return align_and_blend_overlaps(candidate.chunks)  # Kabsch on overlap
    if candidate.source == "neural":
        return candidate.xyz if passes_validity_checks(candidate.xyz) else candidate.fallback
    return candidate.xyz
```
