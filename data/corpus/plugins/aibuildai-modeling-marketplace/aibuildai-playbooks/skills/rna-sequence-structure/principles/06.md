## Principle 6: Validate on the Same Kind of Novelty the Hidden Set Contains

*Consensus: All 3 competition families exposed major random-split failure modes: sequence duplication, cluster imbalance, temporal leakage, longer hidden RNAs, or newly synthesized targets.*

Construct validation around homology clusters, temporal cutoffs, length bands, assay quality, and chain composition rather than relying only on random folds. Maintain more than one holdout when the private set may combine several shifts.

**Why this matters:** Near-duplicate RNA sequences and structures make random validation measure denoising or memorization rather than generalization. Temporal leakage is particularly damaging in 3D prediction because a released PDB structure can turn a hard target into trivial template copying.

**When to use:** Use cluster and temporal splits for natural RNA and structure databases; use length and design-family holdouts for synthetic libraries; add assay-quality strata for experimental profiles.

**When NOT to use:** A random fold is still useful for fast iteration if its ranking is proven to correlate with stricter holdouts, as the Ribonanza winner observed. It should not be the only evidence when target novelty is known.

**How to reason about it:**
Create a validation matrix rather than one score: random fold, cluster holdout, longest-length holdout, temporal holdout, and low-template-confidence subset. Promote changes that are stable across the axes most similar to the hidden evaluation; diagnose public-LB gains that conflict with those holdouts as potential leakage or overfitting.
