## Principle 8: Ablate Biological Side Information by Regime, Not by Feature Count

*Consensus: All three competitions tested BPP, secondary structure, MSA, language-model embeddings, or external folds, but their value differed sharply by data regime and model.*

Add side information only when it supplies a missing signal: BPP for long-range pairing, MSA for evolutionary covariation, language-model embeddings for remote homology, or secondary structure for template alignment. Evaluate information sources as replaceable priors rather than accumulating every available feature.

**Why this matters:** Correlated folding engines often repeat the same errors and increase compute without adding information. Synthetic designed RNAs may have weak evolutionary MSAs, whereas natural 3D targets can benefit from them; the value of engineered folds can also change with the size of the labeled dataset, so re-ablate them for each regime.

**When to use:** Use BPP when pair state drives the target, MSA when homolog depth and diversity are adequate, and pretrained embeddings when labeled structural data are scarce or remote-homology search is important.

**When NOT to use:** Skip expensive MSA generation for synthetic or shallow families if no-MSA validation is equal or better. Do not add multiple BPP packages merely for nominal diversity; several top Ribonanza solutions found EternaFold alone sufficient, and Part 2 solutions reported mixed MSA gains.

**How to reason about it:**
For each side channel ask: Does it contain information unavailable from sequence? Is it available identically at hidden inference? Is its quality stable across length and novelty? Does it improve the hard holdout, not just random CV? Keep a sequence-only path or candidate as insurance against prior failure.

```python
def choose_side_inputs(stats):
    inputs = ["sequence"]
    if stats.bpp_validated_on_shift:
        inputs.append("bpp")
    if stats.msa_depth >= stats.min_depth and stats.msa_diversity >= stats.min_diversity:
        inputs.append("msa")
    if stats.remote_homology_problem:
        inputs.append("foundation_embedding")
    return inputs
```
