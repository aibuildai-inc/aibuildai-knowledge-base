## Principle 2: Represent Both Backbone Neighborhoods and Long-Range Pairing

*Consensus: 5/5 top Ribonanza solutions reviewed used an explicit combination of local sequence processing and pair/graph information.*

For per-nucleotide prediction, maintain a 1D residue stream for local chemistry and a 2D pair stream or graph for nonlocal interactions. Inject base-pair probabilities, secondary-structure edges, or learned pair features into attention rather than reducing RNA to a plain token string.

**Why this matters:** Adjacent nucleotides interact through the covalent backbone, but bases far apart in sequence can become neighbors after folding. Convolutions or recurrent blocks capture local motifs, while pair-biased attention or graph propagation gives short computational paths between paired residues.

**When to use:** Use this design when reliable BPP matrices, dot-bracket structures, pair edges, or learned pair representations exist. It is especially valuable for reactivity targets whose values depend on whether a base is protected by pairing.

**When NOT to use:** Do not hard-code a weak folding engine as unquestioned truth. If BPP quality shifts across domains, retain sequence-only heads or layers and let the model attenuate the pair prior; several Ribonanza solutions found additional folding packages redundant or harmful after a strong EternaFold BPP was present.

**How to reason about it:**
Treat pair information as a prior, not a label. Compare sequence-only, pair-summary, raw pair-bias, and learned 2D-pair-stream variants. If gains disappear on homology- or length-shifted validation, reduce the number of pair-biased layers or blend with a sequence-only model.

```python
def pair_biased_attention(q, k, v, bpp, pair_net, mask=None):
    logits = q @ k.transpose(-1, -2) / q.size(-1) ** 0.5
    pair_bias = pair_net(bpp[:, None]).permute(0, 1, 2, 3)  # customize channels=heads
    logits = logits + pair_bias
    if mask is not None:
        logits = logits.masked_fill(~mask, float("-inf"))
    return logits.softmax(-1) @ v
```
