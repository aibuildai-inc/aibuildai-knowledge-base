## Principle 1: Choose the Modeling Regime from the Output Geometry and Metric

*Consensus: 3/3 competitions support this split; the profile competition converged on sequence/pair encoders, while both 3D competitions required coordinate-producing or coordinate-transferring pipelines.*

First classify the task as per-residue scalar prediction or 3D structure prediction. Use a sequence-plus-pair encoder for scalar profiles; for 3D, use template transfer, geometric/diffusion models, or a hybrid, because coordinates are meaningful only up to rigid alignment and must form a coherent molecule.

**Why this matters:** A scalar loss such as MAE or columnwise RMSE decomposes over positions and can tolerate direct regression. TM-score instead evaluates the global fold after alignment, so independent coordinate regression can minimize local error while producing an impossible or globally wrong structure.

**When to use:** Use the profile branch when targets are chemical reactivities or other per-position measurements. Use the 3D branch when the submission contains atom coordinates and scoring performs structural alignment.

**When NOT to use:** Do not force a single architecture across both branches. A graph regressor is not automatically a viable 3D generator, while a costly equivariant diffusion model is unnecessary when only scalar profiles are scored.

**How to reason about it:**
Ask in order: (1) What object is scored—scalars, contacts, or coordinates? (2) Is the metric positionwise or alignment-based? (3) Are multiple conformations rewarded? (4) Does the prediction need to obey chain continuity and steric constraints? These answers determine the representation and inference strategy before model tuning begins.

```python
def choose_regime(target_kind, metric):
    if target_kind == "per_residue_scalar":
        return {"encoder": "sequence_plus_pair", "head": "masked_regression"}
    if target_kind == "coordinates" and metric in {"tm_score", "rmsd"}:
        return {"pipeline": "template_neural_hybrid", "head": "geometric_generator"}
    raise ValueError("Inspect the target geometry and metric before choosing a model")
```
