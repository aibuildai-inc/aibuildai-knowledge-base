## Principle 5: Model Chains, Copies, and Molecular Context Explicitly

*Consensus: 5/6 reviewed Part 2 solutions explicitly handled chain segmentation, chain matching, per-chain constraints, or chain-aware long-sequence inference; the metric itself permuted equivalent chains.*

Parse stoichiometry and all molecular chains before alignment or inference. Distinguish backbone adjacency from chain membership, match query and template chains without assuming input order, and never create artificial bonds across chain breaks.

**Why this matters:** Concatenation makes unrelated chain endpoints appear adjacent and can corrupt attention masks, geometric refinement, and template transfer. Repeated chains also make chain order non-identifiable, so a good monomer fold can still score poorly if assembly handling is wrong.

**When to use:** Use chain-aware logic for multimers, repeated copies, RNA–protein/DNA complexes, or metrics that permute chains. Consider Hungarian assignment over pairwise chain-alignment scores when template and query chain order may differ.

**When NOT to use:** For guaranteed single-chain profile regression, elaborate assembly machinery adds no value. Also avoid hallucinating partner coordinates when only the target RNA is scored; use partner context as input only if it is legal and demonstrably informative.

**How to reason about it:**
Separate three questions: Which chains are predicted? Which partners influence folding? Which chains are equivalent under scoring? Build masks and template assignments from those answers, then validate chain breaks and residue numbering before evaluating model quality.

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def assign_chains(query_chains, template_chains, align_score):
    scores = np.array([[align_score(q, t) for t in template_chains]
                       for q in query_chains])
    q_idx, t_idx = linear_sum_assignment(-scores)  # maximize compatibility
    return list(zip(q_idx, t_idx))
```
