## Principle 12: Handle Missing or Unreliable Sensor Data via Uncertainty Weighting

*Consensus: 2/2 top indoor navigation solutions, 1/1 GNSS solution with quality analysis*

Track sensor reliability (signal strength, dropout rate, historical error) and weight predictions inversely by uncertainty. For discrete optimization, scale penalties by inverse variance. For missing modalities, rely on available sensors rather than imputing.

**Why this matters:** Real-world sensors fail intermittently. WiFi drops in corridors, GPS is noisy near buildings, magnetometers drift near metal. Fixed weights assume constant reliability, but sensor quality varies by location and time. Indoor navigation: weighting WiFi predictions by signal quality and time-since-seen improved scores significantly.

**When to use:** Multi-sensor fusion in noisy real-world conditions. Indoor navigation (WiFi dropout), GNSS (multipath, obstruction), autonomous vehicles (occlusion, weather). When sensor metadata includes quality indicators (RSSI, SNR, uncertainty estimates).

**When NOT to use:** Clean simulation data with perfect sensors. Single-modality tasks. If uncertainty estimates are unreliable or uncalibrated (model confidence is often overconfident), fixed weights may be safer.

**How to reason about it:**
Can you estimate per-prediction uncertainty? WiFi: use signal strength + time decay. GNSS: use DOP (dilution of precision), SNR. Sensor: use variance of recent history. In optimization: penalty_weight = base_weight / (uncertainty^2). For dropout: detect missing data (NaN, timestamp gaps) and set weight to 0 or use fallback modality. Tune base weights on validation.

```python
# Uncertainty-weighted WiFi penalty (indoor navigation)
def wifi_penalty(predicted_pos, wifi_obs, waypoints):
    knn_results = wifi_knn(wifi_obs, waypoints)  # returns (pos, uncertainty)
    
    penalties = []
    for pos, unc in knn_results:
        dist = euclidean(predicted_pos, pos)
        # Weight by inverse variance
        weight = 1.0 / (unc ** 2 + 1e-6)
        penalties.append(weight * dist)
    
    return np.mean(penalties)
```
