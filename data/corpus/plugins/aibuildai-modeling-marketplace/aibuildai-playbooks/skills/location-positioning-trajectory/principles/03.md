## Principle 3: Fuse Multi-Modal Data at the Prediction Level, Not Feature Level

*Consensus: 4/5 top indoor navigation solutions, 3/5 GNSS solutions*

Build separate models for each data modality (WiFi, sensors, magnetic field, GPS) and combine their predictions via weighted averaging, discrete optimization, or GMM ensemble rather than concatenating raw features into a single model.

**Why this matters:** Different modalities have different noise characteristics, update rates, and failure modes. WiFi gives absolute position but is coarse and sparse; IMU sensors give smooth relative motion but drift over time; GNSS is globally consistent but has outliers. Modality-level fusion lets you weight predictions by reliability and handle missing modalities gracefully.

**When to use:** When you have 2+ distinct sensor types with different semantics: absolute position sources (WiFi, GPS) + relative motion sources (accelerometer, gyro) + orientation sources (magnetometer, compass). Indoor navigation, smartphone positioning, autonomous vehicles.

**When NOT to use:** Pure trajectory prediction from homogeneous data (video frames, single sensor stream) doesn't benefit—just feed all frames to one model. If modalities are tightly synchronized and semantically similar, early fusion can work (e.g., RGB + semantic maps in rasterization).

**How to reason about it:**
Ask: can this modality fail independently? (WiFi drops in corridors, GPS fails indoors, magnetometer drifts near metal). If yes, separate models. Train each to convergence, then ensemble with weights proportional to inverse error variance. For hybrid tasks, use absolute predictions to anchor and relative predictions to interpolate.

```python
# Multi-modal fusion in indoor navigation
wifi_pred = wifi_knn_model.predict(wifi_features)  # absolute position
sensor_delta = sensor_model.predict(imu_data)  # relative displacement
mag_angle = magnetometer_model.predict(mag_data)  # direction

# Fuse via discrete optimization penalties
penalty = (alpha * dist(pos, wifi_pred) + 
           beta * angle_diff(delta, mag_angle) + 
           gamma * dist(delta, sensor_delta))
```
