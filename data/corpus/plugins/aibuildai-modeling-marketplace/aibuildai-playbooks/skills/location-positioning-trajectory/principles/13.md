## Principle 13: Generate Additional Waypoints for Discrete Optimization

*Consensus: 2/2 top indoor navigation solutions*

For indoor navigation, augment the training waypoint grid by procedurally generating plausible waypoints along walls, in corridors, and at intersections. Use distance statistics from training data to place points at realistic intervals.

**Why this matters:** Training waypoints are sparse—they cover only ~85% of test positions. Without generated waypoints, discrete optimization is forced to pick suboptimal training points, adding error. Generated waypoints fill gaps while respecting building structure (walls, corridors).

**When to use:** Indoor navigation with floor plans (GeoJSON, maps). Any grid-based discrete optimization where test data falls between training points. The test distribution is similar to training but not identical.

**When NOT to use:** If >95% of test positions match training positions exactly, generation adds noise without benefit. Open-space trajectories (roads, fields) have infinite possible positions—don't generate a dense grid, use continuous optimization instead. If you lack map data (walls, corridors), procedural generation is unreliable.

**How to reason about it:**
What fraction of test data matches training waypoints? <90% → generate. Do you have map constraints (walls, corridors)? Yes → generate along walls and in open spaces. Steps: (1) identify walls from floor plan, (2) place points at regular intervals along walls (use training data stats for spacing), (3) fill corridor centers, (4) de-duplicate too-close points. Ensemble multiple grids (sparse, dense) to balance coverage vs noise.

```python
# Waypoint generation (simplified)
def generate_waypoints(floor_geojson, train_waypoints):
    walls = extract_walls(floor_geojson)
    
    # Statistics from training data
    wall_spacing = np.percentile(wall_distances(train_waypoints), 50)  # e.g., 2m
    
    generated = []
    for wall in walls:
        # Place points along wall at typical spacing
        for dist in np.arange(0, wall.length, wall_spacing):
            point = wall.interpolate(dist)
            generated.append((point.x, point.y))
    
    # De-duplicate: remove generated points too close to training points
    final = [p for p in generated 
             if min_distance(p, train_waypoints) > 0.5]
    
    return train_waypoints + final
```
