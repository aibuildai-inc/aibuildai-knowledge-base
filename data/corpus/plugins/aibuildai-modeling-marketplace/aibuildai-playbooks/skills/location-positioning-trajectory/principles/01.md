## Principle 1: Classify Problem Type to Choose Methodology

*Consensus: All competitions fall into 3 clusters, each requiring fundamentally different approaches*

Location tasks split into absolute positioning (predict static location from features), trajectory prediction (forecast future motion), and precision refinement (improve noisy position estimates). Your problem type determines whether you need classification/regression, sequence modeling, or optimization-based filtering.

**Why this matters:** Absolute positioning uses KNN/classification over discrete places; trajectory prediction needs temporal models (CNN/RNN/Transformer); precision refinement requires signal processing and global optimization (factor graphs, Kalman filters). Mixing methodologies wastes effort—a trajectory model won't work for check-in prediction.

**When to use:** Apply this classification first. Absolute positioning: predict which discrete location from coordinates/features (check-ins, location matching). Trajectory: predict future path from history (AV motion, sports). Precision refinement: raw GNSS/GPS signals need meter/decimeter accuracy (smartphone positioning).

**When NOT to use:** Indoor navigation is hybrid—combines absolute WiFi positioning with relative sensor-based trajectory tracking—so it needs BOTH methodologies working together via discrete optimization, not either alone.

**How to reason about it:**
Read the evaluation metric. MAP@K over discrete places → absolute positioning (classification). Distance error on future coordinates → trajectory prediction (regression). Percentile positioning error from raw signals → precision refinement (filtering/optimization). If the test set is trajectories with waypoint-level errors, it's hybrid.
