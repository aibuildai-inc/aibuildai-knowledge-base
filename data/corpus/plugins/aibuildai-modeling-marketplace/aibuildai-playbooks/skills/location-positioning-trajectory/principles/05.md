## Principle 5: Rasterize Spatial Context for CNN-Based Trajectory Prediction

*Consensus: 5/5 top Lyft solutions, 2/2 top autonomous driving solutions*

Convert vector map data (lane boundaries, agent positions, traffic lights) into multi-channel raster images (224×224 or 448×224 pixels) centered on the ego agent, then use pretrained CNNs (EfficientNet, ResNet, Xception) to predict future trajectories.

**Why this matters:** Rasterization provides translation/rotation invariance, leverages ImageNet pretraining (critical—saves ~1.0 on the metric), and handles variable numbers of agents naturally. Vector representations require custom architectures (GNNs, Transformers) that are harder to train and lack strong pretrained weights.

**When to use:** Autonomous vehicle trajectory prediction with map data and multiple agents. The spatial context (roads, lanes, nearby cars) matters more than exact agent count or fine-grained interactions. Large training sets (100M+ samples) are available.

**When NOT to use:** Small datasets can't fine-tune large CNNs effectively. If agent interactions are critical and variable (sports with 5–20 players), Graph Transformers handle permutation invariance better. Pure sequence tasks without spatial context (time-series prediction) don't need rasterization.

**How to reason about it:**
Can you represent the problem as a top-down image? (Yes for driving, maybe for sports). Will ImageNet pretraining help? (Yes if the spatial reasoning is generalizable). Is the context static enough to rasterize once? (Yes for maps, no for rapidly changing scenes). Start with baseline rasterization (semantic map + agent boxes), tune pixel size and image dimensions, optimize the rasterizer speed (4×+ gains possible).

# Rasterization config for Lyft competition
raster_params = {
    'raster_size': [448, 224],  # asymmetric: more forward context
    'pixel_size': [0.1875, 0.1875],  # meters per pixel
    'ego_center': [0.25, 0.5],  # ego at bottom 1/4 of image
    'history_frames': [0, 1, 2, 4, 8],  # non-uniform sampling
    'channels': ['semantic_map', 'agent_boxes', 'ego_box']
}
