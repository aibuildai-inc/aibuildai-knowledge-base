## Principle 9: Ensemble Multi-Mode Predictions via GMM or Set Transformer

*Consensus: 3/3 top Lyft solutions, 1/1 NFL multi-mode solution*

For trajectory prediction, output K diverse trajectory hypotheses (modes) with confidence scores. Ensemble multiple models by sampling their predictions and fitting a K-component Gaussian Mixture Model or training a Set Transformer to compress N×K modes into K final modes.

**Why this matters:** Traffic is inherently multi-modal—an agent can turn left, right, or go straight. Outputting a single trajectory (mean of modes) is penalized heavily by the negative log-likelihood metric. GMM ensembling preserves diversity while removing redundancy better than naive averaging.

**When to use:** Trajectory prediction competitions with multi-modal metrics (negative log-likelihood over K modes). When ensembling diverse models (different backbones, raster sizes) that produce overlapping but not identical mode distributions.

**When NOT to use:** Single-mode regression tasks (absolute positioning, single path prediction). If modes are already well-separated and diverse (rare), simple weighted averaging of confidences may suffice. GMM is overkill for 2-model ensembles—only helps with 3+ diverse models.

**How to reason about it:**
Does the metric reward multi-modal predictions? (Yes for Lyft NLL, no for simple MSE). Are individual model modes overlapping? (Yes if trained similarly). Sample M trajectories from each model's K modes (weighted by confidence), pool all M×N samples, fit K-component GMM with covariance fixed to metric's sigma. Alternatively, train Set Transformer to learn the optimal K modes from the pool.

```python
# GMM ensemble for Lyft (3 modes)
from sklearn.mixture import GaussianMixture

# Sample from each model
all_samples = []
for model in models:
    preds, confs = model.predict(X)  # preds: (N, 3, 50, 2), confs: (N, 3)
    for i in range(3):
        # Sample proportional to confidence
        n_samples = int(confs[:, i].mean() * 1000)
        all_samples.append(preds[:, i, :, :].repeat(n_samples, axis=0))

# Fit GMM
gmm = GaussianMixture(n_components=3, covariance_type='spherical')
gmm.fit(np.concatenate(all_samples))
final_modes = gmm.means_  # (3, 50, 2)
final_confs = gmm.weights_  # (3,)
```
