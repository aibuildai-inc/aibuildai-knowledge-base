## Principle 6: Handle Small-Sample Classes with Class-Specific Strategies

*Consensus: Critical in the majority of audio competitions analyzed (including BirdCLEF and rainforest species detection), 2/2 insurance/fraud tasks with rare events, and 1/1 particle physics (TrackML weighted rare tracks higher).*

When classes have imbalanced sample counts (common in niche domains: rare species, rare fraud patterns, rare particle types), split classes into groups and use different models, losses, thresholds, or data strategies for each group based on sample size and error tolerance.

**Why this matters:** A single global strategy optimizes for the majority class and ignores rare classes. BirdCLEF 3rd place divided birds into Group 1 (≥10 samples, BCE loss) and Group 2 (<10 samples, focal loss + hand-labeling). This split gave +0.02-0.03 improvement because small classes need conservative predictions (focal loss prevents false negatives) while large classes need confident predictions (BCE maximizes discrimination). Ignoring this asymmetry means either missing rare classes entirely or flooding predictions with false positives.

**When to use:** When class sample counts span 2+ orders of magnitude, when evaluation weights rare classes equally (macro F1, per-class AUC), when false negatives on rare classes are costly (endangered species, critical failures), or when you observe divergent per-class performance across models.

**When NOT to use:** When all classes have similar sample counts, when evaluation is micro-averaged (total accuracy, weighted metrics), when rare classes are noise not signal, or when you lack enough data to train separate models reliably.

**How to reason about it:**
Plot per-class OOF predictions for different loss functions. Do focal-loss models and BCE-loss models disagree systematically by class size? If yes, split classes into small/medium/large groups. For small classes: use focal loss, oversample, pseudo-label, or hand-label. For large classes: use BCE or CE. Tune thresholds per class or per group. Combine predictions at inference (different models for different classes).

```python
# BirdCLEF example: class-conditional model selection\nGROUP1_BIRDS = [b for b in all_birds if sample_count[b] >= 10]  # Large\nGROUP2_BIRDS = [b for b in all_birds if sample_count[b] < 10]   # Small\n\n# Train separate models\nmodel_group1 = train_with_bce_loss(data, classes=GROUP1_BIRDS)\nmodel_group2 = train_with_focal_loss(data, classes=GROUP2_BIRDS, oversample=True)\n\n# Inference: route to appropriate model\ndef predict(sample):\n    preds = {}\n    preds.update(model_group1.predict(sample, classes=GROUP1_BIRDS))\n    preds.update(model_group2.predict(sample, classes=GROUP2_BIRDS))\n    return preds
```
