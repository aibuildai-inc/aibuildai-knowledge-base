## Principle 9: Treat Threshold and Hyperparameter Selection as First-Class Modeling

*Consensus: Explicitly mentioned in 7/8 audio solutions (class-specific thresholds critical), 2/2 fraud tasks (threshold tuning as important as features), and optimization tasks (move sequence selection).*

Thresholds and hyperparameters are not post-processing tweaks; they are part of the model. Tune them per-class, per-group, or per-subproblem using validation data or distributional analysis, not global defaults.

**Why this matters:** Default thresholds (0.5) assume balanced classes and calibrated probabilities, both rare in niche domains. BirdCLEF 3rd place used threshold 0.05 for large classes, 0.35 for one specific bird, and per-bird 91st-percentile thresholds for small classes (from OOF distribution analysis). This gave +0.02-0.03 lift. Using global 0.5 would have missed most detections. Similarly, optimization winners tuned move-sequence selection criteria per puzzle type.

**When to use:** When classes are imbalanced, when probabilities are uncalibrated (common with focal loss or ensembles), when different classes have different cost profiles (false positive vs false negative costs vary), or when default hyperparameters underperform.

**When NOT to use:** When classes are balanced and probabilities are well-calibrated, when evaluation is rank-based (AUC) not threshold-based (F1, precision@k), or when you have so little validation data that threshold tuning is noisy.

**How to reason about it:**
Plot the OOF prediction distribution per class. Are the scales similar? If not, tune thresholds per class. Compute the optimal threshold per class on validation using your target metric. For large classes: use data-driven threshold (maximize F1 on validation). For small classes: use distributional threshold (91st percentile of non-target predictions) to control false positives. Store thresholds as part of your model config.

```python
# Per-class threshold tuning\ndef find_optimal_threshold(oof_preds, oof_labels, class_id):\n    thresholds = np.linspace(0.01, 0.99, 99)\n    best_f1, best_thr = 0, 0.5\n    for thr in thresholds:\n        pred_binary = (oof_preds[:, class_id] > thr).astype(int)\n        f1 = f1_score(oof_labels[:, class_id], pred_binary)\n        if f1 > best_f1:\n            best_f1, best_thr = f1, thr\n    return best_thr\n\n# Tune per class and store\nclass_thresholds = {cls: find_optimal_threshold(oof, labels, i) \n                    for i, cls in enumerate(class_names)}
```
