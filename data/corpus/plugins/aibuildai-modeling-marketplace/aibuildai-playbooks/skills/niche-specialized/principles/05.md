## Principle 5: Design Architecture to Respect Domain Asymmetries

*Consensus: Explicit in top audio solutions, 2/2 graph-based solutions (TrackML, predict-ai-runtime), and implicit in fraud (grouped aggregations) and LLM challenges (role-specific models).*

Standard architectures assume spatial/temporal/feature symmetry that often doesn't hold in niche domains. Modify architectures to respect domain-specific asymmetries: time vs frequency in audio, node vs edge in graphs, question vs answer in LLM games.

**Why this matters:** Treating asymmetric dimensions symmetrically wastes capacity and loses information. Time and frequency have different semantic meanings—frequency bins are perceptual features, time bins are event boundaries—so audio models should avoid downsampling time early. BirdCLEF winners changed CNN stride from (2,2) to (1,1) to preserve time resolution. Uniform pooling or symmetric convolutions destroy this structure.

**When to use:** When dimensions have different semantics (time vs frequency, spatial vs spectral, node attributes vs edge attributes), when domain knowledge says one dimension is more informative or should be preserved longer, or when baseline models underperform despite sufficient capacity.

**When NOT to use:** When dimensions are truly symmetric (RGB channels, spatial dimensions in natural images), when domain knowledge is unavailable and you're doing pure exploration, or when asymmetric designs introduce so much complexity that debugging becomes infeasible.

**How to reason about it:**
Ask: Do all dimensions mean the same thing? Which dimensions encode identity vs context vs events? What happens if I downsample dimension X vs dimension Y? Read domain papers for established architectural patterns. For audio: time is events, frequency is perceptual features → preserve time, downsample frequency. For graphs: nodes and edges have different feature types → use separate encoders. For multi-agent LLM: questioner and answerer have different objectives → train separate models.

```python
# Audio classification: preserve time resolution, downsample frequency\nclass TimePreservingConvNet(nn.Module):\n    def __init__(self, backbone):\n        self.backbone = backbone\n        # Replace the first stride (2, 2) with (1, 1) so early layers keep time resolution\n        self.backbone.conv1.stride = (1, 1)\n        self.pool_freq = nn.AvgPool2d((2, 1))  # freq only\n    \n    def forward(self, x):  # x: (batch, 1, freq, time)\n        x = self.pool_freq(x)  # downsample freq, keep time\n        return self.backbone(x)
```
