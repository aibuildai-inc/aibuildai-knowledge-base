## Principle 11: Use Adversarial Training or Stochastic Weight Averaging for Robustness

*Consensus: Seen in several competitions - Feedback Prize (1st: AWP), NBME (1st: AWP, 2nd: tried multiple adversarial methods), PII (some solutions)*

Apply adversarial perturbations to embeddings during training (FGM, AWP, SMART) to make the model robust to small input changes, or use Stochastic Weight Averaging (SWA) to find flatter minima. Both improve generalization, especially on noisy or adversarially-chosen test data.

**Why this matters:** Entity extraction is sensitive to small wording changes (synonyms, typos, abbreviations). Adversarial training forces the model to be invariant to embedding perturbations, improving robustness. Feedback Prize's 1st place: AWP gave +0.01 CV. NBME's 1st place: AWP with adv_lr=1.0, adv_eps=0.01 gave +0.002 CV. These are non-trivial gains for a training trick.

**When to use:** Use when: (1) you have time for longer training (adversarial training is 1.5-2x slower), (2) baseline models show high variance across seeds (sign of sharp minima), (3) the domain is noisy or test distribution may shift (student writing, clinical notes). Common methods: FGM (fastest, +5% training time), AWP (best results, +50% training time), SMART (comprehensive, +100% training time). Start with FGM; if it helps, try AWP.

**When NOT to use:** Skip if: (1) training time is very limited, (2) your models already generalize well (CV ≈ LB, low variance across seeds), (3) you're using very large models (adversarial training on XL models is expensive). NBME's 2nd place tried adversarial training but found pseudo-labeling worked better—adversarial training isn't always the answer.

**How to reason about it:**
Baseline: train model normally, note CV and variance across 3 seeds. If variance is >0.01, model is unstable (try AWP/SWA). If CV << LB, overfitting (try adversarial). Implement FGM first (easiest): perturb embeddings in gradient direction, compute loss, backprop. If FGM improves CV by >0.005, try AWP (perturb model weights, not embeddings). If AWP improves further, use it. Tune: adv_lr (perturbation strength, 0.1-2.0), adv_eps (step size, 0.001-0.1). Start with adv_lr=1.0, adv_eps=0.01. For SWA: average model weights from last 3-5 epochs.

```python
# FGM (Fast Gradient Method) - simplest adversarial training
class FGM:
    def __init__(self, model, epsilon=0.5):
        self.model = model
        self.epsilon = epsilon
        self.backup = {}
    
    def attack(self, emb_name='word_embeddings'):
        for name, param in self.model.named_parameters():
            if param.requires_grad and emb_name in name:
                self.backup[name] = param.data.clone()
                norm = torch.norm(param.grad)
                if norm != 0:
                    r_at = self.epsilon * param.grad / norm
                    param.data.add_(r_at)
    
    def restore(self, emb_name='word_embeddings'):
        for name, param in self.model.named_parameters():
            if param.requires_grad and emb_name in name:
                param.data = self.backup[name]
        self.backup = {}

# Training loop with FGM
fgm = FGM(model, epsilon=0.5)
for batch in train_loader:
    # Normal forward-backward
    loss = model(batch).loss
    loss.backward()
    
    # Adversarial step
    fgm.attack()
    loss_adv = model(batch).loss
    loss_adv.backward()  # Accumulate adversarial gradient
    fgm.restore()
    
    optimizer.step()
    optimizer.zero_grad()

# AWP (Adversarial Weight Perturbation) - stronger, slower
class AWP:
    def __init__(self, model, adv_lr=1.0, adv_eps=0.01):
        self.model = model
        self.adv_lr = adv_lr
        self.adv_eps = adv_eps
    
    def perturb(self):
        # Perturb model weights in gradient direction
        for name, param in self.model.named_parameters():
            if param.requires_grad and param.grad is not None:
                norm = torch.norm(param.grad)
                if norm != 0:
                    param.data.add_(self.adv_lr * param.grad / norm * self.adv_eps)
```
