## Principle 2: Pre-train on Task-Aligned Data Even When Transfer Seems Indirect

*Consensus: Seen across competitions - SQuAD-trained QA models reused for span extraction in Coleridge (47th) and Gendered Pronoun Resolution (9th); MLM on domain data in NBME (1st, 3rd, 19th, 24th)*

Pre-train the backbone on data that shares the task structure (question-answering for span extraction) or domain vocabulary (MLM on unlabeled domain text), even if the source task differs from the target.

**Why this matters:** A model pre-trained on SQuAD has already learned to predict spans given a query, which transfers to any span-extraction task regardless of domain. MLM on domain data teaches the model domain-specific vocabulary and abbreviations that general pre-training missed.

**When to use:** For span extraction: always pre-train on SQuAD (or similar QA datasets) if starting from a general transformer. For domain-specific vocabulary (medical, scientific, student writing): run MLM on the competition's unlabeled data (patient_notes.csv, publication text) before fine-tuning. NBME's 1st and 3rd place ran MLM on the unlabeled patient notes before task fine-tuning. A Coleridge solution (47th) extracted dataset names with an ELECTRA model trained on SQuAD v2, and a Gendered Pronoun Resolution solution (9th) framed the task as QA with a SQuAD-style BERT model.

**When NOT to use:** Skip SQuAD pre-training if: (1) the task is pure classification without span boundaries (not extraction), (2) you're using a domain-specific model already trained on QA (e.g., BioBERT fine-tuned on medical QA). Skip MLM if the domain vocabulary is standard and the unlabeled data is small (<10k documents) or low-quality.

**How to reason about it:**
Ask: does the task require predicting span boundaries? If yes, SQuAD pre-training helps. Ask: does the domain have jargon/abbreviations not in standard pre-training (medical, legal, scientific)? If yes, MLM on unlabeled data helps. If both, chain them: base model → SQuAD → MLM → task. Check if a domain-pretrained model exists (BioBERT, SciBERT) to skip MLM.
