## Principle 7: Use Joint Start-End Prediction or Beam Search for Coherent Spans

*Consensus: Limited direct evidence - QA-style start-end span extraction in Coleridge (47th) and Gendered Pronoun Resolution (9th); joint start-end decoding is standard QA practice for valid spans*

Instead of predicting start and end positions independently, condition the end prediction on the start position (or vice versa). At inference, use beam search to find the k best start positions, then for each, find the k best end positions, ranking by joint probability.

**Why this matters:** Independent start-end prediction can produce invalid spans (end < start) or semantically incoherent spans (start and end from different entities). Joint prediction ensures coherence. The design follows XLNet's question-answering head.

**When to use:** Use when: (1) the task is span extraction with variable-length targets (dataset names, answers, key phrases), (2) invalid spans (end < start) are common in baseline models, (3) inference speed is not critical (beam search is slower). Works best with autoregressive or QA-pretrained models (XLNet, GPT).

**When NOT to use:** Skip if: (1) spans are short and constrained (single words, fixed formats), (2) you're using a pure token classifier (BIO tagging) where start/end aren't separate, (3) inference must be very fast (beam search is slower). For BIO tagging tasks (NER), this doesn't apply—just use Viterbi decoding or greedy.

**How to reason about it:**
Training: predict start index normally. Extract hidden state at the true start position, concatenate it to all token hidden states, then predict end index conditioned on that. Loss: CE on start, then CE on end. Inference: predict start logits, take the top-k start positions by probability (sigmoid, not softmax for multi-span). For each top-k start, extract its hidden state, concat to all positions, predict end logits, take top-k ends. This gives k*k candidate spans. Rank by joint probability: P(start) * P(end | start). Filter: keep spans where joint_prob > threshold (tuned on validation) and end >= start.

```python
# Training: joint start-end prediction
class JointSpanHead(nn.Module):
    def __init__(self, hidden_size):
        self.start_head = nn.Linear(hidden_size, 1)
        self.end_head = nn.Linear(hidden_size * 2, 1)  # Conditioned on start
    
    def forward(self, hidden_states, start_positions=None):
        start_logits = self.start_head(hidden_states).squeeze(-1)
        
        if start_positions is not None:  # Training
            # Extract hidden state at true start position
            start_hidden = hidden_states[range(len(start_positions)), start_positions]
            # Concat to all positions
            start_hidden_expanded = start_hidden.unsqueeze(1).expand(-1, hidden_states.size(1), -1)
            end_input = torch.cat([hidden_states, start_hidden_expanded], dim=-1)
            end_logits = self.end_head(end_input).squeeze(-1)
        else:  # Inference: beam search
            start_probs = torch.sigmoid(start_logits)
            top_starts = torch.topk(start_probs, k=k, dim=-1)  # beam width k
            
            all_spans = []
            for batch_idx in range(len(hidden_states)):
                for start_idx, start_prob in zip(top_starts.indices[batch_idx], top_starts.values[batch_idx]):
                    start_hidden = hidden_states[batch_idx, start_idx]
                    start_hidden_expanded = start_hidden.unsqueeze(0).expand(hidden_states.size(1), -1)
                    end_input = torch.cat([hidden_states[batch_idx], start_hidden_expanded], dim=-1)
                    end_logits = self.end_head(end_input).squeeze(-1)
                    end_probs = torch.sigmoid(end_logits)
                    top_ends = torch.topk(end_probs, k=k)
                    
                    for end_idx, end_prob in zip(top_ends.indices, top_ends.values):
                        if end_idx >= start_idx:  # Valid span
                            joint_prob = start_prob * end_prob
                            all_spans.append((start_idx.item(), end_idx.item(), joint_prob.item()))
            
            # Keep spans above threshold
            all_spans = [(s, e, p) for s, e, p in all_spans if p > threshold]
            return all_spans
        
        return start_logits, end_logits
```
