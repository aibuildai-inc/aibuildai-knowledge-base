## Principle 8: Detect and Exploit Domain-Specific Structural Patterns

*Consensus: Seen in several competitions - Coleridge (2nd, 4th, and others used acronym detection), NBME (medical acronym tokens), PII (name propagation)*

Analyze the domain for recurring structural patterns in how entities are expressed, and use rule-based or hybrid methods to exploit them. Examples: scientific datasets often appear as 'LONG-FORM (ACRONYM)', medical notes use standardized abbreviations, names repeat throughout a document.

**Why this matters:** Domain conventions create high-precision signals that models struggle to learn from limited data. Coleridge's 2nd place used the Schwartz-Hearst algorithm (a non-ML acronym extractor) and achieved competitive performance with minimal model complexity. Exploiting structure is often simpler and more reliable than teaching a model to discover it.

**When to use:** Inspect 50-100 training samples for patterns. Common patterns: (1) Acronyms: 'LONG NAME (ABBR)' → extract both. (2) Repetition: entity mentioned once with full form, then abbreviated → propagate. (3) Templates: medical notes follow sections (History, Exam, Plan) → use section info. (4) Formatting: emails, URLs, IDs have fixed formats → regex. If a pattern covers >20% of entities, exploit it. Coleridge's top solutions all used acronym detection. NBME used medical abbreviation normalization.

**When NOT to use:** Skip if: (1) the domain is highly unstructured (creative writing, social media without conventions), (2) patterns are too variable to capture with rules (entity forms are completely free), (3) you have abundant training data and a model learns the pattern well. Don't over-engineer: if a transformer captures it, rules add complexity without gain.

**How to reason about it:**
Domain analysis: read 50 samples, list entity surface forms. Check for patterns: fixed formats (regex-able), repetition (entity appears multiple times), structure (sections, citations). For each pattern, estimate coverage: what % of entities match? If >20%, implement. Acronym detection: use Schwartz-Hearst algorithm (search for uppercase-words in parens, match initial letters to preceding words). Repetition: if entity E is detected once with high confidence, search document for exact matches, propagate label. Templates: if domain has sections, add section ID as input feature or use section-specific thresholds. Combine: apply rules first (high precision), then model (high recall), then post-process (fix errors).

```python
# Acronym detection (Schwartz-Hearst algorithm)
import re
def detect_acronyms(text):
    # Find potential acronyms: uppercase in parentheses
    acronym_pattern = r'\(([A-Z]{2,})\)'
    acronyms = []
    
    for match in re.finditer(acronym_pattern, text):
        acronym = match.group(1)
        acronym_start = match.start()
        
        # Look backwards for long-form (words before the acronym)
        words_before = text[:acronym_start].split()[-len(acronym):]
        
        # Check if initial letters match acronym
        if len(words_before) >= len(acronym):
            long_form = []
            acronym_idx = 0
            for word in words_before:
                if word[0].upper() == acronym[acronym_idx]:
                    long_form.append(word)
                    acronym_idx += 1
                    if acronym_idx == len(acronym):
                        break
            
            if acronym_idx == len(acronym):  # Full match
                long_form_text = ' '.join(long_form)
                acronyms.append((long_form_text, acronym))
    
    return acronyms
```
