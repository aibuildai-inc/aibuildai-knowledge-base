## Principle 3: Use Soft Pseudo-Labels on Unlabeled Data with Confidence Filtering

*Consensus: Seen mainly in NBME - pseudo-labels on unlabeled patient notes in NBME (1st, 3rd, 4th, 5th, and most other top solutions), soft labels in NBME (1st, 19th, 20th)*

Generate pseudo-labels on unlabeled data using an ensemble of trained models, keep the soft probabilities (not hard 0/1 labels), and filter by prediction confidence. Train the next model on a mix of true labels and high-confidence pseudo-labels.

**Why this matters:** Soft pseudo-labels preserve the model's uncertainty, allowing the next model to learn from confident predictions while down-weighting uncertain ones. This prevents error amplification that hard pseudo-labels cause. Unlabeled domain data (10x more in NBME) is a massive signal source when used correctly.

**When to use:** Use when: (1) unlabeled data is abundant (>5x labeled data), (2) annotations are sparse/incomplete (not all entities labeled), (3) you have a strong initial model (CV close to LB). NBME's 1st place used 90% pseudo, 10% true labels with soft targets; it tried keeping only notes with a confident prediction, but random sampling from all unlabeled notes gave better CV, so validate any filter against random sampling.

**When NOT to use:** Skip if: (1) unlabeled data is noisy or off-distribution from test, (2) initial models are weak (CV far from LB), (3) training time is very limited (pseudo-labeling requires retraining). Coleridge competitors reported pseudo-labeling didn't help because unlabeled publications were too diverse. PII's 1st place skipped it—external generated data was better.

**How to reason about it:**
Train a strong baseline ensemble (3+ diverse models). Generate predictions on unlabeled data, keep logits/probabilities. Filter (optional): discard samples whose highest predicted probability is low, and compare this against random sampling on CV. Create training batch: 10-30% true labels, 70-90% pseudo-labels. Use loss that handles soft targets: focal loss or custom BCE that down-weights 0.5 probabilities. Train for fewer epochs than original (1-2). Evaluate: does CV and LB improve? If not, your filter is too loose or the unlabeled data is off-distribution.

```python
# Generate soft pseudo-labels from ensemble (per-token probabilities)
ensemble_logits = sum([model(unlabeled_texts) for model in models]) / len(models)
soft_targets = torch.sigmoid(ensemble_logits)  # [num_texts, seq_len]

# Optional confidence filtering (compare against random sampling on CV)
confidence = soft_targets.max(dim=1)[0]
keep_mask = confidence > threshold
pseudo_data = unlabeled_data[keep_mask]
pseudo_targets = soft_targets[keep_mask]

# Custom loss for soft targets (down-weight uncertain predictions)
def soft_bce_loss(logits, soft_targets):
    targets_weight = torch.where(soft_targets >= 0.5, 2*soft_targets - 1, 1 - 2*soft_targets)
    logits_adjusted = torch.where(soft_targets >= 0.5, logits, -logits)
    return -targets_weight * F.logsigmoid(logits_adjusted)

# Mix true and pseudo labels in training
train_data = true_labels + 9 * pseudo_data  # 10% true, 90% pseudo
```
