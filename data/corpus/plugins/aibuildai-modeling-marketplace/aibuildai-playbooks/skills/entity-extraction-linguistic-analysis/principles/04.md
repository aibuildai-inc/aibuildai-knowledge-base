## Principle 4: Analyze Annotation Consistency and Adapt Loss Weighting Accordingly

*Consensus: Seen in several competitions - NBME (1st, 2nd, multiple), PII (1st, 5th), Feedback Prize*

Manually inspect training annotations to detect incompleteness (only first occurrence labeled, not all) or inconsistency (similar entities labeled differently). Adjust class weights or loss functions to account for this, especially down-weighting the 'O' (outside) label.

**Why this matters:** Incomplete annotations mean unlabeled spans in training data are not true negatives—they're missing positives. Training with equal class weights causes the model to over-predict 'O' (outside entity). NBME annotators often labeled only one mention of a feature per note; treating unlabeled mentions as hard negatives would be wrong.

**When to use:** Always inspect 50-100 training samples for annotation patterns. Check: (1) Are all occurrences of an entity labeled, or only the first? (2) Are there near-duplicate entities with different labels? (3) Is the 'O' class overwhelming (>95% of tokens)? If any yes, down-weight 'O' in the loss (weight 0.05-0.1) and up-weight entity classes (5-10x). NBME/PII/Feedback Prize all used 'O' weight 0.05-0.1.

**When NOT to use:** Use equal weights if: (1) annotations are exhaustive and verified complete, (2) entity density is high (>20% of tokens are entities), (3) the task has a single entity type with no ambiguity. When annotations are near-complete, equal weights work.

**How to reason about it:**
Inspect annotations: sample 50 documents, search for repeated entity strings, check if all occurrences are labeled. Calculate class balance: what fraction of tokens are 'O' vs entities? If 'O' is >95%, it's overwhelming. Set weight_O = 1.0, weight_entity = (count_O / count_entity) * alpha, where alpha=0.05-0.2. Start with alpha=0.1 (10x up-weight), tune via CV. Alternative: use focal loss (gamma=2) which auto-down-weights easy examples ('O' predictions).

```python
# Calculate class weights from training data
from collections import Counter
token_labels = [label for doc in train_data for label in doc['labels']]
label_counts = Counter(token_labels)
total = sum(label_counts.values())

# Down-weight 'O', up-weight entities
class_weights = {}
for label, count in label_counts.items():
    if label == 'O':
        class_weights[label] = 0.1  # Down-weight dominant class
    else:
        class_weights[label] = 10.0  # Up-weight rare entities

weights_tensor = torch.tensor([class_weights[label] for label in label_list])
loss_fn = nn.CrossEntropyLoss(weight=weights_tensor)
```
