## Principle 5: Apply Aggressive Negative Sampling Based on Target Imbalance

*Consensus: All GBDT solutions use negative sampling; ratios vary by target (clicks: 5%, carts: 25%, orders: 40%)*

With 100-500 candidates per user and ~1-5 true purchases, the reranking training data is 95-99% negative. Downsample negatives to 10-100x positives (higher ratio for rarer targets like orders, lower for clicks). Train on the downsampled set; the model learns the relative ranking.

**Why this matters:** Training GBDT on 99% negative data wastes computation on easy negatives and biases the model toward predicting 'no purchase'. Negative sampling focuses the model on hard negatives (plausible but wrong items), improving ranking quality. The 1st-place OTTO solution used per-target sampling rates (5% for clicks, 25% for carts, 40% for orders); another top solution trained without negative sampling wherever memory allowed because sampling lowered its score, showing the optimal rate is target- and task-specific.

**When to use:** Always when positive rate in candidates is <5%. If you have 100 candidates per user and 1-2 are positive, downsample negatives to 10-50x positives.

**When NOT to use:** If the task is balanced (e.g., after heavy candidate filtering, positive rate is >10%), downsampling may discard useful signal. Also skip if you use a ranking objective (LambdaRank) that inherently handles imbalance — though empirically, downsampling still helps.

**How to reason about it:**
Measure positive rate in your candidate set. If <1%, sample negatives to achieve 1-5% positive rate (ratio 20:1 to 100:1). If 1-5%, target 5-10% positive rate (ratio 10:1 to 20:1). Train models with different ratios and validate: too few negatives (>10% positive) overfits; too many (<1% positive) underfits. The optimal ratio is task-specific but usually 20-50x positives.

```python
# Negative sampling
import numpy as np

def downsample_negatives(train_df, neg_sample_ratio=20, seed=42):
    pos = train_df[train_df['label'] == 1]
    neg = train_df[train_df['label'] == 0]
    
    n_pos = len(pos)
    n_neg_sampled = n_pos * neg_sample_ratio
    
    if len(neg) > n_neg_sampled:
        neg_sampled = neg.sample(n=n_neg_sampled, random_state=seed)
    else:
        neg_sampled = neg
    
    train_sampled = pd.concat([pos, neg_sampled]).sample(frac=1, random_state=seed)
    print(f'Sampled: {len(pos)} pos, {len(neg_sampled)} neg, ratio 1:{neg_sample_ratio}')
    return train_sampled

# For multi-target tasks (clicks/carts/orders), use different ratios
def downsample_by_target(train_df, target_col='action_type'):
    # Empirical ratios from OTTO competition
    ratios = {'clicks': 0.05, 'carts': 0.25, 'orders': 0.40}
    
    sampled_dfs = []
    for target, ratio in ratios.items():
        target_df = train_df[train_df[target_col] == target]
        sampled_dfs.append(downsample_negatives(target_df, neg_sample_ratio=int(1/ratio)))
    
    return pd.concat(sampled_dfs)
```
