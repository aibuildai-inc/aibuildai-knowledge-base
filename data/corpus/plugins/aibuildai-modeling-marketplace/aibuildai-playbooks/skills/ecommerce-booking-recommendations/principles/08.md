## Principle 8: Include Candidate-Source Features as Ranking Signals

*Consensus: Multiple top OTTO solutions tag candidates with their generating retrieval method and use it as a ranking feature*

For each candidate, add binary features indicating which retrieval method generated it (e.g., from co-visitation matrix A, from popularity, from revisit) and the rank within that method. These features let the ranker learn which sources are reliable for which users.

**Why this matters:** Not all candidate sources are equally reliable. Popular items are safe for cold-start users but generic; co-visitation is strong for active users. By encoding the source and rank, the ranker learns to trust high-rank candidates from strong sources and discount low-rank candidates from weak sources. This meta-learning often contributes 10-20% of the reranker's gain over simple candidate aggregation.

**When to use:** Always when using multiple candidate sources (>3). If you only use one source, the feature is uninformative.

**When NOT to use:** If all candidates come from one source (e.g., only co-visitation), the feature is constant and useless. Also skip if you have <100 candidates per user — the ranker has enough capacity to learn source quality implicitly.

**How to reason about it:**
For each candidate source, tag each candidate with: (1) binary flag 'from_source_X', (2) rank within that source (1-100). Train the ranker with these features. Measure feature importance: if 'from_co-visitation_rank' is high-importance, the ranker is using it to prioritize certain sources. If all source features are low-importance, either the sources are equally good or the ranker has enough signal from interaction features.

```python
# Add candidate source features
def add_candidate_source_features(candidates_df):
    # Assume candidates_df has columns: user_id, item_id, source (e.g., 'covisit_A', 'popularity')
    
    # Binary flags for each source
    sources = candidates_df['source'].unique()
    for src in sources:
        candidates_df[f'from_{src}'] = (candidates_df['source'] == src).astype(int)
    
    # Rank within each source
    candidates_df['source_rank'] = (
        candidates_df
        .groupby(['user_id', 'source'])
        .cumcount() + 1
    )
    
    # Normalize rank to [0, 1] (higher rank = lower score)
    max_rank = candidates_df.groupby(['user_id', 'source'])['source_rank'].transform('max')
    candidates_df['source_rank_norm'] = 1.0 - (candidates_df['source_rank'] - 1) / max_rank
    
    return candidates_df
```
