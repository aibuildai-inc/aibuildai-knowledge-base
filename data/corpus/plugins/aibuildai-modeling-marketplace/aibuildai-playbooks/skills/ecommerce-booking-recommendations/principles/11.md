## Principle 11: Optimize Ensemble Weights on Validation, Not Leaderboard

*Consensus: Most top OTTO solutions ensemble multiple models with equal or validation-tuned weights; OTTO 7th place ensembles LightGBM + GNN*

Train multiple models with different seeds, hyperparameters, or architectures (LightGBM, CatBoost, XGBoost, GNN). Ensemble by averaging predicted scores or ranks. Tune ensemble weights on local validation to avoid overfitting to the public leaderboard.

**Why this matters:** Single models have variance from random seed, data sampling, and hyperparameter choices. Ensembling reduces variance and often gives a small but consistent gain. However, tuning weights on the leaderboard overfits to the public split and hurts private score. Validation-based tuning generalizes better.

**When to use:** Always in the final stages of a competition when you have multiple strong models with close CV scores. If you only have one model or one model is far ahead of the others in CV, focus on improving the best model first.

**When NOT to use:** Early in a competition, ensembling is premature — you haven't found the best single-model architecture yet. Also skip if you have <3 models; the ensemble won't reduce variance meaningfully.

**How to reason about it:**
Train 3-10 models with different seeds, hyperparameters, or model types. Measure each model's validation MAP@K. If the other models score only slightly below the best model, ensemble them. Try: (1) equal-weight average, (2) rank-based ensemble (average ranks, not scores), (3) weighted average with weights proportional to validation score. Validate the ensemble on the local validation set. If the ensemble beats the best single model, use it; if it only ties the best model, the models are too similar to benefit from ensemble.

```python
# Ensemble multiple models
import numpy as np

def ensemble_by_rank(predictions_list, weights=None):
    # predictions_list: list of DataFrames, each with columns [user_id, item_id, score]
    # Convert scores to ranks within each user
    
    if weights is None:
        weights = [1.0] * len(predictions_list)
    
    ranks_list = []
    for preds in predictions_list:
        preds['rank'] = preds.groupby('user_id')['score'].rank(ascending=False, method='first')
        ranks_list.append(preds[['user_id', 'item_id', 'rank']])
    
    # Merge all ranks
    ensemble = ranks_list[0].copy()
    ensemble['weighted_rank'] = ensemble['rank'] * weights[0]
    
    for i, ranks in enumerate(ranks_list[1:], start=1):
        ensemble = ensemble.merge(
            ranks, on=['user_id', 'item_id'], how='outer', suffixes=('', f'_{i}')
        )
        ensemble[f'rank_{i}'] = ensemble[f'rank_{i}'].fillna(1000)  # Penalty for missing
        ensemble['weighted_rank'] += ensemble[f'rank_{i}'] * weights[i]
    
    # Rank by weighted average rank (lower is better)
    ensemble['final_rank'] = ensemble.groupby('user_id')['weighted_rank'].rank(method='first')
    
    return ensemble.sort_values(['user_id', 'final_rank'])
```
