## Principle 12: Differentiate Reranker Objectives by Target Type

*Consensus: OTTO winners train separate models for clicks/carts/orders*

If the task has multiple target types (clicks, cart-adds, purchases) with different importance, train separate rankers for each or adjust loss weights. Clicks are abundant and noisy; purchases are rare and high-value. Reflect this in negative sampling ratios and model capacity.

**Why this matters:** A single model optimizing for clicks will learn to predict clicks (easy, abundant) and ignore purchases (rare, hard). Separate models or weighted objectives let each target receive appropriate attention. OTTO winners trained 3 separate models with negative sampling 5% (clicks), 25% (carts), 40% (orders), reflecting their rarity.

**When to use:** When the task explicitly has multiple targets with different importance (e.g., OTTO: weighted recall = 0.1*clicks + 0.3*carts + 0.6*orders). Train separate models for each target.

**When NOT to use:** If the task has only one target (e.g., purchases only), a single model suffices. Also skip if all targets have similar importance and prevalence.

**How to reason about it:**
Measure prevalence of each target in candidates: e.g., 5% have clicks, 2% have carts, 1% have orders. Train separate models with negative sampling ratios inversely proportional to prevalence (rare targets = more aggressive downsampling of negatives). Validate each model separately, then combine predictions (e.g., weighted average by target importance). If the task weights orders 3x more than clicks, ensure the orders model is optimized first.

```python
# Train separate models for different targets
def train_multi_target_models(train_df, target_types=['clicks', 'carts', 'orders']):
    models = {}
    
    # Different negative sampling ratios for different targets
    neg_ratios = {'clicks': 20, 'carts': 4, 'orders': 2}  # More aggressive for rarer targets
    
    for target in target_types:
        # Filter to this target type
        target_df = train_df[train_df['action_type'] == target]
        
        # Apply target-specific negative sampling
        sampled_df = downsample_negatives(target_df, neg_sample_ratio=neg_ratios[target])
        
        # Train model
        model = lgb.LGBMRanker()
        model.fit(
            sampled_df[feature_cols],
            sampled_df['label'],
            group=sampled_df.groupby('user_id').size()
        )
        
        models[target] = model
    
    return models

# Combine predictions from multiple models
def combine_multi_target_predictions(predictions_dict, weights={'clicks': 0.1, 'carts': 0.3, 'orders': 0.6}):
    combined = predictions_dict['clicks'][['user_id', 'item_id']].copy()
    combined['score'] = 0
    
    for target, weight in weights.items():
        preds = predictions_dict[target]
        combined['score'] += preds['score'] * weight
    
    return combined.sort_values(['user_id', 'score'], ascending=[True, False])
```
