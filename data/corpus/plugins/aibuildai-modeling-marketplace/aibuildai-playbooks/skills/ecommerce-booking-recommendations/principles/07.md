## Principle 7: Validate with Time-Based Splits and Measure CV-LB Correlation Early

*Consensus: Universal: all solutions use last week as validation; top OTTO solutions report near-perfect, stable CV-LB correlation*

Split training data by time: use the last week (or last N days) as validation, all prior data for training. Compute local CV score (MAP@K or NDCG@K) and compare to leaderboard score. If CV and LB move together (correlation >0.9), you can trust local validation. If not, adjust the split or check for data leakage.

**Why this matters:** E-commerce has strong temporal dynamics and distribution shift. Random splits leak future information and overestimate performance. Time-based splits mimic the production setting (train on past, predict future). High CV-LB correlation lets you iterate quickly without wasting submissions.

**When to use:** Always for time-series recommendation tasks. Use the most recent data period that matches the test period length (e.g., if the test period is 7 days, validate on the last 7 days of training).

**When NOT to use:** If the task has no temporal structure (e.g., predicting user preferences from a single survey), use stratified random splits instead.

**How to reason about it:**
Split training data: train on [start, T-7 days), validate on [T-7 days, T). Compute features for validation using ONLY training data (no leakage). Measure MAP@K on validation and compare to leaderboard. If LB is slightly below CV and the two move together, the gap is reasonable (public/private data differ). If LB is far below CV, you have leakage or overfitting. Recheck feature computation for leakage (e.g., using validation period data to compute popularity).

# Time-based train/validation split
import pandas as pd

def time_split(transactions_df, val_weeks=1):
    max_date = transactions_df['date'].max()
    val_start = max_date - pd.Timedelta(weeks=val_weeks)
    
    train = transactions_df[transactions_df['date'] < val_start]
    val = transactions_df[transactions_df['date'] >= val_start]
    
    print(f'Train: {train["date"].min()} to {train["date"].max()}')
    print(f'Val: {val["date"].min()} to {val["date"].max()}')
    print(f'Train users: {train["user_id"].nunique()}, Val users: {val["user_id"].nunique()}')
    
    return train, val

# Compute MAP@K
def mean_average_precision_at_k(y_true, y_pred, k=12):
    # y_true: list of lists of ground truth items per user
    # y_pred: list of lists of predicted items per user (ranked)
    aps = []
    for true_items, pred_items in zip(y_true, y_pred):
        pred_items = pred_items[:k]
        if len(true_items) == 0:
