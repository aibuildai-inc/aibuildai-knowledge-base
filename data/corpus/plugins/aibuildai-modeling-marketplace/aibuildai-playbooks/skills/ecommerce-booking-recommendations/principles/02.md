## Principle 2: Build Multiple Co-Visitation Matrices with Varied Parameters

*Consensus: Top-3 OTTO solution used 20 co-visitation matrices; universal across competitions*

Create 10-20 co-visitation matrices varying time windows (last week, last two weeks, all data, or a forward limit such as 2 hours), action types (clicks→orders, orders→orders), directionality (both-way vs forward-only), time decay, and consecutive vs all pairs. Use each as a candidate source AND feature.

**Why this matters:** A single co-visitation matrix captures one slice of user behavior. Different matrices surface different patterns: recent pairs capture trending items, long-window pairs capture stable preferences, consecutive pairs capture immediate next-item, cart/order-only pairs filter intent. Diversity in candidate sources is the primary driver of recall improvements.

**When to use:** Always for session-based or sequential interaction data. Co-visitation is the cheapest high-recall method. If the data has action types (click/cart/order), create separate matrices per action pair.

**When NOT to use:** If interactions are not sequential or have no temporal structure (e.g., a user rates 100 movies in one batch with no order). Then use standard collaborative filtering instead.

**How to reason about it:**
Start with 3-5 matrices covering different time windows (e.g., last week, last two weeks, all data) and action types (any→any, buy→buy). Measure candidate recall@100 for each. Add matrices that improve recall by surfacing items the existing set misses. Stop when adding more matrices yields <1% recall gain. Then use ALL matrices as features in reranking — the ranker learns which matrix is relevant for each user.

```python
# Example: Create co-visitation matrix with time decay
from collections import defaultdict
import math

def build_covisit_matrix(sessions_df, time_decay=True, consecutive_only=False):
    covisit = defaultdict(Counter)
    
    for session_id, group in sessions_df.groupby('session'):
        items = group['item_id'].tolist()
        timestamps = group['timestamp'].tolist()
        
        for i, item1 in enumerate(items):
            for j, item2 in enumerate(items):
                if item1 == item2:
                    continue
                # Option: only consecutive pairs
                if consecutive_only and abs(i - j) != 1:
                    continue
                
                weight = 1.0
                if time_decay:
                    # Decay by time difference between interactions
                    time_diff = abs(timestamps[i] - timestamps[j]) / 3600  # hours
                    weight = (0.5) ** (time_diff / 24)  # half-life of 1 day
                
                covisit[item1][item2] += weight
    
    return covisit
```
