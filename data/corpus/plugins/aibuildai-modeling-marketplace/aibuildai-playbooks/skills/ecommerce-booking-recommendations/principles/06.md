## Principle 6: Use BPR or Matrix Factorization for User-Item Similarity Features

*Consensus: Many top OTTO solutions use BPR, ALS, or related matrix-factorization embeddings as reranker features*

Learn latent user and item embeddings via BPR (Bayesian Personalized Ranking) or ALS (Alternating Least Squares) matrix factorization. Compute user-item similarity (dot product of embeddings) as a feature in the reranker. This captures collaborative filtering signal not present in co-visitation or interaction counts.

**Why this matters:** Co-visitation captures item-item similarity but not user-item affinity. A user who frequently interacts with one category will have high affinity to new items in that category even if they've never interacted with them. BPR learns this latent preference structure. One top OTTO team combined embeddings from BPR, ALS, LMF, and word2vec, using the inner product of session/candidate embeddings as reranker features alongside statistical features.

**When to use:** When you have enough user-item interactions to learn meaningful embeddings (>100k interactions, >1k users, >1k items). If the data is extremely sparse (most users have <3 interactions), matrix factorization will overfit.

**When NOT to use:** For cold-start users (no training interactions) or new items, matrix factorization produces no embedding. Fall back to content-based or popularity features for these cases.

**How to reason about it:**
Train a BPR or ALS model on all historical interactions before the validation period. Compute user and item embeddings. For each candidate pair (user, item), compute cosine similarity or dot product of their embeddings. Add this as one feature in the reranker. Measure feature importance: if BPR similarity ranks in the top 5 features, it's providing strong signal. If it's low-importance, the data may be too sparse or the embedding dimension too small (try 50-200 dimensions).

```python
# Train BPR model using implicit library
from implicit.bpr import BayesianPersonalizedRanking
from scipy.sparse import coo_matrix

def train_bpr(transactions_df, embedding_dim=64):
    # Create user-item interaction matrix
    user_ids = transactions_df['user_id'].astype('category')
    item_ids = transactions_df['item_id'].astype('category')
    
    interaction_matrix = coo_matrix(
        (np.ones(len(transactions_df)),
         (user_ids.cat.codes, item_ids.cat.codes))
    )
    
    # Train BPR
    model = BayesianPersonalizedRanking(factors=embedding_dim, iterations=50)
    model.fit(interaction_matrix)
    
    return model, user_ids.cat.categories, item_ids.cat.categories

# Compute user-item similarity
def compute_bpr_similarity(user_id, item_id, model, user_map, item_map):
    if user_id not in user_map or item_id not in item_map:
        return 0.0  # cold start
    
    user_idx = user_map.get_loc(user_id)
    item_idx = item_map.get_loc(item_id)
    
    user_emb = model.user_factors[user_idx]
    item_emb = model.item_factors[item_idx]
    
    return np.dot(user_emb, item_emb)
```
