## Principle 7: Control Patch Sampling Before Increasing Model Capacity

*Consensus: 5/5 competitions used some combination of positive crops, class-balanced sampling, small-object anchors, non-empty sampling, hard negatives, or crop-scale control.*

Design the sampling distribution so the model repeatedly sees rare objects, difficult boundaries, and representative background. Balance positive coverage with hard negatives rather than drawing uniformly from enormous mostly empty images or volumes.

**Why this matters:** Uniform voxel sampling can produce batches with almost no learning signal, while positive-only sampling prevents learning object absence and inflates false positives. Sampling changes the effective training objective more strongly than many loss substitutions.

**When to use:** For sparse 3D points, force a fraction of patches around each class and retain random/background patches. For vessels, mix non-empty and empty crops. For dense small instances, tune anchors, proposal counts, crop scale, and maximum detections to observed object sizes and counts.

**When NOT to use:** Do not make training prevalence so different from test prevalence that confidence becomes unusable. Easy negatives add little value, but removing all negative tomograms or slices can make presence decisions unstable; mine hard negatives from OOF predictions when possible.

**How to reason about it:**
Estimate the probability that a uniform crop contains useful signal. If it is low, introduce class-aware sampling. Monitor recall and false positives separately while varying positive fraction. After the first model, collect confident false positives and missed small objects and oversample those regions without discarding broad domain coverage.

```python
def sample_patch(case, rng, positive_fraction=0.33, hard_negative_fraction=0.17):
    u = rng.random()
    if u < positive_fraction and case.positive_centers:
        return crop_around(rng.choice(case.positive_centers))
    if u < positive_fraction + hard_negative_fraction and case.hard_negatives:
        return crop_around(rng.choice(case.hard_negatives))
    return random_crop(case.shape)  # preserves true background prevalence
```
