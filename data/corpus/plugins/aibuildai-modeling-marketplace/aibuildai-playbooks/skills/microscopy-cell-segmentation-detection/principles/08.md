## Principle 8: Match Targets and Loss Weighting to Imbalance and Metric Geometry

*Consensus: 5/5 competitions customized target radius, positive/class weights, boundary terms, hard-voxel mining, focal/Tversky variants, or auxiliary heads; simple BCE/CE also won when the target representation was well chosen.*

First make the target learnable, then choose the simplest stable loss that reflects the dominant error: weighted BCE/CE or hard-voxel mining for sparse points, Dice/Tversky for foreground imbalance, and boundary-aware terms for surface-sensitive masks. Encode metric class weights explicitly when the official score does.

**Why this matters:** Sparse positives can be numerically invisible to an unweighted voxel loss, while pure overlap losses may produce poorly calibrated extreme probabilities. Boundary-sensitive metrics care about errors that occupy little area, and recall-weighted F-scores change the optimal cost of false negatives.

**When to use:** Use class and positive weights when rare particles or hard classes are underdetected; use boundary supervision when surface errors dominate; use deep supervision or pooled loss when coarse localization is acceptable. Tune on decoded metric behavior, not training loss alone.

**When NOT to use:** Do not assume a differentiable metric surrogate is automatically superior. Top solutions often found simple CE or BCE better calibrated and more stable than elaborate Dice, Tversky, MSE, or focal combinations. Remove loss terms that improve pixel metrics but hurt threshold stability or object decoding.

**How to reason about it:**
Identify whether errors are FN, FP, boundary displacement, merge/split, or coordinate error. Change one of target geometry, sampling, and loss at a time because they interact. Sweep operating thresholds for every candidate so a calibration shift is not mistaken for a model-quality change.

```python
def composite_loss(logits, target, boundary=None, pos_weight=None, boundary_w=0.0):
    bce = torch.nn.functional.binary_cross_entropy_with_logits(
        logits, target, reduction="none", pos_weight=pos_weight
    )
    if boundary is not None:
        bce = bce * (1.0 + boundary_w * boundary)
    prob = logits.sigmoid()
    dice = 1 - (2 * (prob * target).sum() + 1) / (prob.sum() + target.sum() + 1)
    return bce.mean() + dice  # customize weights using grouped OOF metric
```
