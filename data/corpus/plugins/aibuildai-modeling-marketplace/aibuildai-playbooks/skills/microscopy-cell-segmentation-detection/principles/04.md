## Principle 4: Encode Ownership Cues When Foreground Masks Cannot Separate Instances

*Consensus: 2/2 instance-mask competitions; the strongest alternative clusters were box/ROI masks and center-flow/watershed systems, with point-localization competitions independently validating heatmap centers.*

For touching or concave cells, predict an intermediate geometric field—centers, boundary energy, distance transform, or vectors/flows toward centers—then recover instances with watershed or flow integration. Treat plain semantic foreground as insufficient unless objects are naturally separated.

**Why this matters:** Adjacent instances have identical semantic labels, so a binary loss provides no incentive to create the separating cut. Direction changes, center peaks, and boundary targets inject ownership information and make the discontinuity between neighboring objects observable to the loss.

**When to use:** Use when merges dominate error analysis, objects are crowded, or the metric scores each object separately. Cellpose-style flows are attractive for irregular morphology; center-seeded watershed is simpler when objects have clear cores.

**When NOT to use:** Skip this machinery for dense vascular semantic segmentation, sparse point localization, or easily separated nuclei where Mask R-CNN already models instances directly. Auxiliary fields should also be removed if ablation shows they do not improve decoded object metrics.

**How to reason about it:**
Measure merge and split errors, not only pixel Dice. If merged masks are common, compare detector/ROI segmentation against semantic plus geometry heads. Choose targets whose decoding assumptions fit morphology: radial centers for compact nuclei, learned flows for irregular cells, and boundaries for shapes without stable centers. Validate the complete decoder because a better auxiliary loss may not improve instance AP.

```python
class GeometryHeads(torch.nn.Module):
    def __init__(self, features):
        super().__init__()
        self.foreground = torch.nn.Conv2d(features, 1, 1)
        self.center = torch.nn.Conv2d(features, 1, 1)
        self.flow = torch.nn.Conv2d(features, 2, 1)  # x/y direction to owner center

    def forward(self, x):
        return {
            "foreground": self.foreground(x),
            "center": self.center(x),
            "flow": self.flow(x),
        }
```
