## Principle 2: Select 2D, 2.5D, or 3D from Anisotropy, Context, and Compute

*Consensus: 3/3 volumetric competitions explicitly compared dimensionality; successful solutions ranged from full 3D to multiview 2D and 2.5D, so there is no universal winner.*

Use full 3D when cross-slice context and approximately meaningful voxel geometry justify its cost; use 2.5D when adjacent slices add evidence but pretrained 2D encoders and high in-plane resolution are valuable; use multiview 2D when compute or anisotropy makes full 3D inefficient.

**Why this matters:** Full 3D preserves volumetric morphology but sharply limits patch size, batch size, and ensemble capacity. Pure 2D preserves detail and accesses mature backbones but can miss depth continuity. A 2.5D stack or pooled 2D encoder often captures enough depth evidence at a much better resolution-throughput trade-off.

**When to use:** Compare physical spacing by axis, object extent across slices, required field of view, GPU memory, inference deadline, and whether 2D pretrained features transfer to the modality. Benchmark at equal wall-clock or memory budgets rather than equal parameter counts.

**When NOT to use:** Do not assume 3D is superior merely because the source is volumetric. In SenNet, high-resolution 2.5D and multiview models were often stronger and more robust; conversely, slice-only detection can fail when a low-SNR object is recognizable only from its 3D neighborhood.

**How to reason about it:**
If through-plane spacing is close to in-plane spacing and the object spans enough slices, start with 3D patches. If spacing is anisotropic or 3D forces destructive downsampling, stack a few neighboring slices as channels or use a 2D encoder with depth pooling. For structures visible from all axes, train or infer on x/y/z views and average in volume coordinates. Keep a lightweight alternative because extra models or higher resolution may beat one expensive 3D network.

```python
def dimensionality(spacing_zyx, object_depth_slices, fits_3d_patch):
    anisotropy = max(spacing_zyx) / min(spacing_zyx)
    if fits_3d_patch and anisotropy < 2.0 and object_depth_slices >= 4:
        return {"mode": "3d", "views": ["zyx"]}
    if object_depth_slices >= 2:
        return {"mode": "2.5d", "channels": 3, "views": ["z", "y", "x"]}
    return {"mode": "2d", "views": ["native"]}
```
