## Principle 12: Calibrate the Operating Point on the Exact Metric

*Consensus: 5/5 competitions treated thresholds, class-specific filters, mask size, or confidence reranking as major parameters rather than afterthoughts.*

Tune thresholds jointly with the decoder using out-of-fold probabilities and the official metric. Use per-class or per-domain thresholds when error costs and calibration differ; consider quantile or target-volume calibration only when test prevalence is stable enough to support it.

**Why this matters:** F-beta, multi-IoU AP, and surface Dice imply different optimal FP/FN trade-offs. A strong probability map can score poorly at the wrong threshold, and changes in target radius or loss often shift calibration without changing ranking quality.

**When to use:** Sweep thresholds after every material change to model, target, or ensemble. For recall-heavy point metrics, tolerate more candidates; for high-IoU instance AP, remove uncertain or malformed masks; for volume masks, seek a broad plateau rather than a sharp optimum.

**When NOT to use:** Do not use a global quantile if object prevalence can shift by dataset, or tune many thresholds directly to a tiny public leaderboard. Quantile thresholding was powerful in BYU because hidden positive prevalence was stable, but it is a risky general assumption.

**How to reason about it:**
Separate ranking from calibration using threshold-free diagnostics where possible. Plot the official score against threshold for every fold/domain, select stable plateaus, and calibrate per class only when there are enough OOF examples. Stress-test prevalence shifts before using quantiles or fixed foreground-volume ratios.

```python
import numpy as np

def select_stable_threshold(oof_probs, oof_targets, decode_and_score):
    thresholds = np.linspace(0.05, 0.95, 37)
    fold_scores = np.array([
        [decode_and_score(p, y, t) for p, y in zip(oof_probs, oof_targets)]
        for t in thresholds
    ])
    mean = fold_scores.mean(1)
    stability = fold_scores.std(1)
    return thresholds[np.argmax(mean - 0.25 * stability)]
```
