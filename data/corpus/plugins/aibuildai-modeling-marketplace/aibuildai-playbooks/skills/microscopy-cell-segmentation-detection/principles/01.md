## Principle 1: Choose the Prediction Representation from the Output Geometry

*Consensus: 5/5 relevant competitions; every top tier first converted the official target into a representation suited to its geometry rather than treating all problems as generic segmentation.*

Branch first on whether the submission requires instances, a connected semantic structure, or object centers. Use box/ROI masks or center-and-flow representations for instances, semantic masks for continuous structures, and heatmaps or blobs for point localization; only use coarse classification when the localization tolerance makes exact geometry unnecessary.

**Why this matters:** The representation determines which ambiguities the network must resolve. Binary foreground cannot identify ownership between touching cells, direct coordinate regression is brittle when object count varies, and a heavy full-resolution decoder wastes capacity when the metric accepts a broad localization radius.

**When to use:** Make this the first architectural decision. Inspect the submission schema, matching rule, allowed number of objects, overlap constraints, object topology, and localization tolerance before selecting a model family.

**When NOT to use:** Do not force a fashionable formulation onto incompatible targets. Box-first models are awkward for branching vessels, watershed adds needless complexity to well-separated objects, and direct coordinates are unsuitable when a volume can contain an unknown number of particles.

**How to reason about it:**
1. If the output is one mask per object, ask whether cells touch or overlap. If little crowding exists, detector plus ROI mask is natural; if crowding is severe, predict centers, boundaries, distances, or flows and decode instances. 2. If the output is one tubular foreground mask, optimize a semantic model with 3D context or multiview consistency. 3. If the output is a set of centers, predict a spatial likelihood field and recover peaks. 4. If each sample has at most one object and distance tolerance is much larger than output stride, compare heatmap localization with a coarse spatial classifier.

```python
def choose_formulation(target, crowded=False, max_objects=None, tolerance_vox=None):
    if target == "instance_masks":
        return "center_flow_or_watershed" if crowded else "detector_plus_roi_mask"
    if target == "dense_tubular_mask":
        return "semantic_unet_with_3d_or_multiview_context"
    if target == "point_locations":
        if max_objects == 1 and tolerance_vox is not None and tolerance_vox >= 16:
            return "coarse_spatial_classifier_or_heatmap"
        return "gaussian_or_distance_blob_heatmap"
    raise ValueError("Inspect the metric and submission geometry")
```
