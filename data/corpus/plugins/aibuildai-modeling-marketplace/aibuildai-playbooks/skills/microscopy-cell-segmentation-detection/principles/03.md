## Principle 3: Set Resolution, Output Stride, and Target Width in Physical Units

*Consensus: 5/5 competitions; top solutions repeatedly gained from larger cell crops, voxel-spacing normalization, class-specific radii, or deliberately coarse heatmaps matched to metric tolerance.*

Choose input spacing, crop resolution, heatmap stride, and target radius from object size and the evaluation tolerance—not from framework defaults. Preserve enough pixels to recognize the smallest object or boundary while avoiding resolution that the metric cannot reward.

**Why this matters:** Microscopy scale changes across magnifications, scanners, and specimens. Too much downsampling erases small nuclei or motor texture; too little wastes memory and shrinks context. For point metrics, a broad low-resolution blob reduces imbalance and encodes acceptable uncertainty, while zero-tolerance surface metrics require much finer boundary fidelity.

**When to use:** Always estimate object diameter, vessel thickness, annotation uncertainty, and matching tolerance in both physical and voxel units. Resample when reliable spacing is available or when train/test resolution differences are known; otherwise use scale augmentation and resolution ensembles.

**When NOT to use:** Avoid blind resampling when test spacing is missing or interpolation destroys weak cryoET texture. Do not enlarge crops and call it higher resolution if the physical pixel size is unchanged; upsampling or changing spacing, not merely adding context, changes effective object scale.

**How to reason about it:**
Require the smallest recognizable feature to occupy several input pixels. For point localization, choose output stride so the tolerance spans multiple output cells and choose blob sigma/radius large enough to make positives learnable but smaller than the distance at which nearby objects merge. For mask metrics that sweep high IoU or use zero-tolerance surface Dice, allocate more resolution to edges.

```python
def geometry_config(object_diameter_um, spacing_um, tolerance_um=None):
    diameter_vox = object_diameter_um / spacing_um
    cfg = {"diameter_vox": diameter_vox}
    if tolerance_um is not None:  # point localization
        tol_vox = tolerance_um / spacing_um
        cfg["output_stride"] = max(1, int(tol_vox // 3))
        cfg["heatmap_sigma_vox"] = max(1.0, 0.2 * tol_vox)
    else:  # boundary-sensitive mask
        cfg["target_min_pixels_across"] = 8
        cfg["upscale"] = max(1, int(8 / max(diameter_vox, 1)))
    return cfg
```
