My exploration:

**1. How to produce this dataset ?**

**The first clue:** All original features are independent and each var unique count in train are consistent with gaussian.

**Second:** I note that the distribution of sample which target==0 like gaussian(u,sigma), where u=train[var].mean(), sigma=train[var].std().




So I guess that much target==0 samples are noise which generated by gaussian(u,sigma).  Therefore, we need to do two things.

One, distinguishing the real samples and noise samples(target==0). Two, classifying the real samples.

**Third:** Thanks to @YaG320 for sharing the great [discover](https://www.kaggle.com/yag320/list-of-fake-samples-and-public-private-lb-split).

I realized that the test contain 100k real samples and 100k fake samples. Further more, the fake samples were generated by randomly shuffle in different target.

**So I conclued that there are some original real samples(maybe &lt; 100k) with original features which are extracted from PCA.  Then add some gaussion noise with target == 0 to get 300k samples. And then, split 300k samples to 200k train and 100k test. Finally, randomly shuffle test in different target to get 200k test samples.(This is why we need only count train and real test.)**

**2. Why counts can work ?**

Based on the above, we need distinguish the real samples and noise samples(target==0) and classify the real samples.  For the second task, a common model can do it. But for first task, we need more info. 

Different value with the same count are a breakthrough. A value near u and A value near min or max have the same count is very different.

If count is **big**, the value near u is probably from the gaussian noise and the value near min or max is probably from the real samples. 

Conversely,  if count is **small**, the value near u is probably from the real smaples and the value near min or max is probably from the gaussian noise.

So how to distinguish whether a value comes from gaussian noise or not is the key point.
