<p>Well, that was an unexpected surprise this morning. I was just hoping to stay in the top 10%. <br>Congratulations to small yellow duck and the other top scorers.</p>
<p>My approach seems similar to a number of the ones posted above. I used scikit-learn GradientBoostingClassifier (thanks to the authors!).</p>
<p>Early on I saw that CV was going to be relatively inaccurate so I ended up choosing 500 resamples of different 2/3 &#8211; 1/3 splits. This took the standard error on my CV AUC calculation down to about 0.0007 so that I could reasonably have an idea of whether each feature I tested was making a positive or negative difference. The inaccuracy on a single CV fold and the helpful post by T. Scharf,&nbsp;<a href="https://www.kaggle.com/c/facebook-recruiting-iv-human-or-bot/forums/t/14394/a-basic-look-at-lb-scores">https://www.kaggle.com/c/facebook-recruiting-iv-human-or-bot/forums/t/14394/a-basic-look-at-lb-scores</a> <br>suggested that public LB scores were not going to be particularly useful so I only made 3 submissions to avoid any temptation to overfit the public LB - I find this a very difficult thing to do&#8230;</p>
<p><br>Some of my most helpful features were:</p>
<p>- The proportion of each bidder&#8217;s bids that were in each day ( I believe there were 9 days of bid data).<br>- The proportion of each bidder&#8217;s bids that were in each of 8 3-hour time slots.<br>- The mean time of day for the bids of each bidder.<br>- The total number of bids for each bidder.<br>- The frequency of each final part of the IP address averaged for each bidder &#8211; the first three parts had no positive effect.<br>- The average proportion of bots associated with each device code. NB &#8211; (difficult to put into CV without data leakage &#8211; a slightly different data set for each fold!)<br>- Same as above for each country code.<br>- The total number of bids made in each auction averaged for each bidder. (i.e. did the bidder tend to bid in popular auctions or less popular ones)<br>- The maximum number of auctions a bidder has participated in, in one hour.</p>
<p>Hopefully, this gives a flavour of what I was trying. Some of the features are quite hard to put into words!</p>
<p>One final trick that may have made the difference is that I looked at the histogram of the number of bids made by each bot in the training set. There were 5 bots that made just one bid, which looked anomalous to my eye. I wondered if this might not help to predict on a different data set so I submitted an entry which was just my main model but trained on the training set without these five bots. I think this one was the winner, but I&#8217;ll confirm when I can see all my submission private scores.</p>
<p>I&#8217;ll post in greater detail when I have written my model up. Apologies, as was not expecting to win! </p>
