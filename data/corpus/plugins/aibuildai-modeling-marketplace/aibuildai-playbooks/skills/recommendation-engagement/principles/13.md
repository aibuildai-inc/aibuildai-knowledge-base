## Principle 13: Create Nested Models on Sub-Tables for Implicit Target Propagation

*Consensus: Home Credit #5 (nested models on 6 sub-tables, +0.002 CV), unique to multi-table credit risk tasks.*

For each one-to-many sub-table, join the main target to sub-table rows, train a model to predict target at the sub-table level, then aggregate the row-level predictions (mean, max, min) back to the main table as features.

**Why this matters:** Sub-table rows don't have direct targets, but they indirectly relate to user-level outcomes. A nested model learns 'what installment payment patterns correlate with default' without manual feature engineering. The model automatically weights recent vs. old records, large vs. small payments, etc. Aggregated predictions capture nuanced sub-table risk signals in a single feature.

**When to use:** For credit/risk tasks with rich sub-tables (installment_payments, previous_applications, bureau_records). When sub-table behaviors are complex (many columns, temporal patterns). When hand-crafted aggregations miss subtle patterns. When you have sufficient rows in sub-tables (>100k total) for the nested model to train.

**When NOT to use:** When sub-tables are sparse (<10 rows per user on average—nested model has no data). When you're already at compute limits (nested models double training time). When simple aggregations (mean, count) already capture the signal (nested models overfit). For CTR/ad tasks without sub-tables (no nested structure).

**How to reason about it:**
Join main table target to sub-table on user_id (each sub-table row gets the user's target). Train LGBM to predict target using sub-table features. Generate out-of-fold predictions for sub-table rows. Aggregate predictions per user (mean, max, min, std). Add aggregated predictions as features to main model. If nested model AUC is low (0.55-0.65), that's expected—signal is weak but still additive.

```python
# Nested model on sub-table\nsub_table_with_target = sub_table.merge(main_table[['user_id', 'target']], on='user_id')\n\n# Train model on sub-table to predict user-level target\nnested_model = lgb.LGBMClassifier()\nnested_model.fit(sub_table_with_target[sub_features], sub_table_with_target['target'])\n\n# Predict on sub-table rows (use OOF for train)\nsub_table_with_target['nested_pred'] = nested_model.predict_proba(\n    sub_table_with_target[sub_features]\n)[:, 1]\n\n# Aggregate back to user level\nnested_agg = sub_table_with_target.groupby('user_id')['nested_pred'].agg(['mean', 'max', 'std'])\nmain_table = main_table.merge(nested_agg, on='user_id', how='left')
```
