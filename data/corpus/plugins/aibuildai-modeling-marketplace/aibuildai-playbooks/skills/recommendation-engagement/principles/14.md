## Principle 14: Use Target Encoding with Strict Time-Based or Fold-Based Holdout

*Consensus: Standard across competitions, but TalkingData #5 (lagged target encoding by day), Home Credit top solutions (careful CV to avoid leakage).*

Replace categorical values with the mean target of that category. For time-series, use previous period's mean. For cross-validation, compute target mean on train folds only, never including the validation fold.

**Why this matters:** Target encoding compresses high-cardinality categoricals into a single numerical feature that directly correlates with the target. It's the most powerful encoding for tree models. But it's also the easiest to leak: computing mean target on the full dataset (including validation) creates a circular dependency—the feature knows the answer. Proper holdout is essential.

**When to use:** For high-cardinality categoricals (>100 unique values) where one-hot encoding is infeasible. When category frequency is sufficient (>50 samples per value). With GBMs (GBMs use target-encoded features well; NNs can overfit them). When you have proper CV infrastructure to avoid leakage.

**When NOT to use:** For low-cardinality features (<10 values—one-hot encoding is safer). When categories have <20 samples (mean target is noisy). When you can't implement proper holdout (your CV is broken—fix that first). When you've already used extensive aggregations (target encoding may be redundant).

**How to reason about it:**
For K-fold CV: compute target mean per category on K-1 folds, apply to the held-out fold. For time-series: compute target mean on data before time T, apply to data at time T. Never compute on the same data you're encoding. Add smoothing (global mean weighted by sample count) for rare categories. Validate that encoded feature doesn't leak by checking train/val correlation—if val correlation is much lower, you leaked.

```python
# Target encoding with K-fold holdout (no leakage)\nfrom sklearn.model_selection import KFold\nkf = KFold(n_splits=5)\ntrain['target_encoded'] = 0\n\nfor train_idx, val_idx in kf.split(train):\n    # Compute mean on train fold\n    target_mean = train.iloc[train_idx].groupby('category')['target'].mean()\n    # Apply to validation fold\n    train.loc[val_idx, 'target_encoded'] = train.iloc[val_idx]['category'].map(target_mean)\n\n# For test: use full train\ntest_target_mean = train.groupby('category')['target'].mean()\ntest['target_encoded'] = test['category'].map(test_target_mean).fillna(train['target'].mean())
```
