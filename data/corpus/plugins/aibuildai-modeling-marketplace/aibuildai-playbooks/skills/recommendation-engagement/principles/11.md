## Principle 11: Stack Multiple Levels with Raw Feature Restacking

*Consensus: Home Credit #1 (3-level stacking with raw features at L2), standard in top solutions with large teams.*

Level 1: diverse base models (GBM, NN, different feature sets). Level 2: meta-models trained on L1 predictions PLUS selected raw features (not just predictions). Level 3: simple blend of L2 models.

**Why this matters:** Pure stacking (L2 sees only L1 predictions) can't recover information lost if all L1 models miss a pattern. Adding raw features to L2 gives meta-models direct signal, letting them correct L1 errors. This 'restacking' often adds 0.001-0.002 over pure stacking. Multiple L2 models (NN, ExtraTrees, linear) capture different meta-patterns.

**When to use:** When you have 10+ diverse base models (different algorithms, feature sets, hyperparameters). When single models and simple blending plateau. When team has enough compute for multi-level training. When you've verified no target leakage in the stacking pipeline.

**When NOT to use:** When you have <5 base models (stacking overfits). When base models are highly correlated (>0.98—no diversity to exploit). When you lack time/compute for proper CV-based stacking (shortcuts create leakage). When a simple average of top 3 models already maximizes LB (more complexity adds no value).

**How to reason about it:**
Train 10-50 L1 models with 5-fold CV, save out-of-fold predictions. Create L1 meta-features (50 columns of predictions). Add top 5-10 raw features by importance from base models. Train L2 models (NN, GBM, ExtraTrees) on L1_preds + raw_features. Create L2 meta-features. Train L3 (simple weighted average or linear blend). Validate that CV correlates with LB at each level.

```python
# Level 1: out-of-fold predictions from base models\nl1_preds = np.column_stack([model.oof_predictions for model in base_models])\n\n# Level 2: combine L1 predictions with top raw features\ntop_raw_features = ['AMT_INCOME_TOTAL', 'EXT_SOURCE_2', 'DAYS_BIRTH']  # from feature importance\nl2_features = np.column_stack([l1_preds, train[top_raw_features]])\n\n# Train L2 meta-models\nl2_nn = train_nn(l2_features, target)\nl2_et = ExtraTreesClassifier(max_depth=4, min_samples_leaf=1000).fit(l2_features, target)\nl2_preds = np.column_stack([l2_nn.predict(l2_features), l2_et.predict_proba(l2_features)[:, 1]])\n\n# Level 3: simple average\nfinal_pred = l2_preds.mean(axis=1)
```
