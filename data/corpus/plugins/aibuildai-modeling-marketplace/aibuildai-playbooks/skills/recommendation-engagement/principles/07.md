## Principle 7: Use Time-Based Train/Validation Split for Temporal Data

*Consensus: KKBox #1 (last 20% by time), TalkingData #1 (day 7-8 train, day 9 val), standard across temporal competitions.*

Split data chronologically: train on earlier time periods, validate on later. Generate features from train-only data for validation, from train+test for final submission.

**Why this matters:** Random CV leaks future information to past (feature statistics computed on day 10 shouldn't inform day 1). Chronological split respects causality. It also reveals temporal drift—if CV/LB diverge, distribution is shifting. Using train+test features for submission (but train-only for validation) avoids false positives from data leakage during development.

**When to use:** When data has timestamps and you're predicting future events. When features depend on historical statistics (counts, means, target encoding). When temporal drift is likely (user behavior changes over months). For any time-series or sequential prediction.

**When NOT to use:** When timestamps are absent or irrelevant. When the task is static classification (medical diagnosis from lab results with no time component). When you have so little data (<10k rows) that losing 20% to validation is unaffordable—but even then, time split is more honest than random.

**How to reason about it:**
Sort by timestamp. Use last 10-20% as validation (adjust based on data volume). Compute all aggregated/encoded features using ONLY train data for validation. For submission, recompute features using train+test. Compare CV to LB—divergence signals drift or leakage. If CV is stable, trust it over LB for model selection.

# Time-based split\ndf = df.sort_values('timestamp')\nsplit_idx = int(len(df) * 0.8)\ntrain = df.iloc[:split_idx]\nval = df.iloc[split_idx:]\n\n# Features from train-only (for validation)\ntrain_stats = train.groupby('category')['target'].mean()\nval['target_encoded'] = val['category'].map(train_stats).fillna(0)\n\n# Features from train+test (for submission)\nfull_stats = pd.concat([train, test]).groupby('category')['target'].mean()\ntest['target_encoded'] = test['category'].map(full_stats).fillna(0)
