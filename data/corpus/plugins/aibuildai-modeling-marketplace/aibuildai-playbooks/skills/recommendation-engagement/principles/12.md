## Principle 12: Engineer Uniqueness and Count-Based Features

*Consensus: Santander #1 (uniqueness features were the 'magic' enabling 0.927 LB), TalkingData top solutions (nunique counts, top-k value ratios).*

For each feature, create: (1) is this value unique in train? (2) is it unique in train+test? (3) count of this value in data. (4) ratio of top-k most frequent values. These capture distribution anomalies.

**Why this matters:** Unique values are often synthetic, test-only, or anomalous—strong signal for adversarial validation and some tasks. Value frequency reveals common vs. rare patterns. Top-k ratios measure concentration (one dominant value vs. uniform distribution). In Santander, uniqueness alone separated real from fake test samples and enabled >0.92 LB.

**When to use:** When adversarial validation shows high train/test separability. For fraud/anomaly detection (unique IDs are suspicious). When you suspect synthetic test data. When categorical features have extreme cardinality (1M+ unique values). For count-based features in CTR/ad tasks.

**When NOT to use:** When all values appear multiple times (no uniqueness signal). When features are continuous (uniqueness is trivial—every float is unique). When you've already embedded categories (count features are redundant). When uniqueness is by design (user_id is always unique per user—no anomaly).

**How to reason about it:**
For each categorical or discrete numerical feature: (1) compute value counts in train, test, and train+test. (2) Create binary feature: is_unique_in_train, is_unique_in_traintest. (3) Create count/ratio features: value_count, top1_ratio (frequency of most common value / total), nunique_ratio (# unique values / total). (4) Test on CV—remove if no lift.

```python
# Uniqueness features\nfor col in categorical_features:\n    train_counts = train[col].value_counts()\n    combined_counts = pd.concat([train[col], test[col]]).value_counts()\n    \n    # Is value unique in train?\n    train[f'{col}_is_unique_train'] = train[col].map(train_counts == 1).astype(int)\n    \n    # Is value unique in train+test?\n    train[f'{col}_is_unique_combined'] = train[col].map(combined_counts == 1).astype(int)\n    \n    # Count and ratio\n    train[f'{col}_count'] = train[col].map(train_counts)\n    train[f'{col}_top1_ratio'] = train[col].map(train_counts / len(train))
```
