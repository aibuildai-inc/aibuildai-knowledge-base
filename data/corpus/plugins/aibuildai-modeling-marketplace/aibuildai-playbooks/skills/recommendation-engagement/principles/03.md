## Principle 3: Engineer Multi-Level Aggregations from Related Tables

*Consensus: Home Credit top 5 all created 500-3000+ aggregated features. KKBox #1 used 400 features. Standard in all relational datasets.*

For one-to-many relationships (user → transactions, customer → loans), create aggregated features with multiple functions (count, mean, std, min, max) and time windows (last N, first N, last K days).

**Why this matters:** Raw sub-table rows can't directly predict user-level targets. Aggregations compress user history into fixed-width features the model can use. Different aggregation functions capture different patterns: count → activity level, mean → typical behavior, std → consistency, max → worst case. Time-windowed aggregations capture recent vs. distant behavior.

**When to use:** Whenever you have one-to-many tables (previous_applications, transactions, installment_payments, bureau_records). When user/item history is relevant to prediction. When the dataset provides relational structure.

**When NOT to use:** Don't aggregate everything blindly—creates thousands of redundant features. Skip aggregations that have no business logic (e.g., std of categorical codes). For very sparse sub-tables (<5% users have records), aggregations may be mostly null and add noise.

**How to reason about it:**
List all one-to-many tables. For each, identify meaningful numerical columns and define aggregations. Start with [count, mean, max, min, std]. Add time-based slices (last 3, last 5, first 2 records; last 60/90/180 days). Test subsets on CV. Use feature importance to prune low-value aggregations.

```python
# Multi-level aggregations\nagg_features = transactions.groupby('user_id').agg({\n    'amount': ['mean', 'std', 'max', 'min', 'sum'],\n    'transaction_id': 'count',  # activity count\n    'is_fraud': 'mean'  # fraud rate\n})\n\n# Time-windowed aggregations\nrecent = transactions[transactions.days_ago <= 60]\nrecent_agg = recent.groupby('user_id')['amount'].mean()\n\n# Sliced by recency\nlast_3 = transactions.groupby('user_id').head(3).groupby('user_id')['amount'].mean()
```
