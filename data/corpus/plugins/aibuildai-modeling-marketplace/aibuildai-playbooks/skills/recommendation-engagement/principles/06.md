## Principle 6: Embed High-Cardinality Categories with Matrix Factorization

*Consensus: TalkingData #1 (LDA/NMF/PCA on user-app matrix), KKBox #1 (SVD on user-song and user-artist matrices), used in 5+ top solutions.*

Create user-item co-occurrence matrix, apply SVD/LDA/NMF to get low-dimensional embeddings (5-50 dimensions). Use embeddings as numerical features.

**Why this matters:** Raw user_id/item_id have millions of values, impossible for tree models to split. Embeddings compress identity into dense vectors capturing latent preferences. SVD on user-song matrix learns 'user X likes rock' without explicit genre labels. The 'missing not at random' property means co-occurrence itself is signal.

**When to use:** For user_id, item_id, or any categorical with >10k unique values. When co-occurrence patterns are informative (users who listen to song A also listen to B). When you have a user-item interaction matrix. For collaborative filtering scenarios.

**When NOT to use:** When categories are low-cardinality (<100 values)—simple one-hot encoding suffices. When co-occurrence is random (user and item are independent). When the matrix is too sparse (<0.1% filled—factorization learns noise). When you've already used these IDs in FFM (FFM learns embeddings internally).

**How to reason about it:**
Build user-item matrix (rows=users, cols=items, values=interaction count or binary). Check sparsity. If <5% filled but still meaningful signal, use factorization. Try SVD (5-20 components), LDA (5-10 topics), NMF (5-20 components). Add resulting user/item embeddings as features. Test on CV.

```python
# SVD embeddings for user-song matrix\nfrom sklearn.decomposition import TruncatedSVD\nfrom sklearn.feature_extraction.text import CountVectorizer\n\n# Treat each user's items as a 'document'\nuser_items = df.groupby('user_id')['item_id'].apply(lambda x: ' '.join(x.astype(str)))\ncount_matrix = CountVectorizer().fit_transform(user_items)\nsvd = TruncatedSVD(n_components=10)\nuser_embeddings = svd.fit_transform(count_matrix)  # shape (n_users, 10)\n\n# Join back\nembedding_df = pd.DataFrame(user_embeddings, index=user_items.index, \n                             columns=[f'user_svd_{i}' for i in range(10)])
```
