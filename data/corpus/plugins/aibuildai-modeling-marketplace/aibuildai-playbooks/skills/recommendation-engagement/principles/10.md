## Principle 10: Use Field-Aware Neural Network Architectures for Multi-Entity Data

*Consensus: KKBox #1 (separate user/song/context fields with independent embeddings then concatenate), standard in recommendation NNs.*

Divide features into fields (user, item, context). Embed each field separately with independent dense layers before concatenating. This mimics FFM's field-awareness in neural networks.

**Why this matters:** Concatenating all features into one dense layer forces user, item, and context to share weights, preventing specialized feature extraction. Field-aware architecture lets each entity learn its own representation before interaction. Reduces parameters (smaller embeddings per field vs. one huge layer) and improves generalization. Typically adds 0.001-0.003 AUC over naive concatenation.

**When to use:** For recommendation/engagement tasks with clear entities (user, item, ad, context). When you have separate metadata tables (user_features, item_features). When entities have different cardinalities and semantics. When naive NN underperforms GBM—field-aware structure often closes the gap.

**When NOT to use:** When features don't naturally group into fields (all features are aggregated user stats—no item or context). When you have very few features (<20 total—field splitting overhead isn't worth it). When you're using FFM for base model (it already handles fields).

**How to reason about it:**
Identify natural groupings: user features (demographics, history stats), item features (attributes, popularity), context features (time, platform, session). Create separate embedding layers for each field's categorical features and dense layers for numericals. Extract field-level representations (e.g., 50-dim user vector, 50-dim item vector, 20-dim context vector). Concatenate, then feed to final dense layers and output.

```python
# Field-aware NN in Keras\nuser_input = Input(shape=(len(user_features),))\nuser_embed = Dense(64, activation='relu')(user_input)\n\nitem_input = Input(shape=(len(item_features),))\nitem_embed = Dense(64, activation='relu')(item_input)\n\ncontext_input = Input(shape=(len(context_features),))\ncontext_embed = Dense(32, activation='relu')(context_input)\n\n# Concatenate field representations\nconcat = Concatenate()([user_embed, item_embed, context_embed])\nhidden = Dense(128, activation='relu')(concat)\noutput = Dense(1, activation='sigmoid')(hidden)\n\nmodel = Model(inputs=[user_input, item_input, context_input], outputs=output)
```
