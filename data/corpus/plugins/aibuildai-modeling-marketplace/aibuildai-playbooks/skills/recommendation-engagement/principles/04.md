## Principle 4: Create Conditional Probability Features for Categorical Interactions

*Consensus: KKBox #1 used P(source_type|user), P(artist|user) as top features. Multiple CTR solutions used P(click|user,ad) style features.*

Compute P(feature_A | feature_B) = count(A and B) / count(B) for categorical pairs. Captures user preferences, item characteristics, and interaction patterns.

**Why this matters:** Raw categorical combinations create impossible-to-learn sparse interactions. Conditional probabilities compress user behavior patterns into dense numerical features. P(genre|user) directly encodes 'user X prefers jazz' without requiring the model to learn it from co-occurrence. Maximum Likelihood Estimation (no smoothing) often works best despite sparsity.

**When to use:** For user-item preferences (P(genre|user), P(source_type|user)). For item characteristics (P(category|item)). When you have high-cardinality categoricals with meaningful relationships. When simple count features don't capture the preference signal.

**When NOT to use:** When categories are unique (user_id has 1M values, each appears once—probability is always 1/N and uninformative). When you've already embedded the categories (SVD/LDA features already capture this). When sample sizes are tiny (<10 observations per group—probabilities are noise).

**How to reason about it:**
Identify categorical pairs with business meaning: user preferences (user→genre), item traits (item→category), context patterns (time→event_type). Compute count(A,B) and count(B) via groupby. Divide for probability. Test MLE (no smoothing) first; add Laplace smoothing only if MLE underperforms on CV.

```python
# Conditional probability: P(genre | user)\nuser_genre_counts = df.groupby(['user_id', 'genre']).size()\nuser_total_counts = df.groupby('user_id').size()\nprob_genre_given_user = user_genre_counts / user_total_counts\n\n# Join back as feature\ndf['prob_genre_given_user'] = df.set_index(['user_id', 'genre']).index.map(\n    prob_genre_given_user\n).fillna(0)  # unseen combinations get 0
```
