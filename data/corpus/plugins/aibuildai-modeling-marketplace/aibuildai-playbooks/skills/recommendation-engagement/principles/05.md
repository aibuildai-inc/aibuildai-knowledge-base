## Principle 5: Extract Time Delta and Lagged Target Features

*Consensus: TalkingData #5 (time_diff forward/backward as top features), KKBox #1 (timestamp index), Home Credit #1 (lag features from last 5 applications).*

Compute time differences between consecutive events (forward/backward deltas). Create lagged target encoding by using previous time period's target mean for current period.

**Why this matters:** Time deltas reveal behavior patterns: regular 5-second clicks indicate bots, irregular spacing suggests humans. Forward/backward deltas capture local context. Lagged target encoding uses yesterday's conversion rate to predict today, respecting temporal causality. These features often rank in top 10 by importance.

**When to use:** When data has timestamps and events are ordered chronologically. For fraud/bot detection (regular time patterns are suspicious). When behavior changes over time. For any time-series prediction where recent past predicts near future.

**When NOT to use:** When timestamps are coarse (day-level only) and event ordering within a day is random—deltas are noise. When users/items are independent (no sequence)—cross-user time deltas are meaningless. When you have <3 events per user—can't compute meaningful deltas or lags.

**How to reason about it:**
Sort data by user and timestamp. Compute diff() for time deltas to next/previous event. For lagged target encoding: split by time periods (days/weeks), compute target mean per category in period T, use as feature in period T+1. Never use same-period target (that's leakage).

```python
# Time deltas\ndf = df.sort_values(['user_id', 'timestamp'])\ndf['time_diff_forward'] = df.groupby('user_id')['timestamp'].diff()\ndf['time_diff_backward'] = df.groupby('user_id')['timestamp'].diff(-1)\n\n# Lagged target encoding (day-over-day)\ndf['day'] = df['timestamp'].dt.date\nday_target_mean = df.groupby(['day', 'category'])['target'].mean()\ndf['lagged_target'] = df.apply(\n    lambda row: day_target_mean.get((row['day'] - pd.Timedelta(days=1), row['category']), 0),\n    axis=1\n)
```
