## Principle 14: Choose Global-Only vs. Local+Global Based on Computational Budget and Marginal Gain

*Consensus: 1st place 2020 used global-only, 1st place 2021 used local+global (DOLG). Mixed approaches across top solutions.*

Decide whether to use pure global descriptors (CNN/ViT → pooling → embedding) or incorporate local descriptors (keypoint-based features like DELG/DOLG). Local features add geometric information but increase complexity and inference time significantly. Global-only with strong post-processing often matches local+global performance.

**Why this matters:** Local features provide fine-grained spatial information that helps distinguish similar landmarks and enables geometric verification (RANSAC). However, they require additional model components, slower inference, and careful tuning. Multiple top solutions (1st place 2020 recognition) achieved winning performance with global features alone by investing in better training, ensembling, and re-ranking. The choice is a cost-benefit trade-off: local features add ~0.02-0.05 to mAP but 3-5x to inference time.

**When to use:** Use local+global when: (1) You have ample computational budget, (2) Your task explicitly requires spatial verification or fine-grained discrimination, (3) Architectures like DOLG/DELG are available and proven for your task, (4) Global-only models plateau and you need the extra 2-5% improvement. Use global-only when: (1) Inference time is constrained, (2) You're early in development and want to iterate quickly, (3) Previous solutions showed global-only can win, (4) Your computational budget is better spent on ensembles or better post-processing.

**When NOT to use:** Don't default to local features without testing global-only first. Don't use local features if you can't afford proper geometric verification (RANSAC)—just extracting keypoints without verification often doesn't help. Don't use local features for pure retrieval tasks where spatial verification isn't needed (image matching for SfM is different—there local features are essential).

**How to reason about it:**
1. Start with global-only: train a strong global descriptor model with good backbone, metric learning, and post-processing. 2. Measure performance and inference time. 3. If you're within 5% of your target and inference time matters, stick with global. 4. If you're stuck and need more signal, test local+global: implement DOLG or DELG, or add SuperPoint + spatial verification as a re-ranking step. 5. Measure the gain: if local features add <0.02 to mAP but double inference time, reconsider. 6. Check top solutions: did any win with global-only? If yes, that path is viable.

# Global-only approach
class GlobalModel(nn.Module):
    def __init__(self, backbone):
        super().__init__()
        self.backbone = backbone
        self.gem = GeM(p=3.0)  # Global pooling
        self.fc = nn.Linear(2048, 512)
    
    def forward(self, x):
        features = self.backbone(x)  # (B, C, H, W)
        global_desc = self.gem(features).squeeze()  # (B, C)
        embedding = self.fc(global_desc)  # (B, 512)
        return F.normalize(embedding)

# Local+Global approach (DOLG-style)
class LocalGlobalModel(nn.Module):
    def __init__(self, backbone):
        super().__init__()
        self.backbone = backbone
        # Global branch
        self.gem = GeM(p=3.0)
        self.global_fc = nn.Linear(2048, 512)
        # Local branch  
        self.local_attention = AttentionModule(2048)
        self.local_fc = nn.Linear(2048, 128)
        # Fusion
        self.fusion = OrthogonalFusion(512, 128)
    
    def forward(self, x):
        features = self.backbone(x)  # (B, C, H, W)
        
        # Global descriptor
        global_desc = self.gem(features).squeeze()
        global_emb = self.global_fc(global_desc)  # (B, 512)
        
        # Local descriptors
        local_features = self.local_attention(features)  # (B, C, H, W)
        local_desc = local_features.max(dim=2)[0].max(dim=2)[0]  # (B, C)
        local_emb = self.local_fc(local_desc)  # (B, 128)
        
        # Fuse
        fused = self.fusion(global_emb, local_emb)  # (B, 512)
        return F.normalize(fused)

# If global-only gets mAP=0.60 in 2s, local+global gets 0.63 in 8s
# → Use global unless you specifically need 0.63+
