## Principle 3: Use ArcFace with Dynamic Margins Based on Class Frequency

*Consensus: 4/5 top landmark solutions 2020-2021. Introduced by 3rd place 2020, adopted widely after.*

Use ArcFace (additive angular margin) loss instead of softmax, with margins that vary by class size: smaller/rarer classes get larger margins (harder to classify), larger/frequent classes get smaller margins. The margin is a continuous function of log(class_count), not discrete buckets.

**Why this matters:** Landmark datasets have extreme class imbalance—some landmarks have 1000s of images, others have <10. Fixed-margin ArcFace causes the model to overfit to head classes while ignoring tail classes. Larger margins for rare classes force the model to learn more discriminative features for them, preventing the embedding space from collapsing to just the frequent landmarks. This directly improves retrieval of rare landmarks.

**When to use:** When your dataset has heavy class imbalance (>10x difference between head and tail class sizes). When using metric learning losses (ArcFace, CosFace). When your evaluation metric cares about rare classes (mAP weights all classes equally, unlike top-K accuracy).

**When NOT to use:** When classes are relatively balanced (variance in class size <3x), fixed margin works fine. When using other metric learning approaches like contrastive learning with hard negative mining, where the mining strategy already addresses imbalance. Some top solutions (1st place 2020 retrieval) used fixed margin 0.5 and compensated with strong data sampling strategies.

**How to reason about it:**
1. Compute class frequency distribution: plot histogram of log(class_count). 2. If long-tailed (>2 orders of magnitude range), use dynamic margins. 3. Define margin function: m = m_min + (m_max - m_min) * (1 - log(count)/log(max_count)). 4. Set m_min=0.2-0.3 (for frequent classes), m_max=0.5-0.7 (for rare classes). 5. Monitor per-class accuracy during validation—if tail classes aren't improving, increase m_max.

```python
import numpy as np
import torch.nn as nn

class DynamicArcFace(nn.Module):
    def __init__(self, embedding_dim, num_classes, class_counts, 
                 s=30.0, m_min=0.3, m_max=0.5):
        super().__init__()
        self.s = s
        self.weight = nn.Parameter(torch.randn(num_classes, embedding_dim))
        
        # Compute dynamic margins based on class frequency
        log_counts = np.log(class_counts + 1)
        # Rare classes (low count) get high margin, frequent get low margin
        normalized = (np.max(log_counts) - log_counts) / (np.max(log_counts) - np.min(log_counts))
        self.margins = m_min + (m_max - m_min) * normalized
        self.margins = torch.FloatTensor(self.margins)
        
    def forward(self, embeddings, labels):
        # Normalize embeddings and weights
        embeddings = F.normalize(embeddings)
        weights = F.normalize(self.weight)
        
        # Cosine similarity
        cosine = F.linear(embeddings, weights)
        
        # Apply class-specific margins
        theta = torch.acos(torch.clamp(cosine, -1.0 + 1e-7, 1.0 - 1e-7))
        target_margins = self.margins[labels].to(embeddings.device)
        target_logits = torch.cos(theta + target_margins.unsqueeze(1))
        
        # Replace target class logits
        one_hot = F.one_hot(labels, num_classes=cosine.size(1))
        output = cosine * (1 - one_hot) + target_logits * one_hot
        return output * self.s
```
