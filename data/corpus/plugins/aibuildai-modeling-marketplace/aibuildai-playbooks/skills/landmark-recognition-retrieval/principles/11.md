## Principle 11: Use Minimal Augmentation for Metric Learning: Horizontal Flip, Shift-Scale-Rotate, Cutout

*Consensus: 3rd place landmark 2020 published exact augmentation config, adopted by 2021 winners.*

For metric learning on landmarks, use conservative augmentations: horizontal flip (p=0.5), ShiftScaleRotate (shift ±20%, scale ±20%, rotate ±10°, p=0.7), ImageCompression (quality 99-100%), Cutout (40% of image size, 1 hole, p=0.5), and resize. Do NOT use vertical flip, heavy color jitter, or extreme distortions.

**Why this matters:** Landmarks have characteristic orientations—buildings don't appear upside down. Metric learning requires consistency: the same landmark in different photos should map to nearby embeddings. Heavy augmentation introduces too much variance, making it harder to learn tight clusters. Horizontal flip and moderate rotation cover real-world viewpoint variation. Cutout teaches robustness to occlusions without distorting the landmark's appearance. This specific recipe has been validated across multiple winning solutions.

**When to use:** For metric learning tasks (ArcFace, contrastive learning) where embedding consistency matters. For instance-level recognition where objects have canonical orientations. When training on landmarks, buildings, or man-made structures.

**When NOT to use:** For classification tasks where invariance to heavy augmentation can help (rotate 360°, strong color jitter). For natural objects without orientation (animals, plants) where vertical flip may be valid. For domain-specific augmentations (medical images may need intensity transforms). When your data is extremely limited (<1K images per class), heavier augmentation may be necessary despite the trade-off.

**How to reason about it:**
1. Start with the proven recipe: HorizontalFlip + ShiftScaleRotate + Cutout. 2. Validate on a hold-out set: does adding VerticalFlip or ColorJitter improve or hurt? For landmarks, they typically hurt. 3. Check if your domain differs: if training on natural scenes or objects without orientation, test additional augmentations. 4. Monitor training: if loss oscillates heavily, augmentation may be too strong. 5. Keep ImageCompression quality high (99-100%) to avoid introducing compression artifacts the model learns.

```python
import albumentations as A

# Validated augmentation pipeline for landmark metric learning
train_transform = A.Compose([
    A.HorizontalFlip(p=0.5),
    A.ImageCompression(quality_lower=99, quality_upper=100),
    A.ShiftScaleRotate(
        shift_limit=0.2,   # ±20% translation
        scale_limit=0.2,   # ±20% zoom  
        rotate_limit=10,   # ±10° rotation
        border_mode=0,     # constant border
        p=0.7
    ),
    A.Resize(image_size, image_size),
    A.Cutout(
        max_h_size=int(image_size * 0.4),  # 40% of image height
        max_w_size=int(image_size * 0.4),  # 40% of image width
        num_holes=1,
        p=0.5
    ),
    A.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

val_transform = A.Compose([
    A.Resize(image_size, image_size),
    A.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

# - A.VerticalFlip()  # Buildings don't appear upside down
# - A.ColorJitter(brightness=0.5, contrast=0.5)  # Too strong
# - A.RandomRotate90()  # Destroys orientation information  
# - A.CoarseDropout()  # Cutout is sufficient
```
