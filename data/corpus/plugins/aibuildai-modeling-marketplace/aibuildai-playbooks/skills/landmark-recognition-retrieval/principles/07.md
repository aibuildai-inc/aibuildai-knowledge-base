## Principle 7: Aggregate Top-K Neighbors with Power-Weighted Voting, Not Just Top-1

*Consensus: 3rd place landmark 2020, multiple retrieval solutions. Significant boost over top-1.*

Instead of using only the top-1 nearest neighbor for prediction, aggregate the top-K (typically K=3 to 5) neighbors and weight their votes by similarity raised to a high power (e.g., similarity^8 to similarity^12). Sum weighted votes per class and predict the class with highest total.

**Why this matters:** Top-1 nearest neighbor is brittle—if the single closest match is wrong, the prediction fails. Top-K with power weighting combines multiple pieces of evidence while still heavily weighting the most confident matches. The high power (8-12) ensures the closest match dominates unless several other matches agree on a different class, providing robustness without diluting strong signals. This typically adds +0.01-0.02 to retrieval mAP.

**When to use:** For retrieval and recognition tasks using KNN on embeddings. When you have sufficient index images (>10 per class on average) to make top-K meaningful. When your embeddings are well-calibrated (similar images have high cosine similarity, dissimilar have low).

**When NOT to use:** When classes have very few index images (<3 per class), top-K may not be meaningful. When computational budget is extremely tight and you can't afford K similarity computations (though K=3 vs K=1 is negligible cost). When embeddings are poorly calibrated and similarity scores don't reliably indicate correctness—fix the embeddings first.

**How to reason about it:**
1. Start with top-1 baseline. 2. Test top-K for K=3, 5, 10 with simple averaging. 3. If top-K > top-1, test power weighting with p=2, 4, 8, 12. 4. Higher powers emphasize confident matches; if your metric cares more about precision than recall, use p=8-12. If recall matters more, use p=4-6. 5. Optionally combine with ArcFace head predictions by multiplying: (neighbor_score^p1) × (arcface_score^p2).

```python
import numpy as np
from collections import defaultdict

def predict_with_power_voting(test_embedding, index_embeddings, index_labels, 
                               top_k=3, power=8, combine_arcface=False, 
                               arcface_logits=None):
    """
    test_embedding: (embed_dim,) normalized
    index_embeddings: (N_index, embed_dim) normalized  
    index_labels: (N_index,) class labels
    """
    # Compute similarities
    similarities = test_embedding @ index_embeddings.T  # (N_index,)
    
    # Get top-K
    top_k_indices = np.argsort(similarities)[-top_k:][::-1]
    top_k_sims = similarities[top_k_indices]
    top_k_labels = index_labels[top_k_indices]
    
    # Power-weighted voting
    class_scores = defaultdict(float)
    for sim, label in zip(top_k_sims, top_k_labels):
        class_scores[label] += sim ** power
    
    # Optionally combine with ArcFace head predictions
    if combine_arcface and arcface_logits is not None:
        # arcface_logits: (num_classes,) raw logits from classification head
        arcface_probs = softmax(arcface_logits)
        for label in class_scores:
            class_scores[label] *= arcface_probs[label] ** 12  # Even higher power
    
    # Predict class with highest score
    predicted_class = max(class_scores, key=class_scores.get)
    confidence = class_scores[predicted_class]
    
    return predicted_class, confidence

# Example power settings from 3rd place 2020:
# - Neighbor voting: similarity^8
# - ArcFace combination: similarity^8 × arcface_prob^12
```
