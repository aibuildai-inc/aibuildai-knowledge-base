## Principle 4: Use GeM Pooling with Learned or Fixed p≈3

*Consensus: 10+ solutions across all years. Standard pooling choice for landmark tasks.*

Replace global average pooling with Generalized Mean (GeM) pooling, which computes the p-th power mean of spatial activations. Use p=3 as default or make p a learnable parameter initialized at 3.

**Why this matters:** GeM pooling with p>1 emphasizes stronger activations while still aggregating spatial information, unlike max pooling which discards most information. For landmarks, the most discriminative regions (e.g., distinctive architectural features) should dominate the global descriptor, but completely ignoring other regions (as max pooling does) loses context. GeM with p≈3 strikes the optimal balance between these extremes for instance-level recognition.

**When to use:** When building global descriptors for retrieval or recognition. When your backbone outputs spatial feature maps that need aggregation into a fixed-size embedding. Standard for CNN backbones; less critical for ViTs which have CLS tokens.

**When NOT to use:** When using transformer architectures with CLS tokens—the attention mechanism already performs learned aggregation, though some solutions still apply GeM to patch tokens. When your task requires explicit spatial localization (use local descriptors instead). When using architectures with built-in attention-based pooling.

**How to reason about it:**
1. Check your backbone output: if it's a spatial feature map (H×W×C), you need pooling. 2. Start with GeM p=3.0 fixed. 3. If validation mAP is sensitive to small changes, make p learnable. 4. If p learns to be >5, your model is becoming too max-pool-like; add regularization. 5. For retrieval tasks, learnable p often helps; for recognition, fixed p=3 is usually sufficient.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class GeM(nn.Module):
    def __init__(self, p=3.0, eps=1e-6, learnable_p=False):
        super().__init__()
        if learnable_p:
            self.p = nn.Parameter(torch.ones(1) * p)
        else:
            self.p = p
        self.eps = eps
    
    def forward(self, x):
        # x: (batch, channels, height, width)
        # Compute p-th power mean
        return F.avg_pool2d(
            x.clamp(min=self.eps).pow(self.p), 
            (x.size(-2), x.size(-1))
        ).pow(1.0 / self.p)
        # Output: (batch, channels, 1, 1)

# Usage in model
class LandmarkModel(nn.Module):
    def __init__(self, backbone, embedding_dim=512):
        super().__init__()
        self.backbone = backbone
        self.gem = GeM(p=3.0, learnable_p=True)  # Learn p during training
        self.fc = nn.Linear(backbone.feature_dim, embedding_dim)
```
