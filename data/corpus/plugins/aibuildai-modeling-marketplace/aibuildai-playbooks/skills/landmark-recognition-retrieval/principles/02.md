## Principle 2: Train Progressively: Clean→Noisy Data, Small→Large Images

*Consensus: 5/5 top landmark solutions 2020-2021 used 3-stage training. Recognized as standard approach.*

Train in multiple stages with increasing data scale and image resolution: (1) Clean subset, small images (~224-256px), (2) Extended noisy dataset, medium images (~512-768px), (3) Full dataset or clean-only, large images (~768-1024px). Each stage uses fewer epochs than the previous.

**Why this matters:** Starting with clean data and small images allows the model to learn robust high-level representations quickly without overfitting to noise. Progressive scaling prevents the model from learning texture shortcuts while managing GPU memory. The noisy data contains valuable visual diversity (different angles, lighting) that clean data lacks, but introducing it too early causes training instability. Large images capture fine details critical for distinguishing similar landmarks.

**When to use:** When you have access to both clean and noisy/extended versions of your dataset (common in landmark datasets with cleaned subsets). When your task requires fine-grained discrimination where both global structure and local details matter. When you have sufficient computational budget for multi-stage training.

**When NOT to use:** When you only have a single cleaned dataset with no extended version—in this case, use curriculum learning by image difficulty instead. When extremely limited compute forces you to train once—better to train longer on medium-resolution images than to rush through stages. Top solutions that skipped stages (some 2019 solutions) compensated with extremely strong post-processing.

**How to reason about it:**
1. Identify your data subsets: What's the cleanest subset? Is there a larger noisy version with the same classes? A full dataset with additional classes? 2. Choose image sizes based on your backbone: 224/256 → 512/768 → 768/1024 for EfficientNets; 224 → 384 → 512 for ViTs. 3. Allocate epochs: ~10 epochs stage 1, ~30-40 epochs stage 2, ~2-5 epochs stage 3. 4. Use learning rate warm restarts between stages. 5. Monitor both clean validation accuracy and noisy validation mAP—if clean accuracy plateaus but noisy mAP keeps rising, the noisy data is working.

```python
# 3-stage progressive training
stages = [
    {  # Stage 1: Learn clean patterns
        'data': 'gldv2_clean',  # 1.6M images, 81K classes
        'image_size': 224,
        'epochs': 10,
        'lr': 1e-3
    },
    {  # Stage 2: Add visual diversity via noisy data
        'data': 'gldv2_extended',  # 3.2M images, same 81K classes
        'image_size': 512, 
        'epochs': 35,
        'lr': 1e-4  # Lower LR for noisy data
    },
    {  # Stage 3: Capture fine details
        'data': 'gldv2_extended',  # or back to clean for some solutions
        'image_size': 768,
        'epochs': 3,
        'lr': 1e-5
    }
]

for stage in stages:
    train_loader = create_loader(
        stage['data'], 
        image_size=stage['image_size']
    )
    # Reload optimizer with new LR, optionally reload model from prev stage
    train(model, train_loader, epochs=stage['epochs'], lr=stage['lr'])
```
