## Principle 10: Apply Test-Time Augmentation with Aspect-Ratio-Aware Resizing

*Consensus: Universal embedding 5th place detailed this explicitly; landmark solutions used multi-scale TTA.*

At test time, process each image with multiple augmentations and average the resulting embeddings. Use aspect-ratio-aware strategies: for square images, use center-crop; for non-square, preserve aspect ratio by padding or use both crop and pad variants. Optionally use horizontal flip and multiple scales.

**Why this matters:** Training typically uses square crops, but test images may have important content at the edges that gets cropped out. Different crops expose different parts of the landmark. TTA reduces variance in the embedding due to cropping randomness, making retrieval more robust. For tasks with diverse image aspect ratios (products, artwork), aspect-ratio awareness is critical—distorting a tall product into a square loses shape information.

**When to use:** When test-time compute budget allows (TTA is 2-5x slower). When your test images have variable aspect ratios or important content near edges. When small improvements matter (TTA typically adds +0.005-0.015 to mAP). When your model was trained with aggressive cropping and may be sensitive to crop position.

**When NOT to use:** When inference time is tightly constrained (real-time applications). When validation shows no improvement (some datasets are already well-centered). When your training already used diverse crops that cover the test distribution. For extremely small images where padding adds more noise than signal.

**How to reason about it:**
1. Measure validation mAP with single inference (center crop). 2. Test TTA with flip: avg(emb(image), emb(flip(image))). If gain < 0.002, skip flip. 3. Test multi-scale: avg(emb(resize(image, s)) for s in [224, 256, 288]). If gain > 0.005, include. 4. If aspect ratio variance is high (std > 0.3), test aspect-ratio-aware: for square images use crop, for non-square use padding to preserve ratio. 5. Limit to 2-3 augmentations total to keep inference practical.

```python
import torch
import torchvision.transforms.functional as TF

def tta_inference(model, image, preserve_aspect=True):
    """
    image: PIL Image
    """
    H, W = image.size
    ratio = W / H
    embeddings = []
    
    # Strategy 1: Center crop (always)
    img_crop = TF.center_crop(TF.resize(image, 256), 224)
    embeddings.append(model.encode(img_crop))
    
    # Strategy 2: Flip
    img_flip = TF.hflip(img_crop)
    embeddings.append(model.encode(img_flip))
    
    # Strategy 3: Aspect-ratio aware (if non-square)
    if preserve_aspect and abs(ratio - 1.0) > 0.1:
        # Pad to square preserving aspect ratio
        if W > H:
            img_padded = TF.pad(image, (0, (W-H)//2, 0, (W-H)//2))
        else:
            img_padded = TF.pad(image, ((H-W)//2, 0, (H-W)//2, 0))
        img_padded = TF.resize(img_padded, 224)
        embeddings.append(model.encode(img_padded))
    
    # Average embeddings
    final_emb = torch.mean(torch.stack(embeddings), dim=0)
    return final_emb / torch.norm(final_emb)  # L2 normalize

# Usage
for test_image in test_set:
    embedding = tta_inference(model, test_image, preserve_aspect=True)
```
