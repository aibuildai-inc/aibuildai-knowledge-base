## Principle 6: Re-rank Predictions by Penalizing Similarity to Non-Landmarks

*Consensus: 1st place landmark recognition 2020/2021, multiple top retrieval solutions. Critical for GAP metric.*

For recognition tasks with non-landmark images, re-rank predictions by computing each test image's similarity to a reference set of non-landmark images. Penalize the confidence score of test images that are similar to non-landmarks, pushing them down in the ranking. Use the top-5 or top-10 most similar non-landmarks for scoring.

**Why this matters:** The GAP (Global Average Precision) metric used in recognition competitions is extremely sensitive to the ranking of non-landmarks vs. landmarks. A non-landmark ranked high with high confidence destroys the score more than getting a landmark label wrong. Models trained only on landmarks have no way to recognize non-landmarks during training. Post-processing with a non-landmark reference set provides the signal the model lacks, typically adding +0.05-0.15 to GAP.

**When to use:** When your task includes non-target instances (non-landmarks, distractors, background images) that must be identified but aren't in the training set. When your metric penalizes false positives heavily (precision-focused metrics like GAP, mAP@threshold). When you have access to a representative set of non-target images.

**When NOT to use:** For pure retrieval tasks where all query images are known positives (no non-landmarks to filter). When your metric is recall-focused or doesn't weight ranking (top-K accuracy with fixed K). When you lack a good non-landmark reference set—using an unrepresentative set can hurt more than help. Some retrieval competitions (2020) had no non-landmarks, making this unnecessary.

**How to reason about it:**
1. Obtain a non-landmark reference set: use provided test non-landmarks, sample from ImageNet, or use images flagged as 'unknown' in training. 2. Compute embeddings for all reference images. 3. For each test image, compute cosine similarity to all reference images, take mean of top-5 or top-10. 4. Define penalty function: if similarity > threshold (e.g., 0.3), multiply confidence by (1 - similarity) or subtract a fixed penalty. 5. Validate the threshold on a held-out set—too aggressive penalization hurts actual landmarks with generic features (modern buildings).

```python
import numpy as np
from sklearn.preprocessing import QuantileTransformer

# Compute embeddings
test_embeddings = model.predict(test_images)  # (N_test, embed_dim)
nonlandmark_embeddings = model.predict(nonlandmark_images)  # (N_non, embed_dim)
index_embeddings = model.predict(index_images)  # (N_index, embed_dim)

# Normalize
test_embeddings = test_embeddings / np.linalg.norm(test_embeddings, axis=1, keepdims=True)
nonlandmark_embeddings = nonlandmark_embeddings / np.linalg.norm(nonlandmark_embeddings, axis=1, keepdims=True)

# Compute similarity to non-landmarks for each test image
sim_to_nonlandmarks = test_embeddings @ nonlandmark_embeddings.T  # (N_test, N_non)
top_k_nonlandmark_sim = np.mean(np.sort(sim_to_nonlandmarks, axis=1)[:, -5:], axis=1)  # top-5 mean

# Get initial predictions from KNN on index
sim_to_index = test_embeddings @ index_embeddings.T
initial_scores = np.max(sim_to_index, axis=1)

# Apply penalty
penalty_threshold = 0.3
penalty = np.where(
    top_k_nonlandmark_sim > penalty_threshold,
    top_k_nonlandmark_sim,  # Penalize proportionally
    0
)
final_scores = initial_scores - penalty

# Alternatively: scale similarities with QuantileTransformer for stability
scaler = QuantileTransformer()
scaled_sim = scaler.fit_transform(test_embeddings)
```
