## Principle 9: Ensemble by Concatenating Then Scaling Embeddings, Not Averaging Similarities

*Consensus: 1st place landmark 2020/2021, universal embedding top solutions. Standard ensembling method.*

To ensemble multiple models, L2-normalize each model's embeddings separately, concatenate them into a single long vector, apply QuantileTransformer or StandardScaler to each feature, then use the scaled concatenated embedding for retrieval. Do NOT average the embeddings or average the similarity scores.

**Why this matters:** Different models may use their embedding space scales differently—one model's similarity of 0.7 may be more confident than another's 0.9. Simple averaging treats them equally, diluting strong signals. Concatenation preserves each model's full information. Scaling (especially QuantileTransformer) brings them to a common scale where all models contribute equally, and the retrieval metric (cosine similarity) can weigh their agreement. This consistently outperforms averaging and adds substantial gain over single models.

**When to use:** When ensembling multiple models with different architectures or training setups. When models are somewhat uncorrelated (different backbones, different image sizes, different augmentations). When you have computational budget to store concatenated embeddings (K models × embed_dim each).

**When NOT to use:** When embedding storage is severely limited (concatenation increases size K-fold). When all models are nearly identical (same architecture, same data, only different seeds)—averaging may be sufficient. When models are highly correlated, the gain is small; invest in diversity first. Some solutions use weighted averaging when they can't afford storage.

**How to reason about it:**
1. Train K diverse models (different architectures, image sizes, or training stages). 2. For each test image, get K embeddings. 3. L2-normalize each: emb_i = emb_i / ||emb_i||. 4. Concatenate: emb_concat = [emb_1, emb_2, ..., emb_K]. 5. Fit QuantileTransformer on test set concatenated embeddings (or validation set). 6. Transform both test and index concatenated embeddings. 7. Retrieve using cosine similarity on scaled concatenated embeddings. 8. Validate: does this outperform (a) best single model and (b) averaged embeddings?

```python
from sklearn.preprocessing import QuantileTransformer
import numpy as np

# Get embeddings from K models
models = [model_effb7, model_effb6, model_vit]  # 3 diverse models
test_embeddings = []
for model in models:
    emb = model.encode(test_images)  # (N, embed_dim)
    emb = emb / np.linalg.norm(emb, axis=1, keepdims=True)  # L2 normalize
    test_embeddings.append(emb)

# Concatenate
test_concat = np.hstack(test_embeddings)  # (N, K × embed_dim)

# Scale to common scale
scaler = QuantileTransformer()
test_scaled = scaler.fit_transform(test_concat)

# Do the same for index
index_embeddings = [model.encode(index_images) for model in models]
index_embeddings = [e / np.linalg.norm(e, axis=1, keepdims=True) for e in index_embeddings]
index_concat = np.hstack(index_embeddings)
index_scaled = scaler.transform(index_concat)

# Retrieve using scaled concatenated embeddings
similarities = test_scaled @ index_scaled.T
```
