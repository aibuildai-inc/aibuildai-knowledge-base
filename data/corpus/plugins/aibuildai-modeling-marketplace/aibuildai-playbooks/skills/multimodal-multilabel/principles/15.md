## Principle 15: Apply Test-Time Augmentation Strategically Based on Compute Budget

*Consensus: 4/5 - iMet used minimal TTA (horizontal flip), Stable Diffusion used different normalizations, Open Problems mostly skipped TTA due to data size*

Test-time augmentation (predicting on multiple augmented versions and averaging) can improve robustness, but it multiplies inference cost. The gain is usually +0.001-0.005, so it's only worth it if you have compute budget and the augmentations are task-appropriate.

**Why this matters:** iMet 1st place: RandomCropIfNeeded + horizontal flip TTA (2x cost) gave +0.002-0.003 F2. More aggressive TTA (10x) gave diminishing returns. Stable Diffusion 4th place: different image normalization stats as TTA gave +0.02, but this is unusual (most TTA gives <0.005). Open Problems: TTA wasn't used due to data size (140K cells, predicting 23K outputs, TTA would 10x the cost for <0.003 gain).

**When to use:** Inference budget allows (you can afford 2-10x slower predictions). Task has invariances you can exploit (horizontal flip for symmetric objects, rotations for isotropic data). Evaluation metric is sensitive to small improvements (0.001 matters for ranking).

**When NOT to use:** Inference is time-constrained (code competition 9-hour limit). Data is huge (TTA on 100K samples is prohibitive). Task has no invariances (text is not flip-invariant, biological samples have orientation).

**How to reason about it:**
Identify valid augmentations: horizontal flip for natural images/art, crops for multi-scale, rotations for isotropic data (NOT for text, oriented biology). Measure cost: TTA with N augmentations is N x slower. Measure gain: try TTA on validation, check if it improves by >0.002. If gain < 0.002 and you're compute-limited, skip TTA. If you use TTA, keep it minimal (2-5 augmentations, not 10-20).

```python
# Minimal TTA: horizontal flip
def predict_with_tta(model, image):
    pred_original = model(image)
    pred_flipped = model(torch.flip(image, dims=[-1]))  # horizontal flip
    return (pred_original + pred_flipped) / 2

# Multi-augmentation TTA (more expensive)
import torchvision.transforms as T

tta_transforms = [
    T.Compose([]),  # original
    T.Compose([T.RandomHorizontalFlip(p=1.0)]),
    T.Compose([T.RandomResizedCrop(size, scale=(0.9, 1.0))]),
]

def predict_with_multi_tta(model, image):
    preds = []
    for transform in tta_transforms:
        augmented = transform(image)
        preds.append(model(augmented))
    return torch.stack(preds).mean(dim=0)
```
