## Principle 6: Pretrain on Large Noisy Data, Then Finetune on Small High-Quality Data

*Consensus: 4/5 - Stable Diffusion winners ALL used two-stage (6.6M low-quality → 2M high-quality), iMet used progressive training, Open Problems used batch-specific finetuning*

Large-scale noisy data teaches broad patterns and vocabulary; small-scale curated data teaches precision. Training only on high-quality data underfits; training only on noisy data overfits to noise. The two-stage approach combines both.

**Why this matters:** Stable Diffusion 1st place: pretraining on 6.6M COYO images gave +0.008-0.01 over training only on 2M high-quality prompts. The large dataset provides coverage of the full prompt vocabulary; the small dataset corrects for noise and teaches the specific task distribution. This pattern appears across vision (ImageNet pretrain → task finetune) and NLP (large corpus → domain corpus).

**When to use:** You can generate or access a large (>1M) noisy dataset and a smaller (<1M) high-quality dataset. The noisy data covers the input/output space better, but the quality data matches the test distribution. You have GPU budget for multi-stage training.

**When NOT to use:** You only have one dataset (use it all). The noisy data is SO noisy it hurts more than helps (check by training on it and seeing if CV improves). Computational constraints limit you to one training pass.

**How to reason about it:**
Stage 1 (pretrain): train on the large noisy dataset for 2-3 epochs with higher learning rate. This learns general representations. Stage 2 (finetune): initialize from stage 1 weights, train on high-quality data for 3-4 epochs with lower learning rate. This adapts to the task. Use EMA (exponential moving average) of weights during training to stabilize. Compare against single-stage baselines to confirm the benefit.

```python
# Stage 1: pretrain on 6.6M COYO-derived prompts (noisy but diverse)
model = VisionTransformer(...)
optimizer = Adam(model.parameters(), lr=1e-4)
for epoch in range(2):
    train(model, large_noisy_dataset, optimizer)

# Stage 2: finetune on 2M high-quality prompts
optimizer = Adam(model.parameters(), lr=5e-5)  # lower LR
for epoch in range(3):
    train(model, small_hq_dataset, optimizer)

# EMA for stability
from torch_ema import ExponentialMovingAverage
ema = ExponentialMovingAverage(model.parameters(), decay=0.995)
for batch in dataloader:
    loss = train_step(batch)
    optimizer.step()
    ema.update()  # smooth weights
```
