## Principle 11: Generate Synthetic Training Data When Real Data is Scarce

*Consensus: 2/2 relevant competitions - Stable Diffusion winners generated 1M-10M images from prompts, Open Problems explored but didn't use heavily*

When real paired data is limited, you can often generate synthetic data using existing models (text-to-image, data augmentation, simulation). If the generative model is good enough, synthetic data can match or exceed real data for training downstream models.

**Why this matters:** Stable Diffusion: the competition provided 16K prompt-image pairs. Winners generated 1M-10M additional pairs by running Stable Diffusion on collected/generated prompts. Training on 10M synthetic pairs gave +0.05-0.10 over training on only 16K real pairs. The key: the generative model (Stable Diffusion) defines the task distribution, so synthetic data from it is the ideal training set.

**When to use:** Real paired data is scarce (<100K) but you can generate more (text-to-image, simulation, augmentation). A generative model exists that defines the task (Stable Diffusion for prompts, simulators for physics). The synthetic data quality is high (close to real). You have compute to generate millions of samples.

**When NOT to use:** Real data is abundant (>1M). Synthetic data is low-quality or off-distribution (hurts more than helps). No generative model available (can't synthesize realistic samples).

**How to reason about it:**
Ask: is there a generative model I can use? For image-text: Stable Diffusion, DALL-E. For biology: simulation models. For data augmentation: GANs, mixup. If yes: (1) Collect or generate prompts/conditions (use existing datasets, LLMs, templates). (2) Run the generative model to create synthetic data. (3) Train your model on synthetic data. (4) Compare CV on real validation: if synthetic helps, scale it up. Balance real and synthetic (often 10:1 synthetic:real).

```python
# Generate 1M images from Stable Diffusion for training
from diffusers import StableDiffusionPipeline
import torch

pipe = StableDiffusionPipeline.from_pretrained('stabilityai/stable-diffusion-2')
pipe = pipe.to('cuda')

prompts = load_prompts()  # 1M prompts from DiffusionDB, COCO, ChatGPT
for i, prompt in enumerate(prompts):
    image = pipe(prompt, num_inference_steps=25).images[0]
    image.save(f'synthetic/{i}.png')

# Train model on synthetic data
train_model(synthetic_images, prompts)
```
