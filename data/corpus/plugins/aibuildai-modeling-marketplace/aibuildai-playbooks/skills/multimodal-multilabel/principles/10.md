## Principle 10: Tune Image Resolution to Match Task Complexity

*Consensus: 3/3 vision competitions - Stable Diffusion winners found 336+ better than 224, iMet used 320-331, YouTube-8M noted resolution matters*

Higher resolution captures finer details needed for complex tasks (multiple objects, fine-grained attributes, small text). But it increases compute 4x per doubling. The optimal resolution depends on what the task requires: simple object recognition works at 224, complex scenes need 336-448.

**Why this matters:** Stable Diffusion 2nd place: training at 336 instead of 224 gave +0.003-0.005. Prompts like 'a cat wearing a hat next to a dog holding a balloon' require resolving multiple objects and their attributes, which is hard at 224x224. iMet used 320-331 for fine-grained artwork attributes. The gain plateaus beyond 448 for most tasks.

**When to use:** Task requires fine-grained recognition (attributes, multiple objects, small text, detailed textures). Models are vision transformers (ViT), which handle variable resolution via positional encoding interpolation. You have GPU memory for larger images (batch size can decrease).

**When NOT to use:** Task is coarse-grained (binary classification, simple object detection). Models are CNNs pretrained at fixed resolution (they need retraining). You're compute-limited (4x cost for 2x resolution).

**How to reason about it:**
Start with the pretrained resolution (usually 224). If your task has multiple objects, small text, or fine-grained attributes, try 336. Train at 224 first (faster), then use those weights to initialize training at 336 (interpolate positional encodings). Compare CV: if +0.003-0.005, the higher resolution helps. Try 448 if you have budget, but expect diminishing returns.

```python
# For ViT: interpolate positional encoding to support higher resolution
import torch.nn.functional as F

def interpolate_pos_encoding(pos_embed, new_size):
    # pos_embed: (1, num_patches + 1, dim)
    # new_size: target number of patches
    cls_token = pos_embed[:, :1, :]
    patch_pos = pos_embed[:, 1:, :]
    # Reshape to 2D grid, interpolate, reshape back
    old_size = int(patch_pos.shape[1] ** 0.5)
    patch_pos = patch_pos.reshape(1, old_size, old_size, -1).permute(0, 3, 1, 2)
    patch_pos = F.interpolate(patch_pos, size=(new_size, new_size), mode='bicubic')
    patch_pos = patch_pos.permute(0, 2, 3, 1).reshape(1, new_size * new_size, -1)
    return torch.cat([cls_token, patch_pos], dim=1)

# Use when loading model trained at 224 for finetuning at 336
model.pos_embed = interpolate_pos_encoding(model.pos_embed, new_patches)
```
