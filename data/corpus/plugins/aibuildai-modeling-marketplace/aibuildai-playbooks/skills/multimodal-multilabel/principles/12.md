## Principle 12: For Biology/Count Data, Use Correlation Loss Instead of MSE

*Consensus: 3/3 biological competitions - Open Problems winners ALL used correlation loss for CITEseq, metrics were correlation-based*

Biological measurements (gene expression, protein levels) have technical variability that shifts absolute values but preserves relative rankings. Correlation-based loss and metrics focus on the ranking structure, which is what matters biologically, while MSE is sensitive to scale shifts.

**Why this matters:** Open Problems evaluation was Pearson correlation, not MSE. MSE penalizes scale differences (predicting 100 when truth is 110) equally to rank inversions (predicting 100 when truth is 10). Correlation loss ignores scale, focusing on co-variation. Winners using correlation loss outperformed MSE baselines by +0.01-0.03. Biologically, 'gene A is 2x gene B' matters more than 'gene A is exactly 53.2 counts'.

**When to use:** Data is count-based or has technical scale variability (RNA-seq, protein assays, noisy sensors). Evaluation metric is correlation, not MSE. Absolute values are less meaningful than relative ordering.

**When NOT to use:** Evaluation metric is MSE, MAE, or another scale-sensitive metric. Absolute values matter (clinical thresholds, physical units). Data has no technical variability.

**How to reason about it:**
Check the evaluation metric. If it's correlation (Pearson, Spearman), use correlation loss. If MSE, use MSE loss (mismatched loss and metric is usually bad). Correlation loss: compute Pearson correlation between predictions and targets, maximize it (or minimize 1 - correlation). This treats scale shifts as irrelevant, focusing on co-variation.

```python
import torch

def pearson_correlation_loss(preds, targets):
    # preds, targets: (batch, num_targets)
    # Compute correlation per sample, average across batch
    preds_centered = preds - preds.mean(dim=1, keepdim=True)
    targets_centered = targets - targets.mean(dim=1, keepdim=True)
    
    cov = (preds_centered * targets_centered).sum(dim=1)
    preds_std = torch.sqrt((preds_centered ** 2).sum(dim=1) + 1e-8)
    targets_std = torch.sqrt((targets_centered ** 2).sum(dim=1) + 1e-8)
    
    corr = cov / (preds_std * targets_std)
    return 1 - corr.mean()  # minimize 1 - correlation

# Usage
loss = pearson_correlation_loss(predictions, targets)
loss.backward()
```
