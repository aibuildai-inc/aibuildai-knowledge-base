## Principle 8: Use Focal Loss or Class Balancing for Imbalanced Multilabel Data

*Consensus: 3/5 - iMet 1st and 4th place used focal loss, 9th used focal + F-beta loss; YouTube-8M dealt with extreme imbalance across 4716 classes*

Multilabel data is often imbalanced (some labels appear in 50% of samples, others in 0.1%). Standard BCE treats all labels equally, letting common labels dominate the gradient. Focal loss down-weights easy examples, focusing learning on hard/rare cases.

**Why this matters:** iMet had culture labels appearing in 5-20% of images and tag labels in 20-80%. BCE converged to predicting only common labels. Focal loss (with gamma=2) reweighted the loss to emphasize rare labels, improving F2 by +0.02-0.03. The metric (F2) favors recall, so missing rare labels hurts more than over-predicting common ones.

**When to use:** Label frequencies span >1 order of magnitude (some at 1%, others at 50%). Evaluation metric cares about rare labels (F-score, macro-average). BCE baseline predicts only common labels (check per-class recall).

**When NOT to use:** Labels are roughly balanced. Evaluation metric is micro-averaged or weighted by frequency (common labels matter more). Focal loss hurts your CV (some datasets don't have the 'easy example' problem focal loss targets).

**How to reason about it:**
Compute label frequencies in training data. If the ratio of most common to least common is >10x, try focal loss. Start with gamma=2 (standard). If the model still ignores rare labels, increase gamma to 3-4. If it overfits to rare labels (predicts too many), decrease gamma to 1-1.5 or add class weights. Monitor per-class recall: focal loss should increase recall on rare classes without tanking precision on common ones.

```python
import torch
import torch.nn.functional as F

class FocalLoss(torch.nn.Module):
    def __init__(self, gamma=2.0, alpha=None):
        super().__init__()
        self.gamma = gamma
        self.alpha = alpha  # optional class weights
    
    def forward(self, inputs, targets):
        bce_loss = F.binary_cross_entropy_with_logits(inputs, targets, reduction='none')
        probs = torch.sigmoid(inputs)
        # Focal term: (1 - p)^gamma for positive class, p^gamma for negative
        pt = torch.where(targets == 1, probs, 1 - probs)
        focal_weight = (1 - pt) ** self.gamma
        loss = focal_weight * bce_loss
        if self.alpha is not None:
            loss = self.alpha * loss
        return loss.mean()

# Usage
criterion = FocalLoss(gamma=2.0)
loss = criterion(logits, targets)
```
