## Principle 4: Handle Label Noise Through Soft Targets, Not Just Data Cleaning

*Consensus: 3/5 - iMet used knowledge distillation and pseudo-labeling, Open Problems used model predictions as soft targets, single-cell data inherently noisy*

When labels are noisy (crowdsourced tags, incomplete annotations, measurement error), training on hard 0/1 labels forces the model to fit noise. Soft targets from ensembles or pseudo-labels provide a regularized signal that improves generalization.

**Why this matters:** Hard labels on noisy data create a ceiling on performance. Knowledge distillation (train student on teacher's probabilities) and pseudo-labeling (add model predictions as soft training targets) both inject uncertainty that acts as label smoothing. iMet 1st place gained +0.01 F2 from pseudo-labeling; 9th place gained +0.01 from distillation.

**When to use:** Labels are crowdsourced, incomplete, or measured with error (artwork tags, single-cell assays). The metric favors recall over precision (F-beta, correlation). You have compute budget for multi-stage training (train teachers → generate soft labels → retrain).

**When NOT to use:** Labels are ground truth (exact measurements, verified annotations). You're already at the label noise ceiling (further softening hurts CV). Single-stage training constraint (knowledge distillation requires at least two stages).

**How to reason about it:**
If you suspect label noise: (1) Train an ensemble of diverse models. (2) For each training example, use the ensemble's probabilistic output as a soft target. (3) Retrain a student model on soft targets (either pure distillation or np.maximum(soft, hard) to keep true positives). (4) Compare CV: if soft targets improve, the original labels were noisy. For pseudo-labeling: use high-confidence predictions on unlabeled or test data as additional training signal.

```python
# Knowledge distillation: student trained on teacher's soft outputs
teacher_preds = ensemble.predict_proba(X_train)  # (N, num_classes), values in [0,1]

# Option 1: Pure distillation (trust teacher more than hard labels)
student.fit(X_train, teacher_preds)

# Option 2: Blend teacher and hard labels (iMet approach)
soft_targets = np.maximum(0.7 * teacher_preds, y_train_hard)  # keep true positives
student.fit(X_train, soft_targets)

# Pseudo-labeling: add confident test predictions to training
test_preds = ensemble.predict_proba(X_test)
confident_mask = np.mean(np.abs(test_preds - 0.5), axis=1) > 0.3  # high confidence
X_aug = np.vstack([X_train, X_test[confident_mask]])
y_aug = np.vstack([y_train, test_preds[confident_mask]])
model.fit(X_aug, y_aug)
```
