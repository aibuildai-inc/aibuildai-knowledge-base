## Principle 3: Reduce Dimensionality of High-Dimensional Targets Before Regression

*Consensus: 3/3 regression competitions - Open Problems used tSVD on targets (128-1024 dims), then inverse-transform predictions*

When predicting thousands of correlated outputs (gene expression, protein levels), predicting a low-rank representation (via SVD/PCA) and transforming back often outperforms direct prediction. The targets have latent structure that dimensionality reduction captures.

**Why this matters:** Predicting 23K genes directly treats them as independent, ignoring biological pathways. Reducing to 128-1024 principal components forces the model to learn the shared structure, acts as regularization, speeds up training, and can improve CV by 0.01-0.03. The reconstruction error from dimensionality reduction is smaller than the prediction error saved.

**When to use:** Targets are high-dimensional (>1000) and correlated (biology, embeddings, sequential data). Evaluation metric allows approximate reconstruction (correlation, cosine similarity). You can afford the two-step process (reduce → predict → inverse transform).

**When NOT to use:** Targets are independent or low-dimensional (<100). Evaluation requires exact values at the target scale (classification, strict regression). Some targets have no shared structure (completely independent labels).

**How to reason about it:**
Check target correlation: compute the correlation matrix of training targets. If most off-diagonal entries are near zero, dimensionality reduction won't help. If there are blocks of high correlation, reduce. Try reducing targets to 128, 256, 512, 1024 components and see which maximizes CV. Train model to predict components, then `predictions_original = predictions_components @ svd.components_` to get final output.

```python
from sklearn.decomposition import TruncatedSVD

# Fit SVD on training targets
svd = TruncatedSVD(n_components=128, random_state=42)
targets_reduced = svd.fit_transform(targets_train)  # (N, 23K) -> (N, 128)

# Train model on reduced targets
model.fit(X_train, targets_reduced)

# Predict and inverse transform
preds_reduced = model.predict(X_test)  # (M, 128)
preds_original = svd.inverse_transform(preds_reduced)  # (M, 23K)

# Alternative: predict components, then matmul
preds_original = preds_reduced @ svd.components_  # faster, same result
```
