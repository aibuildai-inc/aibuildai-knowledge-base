## Principle 14: Use KNN or Retrieval as a Non-Parametric Baseline or Ensemble Component

*Consensus: 2/5 - iMet 4th place used KNN-based tag relevance prediction, Stable Diffusion used text retrieval from 56M embeddings*

K-nearest neighbors or embedding-based retrieval provides a non-parametric baseline that can be competitive, especially with noisy labels or when test samples are similar to training. It also diversifies ensembles by contributing a fundamentally different prediction mechanism.

**Why this matters:** iMet 4th place: KNN on CNN embeddings (weighted by distance, using training labels as soft targets) scored 0.634 LB alone and 0.650 when averaged with the CNN classifier (0.618 alone). This +0.032 gain came from KNN's ability to leverage similar training images, compensating for noisy labels. Stable Diffusion: text retrieval from 56M precomputed embeddings contributed 0.61 to the ensemble (0.64 for vision models); the 0.64 ensemble gained from the diversity.

**When to use:** Training data is large enough to have neighbors for most test samples. Labels are noisy (KNN averages over neighbors, reducing noise). Embeddings are good (CLIP, CNN features). You want ensemble diversity (KNN predictions are uncorrelated with parametric models).

**When NOT to use:** Training data is tiny (<10K) or very high-dimensional (curse of dimensionality). Test samples are out-of-distribution (no good neighbors). KNN is too slow (can be mitigated with approximate NN like FAISS).

**How to reason about it:**
Compute embeddings for training and test data (CNN features, CLIP embeddings, tSVD). For each test sample, find K nearest training samples (cosine similarity). Predict as weighted average of neighbor labels (weight by distance). Tune K on validation (typically 5-50). Ensemble KNN with parametric models. Check correlation: if KNN predictions have <0.9 correlation with other models, they add diversity.

```python
import faiss
import numpy as np

# Compute embeddings (e.g., from CNN or CLIP)
train_embeds = model.encode(train_images)  # (N_train, dim)
test_embeds = model.encode(test_images)    # (N_test, dim)

# Build FAISS index for fast KNN
index = faiss.IndexFlatIP(train_embeds.shape[1])  # inner product (cosine if normalized)
faiss.normalize_L2(train_embeds)  # normalize for cosine similarity
index.add(train_embeds)

# KNN prediction
K = 20
faiss.normalize_L2(test_embeds)
distances, indices = index.search(test_embeds, K)  # (N_test, K)

# Weighted average of neighbor labels (weight by similarity)
weights = distances  # already cosine similarity
knn_preds = np.zeros((len(test_embeds), num_classes))
for i in range(len(test_embeds)):
    neighbor_labels = train_labels[indices[i]]  # (K, num_classes)
    knn_preds[i] = (neighbor_labels * weights[i:i+1].T).sum(axis=0) / weights[i].sum()
```
