## Principle 7: Ensemble Diverse Feature Representations, Not Just Diverse Models

*Consensus: 5/5 - Open Problems ensembled tSVD + UMAP + correlation features; Stable Diffusion ensembled text retrieval + vision encoders; iMet ensembled CNN features + ImageNet predictions + image stats*

Ensembling multiple models trained on the SAME features gives diminishing returns. Ensembling models trained on DIFFERENT feature representations (dimensionality reduction methods, domain features, auxiliary predictions) increases diversity and improves the ensemble gain.

**Why this matters:** Open Problems 4th place: ensembling models trained on tSVD, UMAP, and correlation-selected features gave +0.003-0.005 over ensembling models trained only on tSVD. Different feature representations capture different aspects of the data: tSVD captures global structure, UMAP captures local manifolds, correlation features capture direct target relationships. Diversity matters more than individual model strength for ensemble performance.

**When to use:** You're building an ensemble (multiple models). You can afford to engineer multiple feature representations. The representations are complementary (low correlation in predictions). Your evaluation metric rewards ensemble diversity (most metrics do).

**When NOT to use:** You're limited to one model. All feature representations you try give near-identical predictions (no diversity). Adding features doesn't improve CV of individual models (suggests features are redundant).

**How to reason about it:**
Create 3-5 feature sets: (1) Raw features or simple preprocessing. (2) Dimensionality reduction (PCA/tSVD with different n_components). (3) Manifold methods (UMAP, t-SNE). (4) Domain-specific features (for images: color histograms, ImageNet predictions; for biology: cluster means, pathway genes). Train a model on each feature set. Ensemble their predictions (weighted average tuned on validation). Check prediction correlation: if all models agree (corr > 0.95), you need more diverse features.

```python
# Open Problems: ensemble models trained on different feature representations
from sklearn.decomposition import TruncatedSVD, PCA
from umap import UMAP

# Feature set 1: tSVD
svd = TruncatedSVD(n_components=128)
feats_svd = svd.fit_transform(X)

# Feature set 2: UMAP

feats_umap = umap.fit_transform(X)
model2 = train_model(feats_umap, y)

# Feature set 3: correlation-selected raw features
corrs = np.abs([np.corrcoef(X[:, i], y[:, j])[0, 1] for i, j in ...])
top_feats = X[:, np.argsort(corrs)[-500:]]
model3 = train_model(top_feats, y)
```
