## Principle 5: Apply Domain-Specific Augmentations Beyond Standard Transforms

*Consensus: Deepfake 1st/3rd (video compression, face blending, mixup on aligned pairs), camera model ID 4th (the competition's own image manipulations), scientific image forgery 1st (simulated figure artifacts), power line 26th (cyclic shift of a periodic signal)*

Design augmentations that mimic the domain's natural variation or attack the model's failure modes: for camera images, apply the recompression, resizing and gamma manipulations the test set contains; for deepfakes, apply video compression and hide face parts so the model must find blending artifacts; for periodic signals, shift the signal cyclically; for 3D volumes, shift along the depth axis.

**Why this matters:** Standard augmentations (flips, crops, color jitter) improve generalization to pose/lighting changes but don't teach the model to be robust to domain-specific variations. A camera fingerprint survives resizing and recompression only in a changed form; if the model never sees those forms during training, it fails on manipulated test images. Deepfakes are compressed and degraded in the wild; training only on high-quality crops makes models brittle. Domain augmentations force the model to learn the invariant core of the signal, not incidental correlates.

**When to use:** When you understand the domain's forward process well enough to simulate it: camera images (recompress, resize, gamma), deepfakes (compress video, blend faces), scientific figures (add letters, arrows, zoom callouts and copy-pasted cells, as the forgery detection 1st place did), medical imaging (simulate scanner noise). The deepfake 3rd place used mixup on aligned real-fake pairs (interpolating between a real face and its fake version at the same frame), which directly attacks the model's tendency to memorize per-video artifacts rather than learning blending edges.

**When NOT to use:** When you don't have domain knowledge to guide augmentation design, or when the domain variations are already covered by standard transforms. Augmentations that break the signal hurt: the camera model ID 4th place skipped rotations and flips because they should not help for sensor noise, the passenger screening 8th place dropped brightness augmentation because it confused its models, and the deepfake 12th place found strong augmentations (cutout, hue-saturation, 90-degree rotation) did not work. Validate each augmentation's effect on a holdout fold.

**How to reason about it:**
List the variations your test data will have that training doesn't. For deepfakes: compression, resolution changes, frame rate → augment with random ffmpeg encoding. For camera images: the manipulations named in the task description → apply them at random, keeping JPEG blocks aligned to the 8×8 grid. For periodic 1D signals: phase offsets → shift the signal cyclically. For 3D volumes: depth shifts (the signal could be at any slice) → randomly shift the volume along Z. Ablate each augmentation: train with/without and measure whether CV improves.

def cyclic_shift(x, max_frac=0.5):
    part = int(len(x) * np.random.uniform(0, max_frac))
    return np.concatenate([x[part:], x[:part]], axis=0)

def aligned_mixup(real_img, fake_img, alpha=0.5, beta=0.5):
    # Both images are the same frame/bbox from real and fake videos
    lam = np.random.beta(alpha, beta)
    mixed = (1 - lam) * real_img + lam * fake_img
    target = lam  # Continuous target for regression loss
    return mixed, target
