## Principle 11: Clean Up Predictions with Connected-Component Post-Processing

*Consensus: Deepfake 5th (kept only faces that stay connected across space and time for at least 30 frames) and 47th (tracked faces across frames to remove spurious detections)*

After binarizing your predictions, apply connected-component analysis and remove small isolated regions below a size threshold, as these are likely false positives.

**Why this matters:** Models often produce speckle noise—isolated pixels or tiny blobs that are false positives. Setting a lower prediction threshold (to catch more true positives) and then removing small components can beat a higher threshold alone. This is a form of structured prior: true signals (objects, strokes, lesions) form large connected regions, while noise is isolated. The deepfake 5th place applied the same prior in space and time: it marked face boxes in a (frame, height, width) array, treated overlapping boxes as one face moving through the video, and kept only faces connected over many frames, which greatly reduced false face detections.

**When to use:** When your true positives form large connected structures (text, objects, lesions, a face that persists through a video) and false positives are small isolated pixels or short-lived detections. Segmentation tasks with a spatial coherence prior.

**When NOT to use:** When true positives can be small and isolated (e.g., detecting tiny nodules in medical imaging, single-pixel defects). Also skip if you don't have domain knowledge to set the size threshold—too aggressive and you remove true positives; too loose and you keep noise.

**How to reason about it:**
Visualize your false positives: are they small isolated blobs? Measure their size distribution on a validation set. Set a threshold that removes 90% of false positives while keeping 95%+ of true positives. Sweep the minimum component size over a wide range on validation, then re-tune the prediction threshold together with it: cleanup lets you lower the threshold without keeping the extra noise.

```python
# Connected-component cleanup
import cv2

def cleanup_predictions(binary_mask, min_size):
    """Remove small connected components.
    
    Args:
        binary_mask: (H, W) binary array (0/1)
        min_size: Minimum component size in pixels (choose on validation)
    """
    # Find connected components
    num_labels, labels, stats, _ = cv2.connectedComponentsWithStats(
        binary_mask.astype(np.uint8), connectivity=8
    )
    
    # stats[:, cv2.CC_STAT_AREA] gives the area of each component
    # Component 0 is background, so start from 1
    cleaned_mask = np.zeros_like(binary_mask)
    for i in range(1, num_labels):
        if stats[i, cv2.CC_STAT_AREA] >= min_size:
            cleaned_mask[labels == i] = 1
    
    return cleaned_mask

# Usage (threshold and min_size come from a joint validation sweep):
raw_pred = model(image)  # (H, W) probabilities
binary = (raw_pred > best_threshold).astype(np.uint8)  # lower than without cleanup
cleaned = cleanup_predictions(binary, min_size=best_min_size)
# Result: fewer false positives, better precision
```
