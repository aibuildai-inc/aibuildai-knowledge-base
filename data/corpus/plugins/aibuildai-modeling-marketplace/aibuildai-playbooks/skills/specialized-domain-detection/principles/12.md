## Principle 12: Collect and Curate External Data When Allowed

*Consensus: Camera ID 1st place (300GB Flickr/Yandex photos), 2nd place (large external dataset), deepfake solutions (careful avoidance due to rules)*

When competition rules permit external data, aggressively collect domain-specific data, filter it carefully (resolution, quality, metadata), and use it to augment training or as a blending holdout set.

**Why this matters:** Specialized domains often have limited labeled data, and models trained only on the competition set overfit. The camera ID 1st place collected 300GB of Flickr/Yandex photos (filtering by camera model, resolution, JPEG quality >95, no post-processing in EXIF), using 20k for training and 50k for blending. This external data provided diversity the competition set lacked. However, poorly filtered external data (GIGO) can hurt more than help.

**When to use:** When the competition allows external data and you have a reliable source (public datasets, web scraping, pre-existing corpora). Critical: filter rigorously based on metadata, quality, and domain constraints. The camera ID competitors excluded any image with non-default software in EXIF (indicating post-processing) and required quality >95.

**When NOT to use:** When external data is prohibited or when you can't verify its quality. The deepfake 1st place explicitly avoided external data because the rules were ambiguous and pre-trained weights were already strong. Also skip if external data doesn't match the test distribution (different cameras, different manipulation methods)—it will hurt generalization.

**How to reason about it:**
Read the competition rules carefully. If external data is allowed, identify high-quality sources (prior competitions, academic datasets, web scraping). Filter by domain-relevant metadata: for camera ID, require EXIF tags matching target cameras, high JPEG quality, no post-processing. Train a baseline model on competition data, then fine-tune on competition+external and compare validation scores. If external data helps, scale it up; if it hurts, tighten the filters or drop it.

import piexif
from PIL import Image

def filter_external_images(image_paths, target_cameras, min_quality=95):
    """Filter external images for camera model ID task.
    
    Args:
        image_paths: List of image file paths
        target_cameras: List of camera model names to keep
        min_quality: Minimum JPEG quality (0-100)
    """
    filtered = []
    for path in image_paths:
        img = Image.open(path)
        exif_dict = piexif.load(img.info.get('exif', b''))
        
        # Check camera model
        model = exif_dict['0th'].get(piexif.ImageIFD.Model, b'').decode('utf-8', errors='ignore')
        if model not in target_cameras:
            continue
        
        # Check for post-processing (software tag should be empty or default)
        software = exif_dict['0th'].get(piexif.ImageIFD.Software, b'').decode('utf-8', errors='ignore')
        if software and 'Photoshop' in software:  # Example filter
            continue

        if quality < min_quality:
            continue
        
        # Check resolution
        if img.size[0] < 512 or img.size[1] < 512:
            continue
        
        filtered.append(path)
    
    return filtered
