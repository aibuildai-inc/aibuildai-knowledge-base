## Principle 13: Engineer Domain-Specific Features for Signal/Time-Series Data

*Consensus: VSB power line 2nd place (peak features from scipy.signal), freesound audio 4th (MFCC, delta-delta)*

For time-series or signal data, extract domain-specific statistical and spectral features (peak counts, widths, heights, frequency bands) and combine them with deep learning features.

**Why this matters:** Deep learning on raw waveforms can work, but domain-specific features provide strong inductive biases. The VSB 2nd place found that peak features (height, width, count, extracted via scipy.signal.find_peaks) reduced overfitting and stabilized the model—RNN alone overfit badly. These features encode domain knowledge (partial discharge creates voltage peaks) that the model would take longer to learn from scratch.

**When to use:** For 1D time-series or signal data where domain experts have identified key patterns: power line faults (peaks), audio (MFCC, spectrograms), seismic (frequency bands). Especially when your raw-signal-only model overfits or doesn't converge.

**When NOT to use:** When you lack domain knowledge to design features, or when deep learning on raw data already works well. The deepfake/image tasks didn't need hand-crafted features; CNNs learned them automatically. Also skip if feature extraction is too slow.

**How to reason about it:**
Consult domain literature or experts: what features do traditional (pre-deep-learning) methods use? For power line faults, peaks and transients are well-studied. For audio, MFCC and spectrograms are standard. Extract these features and train a baseline model (LightGBM, shallow RNN) on them. Compare to a deep model on raw data. If the feature-based model is competitive, combine them: concatenate hand-crafted features with learned embeddings before the final classifier.

```python
# Domain-specific feature extraction (VSB 2nd place)
from scipy.signal import find_peaks, peak_widths

def extract_peak_features(signal):
    """Extract peak statistics from a 1D signal."""
    # Find positive and negative peaks
    pos_peaks, _ = find_peaks(signal, height=[5, 100])
    neg_peaks, _ = find_peaks(-signal, height=[5, 100])
    
    # Compute peak widths
    widths = peak_widths(signal, pos_peaks)[0]
    heights = signal[pos_peaks]
    
    # Summary statistics
    if len(heights) > 0:
        features = [
            heights.mean(), heights.max(), heights.min(), np.median(heights),
            widths.mean(), widths.max(), widths.min(), np.median(widths),
            len(pos_peaks), len(neg_peaks)
        ]
    else:
        features = [0] * 10
    
    return np.array(features)

# Combine with deep learning:
# signal → RNN → embedding (128-dim)
# signal → extract_peak_features → (10-dim)
# Concatenate → (138-dim) → final classifier
```
