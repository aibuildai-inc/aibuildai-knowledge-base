## Principle 10: Generate Synthetic Data with LLMs When External Corpora Are Unavailable

*Consensus: Several solutions use LLMs to generate synthetic texts; the 1st-place summary solution used meta pseudo-labeling with LLM-generated prompts*

When no external data exists, use LLMs (GPT-4, Claude) to generate synthetic essays, summaries, or discourse elements. Design prompts to control quality level (effective/adequate/ineffective) and topic diversity. Use generated data for: (a) MLM pretraining on domain, (b) Label-preserving augmentation (add to training set), (c) Topic diversification (generate new prompts then write summaries).

**Why this matters:** LLMs can generate realistic student writing—the 3rd-place effectiveness solution used T5-large to generate synthetic discourse elements and 'couldn't distinguish generated from original.' The 1st-place summary solution used LLM to generate diverse prompts, then generated summaries of varying quality, effectively creating a larger, more diverse training set. Gains: 0.005-0.02 depending on use case.

**When to use:** Use when: (a) Training data < 5k samples, (b) Prompt diversity is low (train has 4 prompts, test has 100+), (c) You need domain-specific pretraining data and no corpus exists. For augmentation: blend 0-50% synthetic with real data—too much synthetic data degrades performance.

**When NOT to use:** Skip LLM generation when: (a) External corpora already available (real data > synthetic), (b) Task is too specialized for LLMs to mimic (e.g., genuine student errors vs. LLM's polished output), (c) Augmentation degrades CV (validate before trusting).

**How to reason about it:**
Design prompts carefully: For essays, specify grade level, topic, quality tier ('write an ineffective argument about electoral college'). For summaries, provide source text + quality instruction. Generate diverse prompts first (if topic diversity is the gap), then generate student responses per prompt. Validate: train model with 0%, 10%, 25%, 50% synthetic data—find optimal blend. Use synthetic data for MLM pretraining (cheap, always helps) even if direct augmentation doesn't work. Filter low-quality generations (e.g., too short, off-topic) before adding to training.
