## Principle 11: Ensemble with Simple Mean to Avoid Overfitting, Use Negative Weights Carefully

*Consensus: Many solutions use a simple mean; several use hill-climbing or Nelder-Mead, some allowing negative weights*

For final ensemble, start with unweighted mean of diverse models. If optimizing weights, use Nelder-Mead or hill-climbing on OOF predictions, allow negative weights (they improve diversity by canceling correlated errors), but validate on CV—fitted weights often overfit when train data is small.

**Why this matters:** With small training samples and many models, fitting ensemble weights has high overfitting risk. Simple mean is robust. A commonlit-evaluate-student-summaries top-4 solution considered Nelder-Mead and Optuna for ensemble weights but rejected them over overfitting concerns, using a simple/hill-climb mean instead. Negative weights sound wrong but work: if two models make similar mistakes, subtracting one from the other cancels the error. The 1st-place feedback-prize-effectiveness solution used negative weights successfully.

**When to use:** Use simple mean when: (a) Training data < 10k, (b) Ensemble has < 10 models (weight optimization needs data), (c) Fitted weights hurt LB despite improving CV (sign of overfitting). Use fitted weights (with negative allowed) when: (a) You have > 20k samples, (b) CV-LB correlation is perfect, (c) Simple mean plateaus and fitted weights consistently improve both CV and LB.

**When NOT to use:** Don't fit weights when: (a) Models are near-identical (weights will be arbitrary), (b) Validation set is too small (< 500 samples per fold), (c) Fitted ensemble improves CV but hurts LB (overfitting).

**How to reason about it:**
Start with simple mean. Check: does it beat all individual models? If yes, submit it. Then try Nelder-Mead on OOF predictions—does fitted ensemble improve CV AND improve/maintain LB? If LB degrades, fitted weights overfit. For diversity, vary: pooling, max_length, layer freezing, auxiliary losses—not just random seeds. Negative weights: allow them, but if magnitude > 0.5, inspect—large negatives may indicate overfitting. Optuna/grid search on weights is worse than Nelder-Mead (more prone to overfitting).

```python
from scipy.optimize import minimize

def neg_metric(weights, oof_preds, targets):
    ensemble = np.average(oof_preds, axis=0, weights=weights)
    return -compute_metric(ensemble, targets)  # e.g., -MCRMSE

# Simple mean baseline
ensemble_mean = np.mean(oof_preds, axis=0)
baseline_score = compute_metric(ensemble_mean, targets)

# Fitted weights (Nelder-Mead, allow negative)
init_weights = [1.0] * len(oof_preds)
result = minimize(neg_metric, init_weights, args=(oof_preds, targets), method='Nelder-Mead')
optimal_weights = result.x
ensemble_fitted = np.average(oof_preds, axis=0, weights=optimal_weights)
fitted_score = compute_metric(ensemble_fitted, targets)

print(f"Simple mean: {baseline_score}, Fitted: {fitted_score}")
# If fitted_score <= baseline_score or LB degrades, use simple mean
```
