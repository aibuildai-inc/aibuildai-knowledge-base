## Principle 13: Diversify Ensemble via Architecture Variations, Not Just Hyperparameters

*Consensus: Many solutions vary pooling (CLS, mean, GEM, LSTM, attention); several vary max_length; some use auxiliary losses*

To build a strong ensemble, create diversity through: (1) pooling strategies (CLS, mean pooling, GEM, LSTM over hidden states, attention pooling), (2) max sequence lengths (768, 1024, 1536), (3) auxiliary losses (predicting discourse type, using ArcFace), (4) layer freezing (freeze bottom 6-9 layers). Avoid diversity via random hyperparameter changes—it adds noise, not signal.

**Why this matters:** Ensemble performance depends on diversity. Models that make the same mistakes don't help each other. The 4th-place summary solution used 7 DeBERTa-v3-large models with different pooling, max_length, and layer freezing—each contributed. Randomly varying learning rate or batch size creates models that differ only in noise, not in learned patterns, so they don't ensemble well.

**When to use:** Use pooling diversity when: (a) You're ensembling 5+ models, (b) Single pooling strategy plateaus. Use max_length diversity when: (a) Texts vary in length (some short, some very long), (b) Inference time allows multiple lengths. Use auxiliary losses when: (a) Task has extra labels available (e.g., discourse type for effectiveness task), (b) You need regularization for long training.

**When NOT to use:** Don't add diversity for diversity's sake. If a pooling strategy (e.g., LSTM) consistently underperforms in CV, don't include it in ensemble just for 'diversity'—it will hurt, not help. Avoid varying only hyperparameters (LR, batch size) unless you have data showing they produce genuinely different error patterns.

**How to reason about it:**
Build 3-5 base models with different architectures (pooling + max_length combinations). Evaluate each on CV. Ensemble them—does ensemble beat best single model by > 0.005? If yes, diversity is working. Then add 2-3 more diverse models (auxiliary loss, layer freezing). If adding a model improves ensemble by < 0.001, stop—you've hit diminishing returns. Avoid correlated models: two models with mean pooling at 1024 and 1280 max_length are highly correlated; one mean pooling + one attention pooling is more diverse.

# Diversity via pooling
model_A = DeBERTa_with_pooling('cls', max_length=1024)
model_B = DeBERTa_with_pooling('mean', max_length=1024)
model_C = DeBERTa_with_pooling('attention', max_length=1536)
model_D = DeBERTa_with_pooling('lstm', max_length=1024)

# Diversity via auxiliary loss (e.g., predict discourse type)
model_E = DeBERTa_with_aux_loss(main_loss='mse', aux_loss='ce', aux_weight=0.3)

# Ensemble
ensemble_pred = (model_A.predict(test) + model_B.predict(test) + 
                 model_C.predict(test) + model_D.predict(test) + 
                 model_E.predict(test)) / 5
