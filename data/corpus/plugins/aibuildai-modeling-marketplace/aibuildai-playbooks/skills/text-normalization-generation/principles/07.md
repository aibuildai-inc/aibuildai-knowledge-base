## Principle 7: Engineer Task-Specific Inputs: Add Prompts, Questions, and Special Tokens

*Consensus: Many solutions report gains from adding prompts; several use custom special tokens like <question>, <summary>*

For writing assessment, concatenate not just the student text but also the prompt, question, or rubric text. Use custom special tokens to delineate sections (e.g., `<question> ... <summary> ... <text> ...`). This gives models explicit context about what the student was asked and what dimensions to evaluate.

**Why this matters:** A summary's quality depends on the source text—without it, models can't assess fidelity. Adding `prompt_text` improved scores by 0.005-0.01 in multiple competitions. Special tokens help models learn section-specific representations (e.g., pool only `<summary>` tokens for summary-specific features). The 8th-place solution added `<question>`, `<summary>`, `<text>` tokens and saw consistent CV gains.

**When to use:** Use when: (a) Task evaluates student writing relative to a prompt or source text (summaries, argument responses), (b) Prompt text is available in train and test, (c) You have headroom in max sequence length to include prompt. For discourse-level tasks (e.g., evaluate individual claims in an essay), add discourse type labels and custom tokens per discourse.

**When NOT to use:** Skip prompt addition when: (a) Prompts are unavailable in test data, (b) Max length constraints make it infeasible (prompt + student text > 1536 tokens), (c) Task is prompt-agnostic (e.g., pure grammar scoring).

**How to reason about it:**
Decide input order: put most important section first (less likely to be truncated). Common pattern: `<question> {prompt_question} <summary> {student_text} <text> {prompt_text}` — prompt_text last since it's longest and least critical if truncated. Add custom tokens to tokenizer vocab before training, initialize their embeddings randomly or from [SEP]. Experiment: Does adding prompts improve CV? Does using custom tokens beat plain [SEP]? Typical gains: +0.002 to +0.01.

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained('microsoft/deberta-v3-large')
# Add custom tokens
new_tokens = ['<question>', '<summary>', '<text>']
tokenizer.add_tokens(new_tokens)
model.resize_token_embeddings(len(tokenizer))

# Construct input
input_text = f"<question> {prompt_question} <summary> {student_summary} <text> {prompt_text}"
tokens = tokenizer(input_text, max_length=1024, truncation=True, return_tensors='pt')
```
