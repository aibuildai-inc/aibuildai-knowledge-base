## Principle 5: Expand Data via External Corpora + Pseudo-Labeling

*Consensus: Many top solutions use external data or pseudo-labels; several use meta pseudo-labeling (summaries 1st, Feedback effectiveness 4th, ELL 20th)*

Writing assessment tasks have small labeled datasets (typically a few thousand essays). Augment by: (1) Finding external text corpora (Wikipedia, prior competitions, public essay datasets), (2) Selecting relevant samples via sentence embeddings (cosine similarity to train set), (3) Pseudo-labeling with ensemble of models trained on target data, (4) Optionally: multi-round pseudo-labeling (use pseudo-labeled data to train new ensemble, re-label external data).

**Why this matters:** Small labeled datasets cause models to overfit. The 1st-place readability solution used external data + pseudo-labeling to effectively 10x training data, gaining 0.02-0.03. Sentence embeddings ensure external data is domain-relevant (selecting random Wikipedia is useless). Multi-round pseudo-labeling iteratively improves label quality, though it risks overfitting if not validated carefully.

**When to use:** Use when: (a) Training data < 10k samples, (b) External corpora exist (prior competitions, CommonLit, Persuade corpus, Wikipedia, BookCorpus), (c) You can verify pseudo-labeling improves CV (not just LB). Multi-round pseudo-labeling: use if 1st round improves CV and you have compute for retraining.

**When NOT to use:** Skip external data when: (a) Task is highly domain-specific and no relevant corpus exists, (b) Train data > 50k (diminishing returns), (c) Pseudo-labeling degrades CV (wrong label distribution). Don't blindly trust pseudo-labels—filter by confidence or standard error to avoid corrupting training data.

**How to reason about it:**
Step 1: Identify external corpora (prior competitions are gold—same domain, just different prompts). Step 2: Use sentence embeddings (e.g., `paraphrase-MiniLM-L6-v2`) to select top-5 most similar external samples per train sample. Step 3: Train ensemble on target data, pseudo-label selected external samples. Step 4: Filter pseudo-labels by standard error—keep only samples where pseudo-label is within SE of original sample's score. Step 5: Train on mix of real + pseudo-labeled data. Step 6 (optional): Repeat with new ensemble for round 2. Validate: does adding external data improve CV? If yes, proceed; if no, your selection or filtering is wrong.

```python
from sentence_transformers import SentenceTransformer, util
import torch

# Step 1: Embed train and external data
model_emb = SentenceTransformer('paraphrase-MiniLM-L6-v2')
train_emb = model_emb.encode(train_texts, convert_to_tensor=True)
external_emb = model_emb.encode(external_texts, convert_to_tensor=True)

# Step 2: For each train sample, find top-5 similar external samples
selected_external = []
for i, train_vec in enumerate(train_emb):
    cos_scores = util.cos_sim(train_vec, external_emb)[0]
    top_k = torch.topk(cos_scores, k=5)
    selected_external.extend([external_texts[idx] for idx in top_k.indices])

# Step 3: Pseudo-label with ensemble
pseudo_labels = ensemble.predict(selected_external)
```
