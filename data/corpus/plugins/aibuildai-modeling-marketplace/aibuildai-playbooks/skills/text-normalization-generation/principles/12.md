## Principle 12: Apply Metric-Specific Post-Processing Only When It Survives Validation

*Consensus: Readability and language-learning scoring solutions rescaled predictions by predicted-value range (Nelder-Mead coefficients per bin, interval mean matching) for small gains; several other language-learning and summary solutions found post-processing did not help*

Regression models output shrunken predictions: trained with MSE, they pull extreme scores toward the mean. Range-wise rescaling (a separate multiplier per predicted-value bin) or interval mean matching stretches them back. For log loss, scale class probabilities so their mean per class matches the training class frequencies. For thresholded ordinal metrics (Quadratic Weighted Kappa), tune the class thresholds on out-of-fold predictions instead of rounding at midpoints.

**Why this matters:** A metric can reward a systematic shift that the training loss did not optimize. A top readability solution multiplied predictions by different coefficients depending on the predicted value and gained about 0.001-0.002; a language-learning solution split predictions into 20 bins and fitted one multiplier per bin with Nelder-Mead. But the gains are small and easy to overfit: the coefficients in the readability solution were partly tuned on the public leaderboard, and several other solutions reported that post-processing did not help.

**When to use:** Use range-wise rescaling when OOF predictions are visibly compressed relative to the targets (prediction variance well below target variance). Use mean-matching when the metric is log loss or cross-entropy and predicted class means differ from training class frequencies. Use threshold tuning when the metric is QWK or Cohen's Kappa and target classes are imbalanced.

**When NOT to use:** Skip post-processing if: (a) it improves OOF CV only marginally and you would have to tune it on the public leaderboard, (b) the OOF set is small, so per-bin coefficients fit noise, (c) predictions are already well calibrated. Don't fit coefficients on full-train models separately—fit them on OOF predictions and apply the same values to full-train predictions.

**How to reason about it:**
Use OOF predictions from k-fold. Plot predicted vs. true values: is the slope below 1 at the extremes? If yes, fit per-bin multipliers (few bins, strong regularization) with Nelder-Mead to minimize the metric on OOF. Validate with a nested split: fit coefficients on some folds, evaluate on the others. Keep the post-processing only if it improves the held-out folds. For log loss mean-matching: compute the mean predicted probability per class, compare with the training class frequency, and rescale.

```python
import numpy as np
from scipy.optimize import minimize

def apply_bin_scaling(preds, edges, coefs):
    bins = np.digitize(preds, edges)
    return preds * coefs[bins]

def fit_bin_scaling(oof_preds, oof_targets, n_bins=5):
    edges = np.quantile(oof_preds, np.linspace(0, 1, n_bins + 1)[1:-1])
    def rmse(coefs):
        return np.sqrt(np.mean((apply_bin_scaling(oof_preds, edges, coefs) - oof_targets) ** 2))
    result = minimize(rmse, np.ones(n_bins), method='Nelder-Mead')
    return edges, result.x

# Nested check: fit on folds A, evaluate on folds B
```
