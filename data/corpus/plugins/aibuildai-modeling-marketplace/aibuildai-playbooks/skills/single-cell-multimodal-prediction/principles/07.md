## Principle 7: Use the Simplest Architecture That Captures Output Coupling

*Consensus: 12/13 top-eight solutions used neural multi-output or factorized models, usually alongside simpler models; plain MLPs appeared in nearly every multimodal ensemble and in several perturbation systems.*

Begin with a regularized MLP or low-rank regression baseline, then add CNN, recurrent, transformer, boosting, or tensor-factor models only when their inductive bias or OOF residual diversity is measurable. Treat reshaping a flat vector into a sequence as a hypothesis, not a biological fact.

**Why this matters:** These datasets have many more features and outputs than independent experimental combinations, so model capacity can overwhelm sample support. Simple shared hidden layers already exploit output covariance; more elaborate sequence layers may help optimization or parameter sharing, but arbitrary feature order can make their apparent structure accidental.

**When to use:** Use MLPs for reduced continuous features and full or latent multi-output targets. Use gene-aware tensor factorization when cell, compound, and gene form repeated axes. Consider CNN/RNN/transformer variants when a stable ordering or block structure exists, or when they add robust OOF gains.

**When NOT to use:** Do not prefer complexity merely because the data are biological. Autoencoders, TabNet, nonlinear manifold methods, sequence models over SMILES, and large pretrained biological models were repeatedly reported as neutral or worse. Tree and linear models remain valuable when they extrapolate differently or add ensemble diversity.

**How to reason about it:**
Establish a ladder: marginal-mean baseline, ridge/low-rank model, MLP, then one structured architecture. Compare not only score but variance across hard folds, parameter count relative to unique interactions, and residual correlation with the baseline. Stop when added complexity yields no stable gain or diversity.

```python
import torch.nn as nn

class SharedMultiOutputMLP(nn.Module):
    def __init__(self, n_in, n_out, width=512, dropout=0.2):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_in, width), nn.GELU(), nn.Dropout(dropout),
            nn.Linear(width, width), nn.GELU(), nn.Dropout(dropout),
            nn.Linear(width, n_out),
        )
    def forward(self, x):
        return self.net(x)

```
