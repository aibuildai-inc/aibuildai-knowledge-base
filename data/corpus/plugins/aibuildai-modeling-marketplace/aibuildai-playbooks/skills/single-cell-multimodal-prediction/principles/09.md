## Principle 9: Regularize in Ways Consistent with the Representation

*Consensus: A minority of 4/13 top-eight solutions reported meaningful gains from mixup, feature masking, c-mixup, or pseudolabeling; several others explicitly found pseudo-labels or generic noise ineffective.*

Choose augmentation by asking whether interpolation or corruption preserves the meaning of the current representation. Continuous latent cell states can support mixup; molecular embeddings can support feature masking; categorical IDs generally cannot support Gaussian perturbation.

**Why this matters:** Augmentation encodes an invariance assumption. If that assumption matches the data-generating process, it smooths a severely undersampled high-dimensional regression problem; if it changes entity identity or invents impossible biology, it adds structured label noise.

**When to use:** Use mixup after continuous normalization or projection, masking for redundant descriptors, small target noise when fold tests show robustness, and SWA/seed bagging as low-risk variance reduction. Pseudolabel only when OOF simulations show that label quality and selection thresholds improve the exact held-out regime.

**When NOT to use:** Avoid Gaussian noise on one-hot entity labels, arbitrary interpolation of unrelated categorical entities, and indiscriminate pseudo-labeling under domain shift. Strong multimodal and perturbation writeups reported either tiny or negative pseudo-label gains, so it should not be a default.

**How to reason about it:**
State the invariance before coding: 'a convex combination of these two latent profiles should have the same convex combination of responses' or 'dropping part of this redundant descriptor should preserve identity.' If that sentence is biologically or statistically implausible, do not augment. Validate augmentation on the hardest folds and subgroup tails.

```python
def mixup_continuous(x, y, alpha=1.0):
    # Apply only to continuous representations where interpolation is meaningful.
    lam = torch.distributions.Beta(alpha, alpha).sample().to(x.device)
    idx = torch.randperm(x.size(0), device=x.device)
    return lam*x + (1-lam)*x[idx], lam*y + (1-lam)*y[idx]

def mask_descriptors(x, p=0.1):
    # Appropriate for redundant dense descriptors, not categorical IDs.
    return x * (torch.rand_like(x) > p)

```
