## Principle 1: Choose Signal Representation Based on Physics and Sequence Length

*Consensus: Strong pattern across gravitational wave (15/19 top solutions used both) and spectroscopy competitions*

Select between 1D time-domain, 2D time-frequency, or hybrid approaches based on whether the signal physics favors temporal correlations vs frequency structure and whether sequences are long enough for stable spectrograms.

**Why this matters:** 1D CNNs preserve precise temporal alignment needed for multi-detector correlation (gravitational waves arrive with <20ms offset between detectors), while 2D spectrograms reveal frequency-domain patterns but corrupt boundary regions on short sequences. The wrong choice either loses critical physics or introduces preprocessing artifacts.

**When to use:** Use 1D: when signal is defined by cross-detector temporal correlation (gravitational waves arriving with a time offset at separated detectors), sequences are short (<4s making spectrogram boundaries costly), or you need to learn adaptive frequency filters. Use 2D: when signal has strong frequency structure (continuous gravitational waves that appear as narrow, slowly drifting frequency lines, exoplanet spectral absorption lines), sequences are long enough (>8s), or physical intuition suggests frequency-domain features. Use hybrid: ensemble both for robustness.

**When NOT to use:** Do not force 2D on multi-detector correlation problems where detectors see time-shifted versions of the same signal - early concatenation before learning detector-specific features fails because random shifts prevent joint feature extraction. Do not use 1D when the task is fundamentally about frequency patterns with no temporal ordering importance.

**How to reason about it:**
Ask: (1) Does the signal physics depend on precise temporal alignment between channels? If yes, lean 1D. (2) Is there a known frequency structure to exploit (e.g., absorption lines, harmonics)? If yes, consider 2D. (3) What is the sequence length relative to the target phenomenon duration? If phenomenon occupies >50% of the window, 2D boundary corruption matters less. (4) Can you afford training time for both? Best solutions ensemble 1D and 2D for complementary strengths.

# 1D approach: separate branches per detector, late fusion
class MultiDetector1D(nn.Module):
    def __init__(self):
        self.detector_extractors = nn.ModuleList([Conv1DExtractor() for _ in range(n_detectors)])
        # Share weights for identical detectors (e.g., LIGO H1/L1)
        if share_weights: self.detector_extractors[0] = self.detector_extractors[1]
        self.fusion = ResNetBlocks()  # Fuse AFTER extracting features
    
    def forward(self, x):  # x: (batch, n_detectors, time)
        features = [extractor(x[:, i]) for i, extractor in enumerate(self.detector_extractors)]
        return self.fusion(torch.cat(features, dim=1))
