## Principle 8: Use Test-Time Augmentation for Invariant Transformations

*Consensus: Gravitational wave solutions: 2bps gain from channel swap + vertical flip + time shift; nearly universal across top solutions*

Apply transformations at inference time that respect physical invariances of the problem (channel swaps for identical detectors, time/frequency shifts, vertical flips for symmetric signals, MC dropout for uncertainty), average predictions, and gain 1-3% improvement for negligible cost.

**Why this matters:** Physical systems have symmetries: gravitational wave detector pairs are interchangeable, signals can be time-shifted within the observation window, waveform polarity can flip, noise realizations vary. TTA exploits these to effectively ensemble multiple views of each test sample. The 3rd place g2net solution gained 2bps from swapping LIGO channels and vertical flipping, treating each test sample 4 ways.

**When to use:** Use TTA for: (1) channel/detector permutations when detectors are identical by design, (2) time shifts when signal can appear anywhere in the window, (3) vertical flip (multiply by -1) for waveforms with no intrinsic polarity, (4) MC dropout (64-fold) for additional uncertainty sampling. Always average predictions across augmented versions. Disable random augmentations (Gaussian noise, mixup) at test time - use only deterministic transforms.

**When NOT to use:** Do not use TTA for non-invariant transforms - e.g., do not horizontally flip time series if left-to-right order matters, do not swap channels if detectors are fundamentally different. Do not apply TTA if inference time is severely limited and the gain is marginal. The computational cost is linear in number of augmentations but the gain plateaus quickly (4-8x is usually sufficient).

**How to reason about it:**
Step 1: Identify physical invariances. Identical detectors? -> swap. Signal polarity-agnostic? -> vertical flip. Time-translation invariant? -> shift. Step 2: Test each augmentation individually on validation to confirm it doesn't hurt. Step 3: Combine orthogonal augmentations (swap + flip + shift = 2×2×n_shifts variants). Step 4: Average predictions across all variants. Step 5: For uncertainty tasks, add MC dropout inference with multiple forward passes.

```python
# Test-time augmentation
def predict_with_tta(model, signal, n_shifts=2):
    predictions = []
    # Original
    predictions.append(model(signal))
    # Vertical flip (multiply by -1)
    predictions.append(model(-signal))
    # Channel swap (for multi-detector)
    if signal.shape[1] == 3:  # 3 detectors
        swapped = signal[:, [1, 0, 2], :]  # Swap first two
        predictions.append(model(swapped))
        predictions.append(model(-swapped))
    # Time shifts
    for shift in range(1, n_shifts):
        shifted = torch.roll(signal, shifts=shift*10, dims=-1)
        predictions.append(model(shifted))
    # MC Dropout (enable dropout at test time)
    model.train()  # Enables dropout
    for _ in range(16):
        predictions.append(model(signal))
    model.eval()
    # Average all predictions
    return torch.stack(predictions).mean(dim=0)
```
