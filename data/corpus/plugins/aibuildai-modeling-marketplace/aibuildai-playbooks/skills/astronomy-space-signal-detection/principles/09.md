## Principle 9: Pretrain on Synthetic Data Then Finetune on Real Data

*Consensus: G2net 3rd place: 2-8bps gain from GW pretraining; multiple solutions across competitions used this pattern*

When you can generate synthetic data with known ground truth, pretrain the model on synthetic for 2-4 epochs to learn basic signal structure, then train on real competition data to adapt to real noise and distribution.

**Why this matters:** Synthetic data provides unlimited samples with known labels, letting the model learn the idealized signal structure without noise/artifact overfitting. Pretraining acts as a warm start, especially valuable when real labeled data is limited. The g2net 3rd place gained 2-8bps by pretraining on simulated gravitational wave mergers before training on competition data, learning the chirp mass patterns and waveform shapes in a controlled setting.

**When to use:** Use pretraining when: (1) you have a good simulator that produces realistic signals, (2) real labeled data is limited (<10k samples), (3) the task has low-SNR examples where signal is barely visible (synthetic high-SNR examples teach the model what to look for). Pretrain for only a few epochs to avoid overfitting to synthetic-specific patterns.

**When NOT to use:** Do not pretrain if your synthetic data distribution badly mismatches real data - you will learn the wrong features. Do not pretrain for too long (>5 epochs) - the model will forget to handle real-world noise and artifacts. Do not use pretrained weights if real data is abundant (>100k samples) and different in character from synthetic - training from scratch may be better.

**How to reason about it:**
Step 1: Generate synthetic data with parameter distributions tuned to match real data statistics. Step 2: Pretrain for 2-4 epochs with standard supervised loss. Step 3: Switch to real competition data and train normally - use the pretrained weights as initialization. Step 4: Optionally use a lower learning rate for real data to preserve learned synthetic patterns. Step 5: Monitor validation loss on real data - if it does not improve, pretraining may have hurt (distributions too different).

```python
# Pretraining workflow
# Step 1: Generate synthetic data
synthetic_data = [generate_gw_signal(params) for params in synthetic_params]

# Step 2: Pretrain on synthetic
model = MyModel()
optimizer = Adam(model.parameters(), lr=1e-3)
for epoch in range(3):  # Only a few epochs
    for batch in synthetic_data:
        loss = criterion(model(batch.signal), batch.label)
        loss.backward()
        optimizer.step()

# Step 3: Finetune on real data with lower LR
optimizer = Adam(model.parameters(), lr=3e-4)  # Lower LR
for epoch in range(20):
    for batch in real_competition_data:
        loss = criterion(model(batch.signal), batch.label)
        loss.backward()
        optimizer.step()
```
