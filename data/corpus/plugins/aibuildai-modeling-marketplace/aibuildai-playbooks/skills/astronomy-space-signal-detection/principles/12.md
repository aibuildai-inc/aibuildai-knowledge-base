## Principle 12: Ensemble Diverse Models with CMA-ES or Stacking

*Consensus: G2net 3rd place used CMA-ES optimization; nearly universal pattern*

Combine predictions from architecturally diverse models (1D CNNs, 2D CNNs, recurrent encoders, tree models) using optimized weights found by CMA-ES on validation set or a stacking meta-model trained on out-of-fold predictions, targeting the competition metric directly.

**Why this matters:** Different architectures capture different aspects of the signal: 1D CNNs excel at temporal patterns, 2D CNNs at frequency structure, recurrent encoders at irregular sequences, tree models at global tabular features. Simple averaging underweights strong models; CMA-ES finds optimal weights by directly optimizing the competition metric. The g2net 3rd place found CMA-ES on logits outperformed neural network ensembling.

**When to use:** Use ensembling when: (1) you have 5+ diverse models (different architectures, preprocessing, or training), (2) individual models have similar performance (within 2% of each other), (3) you have held-out validation data to optimize ensemble weights without overfitting. Use CMA-ES to optimize metric directly; use stacking for complex non-linear combinations.

**When NOT to use:** Do not ensemble many weak models - better to iterate on a single strong model. Do not optimize ensemble weights on the same data used to train base models (will overfit). Do not use equal-weight averaging if models have very different quality (e.g., one model is 0.85 and another is 0.75 - weight the strong one higher).

**How to reason about it:**
Step 1: Train diverse base models (1D, 2D, recurrent, tree-based, different preprocessing). Step 2: Generate out-of-fold predictions for each model on validation data. Step 3: Use CMA-ES to find weights that maximize validation metric: weights = cmaes(lambda w: -metric(weighted_avg(predictions, w)), init_weights=uniform). Step 4: Alternatively, train a shallow stacking model (LightGBM max_depth=2, or MLP) on base model predictions. Step 5: Validate on separate holdout and adjust if overfitting.

```python
# Ensemble with CMA-ES optimization
import cma

def ensemble_metric(weights, predictions, targets, metric_fn):
    # predictions: (n_models, n_samples, n_classes)
    weights = np.array(weights) / np.sum(weights)  # Normalize
    ensemble_pred = np.average(predictions, axis=0, weights=weights)
    return -metric_fn(targets, ensemble_pred)  # Negative for minimization

# Optimize weights
n_models = len(predictions)
init_weights = np.ones(n_models) / n_models
es = cma.CMAEvolutionStrategy(init_weights, 0.3)
while not es.stop():
    solutions = es.ask()
    fitness = [ensemble_metric(w, val_predictions, val_targets, competition_metric) for w in solutions]
    es.tell(solutions, fitness)
best_weights = es.result[0]

# Stacking alternative
from lightgbm import LGBMClassifier
stacker = LGBMClassifier(max_depth=2, n_estimators=100)
# Train on base model predictions
stacker.fit(np.column_stack([m.predict(X_val) for m in base_models]), y_val)
```
