## Principle 14: Handle Class Imbalance and Low-SNR Positives with Weighting and Careful Sampling

*Consensus: PLAsTiCC solutions tuned per-class or per-sample weights for the weighted log loss (one gained 0.04 LB from optimized sample weights), and the g2net 1st place noted that because of the SNR wall some positive samples are effectively just noise*

When positive signals are rare, when the metric weights classes unequally, or when many labeled positives are too faint to detect, weight the loss to match the metric, sample batches deliberately, and accept a detection limit instead of chasing unlearnable examples.

**Why this matters:** With 99:1 class imbalance, a model predicting all negatives achieves 99% accuracy but 0% recall. Standard cross-entropy gives equal loss to all samples, so the model optimizes by getting negatives right and ignoring rare positives. A class-weighted metric rewards getting rare classes right, so training with matching weights aligns the optimizer with the score. Faint signals add a second problem: when SNR is below what any detector can resolve, labeled positives are indistinguishable from noise, creating a continuum from clear positives to ambiguous to clear negatives.

**When to use:** Use class or sample weights when the metric weights classes unequally or a class is rare. Use focal loss when many negatives are easy and the metric cares about the minority class (recall, F1, AUC, not accuracy). Use oversampling or weighted sampling to balance batches. For faint synthetic signals, control the SNR range of injected training signals: one continuous-wave solution found that a too-low SNR range made training diverge, while a too-high range made the model less discerning when no signal was present.

**When NOT to use:** Do not use focal loss if classes are balanced or the metric is accuracy (equal weight per sample). Do not oversample to the point of overfitting to the few positive examples - augment positives instead. Do not assume reweighting alone solves the problem - you need sufficient positive examples (at least hundreds) to learn from.

**How to reason about it:**
Step 1: Check class balance and the metric's class weights. Step 2: If the metric weights classes, reproduce those weights in the loss, then tune per-class or per-sample weights on validation. Step 3: If many negatives are easy, try focal loss with γ=2 to down-weight them: FL = -α(1-p_t)^γ log(p_t). Step 4: Oversample the minority class or use weighted sampling, and augment it to create diversity. Step 5: Validate on a metric that reflects minority class importance, not accuracy. Step 6: At very low SNR, check whether different models plateau together - a sign of a fundamental detection limit.

import torch.nn.functional as F

# Focal loss implementation
def focal_loss(logits, targets, alpha=0.25, gamma=2.0):
    probs = torch.sigmoid(logits)
    targets = targets.float()
    bce = F.binary_cross_entropy_with_logits(logits, targets, reduction='none')
    p_t = probs * targets + (1 - probs) * (1 - targets)
    focal_term = (1 - p_t) ** gamma
    alpha_t = alpha * targets + (1 - alpha) * (1 - targets)
    return (alpha_t * focal_term * bce).mean()
