## Principle 6: Combine Neural Networks with Algorithmic Components for Verifiable Tasks

*Consensus: 5/5 top math solutions use code execution, 3/3 top Game of Life use SAT solvers, 6/6 top game-playing use MCTS*

For tasks with verifiable intermediate steps or solutions, hybrid approaches combining learned models with algorithmic solvers consistently outperform pure learning. Math solutions interleave LLM reasoning with Python execution; inverse problems use SAT solvers; games use neural nets to guide MCTS.

**Why this matters:** Neural networks are good at intuition but bad at exact computation and search. Algorithms are good at exact computation and exhaustive search but need good guidance. Combining them gets the best of both: the neural net proposes promising directions, the algorithm verifies and searches. AIMO 1st place: code execution catches arithmetic errors and provides feedback for multi-step reasoning.

**When to use:** When solutions are verifiable (math, code, constraint satisfaction), when the problem has clear sub-steps (inverse problems can be solved iteratively), or when the search space is large but structured (games, optimization).

**When NOT to use:** When verification is expensive or unreliable, when the problem is not decomposable into verifiable steps, or when end-to-end learning already achieves strong performance.

**How to reason about it:**
Identify the boundary: What can the neural net do well? (propose, rank, value estimation) What should the algorithm do? (verify, search, exact computation). For math: LLM generates reasoning + code, Python executes and feeds back results. For games: neural net provides value/policy, MCTS does lookahead. For inverse problems: neural net guides solver initialization, SAT solver finds exact solution. The handoff point is where exactness or exhaustiveness becomes critical.

```python
# Tool-integrated reasoning with code execution feedback (AIMO 1st)
prompt = problem + tool_instruction
for round in range(max_rounds):
    # Neural net generates reasoning + code
    completion = llm.generate(prompt, stop="```output")
    if '```python' in completion:
        code = extract_code(completion)
        result = execute_code(code)
        if is_integer(result) and result >= 0:
            return result % 1000  # Verified answer
        else:
            # Provide feedback and retry
            prompt += completion + f"```output\n{result}\nError: not an integer. Try again.\n```"
```
