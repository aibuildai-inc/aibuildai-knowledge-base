## Principle 10: Use Constraint Solvers for Inverse Problems with Deterministic Rules

*Consensus: 3/3 top Game of Life solutions, 2/2 top ciphertext challenge solutions*

For inverse problems where the forward process is deterministic and the solution must satisfy hard constraints, encode the problem as a SAT instance or use specialized solvers (Z3, Picosat, Kissat). Game of Life 1st place: SAT solvers dramatically outperformed genetic algorithms and neural approaches.

**Why this matters:** Constraint solvers can guarantee correctness and exhaustively search, which learning-based methods cannot. Game of Life: Picosat was much faster than Z3, Kissat was faster on hard instances. The key insight is iterative solving (find state at t-1, then t-2, etc.) with constraints to minimize pixel count at each step, plus timeout-based restarts to escape bad branches.

**When to use:** When the forward process is deterministic and can be encoded as logical constraints (cellular automata, cryptographic ciphers, constraint satisfaction), when you need exact solutions, and when modern SAT solvers are available.

**When NOT to use:** When the inverse problem is underconstrained (many valid solutions) and you need one quickly rather than all of them, when encoding the problem as constraints is intractable, or when approximate solutions are acceptable and faster to find via optimization.

**How to reason about it:**
Encoding: Express the forward rule as CNF clauses (for SAT) or constraints (for SMT). Iterative solving: For multi-step inverse problems, solve one step at a time backward (state at t-1 given state at t, not state at t-3 given state at t directly). Add minimality constraints: binary search on the number of dead cells to find the sparsest solution (which is more likely to have its own parent). Timeouts: Use timeout-based restarts to avoid getting stuck; the solver often picks a bad first branch. Solver selection: try multiple solvers (Z3, Picosat, Kissat) - no single solver dominates all instances.

# SAT-based inverse Game of Life (1st place)
def solve_inverse(stop_state, delta):
    current = stop_state
    for step in range(delta):

        min_dead, max_dead = 0, len(current)
        while min_dead < max_dead:
            mid_dead = (min_dead + max_dead) // 2
            dead_cells = random.sample(range(len(current)), mid_dead)
            # Encode: find parent state such that evolve(parent, 1) == current
