## Principle 14: Balance Exploration and Exploitation in Search via Temperature and Penalties

*Consensus: 5/6 top game-playing solutions using MCTS, 3/5 top math solutions using sampling*

Search-based methods need careful tuning of exploration (trying new options) vs exploitation (refining known good options). Games use PUCT formula and visit counts; math solutions use temperature for sampling diversity and entropy penalties during training.

**Why this matters:** Too much exploitation leads to getting stuck in local optima or predictable strategies (exploitable by opponents). Too much exploration wastes compute on bad options. Hungry Geese: behavioral cloning with high entropy penalty (0.1) encouraged uncertainty, which combined with MCTS allowed exploration. Math: temperature 0.9 for sampling provided diversity for voting while temperature 0 for final answer avoided random errors.

**When to use:** When using search methods (MCTS, beam search), when sampling multiple candidates for voting, or when training agents that play against each other (self-play).

**When NOT to use:** When you want deterministic behavior (inference without voting), when the solution is well-defined and you just need the optimal path, or when computational budget is very limited (can't afford exploration).

**How to reason about it:**
For MCTS: Use PUCT formula with exploration constant c (higher = more exploration). Tune c on validation: does it find better moves given more time? For sampling: Use temperature T during candidate generation (higher = more diversity) but greedy (T=0) for final selection. For training: Add entropy penalty to policy loss to prevent premature convergence to deterministic policies (essential for games where randomness helps). Validate: Plot score vs. number of samples/iterations - should see diminishing returns, not plateau immediately.

# PUCT exploration in MCTS (Hungry Geese)
def select_action(node, c_puct=1.4):
    """Select action with highest PUCT value: Q(a) + c * P(a) * sqrt(N) / (1 + n(a))"""
    N = sum(node.visit_counts)
    puct_values = {}
    for action in node.valid_actions:
        Q = node.Q_values[action]  # Mean value from search
        P = node.prior_policy[action]  # Neural net prior
        n = node.visit_counts[action]
        puct_values[action] = Q + c_puct * P * sqrt(N) / (1 + n)
    return max(puct_values, key=puct_values.get)
