## Principle 8: Apply Aggressive Data Augmentation for Geometric and Permutation Invariances

*Consensus: 5/5 top ARC solutions, 6/6 top game-playing solutions, 2/2 top Game of Life solutions*

For problems with known invariances (rotation, flip, color permutation, agent ordering), apply augmentation at training AND inference time. ARC solutions applied rotation, flip, color swaps, and input-output swaps; game solutions applied board rotations and agent permutations. Average predictions over augmented views at inference.

**Why this matters:** Reasoning tasks often have symmetries that aren't learned from data alone. Explicitly encoding invariances through augmentation improves sample efficiency and generalization. ARC 2nd place used 96 augmented predictions per test input with voting - the augmentation effectively multiplies the effective ensemble size. Game solutions became rotation-invariant without needing to learn it from scratch.

**When to use:** When the problem has known geometric symmetries (grids, boards), permutation symmetries (agent ordering, color labels), or problem-level transformations (ARC: you can swap train and test examples). Apply both during training (improves learning efficiency) and inference (improves prediction quality via ensemble).

**When NOT to use:** When the problem has directional asymmetry (text reading order, time series causality), when augmentation creates invalid states (some games have fixed starting positions), or when inference budget doesn't allow multiple forward passes.

**How to reason about it:**
Identify invariances: What transformations leave the answer unchanged? For grids: rotation (90/180/270°), flip (horizontal/vertical), color permutation. For games: board rotation/reflection. For abstract tasks: input-output swap, example ordering. Training: apply random augmentation to each batch. Inference: generate predictions for all augmentations, transform predictions back to original space, vote or average. Validate: does test-time augmentation improve score?

```python
# ARC data augmentation (2nd place)
augmentations = ['rotate_90', 'rotate_180', 'rotate_270', 'flip_h', 'flip_v', 'color_swap']

def augment_task(task):
    aug = random.choice(augmentations)
    # Apply same transformation to all inputs and outputs
    augmented_examples = []
    for example in task.train_examples + [task.test_input]:
        if aug.startswith('rotate'):
            example = rotate(example, int(aug.split('_')[1]))
        elif aug == 'flip_h':
            example = flip_horizontal(example)
        elif aug == 'flip_v':
            example = flip_vertical(example)
        elif aug == 'color_swap':
            perm = random_permutation(10)  # 10 colors
            example = permute_colors(example, perm)
    return augmented_examples
```
