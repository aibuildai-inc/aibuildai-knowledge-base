## Principle 9: Use GeM Pooling Instead of Average Pooling

*Consensus: 10+ top solutions explicitly mentioned GeM pooling, including prostate grading (PANDA) and abdominal trauma solutions*

Replace the final global average pooling layer in CNN backbones with Generalized Mean (GeM) pooling with trainable parameter p. GeM pooling computes (mean(x^p))^(1/p), interpolating between max pooling (p→∞) and average pooling (p=1).

**Why this matters:** Medical images often have small diagnostic regions (tiny lesions, scattered cells) that get diluted by average pooling. GeM pooling with p>1 emphasizes high-activation regions more than average pooling, helping model focus on salient features. The trainable p parameter lets the model learn the optimal pooling behavior.

**When to use:** When diagnostic features are localized and sparse (small tumors, lesions, specific cell types). As a default replacement for global average pooling in CNNs - it rarely hurts and often helps. When you observe that important features get lost in the final pooling step.

**When NOT to use:** When diagnostic signal is diffuse across the entire image. When you're using attention mechanisms that already handle spatial weighting. Some solutions found max pooling or concat(avg, max) worked equally well - test ablations.

**How to reason about it:**
Implementation: Replace nn.AdaptiveAvgPool2d with GeM module. Initialize p=3.0 and make it a learnable parameter. The gradient flows through p during training, adapting the pooling behavior. p>3 emphasizes strong activations (closer to max pooling), p≈1 behaves like average pooling. Architectural placement: Apply GeM just before the final classification layer, after the last convolutional feature map. Monitor learned p value: if p stays near 1.0, GeM isn't helping; if p>3, model is focusing on sparse features.

```python
# GeM Pooling
class GeM(nn.Module):
    def __init__(self, p=3, eps=1e-6):
        super().__init__()
        self.p = nn.Parameter(torch.ones(1) * p)  # Learnable
        self.eps = eps
    
    def forward(self, x):
        # x: [batch, channels, height, width]
        return F.avg_pool2d(
            x.clamp(min=self.eps).pow(self.p), 
            (x.size(-2), x.size(-1))
        ).pow(1.0 / self.p)

# Replace in model
model = timm.create_model('efficientnet_b4', pretrained=True)
model.global_pool = GeM(p=3.0)  # Replace AvgPool
# During training, p will be learned (often converges to 2.5-4.0)
```
