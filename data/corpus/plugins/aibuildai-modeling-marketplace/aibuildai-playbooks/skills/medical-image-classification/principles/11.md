## Principle 11: Apply Pseudo-Labeling in Stage 3 with Soft Labels and Head-Only Fine-Tuning

*Consensus: 12+ top solutions used pseudo-labeling effectively*

After training strong models on competition data, generate soft pseudo-labels for test set using ensemble predictions. Combine test data with training data and fine-tune, typically freezing backbone and training head only.

**Why this matters:** Test set adds semi-supervised signal when training data is limited. Soft labels (continuous probabilities) preserve model uncertainty, avoiding overconfidence from hard pseudo-labels. Head-only fine-tuning prevents catastrophic forgetting of base features while adapting to test distribution.

**When to use:** When test set is accessible during training (not fully held-out). When training set is small relative to test set. When base models are already strong so pseudo-labels are reliable. After stage 1 (pretrain) and stage 2 (fine-tune) are complete.

**When NOT to use:** When base model is weak - bad pseudo-labels hurt. When test set is tiny compared to train. When severe train/test distribution shift means pseudo-labels are unreliable. When competition rules prohibit using test data (some do). Some found no benefit or even degradation - validate carefully.

**How to reason about it:**
Generate pseudo-labels: Use ensemble of 5-10 diverse models for robustness, not single model. Take soft labels (probabilities) not argmax. For imbalanced tasks, keep the class balance of the combined set close to the training set. Alternatives to one offline round: repeat pseudo-labeling with a retrained ensemble, or add confident test samples progressively during training. Combine datasets: Concatenate train and pseudo-labeled test. Use soft cross-entropy loss to handle continuous labels. Fine-tuning strategy: Freeze backbone, train only classification head with very low LR (1/100 of original) for 3-5 epochs. Or use full model with extremely low LR. Monitor: Track CV on original train data to detect overfitting to test distribution.

```python
# Pseudo-labeling with an ensemble
# Stage 1: Generate soft pseudo-labels with ensemble
test_pseudo_labels = []
for model in ensemble_models:  # 5-10 models
    test_pseudo_labels.append(model.predict_proba(test_data))
pseudo_proba = np.mean(test_pseudo_labels, axis=0)  # Soft labels

# Keep soft labels; do not argmax
test_df['pseudo_label'] = pseudo_proba
combined = pd.concat([train_df, test_df])  # Check class balance against train_df

# Stage 2: Fine-tune head only
for param in model.backbone.parameters():
    param.requires_grad = False

for epoch in range(3):  # Short fine-tune
    for imgs, labels in combined_loader:  # Train + test
        preds = model(imgs)
        # Soft CE loss for continuous labels
        loss = soft_cross_entropy(preds, labels.float())  
        loss.backward()
        optimizer.step()  # LR = 1e-5, very low
```
