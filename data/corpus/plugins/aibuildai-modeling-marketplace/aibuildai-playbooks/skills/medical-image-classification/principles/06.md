## Principle 6: Apply Multi-Stage Training: External Pretraining Then Competition Fine-Tuning

*Consensus: External or prior-release data was common in protein atlas (HPA), skin-lesion (ISIC 2024), and ovarian cancer (UBC-OCEAN) writeups; reported gains ranged from large to none*

Stage 1: Pretrain on large external datasets (previous competitions, public medical databases). Stage 2: Fine-tune on competition data. Optional Stage 3: Add pseudo-labels from test set and fine-tune again.

**Why this matters:** Medical datasets are small due to annotation cost. External data from similar tasks (same anatomy, similar pathology) provides better initialization than ImageNet. Multi-stage training prevents overfitting to the small competition set while learning domain-specific features.

**When to use:** When competition training set is <10k images. When public external datasets exist for the same or related task (earlier releases of the same challenge, public protein-atlas image collections, public slide archives). When you observe poor generalization or quick overfitting.

**When NOT to use:** When external data is from different domains (don't use radiographs to pretrain for microscopy). When competition data is already large (>50k varied samples). When external data has severe label noise or distribution mismatch that hurts more than helps. Test this with ablations.

**How to reason about it:**
Identify external data: Look for previous competitions on same anatomy/task, public repositories, related datasets. Stage 1 pretraining: Train for 15-30 epochs on external data, validate on a held-out set or the competition data. No need to train to convergence. Stage 2 fine-tuning: Load pretrained weights, train on competition data with lower learning rate (1/10 of stage 1), fewer epochs (3-5) to prevent overfitting. Monitor both external-val and competition-val. Stage 3 (optional): If test set is available, pseudo-label it with ensemble, add to training with soft labels, fine-tune head only or with very low LR.

```python
# Stage 1: Pretrain on external or prior-release data
model = timm.create_model(backbone_name, pretrained=True)
for epoch in range(15):  # Don't overtrain
    train_epoch(model, external_data, lr=1e-3)
    val_score = validate(model, comp_data_val)
    # Pick checkpoint with best comp_data val, not external val

# Stage 2: Fine-tune on competition data  
model.load_state_dict(best_pretrain_checkpoint)
for epoch in range(4):  # Short fine-tune
    train_epoch(model, comp_data, lr=1e-4)  # Lower LR

# Stage 3: Pseudo-labeling (optional)
pseudo_labels = ensemble.predict(test_data)  # Soft labels
combined = concat(comp_data, test_data_with_pseudo_labels)
for epoch in range(3):  # Fine-tune head only
    train_epoch(model.head, combined, lr=5e-5)
```
