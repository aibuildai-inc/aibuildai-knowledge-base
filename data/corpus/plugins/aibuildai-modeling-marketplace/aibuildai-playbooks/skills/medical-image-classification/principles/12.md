## Principle 12: Ensemble Predictions with Rank Normalization Before Averaging

*Consensus: 4 solutions explicitly used rank-based ensembling, including the 1st place skin-lesion (ISIC 2024) solution*

Before averaging predictions from multiple models/folds, convert each prediction set to percentile ranks. This ensures predictions are uniformly distributed and prevents models with different score distributions from dominating the ensemble.

**Why this matters:** Different models produce different score distributions (one model outputs 0.1-0.9, another 0.4-0.6). Naive averaging gives more weight to models with wider ranges. Rank normalization equalizes contribution by mapping all predictions to uniform [0,1] distribution, improving ensemble calibration.

**When to use:** When ensembling diverse models (different architectures, training strategies). When you observe uneven contribution in ensembles (some models dominate). When ensembling folds from the same model architecture (fold predictions can have different distributions). As a default practice for any ensemble.

**When NOT to use:** When ensembling very similar models where score distributions are already aligned. When you have a principled weighting scheme (e.g., weighted by validation score). Rank normalization loses absolute calibration - predictions are no longer true probabilities.

**How to reason about it:**
For each model/fold prediction set, compute percentile rank: for each prediction, calculate what fraction of predictions in that set are ≤ this value. This maps predictions to [0, 1] uniform distribution. Average the rank-normalized predictions across models. Final threshold: Optimize on validation set since ranks don't preserve original probability semantics. Pandas implementation: df['pred_rank'] = df['pred'].rank(pct=True).

```python
# Rank normalization before ensemble
import pandas as pd

# Collect predictions from multiple models/folds
predictions = []  # List of arrays, each [n_samples]
for model in models:
    preds = model.predict(test_data)
    predictions.append(preds)

# Rank normalize each prediction set
rank_normalized = []
for preds in predictions:
    df = pd.DataFrame({'pred': preds})
    df['pred_rank'] = df['pred'].rank(pct=True)  # Percentile rank
    rank_normalized.append(df['pred_rank'].values)

# Average rank-normalized predictions
ensemble_pred = np.mean(rank_normalized, axis=0)

# Note: ensemble_pred is now uniformly distributed [0, 1]
```
