## Principle 7: Handle Extreme Class Imbalance with Upsampling and Multi-Class Reformulation

*Consensus: Several solutions oversampled positive or rare-class examples; 6 skin-lesion (ISIC 2024) solutions added finer diagnosis classes or diagnosis-based auxiliary targets to the binary target.*

For rare diseases, upsample the minority class during training so that most batches contain positives. Consider reformulating binary problems as multi-class using auxiliary diagnoses to improve feature learning.

**Why this matters:** With a very low positive rate, random sampling gives many batches with zero positives, destabilizing training, and models can degenerate to predicting all negative. Upsampling fixes batch composition. A multi-class formulation helps the model learn finer-grained features (for example melanoma vs basal cell carcinoma vs nevus) rather than a coarse binary distinction, improving the representation.

**When to use:** When positive class is rare and absolute counts are small. When training becomes unstable (loss oscillates, poor convergence). When auxiliary diagnostic information exists (subtype labels, differential diagnoses) that can enrich the task. When you have enough data in the auxiliary classes.

**When NOT to use:** When classes are already balanced. When upsampling becomes so extreme that the model memorizes the repeated positives; heavy augmentation reduces this risk. When auxiliary classes are too fine-grained or noisy. Focal loss, class-weighted loss, and weighted samplers are alternatives, and some strong solutions used no resampling at all.

**How to reason about it:**
Determine upsampling ratio: target at least one positive per batch on average. If batch_size=32 and positive_rate=0.01, you need about 3x upsampling to get one positive per batch. Very high ratios make the model see the same positives too often, so check the prediction distribution on validation after each change. Multi-class reformulation: use auxiliary diagnoses if available. Map the binary task (malignant/benign) to multi-class (malignant-subtype-A, malignant-subtype-B, benign). Train with cross-entropy on all classes, optionally together with the binary loss. At inference, sum the probabilities of the malignant subtypes to get the binary prediction.

```python
# Upsampling strategy for a rare-positive classification task
import math

class UpsampledDataset(Dataset):
    def __init__(self, df, batch_size, target_pos_per_batch=1):
        pos = df[df['target'] == 1]
        neg = df[df['target'] == 0]
        pos_rate = len(pos) / len(df)
        ratio = max(1, math.ceil(target_pos_per_batch / (batch_size * pos_rate)))
        self.df = pd.concat([pd.concat([pos] * ratio), neg]).sample(frac=1)
```
