## Principle 3: Apply Tile-Based Multiple Instance Learning for Gigapixel Histopathology

*Consensus: 15/15 top solutions in PANDA, UBC-OCEAN used tiling; 10+ used attention/MIL*

Gigapixel whole-slide images (WSI) in histopathology cannot fit in memory. Extract diagnostic tiles (192-256px), train models on tiles, then aggregate tile predictions with attention mechanisms (CLAM) or max-pooling to produce slide-level predictions.

**Why this matters:** A single WSI can be 100,000x100,000 pixels. Only a small fraction contains diagnostic tissue. Naive downsampling loses critical cellular-level detail. Tile-based MIL allows models to focus on informative regions while handling the massive scale.

**When to use:** For whole-slide microscopy images in histopathology or cellular imaging where resolution exceeds GPU memory. When slide-level labels exist but tile-level labels are unavailable (weak supervision scenario).

**When NOT to use:** For already-cropped tissue microarrays (TMA) or cellular images that fit in memory. When you have tile-level annotations and can train a standard supervised classifier. For non-microscopy modalities.

**How to reason about it:**
1) Extract tissue tiles: Use thumbnail to locate tissue (Otsu thresholding on saturation channel), crop tiles at diagnostic magnification (typically 20x), filter background tiles. 2) Feature extraction: Use pretrained feature extractors (ResNet, EfficientNet, or domain-specific like Lunit-DINO for histopathology) to convert each tile to embedding. Run this offline to save compute. 3) Aggregation: Train attention-based MIL (CLAM) that learns which tiles are diagnostic, or use simpler max/mean pooling. 4) Handle class heterogeneity: For 'Other' class in multi-class problems, relax instance-level loss since a slide with cancer can contain healthy tiles.

# Tile extraction (PANDA 1st place)
def extract_tiles(slide_path, tile_size=256, n_tiles=64):
    slide = openslide.OpenSlide(slide_path)
    # Use thumbnail to find tissue regions
    thumb = slide.get_thumbnail((2000, 2000))
    tissue_mask = get_tissue_mask(thumb)  # Otsu on saturation
    # Sample tiles from tissue regions
    tiles = sample_tiles_from_mask(slide, tissue_mask, tile_size, n_tiles)
    return tiles

# CLAM attention aggregation (UBC-OCEAN 3rd place)
class CLAM(nn.Module):
    def __init__(self, feat_dim=1024, hidden=512):
        super().__init__()
        self.attention = nn.Sequential(
            nn.Linear(feat_dim, hidden), nn.Tanh(),
            nn.Linear(hidden, 1)
        )
        self.classifier = nn.Linear(feat_dim, n_classes)
    
    def forward(self, tile_features):  # [n_tiles, feat_dim]
        A = self.attention(tile_features)  # [n_tiles, 1]
        A = F.softmax(A, dim=0)
        slide_feature = (A * tile_features).sum(dim=0)  # Weighted sum
        return self.classifier(slide_feature)
