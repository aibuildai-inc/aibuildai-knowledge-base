## Principle 8: Filter Noisy Labels with Train-Predict-Remove-Retrain

*Consensus: PANDA 1st place (noisy label filtering was key breakthrough); 2+ other competitions used variants*

Medical labels have inter-rater disagreement. Train initial models, predict on training set, identify samples where prediction and label disagree strongly, remove them, retrain. This denoiseing improves both CV and LB.

**Why this matters:** Pathology grading has known subjectivity (PANDA had ~20% label noise). Models trained on noisy labels learn wrong patterns. Filtering removes mislabeled or ambiguous samples, letting model learn cleaner signal. The 1st place PANDA solution gained 0.01+ from this alone.

**When to use:** When labels come from single-rater annotations or competitions mention label quality issues. When training performance is good but validation plateaus. When you observe systematic prediction-label disagreements on certain samples. Histopathology and grading tasks are particularly prone to label noise.

**When NOT to use:** When labels are gold-standard (e.g., genetic tests, multi-expert consensus). When dataset is already small (<1k) - removing samples may hurt more than help. When disagreement could be model failure rather than label noise. Always validate that removed samples are actually ambiguous by manual inspection.

**How to reason about it:**
Stage 1: Train k-fold models on full noisy data (use simple strong baseline like EfficientNet-B0). Predict on held-out folds to get clean out-of-fold predictions. Calculate disparity: |predicted_grade - true_label|. Analyze disparity distribution: high disparity samples are candidates for removal. Set threshold: Conservative is 1.5-2.0 grade difference for ordinal problems. Remove samples above threshold. Optionally use different thresholds per class or data provider if noise varies. Stage 2: Retrain on cleaned data. Compare CV/LB before and after to validate improvement.

```python
# Noisy label filtering (PANDA 1st place)
# Stage 1: Get OOF predictions
for fold in range(5):
    model = train_model(df_train[df_train.fold != fold])
    df_train.loc[df_train.fold == fold, 'pred'] = model.predict(
        df_train[df_train.fold == fold]
    )

# Identify noisy labels
disparity = np.abs(df_train['isup_grade'] - df_train['pred'])
thresh = 1.6  # Tune this
df_clean = df_train[disparity <= thresh]
df_removed = df_train[disparity > thresh]

print(f'Removed {len(df_removed)}/{len(df_train)} samples')
# Manually inspect df_removed to confirm they're ambiguous

# Stage 2: Retrain on cleaned data
model = train_model(df_clean)  # Often improves CV by 0.01-0.02
```
