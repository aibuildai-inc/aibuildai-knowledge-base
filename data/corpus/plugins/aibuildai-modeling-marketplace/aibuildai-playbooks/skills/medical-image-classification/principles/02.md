## Principle 2: Handle Sequential 3D Medical Data with Hybrid 2D+RNN Models

*Consensus: 3/3 top RSNA CT competitions used this; 1st and 2nd place intracranial hemorrhage both used LSTM on 2D embeddings*

For volumetric medical scans (CT, MRI series), extract embeddings from each 2D slice using a CNN, then model spatial relationships across slices with an RNN/LSTM. This outperforms pure 3D CNNs and pure 2D approaches.

**Why this matters:** Pure 2D models ignore anatomical context between slices. Pure 3D CNNs are parameter-heavy and hard to train with limited medical data. The hybrid approach uses pretrained 2D backbones for feature extraction while learning slice-to-slice pathology progression patterns (e.g., hemorrhage spreading across adjacent slices).

**When to use:** When input is a sequence of 2D slices forming a 3D volume (CT, MRI series). Particularly effective when pathology exhibits spatial continuity (lesions spanning multiple slices) or when slice position matters diagnostically.

**When NOT to use:** For single-slice 2D images (X-rays, fundus photos, skin photographs). For histopathology where 'slices' are independent tiles from the same slide. For very short sequences (<5 slices) where context is minimal. When 3D CNNs are proven to work and you have sufficient 3D training data.

**How to reason about it:**
Stage 1: Train 2D CNN on individual slices with data augmentation (ShiftScaleRotate, HFlip). Extract pre-logit embeddings (before final classification layer) at inference. Stage 2: For each patient scan, sequence slices by anatomical position metadata. Feed embedding sequence into LSTM with delta features (current - previous, current - next embeddings) to capture changes. Add positional encoding if helpful. Train LSTM for fewer epochs to avoid overfitting. Pad variable-length sequences with zero embeddings and mask them in loss calculation.

```python
# Stage 1: Extract 2D embeddings
model_2d = ResNext101(pretrained=True)
model_2d.fc = nn.Identity()  # Remove classification head
embeddings = model_2d(slice_batch)  # Shape: [batch, 2048]

# Stage 2: LSTM on sequence
class SequenceModel(nn.Module):
    def __init__(self, embed_dim=2048, lstm_hidden=256):
        super().__init__()
        self.lstm = nn.LSTM(embed_dim*3, lstm_hidden, bidirectional=True)
        # embed_dim*3: current + delta_prev + delta_next
        self.fc = nn.Linear(lstm_hidden*2, num_classes)
    
    def forward(self, embeddings):  # [seq_len, embed_dim]
        # Compute deltas
        delta_prev = embeddings - torch.roll(embeddings, 1, dims=0) 
        delta_next = embeddings - torch.roll(embeddings, -1, dims=0)
        lstm_in = torch.cat([embeddings, delta_prev, delta_next], dim=1)
        out, _ = self.lstm(lstm_in.unsqueeze(1))
        return self.fc(out[-1])  # Use last hidden state
```
