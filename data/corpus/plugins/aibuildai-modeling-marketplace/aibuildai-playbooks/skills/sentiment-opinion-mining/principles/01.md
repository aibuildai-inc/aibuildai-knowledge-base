## Principle 1: Trust Your Cross-Validation Over Public Leaderboard

*Consensus: 14/15 Jigsaw solutions explicitly mentioned this principle*

When the public leaderboard represents a small fraction of test data (e.g., 5%) or shows poor correlation with validation scores, optimize exclusively for local cross-validation performance rather than chasing public leaderboard scores.

**Why this matters:** Small or non-representative public splits create noise that misleads optimization. Public LB variance from sampling can dwarf real performance differences. Teams that chased public scores often experienced severe shake-ups (0.89 public → 0.81 private), while those who trusted CV maintained consistent rankings.

**When to use:** When (1) public LB is explicitly stated to be <10% of test data, (2) you observe low correlation between CV improvements and LB changes (±0.001 CV → ±0.05 LB), or (3) competition organizers provide a separate validation set intended for local evaluation.

**When NOT to use:** When public LB is representative (>30% of data) and stable, or when your CV strategy has known issues (data leaks, distribution mismatch). If CV and LB both point in the same direction, use both signals.

**How to reason about it:**
At the start: establish baseline correlation between CV and public LB across 3-5 submissions. If Spearman correlation < 0.5 or if small CV changes (0.001) produce large LB swings (0.03+), the LB is noisy. From that point: (1) set a CV target (e.g., 0.70+), (2) track only CV for optimization decisions, (3) submit only when CV improves, (4) use LB solely as a sanity check for catastrophic failures (e.g., LB < 0.5 suggests a bug).

```python
# Track CV-LB correlation
import numpy as np
from scipy.stats import spearmanr

cv_scores = [0.701, 0.703, 0.705, 0.702]
lb_scores = [0.78, 0.75, 0.81, 0.76]
corr, p_value = spearmanr(cv_scores, lb_scores)

if corr < 0.5:
    print(f"Low correlation {corr:.2f} - trust CV only")
    optimization_target = 'cv_score'
else:
    optimization_target = 'weighted_cv_lb'
```
