## Principle 14: Monitor and Mitigate Overfitting with Multiple Techniques

*Consensus: The 2nd-place jigsaw-toxic-severity-rating solution warned that the public leaderboard could mislead teams into overfitting, and relied on weight decay, dropout, and early stopping*

Sentiment/opinion tasks are prone to overfitting due to high-dimensional sparse signals and noisy multi-annotator labels. Apply multiple regularization techniques: weight decay (1e-4 to 1e-2), dropout (0.1-0.3) in the head, early stopping based on validation loss, and avoid training beyond 1-3 epochs on small datasets.

**Why this matters:** Annotator disagreement creates label noise; models can memorize noise rather than learn robust patterns. High-dimensional text (50k TF-IDF features, 768-dim BERT embeddings) enables overfitting. Teams that ignored regularization saw large CV-LB gaps. Teams that regularized maintained consistent performance.

**When to use:** Always for sentiment/opinion tasks with multi-annotator labels. Increase regularization strength if you observe (1) training loss << validation loss, (2) CV improving but LB degrading, or (3) model performance degrades after 1-2 epochs.

**When NOT to use:** When you have extremely large datasets (500k+ samples) and single-annotator labels — noise averages out. When validation curves show underfitting (both train and val loss decreasing together) — reduce regularization instead.

**How to reason about it:**
Diagnosis: plot train vs validation loss/metric curves. Overfitting signature: train continues improving while val plateaus or degrades. Remedies in order of impact: (1) Early stopping: save best val checkpoint, stop if val doesn't improve for N evals. (2) Weight decay: start with 0.01, increase to 0.1 if still overfitting. (3) Dropout: add 0.1-0.2 dropout before final layer. (4) Reduce epochs: many solutions converged in 1-2 epochs. If all fail, you may have data leakage.

```python
# Multi-technique regularization
from transformers import TrainingArguments

training_args = TrainingArguments(
    # Early stopping
    load_best_model_at_end=True,
    metric_for_best_model='eval_loss',
    early_stopping_patience=3,
    
    # Weight decay
    weight_decay=0.01,
    
    # Fewer epochs
    num_train_epochs=2,
)

# Dropout in model head
class RobertaForRegression(nn.Module):
    def __init__(self, pretrained_model):
        super().__init__()
        self.roberta = pretrained_model
        self.dropout = nn.Dropout(0.2)
        self.regressor = nn.Linear(768, 1)
    
    def forward(self, input_ids, attention_mask):
        out = self.roberta(input_ids, attention_mask).pooler_output
        out = self.dropout(out)
        return self.regressor(out)
```
