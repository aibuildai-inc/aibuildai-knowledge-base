## Principle 7: Optimize Ensemble Weights on Validation Data with Diversity Awareness

*Consensus: 10/15 solutions used automated weight optimization (Optuna, scipy.optimize, genetic algorithms)*

Ensemble multiple models by optimizing weights on the validation set to maximize the target metric. Normalize predictions (MinMaxScaler, StandardScaler, or rank transformation) before weighting because different models produce different score scales. Prefer diverse models (different architectures, datasets, or preprocessing) over highly correlated ones.

**Why this matters:** Simple averaging assumes all models contribute equally, but some generalize better. Optimized weights can increase CV by 0.01-0.02 (0.70 → 0.72). Normalization prevents models with larger numeric ranges from dominating. Diversity ensures the ensemble captures complementary errors rather than redundant signals.

**When to use:** When you have 3+ models with different strengths (different CV scores, different correlation patterns). Always normalize if models were trained with different loss functions or on different datasets.

**When NOT to use:** When models are highly correlated (>0.95 Pearson) — just use the single best model. When validation set is tiny (<100 samples), weight optimization may overfit; use equal weights or simple averaging instead.

**How to reason about it:**
Normalization choice: compute predictions on validation. If score ranges differ by >2× (e.g., [0,1] vs [0,5]), apply MinMaxScaler or StandardScaler. If models use incompatible scales (probabilities vs logits), use rank transformation (scipy.stats.rankdata). Weight optimization: use Optuna with 500-1000 trials, optimizing the exact competition metric on validation folds. Diversity check: compute pairwise Pearson correlation; if a candidate model has >0.98 correlation with an ensemble member, skip it.
