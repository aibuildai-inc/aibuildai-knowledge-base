## Principle 2: Match Text Preprocessing to Model Architecture

*Consensus: 3/3 solutions that compared cleaning strategies, with 2nd place showing 0.81363 without cleaning vs 0.80826 with cleaning*

Transformer models (BERT, RoBERTa, DeBERTa) often perform worse with aggressive text cleaning because they were pre-trained on raw, uncleaned corpora. Linear models (Ridge, SVM) benefit from cleaning to reduce feature dimensionality and noise.

**Why this matters:** Pre-trained transformers learned representations from text with typos, slang, and formatting intact. Cleaning removes distributional patterns the model relies on. Linear models lack this prior knowledge and need dimensionality reduction to avoid overfitting on noisy character patterns.

**When to use:** Clean text (lowercase, remove punctuation, stem) when using TF-IDF + Ridge/SVM/LightGBM. Use minimal or no cleaning (only basic tokenization) for transformer fine-tuning.

**When NOT to use:** Skip cleaning for transformers unless you observe clear CV improvement (rare). Skip cleaning for linear models only if you have massive training data (100k+ samples) where noise averages out.

**How to reason about it:**
Decision tree: What is your base model? → Transformer: start with raw text, only add cleaning if CV improves. → Linear: apply standard NLP cleaning (lowercase, punctuation removal, stopword removal for TF-IDF). Within transformers: if the pre-training domain matches your task domain (e.g., toxic-bert on toxicity), trust the original preprocessing. If domain-shifted, experiment with light cleaning.

```python
# Conditional preprocessing
def preprocess_text(text, model_type):
    if model_type == 'transformer':
        # Minimal: just tokenization, preserve case and punctuation
        return text.strip()
    elif model_type == 'linear':
        # Aggressive: clean for dimensionality reduction
        text = text.lower()
        text = re.sub(r'[^\w\s]', '', text)  # remove punctuation
        text = ' '.join([word for word in text.split() if word not in stopwords])
        return text
```
