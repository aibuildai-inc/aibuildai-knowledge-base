## Principle 8: Use Pre-Trained Toxicity Models as Feature Extractors

*Consensus: 5/15 solutions used Detoxify or similar pre-trained models, with 3rd place using 11 Detoxify features + 1 TF-IDF*

Leverage models pre-trained on related tasks (e.g., Detoxify for toxicity, unbiased-toxic-roberta) as feature extractors. Extract their predictions (toxicity, severe_toxicity, obscene, threat, insult, identity_attack) and use these as input features to a meta-model (Ridge, LightGBM, or another transformer).

**Why this matters:** Pre-trained models encode domain-specific knowledge that took millions of training samples to learn. Using their predictions as features gives your model a strong prior. The 11th place solution (Ridge + Detoxify + LightGBM) achieved 0.81 private LB with this simple approach, outperforming many end-to-end transformer solutions.

**When to use:** When strong pre-trained models exist for your domain (toxicity, sentiment, hate speech). Especially effective when you lack compute to fine-tune large transformers, or when you want a fast, simple baseline.

**When NOT to use:** When the pre-trained model was trained on your exact test set (data leakage). When the pre-trained model's definition of the target differs fundamentally from yours (e.g., using a formality classifier for toxicity detection).

**How to reason about it:**
Model selection: identify models trained on the most similar task and data (e.g., Detoxify's 'unbiased' variant for general toxicity, 'original' for Wikipedia-style toxicity). Feature extraction: run the model on your data to get predictions for all available labels (don't just use the primary 'toxicity' score). Meta-model: use a simple linear model (Ridge) if features are already high-quality, or LightGBM if you need to learn non-linear combinations and have additional hand-crafted features.

```python
# Extract Detoxify features
from detoxify import Detoxify

models = {
    'original': Detoxify('original'),
    'unbiased': Detoxify('unbiased'),
    'multilingual': Detoxify('multilingual')
}

features = []
for text in texts:
    row = {}
    for name, model in models.items():
        preds = model.predict(text)
        for label, score in preds.items():
            row[f'{name}_{label}'] = score
    features.append(row)

X = pd.DataFrame(features)  # 3 models × ~6 labels = ~18 features
```
