## Principle 5: Apply Multi-Stage Fine-Tuning from General to Specific

*Consensus: 4/15 top solutions explicitly used multi-stage fine-tuning, with 14th place detailing a 5-stage pipeline*

Fine-tune transformers in stages: start with large, lower-quality datasets (OffensEval, Jigsaw 2), progress to smaller, higher-quality datasets (Jigsaw 1, Ruddit), and optionally finish on validation data folds. Each stage initializes from the previous stage's best checkpoint.

**Why this matters:** Large datasets provide broad coverage but noisy labels; small datasets have precise labels but limited coverage. Sequential fine-tuning lets the model first learn general patterns, then refine to task-specific nuances. The 14th place solution improved from 0.68 (OffensEval only) → 0.71+ (5-stage) on the same base model.

**When to use:** When you have 3+ datasets of varying size and quality, and each individually improves over the base pre-trained model. Most effective with transformers that benefit from continual adaptation.

**When NOT to use:** When datasets are similar in size and quality (just pool them). When you lack compute for multiple training runs. When later-stage datasets are too small (<500 samples) to avoid overfitting during fine-tuning.

**How to reason about it:**
Staging order: (1) Rank datasets by validation score when trained individually. (2) Start with the lowest-scoring (typically largest, noisiest). (3) Progress to higher-scoring (smaller, cleaner). (4) Use the validation set last, if at all (risk of overfitting). Hyperparameters: decrease learning rate each stage (1e-5 → 1e-6 → 5e-7). Train fewer epochs as datasets get smaller (5 epochs → 3 → 1). Always validate on the final target distribution.

```python
# Multi-stage fine-tuning
stages = [
    {'data': 'offenseval', 'lr': 1e-5, 'epochs': 5},
    {'data': 'jigsaw_2019', 'lr': 1e-5, 'epochs': 3},
    {'data': 'jigsaw_2018', 'lr': 1e-6, 'epochs': 3},
    {'data': 'ruddit', 'lr': 1e-6, 'epochs': 2},
]

model = load_pretrained('roberta-base')
for stage in stages:
    train_data = load_dataset(stage['data'])
    model = fine_tune(model, train_data, lr=stage['lr'], epochs=stage['epochs'])
    cv = evaluate_on_validation(model)
    print(f"Stage {stage['data']}: CV {cv:.4f}")
    save_checkpoint(model, f"stage_{stage['data']}.pt")
```
