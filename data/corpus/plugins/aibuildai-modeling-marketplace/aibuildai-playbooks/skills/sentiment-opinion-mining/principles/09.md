## Principle 9: Train Linear Models with TF-IDF for Fast, Interpretable Baselines

*Consensus: 8/15 solutions included TF-IDF+Ridge models, with multiple teams reporting 0.68-0.70 CV as baselines*

Build a TF-IDF (or TF-IDF+SVD) feature extractor and train Ridge regression or LightGBM. Add basic text features (length, uppercase ratio, punctuation density, bad word count). Use this as a strong, fast baseline and as one component in a diverse ensemble.

**Why this matters:** TF-IDF captures n-gram patterns that transformers sometimes miss (especially rare, highly predictive phrases). Ridge is 100× faster to train than transformers, enabling rapid iteration. Many top solutions found TF-IDF models contributed meaningfully to ensembles despite lower individual CV, because they capture different signals.

**When to use:** Always, as a baseline. Include in final ensemble if it's not highly correlated (>0.95) with transformer predictions. Especially valuable when you have large vocabularies or domain-specific phrases.

**When NOT to use:** Skip TF-IDF if your text is very short (<10 words) and transformers already achieve near-perfect scores. Skip if your ensemble already has 5+ transformer models and adding TF-IDF decreases ensemble CV.

**How to reason about it:**
Feature engineering: use character n-grams (2-5) and word n-grams (1-3) to capture typos and phrases. Add count features (length, uppercase ratio, bad word count) to provide non-text signals. Hyperparameter search: grid-search over alpha (0.1, 0.5, 1.0, 2.0) for Ridge, max_features (10k, 50k, 100k) for TF-IDF. Model selection: if TF-IDF+Ridge achieves within 0.02 of best transformer CV, include it in ensemble; otherwise use it for error analysis.

# TF-IDF + Ridge with text features
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import Ridge

vectorizer = TfidfVectorizer(
    ngram_range=(1, 3),
    max_features=50000,
    sublinear_tf=True
)
X_tfidf = vectorizer.fit_transform(train_texts)

# Add basic features
X_extra = pd.DataFrame({
    'length': train_texts.str.len(),
    'uppercase_ratio': train_texts.apply(lambda x: sum(c.isupper() for c in x) / max(len(x), 1)),
    'bad_word_count': train_texts.apply(lambda x: sum(w in bad_words for w in x.split()))
})

from scipy.sparse import hstack
X_combined = hstack([X_tfidf, X_extra.values])

model = Ridge(alpha=1.0)
model.fit(X_combined, y_train)
