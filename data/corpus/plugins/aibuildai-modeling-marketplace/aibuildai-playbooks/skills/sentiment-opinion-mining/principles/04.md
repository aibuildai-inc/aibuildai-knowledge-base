## Principle 4: Leverage External Dataset Diversity for Robustness

*Consensus: 15/15 Jigsaw solutions used 2+ external datasets; top-3 used 3-5 datasets each*

Combine training data from multiple related competitions and datasets, each capturing different aspects of the target concept (e.g., Jigsaw 2018 for toxicity labels, Ruddit for severity rankings, OffensEval for multi-platform data). Diversity in annotation guidelines and domains improves generalization.

**Why this matters:** Different datasets capture complementary signals: one dataset's 'toxic' may emphasize profanity, another emphasizes personal attacks, a third emphasizes hate speech. A model trained on diverse definitions learns robust, transferable representations rather than overfitting to one annotation scheme. The 4th place solution explicitly balanced dataset diversity (1/3 weight) with model diversity (2/3 weight).

**When to use:** When (1) multiple related datasets exist (past competitions, academic benchmarks), (2) your task is subjective with ambiguous boundaries (toxicity, sentiment, offensiveness), or (3) test data may come from a different distribution than your primary training set.

**When NOT to use:** When datasets use contradictory definitions (e.g., one labels sarcasm as positive, another as negative) without a clear mapping. When adding a dataset consistently degrades CV (e.g., Measuring Hate Speech hurt most teams), drop it.

**How to reason about it:**
Dataset selection: (1) List candidate datasets by domain overlap with your task. (2) For each, train a single model and measure validation score. (3) Rank by individual CV. (4) Add datasets incrementally, re-measuring CV; stop when CV plateaus or drops. (5) Prioritize datasets with different annotation schemes over larger versions of the same scheme. Weighting: train separate models per dataset, then ensemble (allows the meta-model to learn dataset-specific biases).

```python
# Incremental dataset selection by CV
datasets = ['jigsaw_2018', 'jigsaw_2019', 'ruddit', 'offenseval']
selected = []
best_cv = 0

for ds in datasets:
    candidate = selected + [ds]
    model = train_ensemble(candidate)  # train on combined data
    cv = evaluate_cv(model)
    if cv > best_cv:
        selected.append(ds)
        best_cv = cv
    print(f"Adding {ds}: CV {cv:.4f}")
```
