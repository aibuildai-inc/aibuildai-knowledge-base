## Principle 3: Prevent Data Leakage Between Training and Validation

*Consensus: 7/7 top solutions that used validation_data.csv removed overlapping texts from training*

When competition provides a validation set, rigorously remove all overlapping texts from training datasets before fitting models. For pairwise ranking data, use Union-Find GroupKFold to ensure no text appears in multiple folds.

**Why this matters:** Even a single shared text between train and validation inflates CV scores, leading to overfitting and poor generalization. In pairwise ranking tasks, the same comment can appear in multiple pairs, creating complex dependency graphs that standard KFold misses. Teams that ignored leaks saw 0.72 CV but 0.79 private LB; teams that prevented leaks saw 0.70 CV → 0.81 private.

**When to use:** Always when: (1) you're combining external datasets with competition-provided validation data, (2) your task involves pairwise comparisons where the same item appears multiple times, or (3) data comes from overlapping sources (e.g., Jigsaw 2018 is a subset of Jigsaw 2019).

**When NOT to use:** When all datasets are disjoint by construction (e.g., different time periods, different platforms) and you've verified no text overlap via exact-match hashing.

**How to reason about it:**
Before training: (1) Hash all validation texts (exact match or fuzzy). (2) Scan each training dataset for matches; remove matched rows. (3) For pairwise data: build a graph where nodes are texts and edges connect texts in the same pair; use Union-Find to assign connected components to single folds. (4) Verify: after fold assignment, confirm zero intersection between any fold's texts.

# Remove exact overlaps
val_texts = set(validation_df['text'])

# Union-Find GroupKFold for pairwise data
from sklearn.model_selection import GroupKFold

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    def union(self, x, y):
        self.parent[self.find(x)] = self.find(y)
