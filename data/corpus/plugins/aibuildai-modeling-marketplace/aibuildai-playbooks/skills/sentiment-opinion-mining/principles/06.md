## Principle 6: Choose Loss Function Based on Label Type and Task Goal

*Consensus: 12/15 solutions discussed loss; 8 used MarginRankingLoss for pairwise tasks, 4 used MSE for regression*

For pairwise ranking tasks (A is more toxic than B), use MarginRankingLoss with a margin (0.5 is common). For regression targets (toxicity scores), use MSE or weighted MSE. For multi-class classification with confidence, use cross-entropy on probability distributions.

**Why this matters:** The loss must match the evaluation metric's structure. Ranking metrics (agreement with annotators) reward correct pairwise orderings, not absolute score accuracy, so MarginRankingLoss directly optimizes the target. MSE is appropriate when you need calibrated scores. Mismatch (e.g., MSE for a ranking task) wastes capacity learning irrelevant absolute scale.

**When to use:** MarginRankingLoss when evaluation is pairwise agreement or ranking correlation. MSE when evaluation is RMSE or MAE on scores. Cross-entropy when predicting discrete confidence bins.

**When NOT to use:** Avoid MarginRankingLoss if you lack paired data (you'd need to synthesize pairs, which adds noise). Avoid MSE if your labels are ordinal categories rather than true continuous values (use ordinal regression losses instead).

**How to reason about it:**
Decision: What is the evaluation metric? → Pairwise ranking (e.g., agreement with annotators): MarginRankingLoss. → Score error (RMSE, MAE): MSE or MAE loss. → Multi-class confidence: cross-entropy or KL divergence. Margin tuning for MarginRankingLoss: start with 0.5; if pairs are very clear (obvious more vs less toxic), increase to 1.0; if subtle, decrease to 0.1.

```python
# MarginRankingLoss for pairwise ranking
import torch.nn as nn

loss_fn = nn.MarginRankingLoss(margin=0.5)

# pairs_df has 'less_toxic' and 'more_toxic' columns
for batch in dataloader:
    less_scores = model(batch['less_toxic'])
    more_scores = model(batch['more_toxic'])
    target = torch.ones(len(batch))  # more_toxic should score higher
    loss = loss_fn(more_scores, less_scores, target)

# MSE for regression
loss_fn = nn.MSELoss()
for batch in dataloader:
    pred = model(batch['text'])
    loss = loss_fn(pred, batch['toxicity_score'])
```
