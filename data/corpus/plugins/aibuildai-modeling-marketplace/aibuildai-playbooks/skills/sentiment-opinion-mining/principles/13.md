## Principle 13: Balance Dataset Diversity and Model Diversity in Ensembles

*Consensus: 4th place explicitly weighted dataset diversity 1/3, model diversity 2/3; multiple solutions trained same architecture on different datasets*

When building ensembles, include both (1) different models (RoBERTa, DeBERTa, DistilRoBERTa) on the same dataset and (2) the same model on different datasets (Jigsaw 2018, Ruddit, OffensEval). Dataset diversity is as important as architecture diversity for generalization.

**Why this matters:** Different architectures capture different inductive biases (RoBERTa vs DeBERTa attention mechanisms). Different datasets capture different annotation perspectives (strict vs lenient toxicity thresholds). Combining both provides complementary error patterns. The 4th place solution found 1/3 dataset diversity + 2/3 model diversity optimal.

**When to use:** When you have access to 3+ datasets and 3+ model architectures. When your task has subjective labels (sentiment, toxicity) where different annotators/datasets may emphasize different aspects.

**When NOT to use:** When datasets are near-duplicates (e.g., two versions of the same competition data). When you have severe compute constraints and can only train 3-4 models total — prioritize model diversity first.

**How to reason about it:**
Allocation: for N total models, train ~N/3 on dataset A, ~N/3 on dataset B, ~N/3 on dataset C, ensuring each dataset gets at least 2 different architectures. Correlation check: compute pairwise correlation matrix of all models' validation predictions. Ideal ensemble has max correlation <0.85; if two models have >0.95 correlation, drop the weaker one.
