## Principle 12: Use Ranking Transformation for Ensemble Compatibility

*Consensus: 4/15 solutions explicitly used rank transformation (rankdata) before ensembling*

When ensembling models with incompatible score scales (e.g., one outputs probabilities [0,1], another outputs logits [-5,5]), convert all predictions to ranks via scipy.stats.rankdata before averaging. This preserves relative ordering while normalizing scale.

**Why this matters:** For ranking tasks (toxicity severity, pairwise agreement), only relative ordering matters, not absolute scores. Rank transformation makes models comparable and prevents one model from dominating due to larger numeric range. The 1st place solution used 'weighted rank average' of 15 models; the 9th place used 'rankdata + mean'.

**When to use:** When your evaluation metric is rank-based (Spearman correlation, pairwise agreement) and models were trained with different loss functions or output different score ranges. Essential when mixing classification probabilities with regression outputs.

**When NOT to use:** When your metric requires calibrated probabilities (Brier score, log loss). When all models already output the same scale and you've verified they're comparable (e.g., all are sigmoid outputs from the same architecture).

**How to reason about it:**
Check score ranges: plot histograms of each model's validation predictions. If ranges differ by >2× or distributions are qualitatively different (Gaussian vs bimodal), use rank transformation. Method: apply rankdata to each model's predictions separately, then average ranks, or average first then rank. Experiment: compare both on validation; the 9th place found rankdata-then-mean worked best.

```python
# Rank transformation for ensemble
from scipy.stats import rankdata

# preds shape: (n_samples, n_models)
preds_ranked = np.zeros_like(preds)
for i in range(preds.shape[1]):
    preds_ranked[:, i] = rankdata(preds[:, i])

# Average ranks
ensemble_ranks = preds_ranked.mean(axis=1)

# Or: average scores then rank
ensemble_scores = preds.mean(axis=1)
ensemble_ranks_v2 = rankdata(ensemble_scores)
```
