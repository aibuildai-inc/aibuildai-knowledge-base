Competition: jigsaw-toxic-severity-rating
Rank: #3
Source: https://www.kaggle.com/c/jigsaw-toxic-severity-rating/discussion/306235

Thank you to Jigsaw and Kaggle for hosting a challenging and engaging competition and congratulations to the winners and everyone who enjoied the competition !

I particularly enjoied this competition format because it forces to find a solution that generalizes on unseen data.

## My Solution

For a solution that generalizes on unseen data I tried to use: 
- datasets from previous Jigsaw competitions to extract features
- VAL  data + RUD dataset for ensembling  and parameters tuning

Unfortunately, I could see MHS dataset too late to be able to use it in the competition.

### Feature Extraction
I used the Detoxify pretrained models as feature extractor [*toxicity*, *severe_toxicity*, *identity_attack*...] because [they work very fine on previuos Jigsaw competitions] (https://www.kaggle.com/c/jigsaw-toxic-severity-rating/discussion/303665) ,
I also generated other tf-idf models on JC/JUC dataset  for each specific target [*toxicity*, *severe_toxicity*, *identity_attack* ...] for total of 46 features.

Some models generated by the individual features extracted from the detoxify models work fine on  "unseen data"  VAL e RUD (accuracy > 0.80 on RUD and > 0.69 on VAL) while tf-id are weak models ( < 0.71 on RUD and < 0.66 on VAL)

### How to combine features:

As first attempt I fitted models (Ridge, RF, XGB, LGB) using RUD (with RMSE as metric) and tuning the hyperparameters using VAL: accuracy of these models  varies from 0.700 to 0.707 on VAL. 

In this way, however, I was not sure of the performance of model on unseen data and so I simplified a little more.

I built a simple model by selecting features optimizing ranked mean on VAL : 
This model contains 11 Detoxify features and 1 tf-idf feature [Submission 1](https://www.kaggle.com/steubk/jrsotc-fe-rud-2-linear-rank-sub)

I further eliminated 2 features  which lower the accuracy on RUD to generate another model:  
This model contains only 10 Detoxify features [Submission 2] (https://www.kaggle.com/steubk/jrsotc-fe-rud-2-linear-rank-sub-2)

I preferred to lower a little accuracy on VAL hoping for a better generalization  (and luckily it worked ! )
