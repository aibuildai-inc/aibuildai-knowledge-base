## Overview
I followed weakly semantic segmentation approach. So firstly I trained image level classifier and  prepared CAM, then trained segmentation model with pseudo labels from the CAM. 

## Pipeline
 Image level classification & semantic segmentation & hpa cell segmentator.
[inference piple]

## Image Level Classification
- model: resnest50, resnet50, resnet200d, effb3
- Input size: 512x512 ~ 1280x1280
- Loss: focal loss
- Class Mask: normal CAM and SC-CAM
    + [SC-CAM,  arxiv: 2008.01183](https://arxiv.org/abs/2008.01183)
         Sub-category CAM,  to improve CAM localization this method introduces sub category which is generated by a clustering of CNN feature. This sub category is contributed to differentiate intra-class variation and the area of CAM will be extended as shown below.   This figure is taken from https://github.com/Juliachang/SC-CAM
 [SC-CAM]   

    + SC-CAM improved the score by 0.005~0.02 but it only worked for 512x512.
　+ SC-CAM x Puzzle CAM does not work.
- Best single model: resnest50 768x768,  public 0.445  private 0.441 

## Semantic Segmentation
- model: Unet{resnest50, resnet50, resnext50}
- Input size: 512x512 ~ 768x768
- Label: pseudo label by class mask CAM&SC CAM and instance mask from hpa cell segmentator
- Best single model: resnet50 512x512, public 0.491

## Other Tips
 - Training speed : NGC container x Channel Last for pytorch memory format
     following [the benchmark result at timm](https://gist.github.com/rwightman/bb59f9e245162cee0e38bd66bd8cd77f), my resnet training time reduced by 40% from my initial configuration.  Also effb training reduced by 20 or 30%.
 - TTA
    h/vflip, image scale { x1.2, x1.4} improve the CAM model score by 0.01~0.03
