## Principle 2: Preserve Channel Meaning and Biological Scale

*Consensus: 6/6 competition families explicitly managed channels, resolution, magnification, receptive field, or pixel size.*

Treat fluorescence channels and micrometers-per-pixel as structured metadata, not incidental tensor dimensions. Normalize or rescale images so the same biological structure occupies a comparable model-space size while retaining channel-specific signals.

**Why this matters:** Protein, nucleus, microtubule, ER, and six-channel morphology images contain non-interchangeable signals. In histology, an organelle, vessel, gland, or tumor pattern can disappear if downsampled too aggressively, while inconsistent magnification makes one biological object look like different classes.

**When to use:** Use custom input stems for non-RGB fluorescence, scale-aware resizing when pixel size or magnification varies, and multiresolution features when pathologists use both cellular and tissue architecture. Compare crop size in physical units, not only pixels.

**When NOT to use:** Do not force all samples to one physical scale when scale itself carries target information or when metadata is unreliable. Do not apply independent channel permutations or generic RGB color transforms to channels with fixed biological identities.

**How to reason about it:**
Inspect object diameters in pixels and physical units by source. Select a canonical scale only if it makes target morphology consistent; otherwise expose multiple scales or supply pixel size as an auxiliary input. Verify that the smallest discriminative structure survives preprocessing and that the receptive field covers the largest one.

```python
def rescale_to_physical_size(img, src_um_per_px, target_um_per_px):
    # Customize interpolation: area for downsampling images, nearest for masks.
    scale = src_um_per_px / target_um_per_px
    new_hw = tuple(round(v * scale) for v in img.shape[-2:])
    return torch.nn.functional.interpolate(
        img[None], size=new_hw, mode="bilinear", align_corners=False
    )[0]
```
