## Principle 13: Ensemble Independent Error Sources, Not Redundant Checkpoints

*Consensus: 6/6 families reported ensemble gains, but several also found that excessive TTA or many near-identical models added cost without private-score improvement.*

Build diversity across representation, scale, crop policy, supervision route, or model family, and combine outputs in the space appropriate to the task. Validate every TTA and ensemble member by marginal out-of-fold gain per unit of inference cost.

**Why this matters:** Averaging lowers variance only when errors are not perfectly correlated. Cell-level and image-level models, CNNs and transformers, multiple magnifications, or detectors with different recall profiles often complement one another more than additional seeds of the same pipeline.

**When to use:** Average logits or probabilities for classification, use WBF for complementary detectors, average aligned semantic maps, and fuse cell-local with image-global confidence. Use TTA for genuine symmetries when inversion is exact.

**When NOT to use:** Skip members that do not improve grouped OOF predictions or violate runtime limits. Avoid TTA for instance masks when geometric inversion or matching is unreliable, and avoid ensembling models that share the same domain shortcut.

**How to reason about it:**
Measure pairwise residual or error correlation, not just individual score. Add the model with the best incremental ensemble gain. Keep a Pareto frontier of score versus runtime and favor methodological diversity before seed diversity.

```python
def greedy_ensemble(oof_preds, y, costs, budget):
    chosen, pred, spent = [], None, 0
    while True:
        options = []
        for i, p in enumerate(oof_preds):
            if i in chosen or spent + costs[i] > budget:
                continue
            candidate = p if pred is None else (pred * len(chosen) + p) / (len(chosen) + 1)
            options.append((official_metric(y, candidate), i, candidate))
        if not options:
            break
        score, i, pred = max(options)
        chosen.append(i); spent += costs[i]
    return chosen
```
