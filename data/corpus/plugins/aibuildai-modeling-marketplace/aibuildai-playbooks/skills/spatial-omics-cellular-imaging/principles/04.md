## Principle 4: Make Acquisition Domain a First-Class Modeling Variable

*Consensus: 6/6 families reported meaningful source variation: stain and institution, HPA versus HuBMAP, plate and experiment, cell line, or WSI.*

Diagnose domain variation before optimizing architecture, then choose a mechanism appropriate to its cause: per-image/channel normalization for fluorescence, plate-centered embeddings or adaptive normalization for experiments, and stain transfer or source-aware sampling for histology.

**Why this matters:** Models readily learn acquisition shortcuts because they are often stronger than morphology. A random split can reward those shortcuts, but performance collapses on a new hospital, stain protocol, plate, experiment, or slide.

**When to use:** Use source-aware normalization when nuisance intensity shifts dominate; stain augmentation or bidirectional stain normalization when histology protocols differ; domain-specific branches when image types have genuinely different morphology; and auxiliary source tasks only when they encourage robust shared features rather than shortcutting.

**When NOT to use:** Normalization can erase absolute intensity that carries biological signal. Stain transfer can introduce artifacts, and separate branches can overfit when each domain has little data. If test domains are unknown, broad nuisance augmentation may be safer than mapping everything to one reference.

**How to reason about it:**
Train a simple source classifier on images or embeddings. High source predictability plus weak cross-source transfer indicates a domain problem. Compare within-source and leave-source-out validation, then test whether normalization lowers source predictability without lowering target performance.

```python
def normalize_by_modality(x, modality, stats=None):
    if modality == "fluorescence":
        # Per-image, per-channel normalization; preserve channel identity.
        mu = x.mean((-2, -1), keepdim=True)
        sd = x.std((-2, -1), keepdim=True).clamp_min(1e-6)
        return (x - mu) / sd
    if modality == "histology":
        # Randomly choose original or a validated stain transfer during training.
        return random_stain_transfer(x, references=stats["references"])
    return x
```
