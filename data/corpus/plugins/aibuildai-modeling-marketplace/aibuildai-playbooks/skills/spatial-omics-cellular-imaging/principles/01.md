## Principle 1: Choose the Learning Unit From the Target Geometry

*Consensus: 6/6 competition families; every successful methodology matched the model's unit of reasoning to the submission unit, although the resulting architectures formed several distinct clusters.*

First identify whether the target is attached to a field of view, an individual cell, a semantic region, an object instance, a well, or an entire slide. Choose the architecture around that unit rather than treating all cellular images as ordinary image classification.

**Why this matters:** A mismatch creates an information bottleneck. Global pooling cannot reliably assign weak image labels to individual cells, a patch classifier cannot enforce instance separation, and resizing a whole slide to one tensor removes the morphology needed for diagnosis.

**When to use:** Always. Observable branches include: image-level multilabel fluorescence → multilabel classifier; weak image labels with cell outputs → cell segmentation plus CAM/MIL/dual-head learning; perturbation labels → multi-channel well encoder plus experimental constraints; semantic tissue masks → encoder-decoder; instance masks → detector with mask supervision; WSI diagnosis → tissue tiles plus MIL or learned top-k selection.

**When NOT to use:** Do not introduce hierarchy merely because images are biological. If inputs and targets are already aligned, such as one manageable image with one strong label or one tile with a dense mask, a direct model can be more accurate and much simpler.

**How to reason about it:**
Ask in order: (1) What entity receives one ground-truth label? (2) What entity is scored? (3) Is supervision available at that resolution? (4) If not, what aggregation relation connects labeled bags to unlabeled instances? (5) Does the metric require semantic area, separated instances, calibrated class scores, or only a final class?

```python
def choose_pipeline(target, supervision):
    if target == "slide":
        return "tissue_filter -> tiles -> pretrained_features -> MIL"
    if target == "cell" and supervision == "image_level":
        return "cell_masks -> CAM_or_dual_head_MIL -> cell_scores"
    if target == "instance_mask":
        return "detector + mask_head"
    if target == "semantic_mask":
        return "encoder_decoder"
    return "direct_image_classifier"
```
