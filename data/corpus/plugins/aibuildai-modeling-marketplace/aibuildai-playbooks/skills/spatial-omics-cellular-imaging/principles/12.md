## Principle 12: Decode Predictions With the Metric and Data Constraints in Mind

*Consensus: 6/6 families used consequential post-processing: per-class or per-organ thresholds, structured assignment, confidence refinement, border penalties, size filters, WBF/NMS, outlier rejection, or mask threshold tuning.*

Treat decoding as part of the model. Tune it out-of-fold against the exact competition metric and preserve confidence ranking when AP, rather than a fixed-threshold score, is evaluated.

**Why this matters:** The same probability map can produce very different Dice, macro F1, balanced accuracy, or instance AP. Instance metrics are sensitive to separation and confidence order; macro F1 is sensitive to class thresholds; assignment constraints can correct many independent argmax errors.

**When to use:** Use per-class thresholds for multilabel macro F1, per-organ thresholds for heterogeneous semantic masks, candidate masking plus Hungarian assignment for constrained plates, and object-level score/size/overlap filters for instance AP. Penalize incomplete border objects only if annotation policy omits them.

**When NOT to use:** Avoid post-processing inferred from a tiny public leaderboard or one unstable fold. Dilation, aggressive small-object removal, and hard frequency matching can help one annotation style and catastrophically harm another. If CV disagrees across sources, retain conservative alternatives.

**How to reason about it:**
Implement the official metric locally. Optimize decoding on out-of-fold predictions, then inspect parameter stability across groups. Parameters that vary greatly by WSI or fold indicate annotation/domain shift; choose robust values, condition on legitimate metadata, or reserve diverse final submissions.

```python
def tune_decoder(oof, target, groups, candidates):
    results = []
    for params in candidates:
        fold_scores = []
        for g in groups.unique():
            pred = decode(oof[groups == g], **params)
            fold_scores.append(official_metric(target[groups == g], pred))
        # Reward mean performance but penalize source instability.
        results.append((np.mean(fold_scores) - STABILITY_W * np.std(fold_scores), params))
    return max(results)[1]
```
