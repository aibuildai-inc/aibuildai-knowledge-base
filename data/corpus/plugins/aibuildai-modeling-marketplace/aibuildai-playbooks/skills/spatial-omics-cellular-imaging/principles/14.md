## Principle 14: Design the Submission Pipeline as a Resource-Constrained System

*Consensus: 5/6 families explicitly discussed inference time, memory, image I/O, segmentation speed, or hidden-test robustness; it was especially decisive for WSI and code competitions.*

Profile the complete path from file read to encoded submission, not only neural-network forward time. Stream giant images, cache reusable features, parallelize CPU-safe preprocessing, and make all size assumptions defensive.

**Why this matters:** A theoretically superior model scores zero if it times out, exhausts RAM, corrupts mask coordinates, or cannot handle hidden image dimensions. WSI decoding and mask encoding can dominate runtime, while repeated cell segmentation or TTA can consume the entire budget.

**When to use:** Always for hidden-test notebooks and especially for gigapixel slides, multi-stage cell pipelines, or large ensembles. Use region-based readers such as libvips-style streaming, mixed precision, feature caching, batched tiles, and early background rejection.

**When NOT to use:** Do not optimize away clinically or metrically important resolution before profiling. Parallelism can increase memory and I/O contention, and lossy preprocessing may cost more score than it saves time.

**How to reason about it:**
Create a worst-case budget for file count, dimensions, foreground fraction, tile count, model passes, and serialization. Benchmark the 95th-percentile sample, include startup and encoding, reserve failure margin, and test empty masks, unusual aspect ratios, corrupt files, and both WSI/TMA paths.

```python
budget = {"seconds": MAX_RUNTIME * 0.85, "bytes": MAX_RAM * 0.80}
for sample in samples_sorted_by_expected_cost:
    with open_slide_streaming(sample.path) as slide:
        regions = foreground_regions(slide.thumbnail())
        for batch in batched(regions, TILE_BATCH):
            feats = extractor(read_regions(slide, batch), amp=True)
            aggregator.update(feats)
    writer.append(sample.id, robust_decode_and_encode(aggregator.finalize()))
    assert elapsed() < budget["seconds"]  # fail early during dry runs
```
