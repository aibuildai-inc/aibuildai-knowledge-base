## Principle 13: Use Test-Time Augmentation (TTA) for Robustness

*Consensus: WSDM chatbot arena 1st/2nd/3rd/12th use swap-order TTA, often only on the most uncertain or shortest samples to fit the time limit*

At inference time, create multiple augmented versions of each test sample (swap inputs, vary sequence lengths, flip images), predict on all versions, and average the predictions to reduce variance and improve robustness.

**Why this matters:** Single predictions are noisy. For chatbot preferences, swapping response_a and response_b and averaging predictions corrects for position bias (model favors first response). For other inputs, label-preserving transforms (shifted windows for time series, flips for images) average out noise in the same way. TTA is free performance—no retraining, just more inference time. The WSDM chatbot arena 1st place ran the swapped pass only on the 33% of samples with the most uncertain predictions, and the 12th place found that averaging swapped predictions only for the samples closest to 0.5 improved both efficiency and accuracy compared to TTA on the entire dataset.

**When to use:** When you have inference budget (time, compute) and the task has natural augmentations: (1) text: swap inputs, vary truncation. (2) images: flips, rotations, crops. (3) time series: shift windows. Use for final submissions after models are finalized. Essential in code competitions with loose time limits.

**When NOT to use:** Skip if inference time is tight (TTA requires 2x-10x inference). Don't use augmentations that violate the task (don't flip images if orientation matters, don't swap inputs if order is semantically important). Avoid if CV shows no gain—test on validation first.

**How to reason about it:**
Identify invariances: what transformations should not change the prediction? For chatbot preferences: swapping response_a ↔ response_b should flip probabilities (winner_a ↔ winner_b). For images: horizontal flip should not change class. Generate augmented samples: for each test sample, create K augmented versions. Predict on all K. Average predictions (for regression) or average probabilities (for classification). Check CV: does TTA improve validation score?

```python
import torch

# Text TTA: swap response_a and response_b, average predictions
def predict_with_tta(model, prompt, response_a, response_b):
    # Original order
    input1 = f'{prompt} [SEP] {response_a} [SEP] {response_b}'
    logits1 = model(input1)  # Shape: (2,) for [winner_a, winner_b]
    
    # Swapped order
    input2 = f'{prompt} [SEP] {response_b} [SEP] {response_a}'
    logits2 = model(input2)
    logits2 = logits2[[1, 0]]  # Swap winner_a and winner_b
    
    # Average
    avg_logits = (logits1 + logits2) / 2
    return torch.softmax(avg_logits, dim=0)
```
