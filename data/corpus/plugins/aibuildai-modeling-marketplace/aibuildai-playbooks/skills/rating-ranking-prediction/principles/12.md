## Principle 12: Calibrate Probabilities for Probability-Sensitive Metrics

*Consensus: Some top solutions in logloss competitions (Prudential 1st, Porto Seguro 9th) apply post-hoc calibration*

For competitions scored on logloss or Brier score, ensure predicted probabilities are well-calibrated (predicted 0.7 means 70% actual positive rate). Apply post-hoc calibration (isotonic regression, Platt scaling) to ensemble outputs if reliability plots show miscalibration.

**Why this matters:** Ranking metrics (Gini, AUC) don't care about calibration, but probability metrics (logloss, Brier) penalize overconfidence and underconfidence. A model that predicts [0.9, 0.1] when true probabilities are [0.6, 0.4] gets worse logloss than a calibrated [0.6, 0.4]. Calibration corrects systematic bias in probability estimates without changing rank order. Prudential 1st place: calibrated outputs improved kappa score.

**When to use:** When the metric is logloss, Brier score, or any probability-sensitive metric. After ensembling (calibrate the final blend, not individual models). Check calibration: plot reliability diagram (binned predicted prob vs. actual rate). If bins deviate from diagonal, apply calibration.

**When NOT to use:** Skip if the metric is rank-based (Gini, AUC)—calibration won't change rank order, so it's neutral. Don't calibrate if you're overfitting to validation (calibration is fitted, can overfit). Avoid for very small validation sets (<1000 samples)—isotonic regression needs data.

**How to reason about it:**
Plot reliability diagram: bin predictions into deciles (0-0.1, 0.1-0.2, ..., 0.9-1.0), compute mean predicted prob and actual positive rate per bin. Ideally, points lie on the diagonal (predicted = actual). If predictions are too extreme (sigmoid-shaped curve), apply calibration. Method 1 (Platt scaling): fit logistic regression on validation set: calibrated_prob = sigmoid(a * logit(raw_prob) + b). Method 2 (isotonic regression): fit monotonic step function mapping raw_prob -> calibrated_prob. Use on holdout, not training folds.

```python
from sklearn.calibration import CalibratedClassifierCV, calibration_curve
import matplotlib.pyplot as plt
import numpy as np

# Check calibration: reliability diagram
frac_pos, mean_pred = calibration_curve(y_val, preds_val, n_bins=10)
plt.plot(mean_pred, frac_pos, marker='o', label='Model')
plt.plot([0, 1], [0, 1], 'k--', label='Perfect calibration')
plt.xlabel('Mean predicted probability')
plt.ylabel('Fraction of positives')
plt.legend()
plt.show()

# If miscalibrated: apply isotonic regression
from sklearn.isotonic import IsotonicRegression

iso_reg.fit(preds_val, y_val)
```
