## Principle 9: Distill Large Models into Small Ones for Inference Constraints

*Consensus: WSDM chatbot arena 1st (five Qwen2.5-72B fold teachers distilled into a Qwen2.5-14B student with soft labels) and 3rd (distillation raised a 14B model's CV from 0.705 to 0.717)*

When inference is constrained (GPU memory, time limits), train large models offline to generate soft labels (logits or probabilities), then distill their knowledge into smaller models that fit the constraints while retaining most of the performance.

**Why this matters:** Large models (70B-class LLMs, deep ensembles) learn better representations but don't fit in 9-hour Kaggle notebooks or 16GB GPUs. Distillation transfers their knowledge to smaller models. The WSDM chatbot arena 1st place trained five Qwen2.5-72B teachers on five folds, soft-labeled the training data out of fold, and distilled them into a Qwen2.5-14B student that fit the inference budget. The 3rd place's Qwen2.5-14B model reached 0.705 CV without distillation, 0.713 with distillation from a 72B teacher, and 0.717 with more teachers.

**When to use:** When you have: (1) large models that work well offline but can't deploy, (2) strict inference constraints (time, memory), (3) access to unlabeled data for pseudo-labeling. Common in code competitions (9-hour limits) and production deployments. Combine with quantization (8-bit, 4-bit) for further compression.

**When NOT to use:** If inference constraints are loose or if small models already perform well. Don't expect a big gain if the teacher model isn't clearly better than the student; soft labels can still help as label cleaning (the WSDM 3rd place found self-distillation from its own 14B model's logits reached the same CV as a 72B teacher). Avoid if you lack compute for training large teachers—distillation needs both teacher inference and student training.

**How to reason about it:**
Train teacher models (large, no constraints). Generate soft labels: teacher logits or probabilities on train + unlabeled data. Train student model with distillation loss: combine (a) hard label loss (ground truth) and (b) soft label loss (KL divergence from teacher logits). Balance: 50% hard, 50% soft, or tune the ratio. For multi-teacher: average logits from multiple teachers before distilling (ensemble distillation). Quantize student post-training (GPTQ, bitsandbytes) for further compression.

```python
import torch
import torch.nn.functional as F

# Teacher: large model (offline, no time limit)
teacher = load_large_model('qwen2.5-72b')
teacher_logits = teacher(X_train)  # Shape: (N, num_classes)

# Student: small model (must fit in inference constraints)
student = load_small_model('qwen2.5-14b')

# Distillation loss: combine hard labels + soft labels
def distillation_loss(student_logits, teacher_logits, labels, alpha=0.5, temperature=2.0):
    # Soft loss: KL divergence between teacher and student
    soft_loss = F.kl_div(
        F.log_softmax(student_logits / temperature, dim=1),
        F.softmax(teacher_logits / temperature, dim=1),
        reduction='batchmean'
    ) * (temperature ** 2)
    
    # Hard loss: cross-entropy with true labels
    hard_loss = F.cross_entropy(student_logits, labels)
    
    return alpha * soft_loss + (1 - alpha) * hard_loss
```
