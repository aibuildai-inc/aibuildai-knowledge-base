## Principle 14: Treat Regression as Classification with Soft Targets for Robustness

*Consensus: Mercari 1st place used classification with soft bucketed targets; Prudential 1st place used ordinal regression*

For continuous targets that are bounded or ordinal, discretize into bins and train a classification model with soft targets (smoothed probabilities across adjacent bins) to reduce sensitivity to outliers and improve generalization.

**Why this matters:** Regression losses (MSE, MAE) are sensitive to outliers and extreme values. A few outliers dominate the loss and pull predictions. Classification with soft targets treats the problem as predicting a distribution over bins, which is more robust. Mercari 1st place: bucketed prices into 64 bins, applied softmax-smoothed targets (high temperature), and trained a classifier. This outperformed regression and added diversity to the ensemble.

**When to use:** When the target is continuous but: (1) has outliers, (2) is bounded (prices, scores, probabilities), or (3) is ordinal (ratings 1-5). Use for ensemble diversity—combine regression and classification models. Apply soft targets (distribute probability across adjacent bins) to avoid overconfidence at bin edges.

**When NOT to use:** Skip if the target is truly unbounded and smooth (rare in practice). Don't discretize too coarsely (<10 bins)—you lose resolution. Avoid if the metric penalizes discretization errors (e.g., exact value prediction matters). Don't use hard bucket labels (0/1); always soften across neighbors.

**How to reason about it:**
Choose number of bins: ~32-64 for balanced resolution vs. model capacity. Define bins: equal-width (divides range evenly) or equal-frequency (quantiles, balanced bin sizes). Create soft targets: for true value y, compute distance to each bin center, apply softmax with temperature T (high T = smooth, low T = peaked). Train classifier (cross-entropy loss). At inference: predict bin probabilities, compute expected value = sum(bin_center * prob). Compare CV to regression baseline.

```python
import numpy as np
import torch
import torch.nn.functional as F

# Discretize continuous target into 64 bins
num_bins = 64
bin_edges = np.linspace(y_train.min(), y_train.max(), num_bins + 1)
bin_centers = (bin_edges[:-1] + bin_edges[1:]) / 2

# Create soft targets with temperature-scaled softmax
def create_soft_target(y, bin_centers, temperature=10):
    # Compute L2 distance to each bin center
    distances = np.abs(bin_centers - y)
    # Apply softmax with temperature (higher T = smoother)
    soft_target = F.softmax(torch.tensor(-distances / temperature), dim=0)
    return soft_target.numpy()

# Example: for y=45.3, soft_target might be [0.0, 0.05, 0.6, 0.3, 0.05, 0.0, ...]
soft_targets = np.array([create_soft_target(y, bin_centers) for y in y_train])

# Train classifier
model = ClassificationModel(input_dim, num_classes=num_bins)

# At inference: predict bin probabilities, compute expected value
```
