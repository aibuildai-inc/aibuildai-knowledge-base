## Principle 6: Diversify Ensemble Components Across Features, Preprocessing, and Architectures

*Consensus: Top solutions across competitions use ensembles; most explicitly create diversity via different feature sets or preprocessing*

Build ensemble strength through diversity, not just quantity. Train models on different feature subsets, different preprocessing (with/without normalization, different tokenization), different architectures (GBDT, NN, FM), and different objectives to capture complementary patterns.

**Why this matters:** Ensembling 10 similar models yields marginal gains. Ensembling 3 diverse models (e.g., LightGBM on aggregated features + RNN on raw sequences + NN on text embeddings) captures different aspects of the data. Diversity reduces correlation between predictions, which is what makes ensembles work. Mercari 1st place: 12 models across 3 datasets with different tokenization.

**When to use:** Always for final submissions in competitive settings. Start ensembling after you have 2-3 strong base models (CV within 0.01 of each other). Create diversity via: (1) feature sets (all features, top 500, HMA-only, diff-only), (2) preprocessing (stemming vs no stemming, binarized vs TF-IDF), (3) architectures (tree vs neural), (4) objectives (regression vs classification for continuous targets).

**When NOT to use:** Early exploration—focus on strong single models first. Don't ensemble weak models hoping for magic; diversity helps only when base models are individually strong. Avoid ensembling near-duplicates (same model, same features, random seed variation)—the gain is minimal.

**How to reason about it:**
Check prediction correlation: if two models have correlation > 0.95, they're redundant. Aim for correlation 0.7-0.9 (aligned but different). Create diversity: (1) Features: train on different subsets (importance-based selection, domain subsets like 'payment features only'). (2) Preprocessing: e.g., one model with stemming, one without; one with log-transform, one raw. (3) Architectures: combine LightGBM (captures interactions) + linear model (captures linear trends) + NN (captures nonlinear patterns). (4) Objectives: regression (Huber loss) + classification (logloss on bucketed targets). Test ensemble incrementally: does adding model B to A improve CV?
