## Principle 11: Blend Ensembles with Optimized Weights, Not Simple Averaging

*Consensus: Most top ensemble solutions use weighted blending (optimized via Lasso, Optuna, or hill climbing) over simple averaging*

After training diverse models, blend their predictions with optimized weights rather than equal averaging. Use a small holdout set to tune weights via linear regression (Lasso/Ridge), convex optimization, or hill climbing to maximize the target metric.

**Why this matters:** Models contribute unequally. A strong LightGBM may deserve 0.4 weight, while a weaker NN deserves 0.15. Simple averaging (0.33 each for 3 models) leaves performance on the table. Optimized blending extracts maximum value from each model. Mercari 1st place: tuned blending weights with Lasso on 1% validation set, gaining +0.001 over equal weights.

**When to use:** When you have 3+ models with different strengths (CV scores vary by 0.01+). Reserve a small holdout set (1-5% of data) separate from CV folds for blending. Use after finalizing base models—don't reoptimize weights for every experiment. Optimize on the real metric, not a proxy.

**When NOT to use:** If models are nearly identical (correlation > 0.98), weights won't help—focus on diversity instead. Don't optimize on CV folds used to train base models (leakage). Avoid overfitting to holdout: if you have only 2 models, equal averaging (0.5, 0.5) is often robust enough.

**How to reason about it:**
Reserve holdout set (untouched during base model training). Collect predictions from all models on holdout. Method 1 (linear blending): fit Ridge/Lasso regression with base predictions as features, target as labels. Lasso auto-sets weak models to zero. Method 2 (Optuna): define objective = metric(y_true, weighted_blend(preds, weights)), optimize weights. Method 3 (rank averaging): convert predictions to ranks, average ranks, convert back. Check: does optimized blend improve holdout score vs. simple average?

```python
import numpy as np
from sklearn.linear_model import Ridge, Lasso
import optuna

# Collect predictions from N models on holdout set
preds = np.column_stack([model1_preds, model2_preds, model3_preds])  # Shape: (n_samples, n_models)

# Method 1: Linear blending with Ridge
blender = Ridge(alpha=1.0, positive=True)  # Positive=True enforces non-negative weights
blender.fit(preds, y_holdout)
weights = blender.coef_ / blender.coef_.sum()  # Normalize to sum to 1
final_preds = preds @ weights

# Method 2: Optimize weights with Optuna
def objective(trial):
    w = [trial.suggest_float(f'w{i}', 0.0, 1.0) for i in range(preds.shape[1])]
    w = np.array(w) / sum(w)  # Normalize
    blend = preds @ w
    return compute_metric(y_holdout, blend)  # E.g., logloss, RMSE

study = optuna.create_study(direction='minimize')
study.optimize(objective, n_trials=200)
optimized_weights = np.array([study.best_params[f'w{i}'] for i in range(preds.shape[1])])
optimized_weights /= optimized_weights.sum()

# Method 3: Rank averaging (robust to outliers)
from scipy.stats import rankdata
ranks = np.column_stack([rankdata(p) for p in preds.T])
avg_ranks = ranks.mean(axis=1)
final_preds = rankdata(avg_ranks) / len(avg_ranks)  # Normalize to [0, 1]
```
