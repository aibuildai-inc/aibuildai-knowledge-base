## Principle 12: Average Only Valid Stochastic or Symmetry-Related Views

*Consensus: 3 waveform solutions (1st/4th/14th) used horizontal-flip TTA, mapping each flipped prediction back before averaging.*

At inference, average exact symmetry transforms only after mapping every prediction back to the same physical coordinate system. Allocate repeated views where prediction variance is high rather than uniformly.

**Why this matters:** TTA reduces variance and enforces equivariance, but a view is valid only if it is mapped back correctly. In waveform inversion, a horizontal flip of the input also moves a central source by one position, so the flipped view needs source-aware handling and the prediction must be flipped back before averaging. Periodic or bounded targets also need averaging in a representation where the mean is still a valid value.

**When to use:** Use for exact source-aware flips, validated symmetries of the acquisition geometry, or paired image transforms. Estimate per-example variance to decide how many views are worth the cost.

**When NOT to use:** Do not use approximate symmetries with hidden source shifts or asymmetric acquisition geometry. Skip repeated inference when the input view is deterministic or gains are negligible relative to runtime.

**How to reason about it:**
For each view, verify invertibility and equivariance. Compare single-view error, multi-view error, and prediction variance by regime. Average fields after inverse transforms, then project the mean back to the valid target domain.

```python
preds = []
for transform in validated_transforms:
    x_t = transform.apply_input(x)          # e.g., flip receivers and update the source channel
    y_t = model(x_t)
    preds.append(transform.invert_output(y_t))
mean_pred = torch.stack(preds).mean(0)
# For bounded fields, clip or project afterward.
mean_pred = project_to_target_domain(mean_pred)
```
