## Principle 14: Use Prediction-Time Constraints as Projections or Regularized Refinement

*Consensus: 4/15 waveform writeups explicitly optimized predictions through the forward model, including the 2nd-, 5th-, 10th-, and 14th-place solutions; output-domain projection is relevant to both competitions.*

After obtaining a strong learned estimate, apply the weakest validated correction that enforces measurement consistency, target bounds, structural priors, or submission validity. Treat this as constrained estimation, not cosmetic post-processing.

**Why this matters:** Neural predictions can be close but physically inconsistent. Starting from a learned estimate places iterative inversion in a favorable basin; priors such as total variation, one-dimensional layers, discrete plateaus, or valid value ranges prevent the forward residual from exploiting implausible solutions.

**When to use:** Use when the forward operator is trustworthy, a regime-specific prior is justified, or the target has hard bounds/manifold constraints. Tune iteration count, regularization, and stopping rules on held-out real examples by regime.

**When NOT to use:** Do not minimize measurement residual alone in an ill-posed inverse problem, and do not impose discrete or smooth priors on textured regimes. Skip tiny heuristic corrections unless their gain survives multiple validation groups and the scientific checks.

**How to reason about it:**
Start with universal projections such as clipping to the physical range. Next test a small number of forward-consistency steps. Add structural priors only after residual analysis identifies the relevant regime. Monitor both target metric and measurement residual; stop if residual improves while target validation worsens.

```python
y = model(x).detach().requires_grad_(True)
opt = torch.optim.LBFGS([y], max_iter=customize_steps)

def closure():
    opt.zero_grad()
    data_term = measurement_loss(forward_operator(y), x)
    prior = prior_weight * regime_specific_prior(y)
    loss = data_term + prior
    loss.backward()
    return loss

opt.step(closure)
y_final = project_to_physical_domain(y.detach())
```
