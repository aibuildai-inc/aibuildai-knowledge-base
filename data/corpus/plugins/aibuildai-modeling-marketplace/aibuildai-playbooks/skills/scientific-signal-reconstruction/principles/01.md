## Principle 1: Classify the Measurement-to-Target Geometry Before Choosing a Model

*Consensus: Both competitions require this decision, but they occupy different methodological branches rather than sharing one architecture.*

First determine whether the task is local dense-to-dense restoration, a non-aligned global inverse map, sparse set/sequence reconstruction, or constrained event-level prediction. Choose the architecture from that geometry instead of treating every array as an image or every detector event as ordinary tabular data.

**Why this matters:** Architectural inductive bias determines which dependencies are easy to learn. A local CNN is efficient when output pixels depend mainly on nearby input pixels, but misleading when waveform coordinates do not align with target-field coordinates; variable-size sets of sensor readings require permutation-aware aggregation rather than arbitrary rasterization.

**When to use:** Always, before building a serious baseline. Inspect the physical meaning of every axis, whether input and output coordinates correspond, whether observation count varies, and whether the target is a field, vector, image, or score.

**When NOT to use:** Do not force a single branch across heterogeneous tasks. In waveform inversion, top solutions explicitly rejected naive segmentation assumptions; in Flavours of Physics, event-level models had to satisfy distributional checks.

**How to reason about it:**
Ask in order: (1) Does an output location correspond to the same input location? If yes, start with local convolutional restoration. (2) Is a dense target inferred from globally distributed measurements? Use a global encoder plus a field decoder or an iterative inverse model. (3) Is each example a variable-size set of sensor readings? Use attention or message passing. (4) Is the output an event score with scientific constraints? Use a strong tabular ranker and optimize validity jointly with discrimination.

```python
def choose_model_family(meta):
    # Customize these flags from an axis/physics audit, not array shapes alone.
    if meta.local_alignment and meta.dense_input and meta.dense_target:
        return "residual_cnn"
    if meta.dense_target and not meta.input_target_alignment:
        return "global_encoder_field_decoder"
    if meta.variable_size_sensor_sets:
        return "set_transformer_or_gnn"
    if meta.event_level_target:
        return "tabular_ranker_with_constraints"
    raise ValueError("Inspect the acquisition geometry before modeling")
```
