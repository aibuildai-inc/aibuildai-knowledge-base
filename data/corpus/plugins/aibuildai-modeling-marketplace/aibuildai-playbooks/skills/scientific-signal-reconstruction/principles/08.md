## Principle 8: Augment the Latent Physical State, Then Propagate the Transformation Consistently

*Consensus: All top-6 waveform solutions used augmentation or synthetic generation.*

Prefer transformations defined in physical state space, and regenerate or transform measurements and labels according to the acquisition law. Treat every augmentation as a hypothesis about invariance or equivariance, not as a generic computer-vision recipe.

**Why this matters:** Independent augmentation of an input signal can destroy the inverse relationship. In waveform inversion, velocity scaling changes travel time and sometimes amplitude; a horizontal flip can move a central source by one pixel. Any transform of input coordinates requires the matching transform of a geometric target.

**When to use:** Use when the transformation has a derivable effect on both observation and target, or when a trusted simulator can create the paired observation. This includes paired image transforms, latent CutMix or MixUp of velocity fields followed by simulation, and stretches or deformations of the latent field.

**When NOT to use:** Avoid standard flips, crops, shifts, or mixup when they violate source placement, boundaries, sensor asymmetry, or the target definition. If an approximation is used, quantify simulator or transformation error before scaling it up.

**How to reason about it:**
For each candidate transform T, write the expected relation between forward operator F and measurement transform S: F(T(y)) should approximately equal S(F(y)). Measure the discrepancy. Use exact transforms broadly, approximate transforms conservatively, and invalid transforms not at all.

```python
def physics_aware_augment(y, operator, transform):
    y_aug, metadata = transform.apply_latent(y)
    # Safest path: regenerate x instead of guessing an image-space transform.
    x_aug = operator(y_aug, acquisition=metadata.acquisition)
    return x_aug, y_aug
```
