## Principle 2: Match Local and Global Receptive Fields to the Physical Dependency Range

*Consensus: 5/6 top waveform solutions used ViT/CAFormer/ConvFormer-style global models or a global learned initializer.*

Use local operators for texture, edges, and near-neighbor interactions, and global operators when distant measurements jointly determine the target. Hybrid local-global blocks are valuable when both mechanisms are present.

**Why this matters:** Inverse problems often contain local regularity in the latent field but global dependence in the measurements. Convolutions provide useful locality and translation bias; attention communicates across the full measurement or field. Combining them can improve convergence and model diversity without pretending one dependency scale explains everything.

**When to use:** Use a hybrid when the target has sharp local structures but the acquisition mixes information globally. Use pure local CNNs when each output depends only on a small, aligned input neighborhood.

**When NOT to use:** Avoid expensive global attention when the dependency radius is known to be small or input sizes make quadratic cost unjustifiable.

**How to reason about it:**
Estimate dependency range empirically by masking or perturbing distant observations. If distant evidence changes predictions materially, provide a global path. If local edge fidelity degrades, add convolution or a local decoder. Compare pure-local, pure-global, and hybrid models at matched parameter count and throughput.

```python
class LocalGlobalBlock(nn.Module):
    def __init__(self, dim, heads):
        super().__init__()
        self.local = nn.Conv2d(dim, dim, 3, padding=1, groups=dim)
        self.global_attn = nn.MultiheadAttention(dim, heads, batch_first=True)

    def forward(self, x):
        # x: [B,C,H,W]
        y = x + self.local(x)
        tokens = y.flatten(2).transpose(1, 2)
        tokens = tokens + self.global_attn(tokens, tokens, tokens)[0]
        return tokens.transpose(1, 2).reshape_as(x)
```
