## Principle 3: Encode Physical Coordinates, Symmetries, and Target Manifolds Explicitly

*Consensus: Coordinate realignment and geometry-aware embeddings appeared in waveform solutions.*

Represent continuous sensor coordinates and times at sufficient resolution, expose meaningful geometric relations, and parameterize outputs on their natural domain. Examples include Fourier features or rotary position embeddings for coordinates, an explicit source-position channel that stays correct under flips, and bounded transforms that keep a physical field inside its valid range.

**Why this matters:** Raw scalar coordinates can be hard for shallow token encoders to resolve. An unbounded output can drift outside the physical range, and a raw periodic value has an artificial jump where its two ends meet. A domain-aware output removes such problems: the 1st-place waveform solution applied a sigmoid to its logits and scaled them to the valid velocity range, and another solution added a channel that marks the source position so that features stay consistent after a flip.

**When to use:** Use this whenever targets are periodic, directional, bounded, positive, or otherwise constrained, and whenever sensor geometry or relative travel time carries signal. It is especially important for irregular sensors and continuous coordinates entering transformers.

**When NOT to use:** Do not add redundant engineered coordinates without ablation; extra derived features often add little when they are nearly alternate encodings of an existing coordinate. Do not impose rotational or translational invariance if the sensors, boundary conditions, source placement, or simulator has a preferred frame.

**How to reason about it:**
Identify the symmetry group and the target domain. Decide which transformations should leave the target unchanged, which should transform it equivariantly, and which are not valid. Then choose coordinate encodings and output projections that enforce those facts rather than asking the loss to learn them from scratch.

```python
def bounded_field(logits, low, high):
    # Keep every predicted value inside the physical range [low, high].
    return low + (high - low) * torch.sigmoid(logits)

def add_source_channel(x, source_positions):
    # x: [B, C, T, R]; mark the source receiver index so flips stay consistent.
    marker = torch.zeros_like(x[:, :1])
    for b, pos in enumerate(source_positions):
        marker[b, 0, :, pos] = 1.0
    return torch.cat([x, marker], dim=1)
```
