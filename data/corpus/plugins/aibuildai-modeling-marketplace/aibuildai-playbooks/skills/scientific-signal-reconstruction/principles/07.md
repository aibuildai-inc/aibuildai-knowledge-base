## Principle 7: Optimize the Metric’s Geometry, but Stabilize It with a Compatible Surrogate

*Consensus: Both competitions had materially different objectives; top waveform models generally trained with MAE to match evaluation.*

Align the training objective with the official metric and target domain, while adding a stable surrogate when the direct metric has poor gradients. Use MAE for MAE-scored fields, squared error for RMSE-scored targets, angular or vector losses for directions, and ranking losses plus explicit constraints for constrained classification.

**Why this matters:** A convenient loss may optimize the wrong errors. MSE on an MAE-scored field overweights a few large errors, and ordinary AUC ignores weighted operating regions and validity gates. Waveform solutions kept MAE as the core loss and added compatible terms: one trained a confidence head to predict each sample's MAE, and another gave lower weight to deeper positions it judged noisier.

**When to use:** Use direct metric fine-tuning after a stable warm-up, or combine the metric with auxiliary losses throughout. Add a surrogate term when the direct metric gives flat or unstable gradients.

**When NOT to use:** Do not assume exact metric optimization is always numerically best. Waveform solutions reached top ranks with plain MAE, MAE plus a confidence loss, and depth-weighted MAE; choose based on stability and calibrated validation, not ideology.

**How to reason about it:**
Derive what each prediction error contributes to the leaderboard. Check discontinuities, weighting regions, clipping, and ignored examples. Select a smooth objective with matching local gradients, then verify that lower training loss monotonically improves the exact validation metric.

```python
def field_loss(pred, target, confidence=None, depth_weights=None):
    abs_err = (pred - target).abs()                      # exact metric geometry (MAE)
    if depth_weights is not None:                        # e.g., lower weight for noisier rows
        abs_err = abs_err * depth_weights[None, None, :, None]
    loss = abs_err.mean()
    if confidence is not None:
        # Auxiliary head predicts each sample's error; detach so it does not change the main target.
        per_sample = (pred - target).abs().mean(dim=(1, 2, 3)).detach()
        loss = loss + (confidence - per_sample).abs().mean()
    return loss
```
