## Principle 14: Apply Sample Normalization for Gene Expression and High-Throughput Screening Data

*Consensus: 3/3 solutions on gene expression (MoA, single-cell) and 1/1 on DEL screening used sample-wise normalization*

For gene expression and cell viability data, normalize each sample independently by its distribution (subtract robust center, scale by robust spread) before any feature engineering or model training. This removes batch effects and systematic errors that are sample-specific rather than feature-specific.

**Why this matters:** Gene expression data has systematic sample-to-sample variation from technical factors (different machines, batches, operators). Standard feature normalization (z-score per gene across samples) doesn't remove this. Sample normalization assumes most genes are unchanged by treatment, so the sample's overall distribution should be similar. The MoA 2nd-place used per-sample quantile normalization (subtract mean of 25-75% quantiles) and it was critical for generalization.

**When to use:** For gene expression data (RNA-seq, microarray) and cell viability assays. Normalize each sample by: (1) compute robust center (mean of middle 50% quantiles, or median), (2) subtract center, (3) scale by robust spread (75% quantile or MAD). Do this BEFORE any other preprocessing. Essential when data comes from multiple batches or labs.

**When NOT to use:** Do NOT use for molecular descriptors or fingerprints (they don't have batch effects). Do NOT use if samples are expected to have very different distributions (e.g., different cell types with genuinely different expression patterns). Do NOT use for small molecule properties.

**How to reason about it:**
For each sample (row): (1) Compute 25% and 75% quantiles of gene expression values. (2) Compute robust center = mean(Q25, Q75). (3) Subtract center from all genes in that sample. (4) Compute robust spread (e.g., Q75 after centering). (5) Divide by spread. Do this separately for gene features and cell viability features (they have different distributions). THEN apply standard feature normalization (quantile transform, etc.).

```python
import numpy as np
from sklearn.preprocessing import QuantileTransformer

def sample_normalize(X, q_low=0.25, q_high=0.75):
    """
    X: (n_samples, n_features) gene expression data
    Normalize each sample (row) independently
    """
    X_norm = X.copy()
    for i in range(len(X)):
        sample = X[i, :]
        # Robust center: mean of middle quantiles
        q25, q75 = np.quantile(sample, [q_low, q_high])
        center = (q25 + q75) / 2
        # Center
        sample_centered = sample - center
        # Robust scale
        scale = np.quantile(np.abs(sample_centered), q_high)
        # Normalize
        X_norm[i, :] = sample_centered / (scale + 1e-8)
    return X_norm
```
