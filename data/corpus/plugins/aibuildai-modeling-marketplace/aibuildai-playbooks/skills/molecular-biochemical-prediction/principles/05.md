## Principle 5: Use Test-Time Augmentation for Sequence-Based Models via SMILES Randomization

*Consensus: 4/5 top transformer-based solutions used TTA; single-prediction transformers left 0.01 LB improvement unused*

For SMILES-based models, generate multiple non-canonical SMILES representations of the same molecule at inference time (using RDKit's doRandom=True), predict on each, and aggregate (median or mean). This exploits the fact that SMILES are arbitrary orderings of the same molecular graph.

**Why this matters:** Transformers are sensitive to input token order. The same molecule has ~10-1000 valid SMILES representations (more for larger molecules). Randomizing SMILES during training teaches robustness, but test-time averaging over multiple draws reduces variance further. The 1st-place polymer solution gained 0.01 LB from 50-sample TTA alone; training-time augmentation (10x data) was also critical.

**When to use:** For any SMILES-based transformer model (BERT, 1D-CNN on tokenized SMILES). Use 10-50 random SMILES per test molecule (more is better until you hit inference time limits). Also apply during training: generate 5-10 random SMILES per molecule per epoch to augment data 5-10x.

**When NOT to use:** Do NOT use for graph models (they are already permutation-invariant by design). Do NOT use if inference time is extremely limited (but even 10 samples helps). Do NOT use if your tokenizer cannot handle non-canonical SMILES. Do NOT use for non-SMILES representations (protein sequences have canonical order).

**How to reason about it:**
Training time: FOR each molecule, generate K=10 random SMILES using `Chem.MolToSmiles(mol, canonical=False, doRandom=True)` → this gives K different token sequences for the same molecule → train on all K, no need to change anything else. Test time: FOR each test molecule, generate N=50 random SMILES → predict on all N → aggregate via median (more robust) or mean. CHECK: does TTA improve your single-model CV? If not, your training augmentation may be insufficient.

```python
from rdkit import Chem

# Training-time augmentation: generate multiple SMILES per molecule
def augment_smiles(smiles, n_augment=10):
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return [smiles]  # Invalid SMILES, return original
    augmented = []
    for _ in range(n_augment):
        aug_smi = Chem.MolToSmiles(mol, canonical=False, doRandom=True, 
                                    isomericSmiles=True)
        augmented.append(aug_smi)
    return augmented

# Test-time augmentation: predict on multiple SMILES, aggregate
def predict_with_tta(model, smiles, n_tta=50):
    mol = Chem.MolFromSmiles(smiles)
    augmented_smiles = [Chem.MolToSmiles(mol, canonical=False, doRandom=True) 
                        for _ in range(n_tta)]
    predictions = [model.predict(smi) for smi in augmented_smiles]
    return np.median(predictions, axis=0)  # Median more robust than mean
```
