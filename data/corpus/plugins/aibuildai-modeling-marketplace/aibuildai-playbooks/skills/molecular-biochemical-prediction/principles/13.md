## Principle 13: Encode Positional and Structural Constraints via Distance Embeddings

*Consensus: Recurring in top solutions on sequence-based RNA tasks: distance/position embeddings, not just sequence*

For sequential molecular data (RNA, DNA, polymer chains), encode both sequential position and structure (relative position between residues, base-pair probabilities for RNA). Feed pairwise information as learned embeddings or attention biases, not raw coordinates. This allows models to learn different patterns at different distance scales.

**Why this matters:** Sequential position captures local context, but molecular properties often depend on long-range interactions (RNA base pairs, through-space atom interactions). Distance embeddings let the model learn that interactions at distance 1 (adjacent) behave differently from distance 10 (far in sequence but possibly close in 3D). The Ribonanza RNA folding 1st-place solution added a dynamic positional bias and convolved base-pair probability matrix features to its attention scores, and the 3rd-place solution used relative position encodings plus a base-pair probability attention bias instead of absolute positions. Both chose relative positions because test sequences were longer than training sequences, and absolute positions did not generalize to the longer inputs.

**When to use:** For RNA/DNA: encode (1) relative sequence position (a learned bias per clipped relative distance), (2) base-pairing structure as a pairwise matrix, such as a base-pair probability matrix from a folding package, added to the attention scores. For polymers: embed monomer position in chain. Use learned embeddings (not raw distances) so model learns distance scales. Prefer relative over absolute positions whenever test sequences can be longer than training sequences.

**When NOT to use:** Do NOT use for small molecules without clear sequence structure. Do NOT use raw distances as features - learned embeddings work better. Do NOT use for graph models that already use distance as edge weights. Do NOT assume every structural distance helps: one Ribonanza top solution found that shortest-path (Floyd-Warshall) distance matrices over the pairing structure did not help.

**How to reason about it:**
For RNA: (1) Compute relative position r(i,j) = clip(j - i, -K, K) and learn one bias per value and attention head. (2) Compute a base-pair probability matrix (BPPM) for each sequence with a folding package. (3) Pass the BPPM through a small convolution whose output channels equal the number of attention heads, and add the result to the attention scores. (4) Concatenate with other features (base identity, etc.). CHECK: validate on sequences longer than the training ones when the test set contains them.

```python
import torch
import torch.nn as nn

# Relative position bias (generalizes to longer test sequences)
class RelativePositionBias(nn.Module):
    def __init__(self, max_rel, n_heads):
        super().__init__()
        self.max_rel = max_rel
        self.embedding = nn.Embedding(2 * max_rel + 1, n_heads)

    def forward(self, seq_len):
        pos = torch.arange(seq_len)
        rel = (pos[None, :] - pos[:, None]).clamp(-self.max_rel, self.max_rel) + self.max_rel
        return self.embedding(rel).permute(2, 0, 1)  # (n_heads, L, L)

# Base-pair probability matrix as an attention bias
class BPPBias(nn.Module):
    def __init__(self, n_heads):
        super().__init__()
        self.conv = nn.Conv2d(1, n_heads, kernel_size=3, padding=1)

    def forward(self, bppm):
        # bppm: (batch, L, L) from a folding package
        return self.conv(bppm.unsqueeze(1))  # (batch, n_heads, L, L)

# Use in self-attention
scores = q @ k.transpose(-2, -1) / d_k ** 0.5  # (batch, n_heads, L, L)
```
