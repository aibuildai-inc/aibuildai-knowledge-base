## Principle 7: Combine Molecular Fingerprints with Learned Representations for Tabular Models

*Consensus: 6/6 top GBDT/tabular solutions combined fingerprints + descriptors + learned embeddings*

For gradient boosting or tabular models, engineer features from three sources: (1) molecular fingerprints (ECFP, Morgan), (2) RDKit descriptors (200+ 2D/3D properties), and (3) pretrained model embeddings (ChemBERTa, ESM). Use feature selection (importance-based or Optuna) to find the optimal subset for each target.

**Why this matters:** Each feature type captures different information: fingerprints encode substructure presence (bits = 'has this motif'), descriptors quantify global properties (MW, logP, TPSA), embeddings capture learned semantic similarities. Combining all three beats any single type. The polymer 1st-place AutoGluon model used Morgan FPs + 200 RDKit descriptors + backbone/sidechain features + MD simulation features + PolyBERT embeddings, beating pure neural models.

**When to use:** For tabular models (XGBoost, LightGBM, AutoGluon, TabNet) on molecular data with <50k samples. Use Optuna to tune: (1) which fingerprint types (Morgan, ECFP, MACCS, atom pairs), (2) fingerprint dimensions (1024-4096), (3) which descriptor subsets (select top-K by feature importance), (4) whether to include embeddings. Per-target feature selection often helps.

**When NOT to use:** Do NOT use for end-to-end neural models (they learn their own features). Do NOT combine all features blindly - use feature selection to avoid overfitting. Do NOT use 3D descriptors if you don't have accurate 3D structures (they will be noisy). The MoA 1st-place used minimal feature engineering for CNNs (raw genes/cells) because CNNs learn features.

**How to reason about it:**
Create feature pools: (1) Fingerprints: Morgan (radius=2,3, bits=2048), ECFP (radius=4, bits=2048,3072), MACCS keys, atom pairs, topological torsion. (2) RDKit descriptors: all 2D descriptors (~200), 3D if available (~50). (3) Embeddings: pass SMILES through ChemBERTa, take [CLS] token embedding (384-768 dim). (4) Domain features: for polymers, backbone vs sidechain stats; for proteins, amino acid composition. (5) Use XGBoost/LGBM to compute feature importance on all features. (6) Use Optuna to select: which feature types to keep, how many top-K features of each type, fingerprint dimensions. (7) Retrain final model on selected features.
