## Principle 10: Leverage Domain-Specific Structural Features for Protein and Enzyme Tasks

*Consensus: 5/5 protein/enzyme solutions used 3D structural features; sequence-only models left performance on table*

For proteins and enzymes, combining sequence embeddings (ESM2, T5) with 3D structural features (residue depth, SASA, B-factor, local geometry) substantially outperforms sequence alone. Use AlphaFold structures if experimental PDB unavailable. For stability prediction, engineer features from the mutation site and its spatial neighborhood (nearest 20-50 residues).

**Why this matters:** Protein function and stability depend on 3D structure, not just sequence. The same mutation has different effects depending on local environment (buried vs surface, near active site vs far). Enzyme stability 3rd-place used 21 nearest residues to mutation, computing distances, angles, SASA, B-factor, and got 0.542 Spearman vs 0.4+ for sequence-only. AlphaFold provides structure when PDB missing. Non-experimental GO annotations (from sequence homology) are strong features for function prediction.

**When to use:** For proteins: always use ESM2/T5 embeddings as baseline. ADD 3D features when: (1) predicting function/stability/binding that depends on structure, (2) you have or can generate 3D structures (AlphaFold for unknowns), (3) the task involves specific sites (mutations, binding sites). Extract neighborhood features (not just the mutated residue): for mutation at position i, take 20-50 nearest residues by 3D distance, compute relative distances, angles, SASA, B-factor. For function prediction, add non-experimental GO annotations as auxiliary features.

**When NOT to use:** Do NOT use 3D features for purely sequence-level tasks (e.g., per-position targets along an RNA sequence). Do NOT use if AlphaFold confidence is very low (<50 pLDDT) - the structure is unreliable. Do NOT use if computational cost is prohibitive (AlphaFold is slow, use precomputed if available).

**How to reason about it:**
Baseline: Extract embeddings from ESM2 (for full protein) or T5 (for proteins). IF task is mutation-based (stability, binding): (1) Get 3D structure (PDB or AlphaFold). (2) Identify mutation site position i. (3) Find K=21 nearest residues by Cα distance. (4) Compute features: relative distances to mutation site, angles (3 types), B-factors, SASA, sequence properties (BLOSUM-weighted). (5) Concatenate with ESM2 embedding of local neighborhood. IF task is function prediction: (1) Use ESM2/T5 for full sequence. (2) Add one-hot encoding of non-experimental GO annotations (from UniProt). (3) Add taxonomy one-hot (species info).

```python
from Bio.PDB import PDBParser, SASA
import numpy as np

# Get 3D structure (AlphaFold or PDB)
structure = get_structure(protein_id)  # From AlphaFold DB or PDB
chain = structure[0]['A']

# Find mutation site and nearest neighbors
mutation_idx = 42  # Example
mut_residue = chain[mutation_idx]
mut_ca = mut_residue['CA'].coord

# Find K=21 nearest residues
distances = []
for residue in chain:
    if 'CA' in residue:
        dist = np.linalg.norm(residue['CA'].coord - mut_ca)
        distances.append((residue.id[1], dist))
distances.sort(key=lambda x: x[1])
nearest_21 = distances[:21]

# Compute features for each neighbor
features = []
for res_id, dist in nearest_21:
    residue = chain[res_id]
    # Relative distance (normalized)
    rel_dist = dist / max([d for _, d in nearest_21])
    # Angles to mutation site
    vec = residue['CA'].coord - mut_ca
    angle_xy = np.arctan2(vec[1], vec[0])
    angle_z = np.arccos(vec[2] / (dist + 1e-6))
    # SASA, B-factor
    sasa = compute_sasa(residue)
    b_factor = residue['CA'].bfactor
    features.append([rel_dist, angle_xy, angle_z, sasa, b_factor])

features = np.array(features).flatten()  # Shape: (21*5,)

# Combine with ESM2 embedding of local sequence
local_seq = get_sequence(chain, mutation_idx-10, mutation_idx+10)
esm2_emb = get_esm2_embedding(local_seq)  # Shape: (768,)
final_features = np.concatenate([features, esm2_emb])
```
