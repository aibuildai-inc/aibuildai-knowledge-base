## Principle 3: Integrate External Data with Label Rescaling and Error-Based Filtering

*Consensus: Most winning solutions used external data; all that did applied cleaning - raw merging failed*

External biochemical datasets are universally noisy (different labs, assays, conditions) but add critical training signal. Always rescale external labels to match your training distribution using isotonic regression on a strong model's predictions, then filter high-error samples.

**Why this matters:** Different assays measure the same property differently (constant bias, nonlinear scaling, or uncorrelated noise). Merging raw labels trains the model on contradictory examples. The 1st-place polymer solution improved 0.004 LB by rescaling 7 external datasets via isotonic regression; using raw labels degraded performance. Label rescaling corrects systematic bias while preserving the rank order that carries the signal.

**When to use:** When you have external datasets that measure the same or related properties but from different sources (papers, databases, earlier competitions). Apply when: (1) training data is <5k samples and external is >2k, (2) you can train a reasonable baseline on your clean data first, (3) external data comes from different experimental conditions or assays.

**When NOT to use:** Do NOT merge external data if you cannot train a baseline model first (you need something to rescale against). Do NOT use if external data is too far out-of-distribution (e.g., different molecule types entirely). Skip rescaling only if external data is from the exact same assay/lab. The MoA 1st-place solution did NOT use external data because the competition data was already large (>20k samples) and well-controlled.

**How to reason about it:**
For each external dataset: (1) Train strong baseline on competition data only. (2) Predict external dataset with baseline. (3) Fit isotonic regression: external_labels → baseline_predictions. (4) Use isotonic predictions as rescaled labels. (5) Compute error = |rescaled - baseline_pred|. (6) Filter samples where error > threshold (tune threshold with Optuna to maximize competition-data CV). (7) Assign sample weights per dataset (tune with Optuna). (8) Retrain on competition + rescaled external. VERIFY: does competition-only CV improve?

```python
# Label rescaling pipeline (from polymer 1st place)
from sklearn.isotonic import IsotonicRegression

# Step 1: Train baseline on competition data
baseline = train_model(comp_train_X, comp_train_y)

# Step 2: Predict external data
ext_preds = baseline.predict(external_X)

# Step 3: Rescale external labels
iso = IsotonicRegression(out_of_bounds='clip')
rescaled_labels = iso.fit_transform(external_raw_labels, ext_preds)

# Step 4: Filter high-error samples  
errors = np.abs(rescaled_labels - ext_preds)
mae_baseline = np.mean(np.abs(comp_val_y - baseline.predict(comp_val_X)))
threshold = 2.0 * mae_baseline  # Tune this multiplier
external_filtered = external[errors < threshold]

# Step 5: Combine with sample weights (tune per dataset)
weights = np.concatenate([
    np.ones(len(comp_train)) * 1.0,
    np.ones(len(external_filtered)) * 0.3  # Lower weight for external
])
final_model = train_model(combined_X, combined_y, sample_weight=weights)
```
