## Principle 2: Design Cross-Validation to Match the Generalization Challenge

*Consensus: 9/9 competitions; every top solution used domain-specific CV, never random splits*

Random k-fold CV is incorrect for molecular data because molecules in train/test are never random samples - they differ systematically (new scaffolds, new building blocks, different labs, later time periods). Your CV split must simulate the same distribution shift the leaderboard will test.

**Why this matters:** Molecular datasets have systematic structure: DEL libraries are built from combinatorial building blocks; protein annotations arrive over time; drug trials test new chemical matter. Random CV gives optimistic scores (models memorize molecular motifs) while hide generalization failures. Leave-scaffold-out CV in BELKA caught overfitting that random CV missed by 0.1+ mAP.

**When to use:** For DEL data (BELKA): split by building blocks - training molecules must not share BB2/BB3 with validation. For temporal data (CAFA-5, protein function): split by annotation date - validate on future annotations only, exclude anything annotated in training period from validation. For drug data: leave-molecule-out or leave-scaffold-out. For small molecule properties: ensure high Tanimoto similarity (>0.99) molecules don't leak across folds.

**When NOT to use:** Do NOT use random CV when the test set explicitly has different molecule types (stated in competition rules). Do NOT use temporal CV if your dataset is too small to afford losing recent data (but then question whether your model will generalize). Do NOT use leave-one-out if groups are too small (<20 samples per fold).

**How to reason about it:**
Ask: What makes test molecules different from training? IF test has new building blocks → split by building blocks (DEL). IF test is future time period → split by date, exclude annotations from validation that existed in training. IF test is new drugs → leave drug/molecule out. IF test is new scaffolds → cluster by scaffold similarity, leave clusters out. THEN check: does my CV score align with public LB? If CV is much better, your split is leaking.
