## Principle 9: Detect and Correct Distribution Shifts in Test Labels via Probing

*Consensus: 1/1 competition with a known label issue (polymer Tg); probing caught shifts random CV missed*

When you suspect test data has systematic label errors or distribution shifts (different normalization, assay drift, data preprocessing bugs), probe by submitting predictions adjusted by constant offsets or scaling factors and mapping the LB response. If a clear pattern emerges, apply post-processing corrections.

**Why this matters:** Real biochemical data is messy. The polymer competition had a systematic Tg bias (labels shifted by ~0.5 std), and probing revealed it. The 1st-place solution added offset = 0.5644 * std(predictions), gaining 0.014 LB - more than any modeling improvement. Without probing, this is invisible.

**When to use:** When: (1) CV is well-aligned to public LB but you suspect private LB will differ, (2) you have submission budget to probe (>5 remaining), (3) simple offsets to predictions change LB score non-monotonically (V-shaped or shifted optimum suggests bias). Probe by submitting predictions ± k*std for k=0.1,0.2,...,1.0 and mapping LB response.

**When NOT to use:** Do NOT probe if you have <3 submissions left (save for real models). Do NOT apply corrections if probing shows no pattern (random noise). Do NOT assume public LB pattern holds for private - the polymer solution's optimal offset was different for private. Do NOT use if the metric is rank-based (AUC, AP) - constant offsets don't affect ranks.

**How to reason about it:**
IF you suspect test labels have bias: (1) Generate baseline predictions. (2) For property P, submit: pred_P + k * std(pred_P) for k in [-1.0, -0.5, 0, 0.5, 1.0]. (3) Plot k vs LB score. IF you see a clear V-shape or shifted optimum (min/max at k ≠ 0) → there's a systematic bias. (4) Fit a simple function (V-shaped: two linear pieces) to find optimal k. (5) Apply correction: final_pred = pred + k_optimal * std(pred). (6) VERIFY on private LB if possible (use one submission to check). IF pattern is property-specific, apply per-property.

# Distribution shift probing and correction (polymer 1st place)
import numpy as np

# Step 1: Baseline predictions

    preds = baseline_preds[:, prop_idx]
    std_pred = preds.std()

    for k in [-1.0, -0.5, 0.0, 0.5, 1.0]:
        adjusted = preds + k * std_pred
        submission[prop_name] = adjusted
        # Submit and record LB score
        # scores[k] = LB_score

    # optimal_k = fit_v_curve(scores)  
    
# Step 4: Apply correction with optimal k
# For polymer Tg, optimal_k was 0.5644
