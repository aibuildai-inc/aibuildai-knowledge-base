## Principle 11: Extract Route/Path Features via Dimensionality Reduction on Sparse Encodings

*Consensus: 1/2 taxi competitions with route data (NYC Taxi #4)*

When route data (street names, turn sequences) is available, encode each trip as a sparse dictionary {street_name: distance_traveled} or {street_name: frequency}. Convert to a sparse matrix via DictVectorizer. Apply SVD (TruncatedSVD) to reduce to top 50-100 latent dimensions. Use these as features capturing 'route signature.'

**Why this matters:** Routes are high-cardinality categorical data (thousands of street names). One-hot encoding explodes feature space. Raw street names don't generalize. SVD compresses routes into a latent space where similar routes (same streets, similar sequences) are close. This captures route structure compactly—e.g., 'mostly highways' vs 'residential zigzags'—without memorizing exact street combinations.

**When to use:** When you have route details (street names, GPS sequences, turn-by-turn) and need to encode them as features. Use if routes are diverse and cardinality is high. Apply when you have many trips per route (so latent dimensions are meaningful).

**When NOT to use:** Skip if routes are unavailable or too sparse (few trips per unique route—SVD will overfit). Do not use if simple features (total distance, number of turns) suffice. Avoid if routes are already low-dimensional (few possible paths).

**How to reason about it:**
For each trip, build a dictionary of {street_name: distance_on_that_street} or {street_name: travel_time}. Use DictVectorizer to convert all trips into a sparse matrix (rows=trips, columns=streets, values=distances). Apply TruncatedSVD with n_components=50-100 (keep ~80-90% variance). The resulting 50-100 features are 'route embeddings.' Augment with aggregated route features: for each street, compute its average frequency by hour/weekday, then sum these frequencies weighted by distance for each trip.

```python
from sklearn.feature_extraction import DictVectorizer
from sklearn.decomposition import TruncatedSVD

# Build route dictionaries
route_dicts = []
for trip in trips:
    route_dict = {}  # {street_name: distance_traveled}
    for street, dist in trip['route']:
        route_dict[street] = route_dict.get(street, 0) + dist
    route_dicts.append(route_dict)

# Sparse encoding + SVD
vectorizer = DictVectorizer(sparse=True)
route_matrix = vectorizer.fit_transform(route_dicts)
svd = TruncatedSVD(n_components=50, random_state=42)
route_features = svd.fit_transform(route_matrix)  # Shape: (n_trips, 50)

# Use route_features as additional columns in your dataset
```
