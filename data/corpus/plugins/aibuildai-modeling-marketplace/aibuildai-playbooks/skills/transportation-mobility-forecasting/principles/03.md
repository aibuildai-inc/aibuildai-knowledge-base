## Principle 3: Create Context-Specific Aggregations as Historical Baselines

*Consensus: 5/5 regression solutions*

For each context (e.g., pickup_cluster + hour + weekday, or item + store, or taxi_id), compute aggregate statistics (mean speed, median trip time, sales trend) from historical data. Use these aggregates as features representing 'typical behavior in this context.'

**Why this matters:** Transportation patterns are highly context-dependent: rush hour downtown behaves differently than midnight suburbs; a specific item-store pair has its own baseline demand. Aggregates encode domain structure—'what usually happens here/now'—which simple raw features cannot capture. They provide strong baseline signals for the model to adjust.

**When to use:** When your outcome varies systematically by groups (location × time, item × store, taxi × route). Use many overlapping groupings (hour, weekday, cluster, direction) to capture different facets. Compute count, mean, median, std for each group.

**When NOT to use:** Avoid if group sizes are tiny (high cardinality with few samples per group leads to noisy, overfit aggregates). Do not use future information—only aggregate historical data available at prediction time. Skip if the problem has no natural grouping structure.

**How to reason about it:**
Identify natural groupings: What categories define 'similar situations'? Start with time (hour, day_of_week), location (cluster, zone), and identifiers (taxi_id, store_nbr). For each group, compute mean/median of the target and key derived metrics (e.g., speed = distance/time). Create multiple overlapping aggregations (hour, hour+cluster, weekday+cluster) to let the model pick the most relevant.

```python
# Aggregate average speed by pickup cluster and hour
agg_speed = train.groupby(['pickup_cluster', 'hour'])['speed'].agg(['mean', 'std', 'count']).reset_index()
agg_speed.columns = ['pickup_cluster', 'hour', 'avg_speed', 'std_speed', 'count_trips']

# Join back as features
data = data.merge(agg_speed, on=['pickup_cluster', 'hour'], how='left')
```
