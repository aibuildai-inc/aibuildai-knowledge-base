## Principle 8: Build Per-Entity Baseline Trends and Model Residuals

*Consensus: 2/3 demand forecasting solutions (Walmart #1, Restaurant #1)*

For problems with repeated entities (item-store pairs, restaurants, routes), fit a smooth baseline trend per entity (projection pursuit regression, moving average, or spline). Then train a separate model on residuals (observed - baseline) using richer features (weather, weekday, holidays). Final prediction is baseline + residual.

**Why this matters:** Each entity has its own long-term trend (a restaurant growing in popularity, an item being phased out, a route getting busier). A global model struggles to capture entity-specific slopes. A per-entity baseline captures this trend cheaply. Modeling residuals lets the feature-rich model focus on deviations (weather effects, holiday spikes) rather than re-learning every trend.

**When to use:** When entities have unique, smooth trends and you have enough history per entity to fit them. Use if there's a clear signal in per-entity averages over time. Combine with feature-rich models for context effects (weather, promotions, events).

**When NOT to use:** Skip if entities have sparse history (few observations per entity—baseline will overfit). Do not use if trends are highly irregular or noisy (baseline won't capture them). Avoid if a global model with entity embeddings works well (deep learning with entity IDs).

**How to reason about it:**
For each entity (item-store, restaurant, intersection-hour), fit a smooth curve: y = f(days_since_start). Use R's ppr (projection pursuit regression), loess, or a spline. Predict baseline for all dates. Compute residuals: resid = y_true - baseline. Train a model (XGBoost, linear with Lasso) on residuals using all available features (weather, weekday, holidays, aggregates). Predict new points as baseline + predicted_residual.

```python
from scipy.interpolate import UnivariateSpline

# Fit per-entity baseline
baselines = {}
for entity_id in data['entity_id'].unique():
    entity_data = data[data['entity_id'] == entity_id]
    spline = UnivariateSpline(entity_data['days_since_start'], entity_data['sales'], s=100)
    baselines[entity_id] = spline

# Compute residuals
data['baseline'] = data.apply(lambda row: baselines[row['entity_id']](row['days_since_start']), axis=1)
data['residual'] = data['sales'] - data['baseline']

# Train on residuals
model.fit(X, data['residual'])

# Predict
test['baseline'] = test.apply(lambda row: baselines[row['entity_id']](row['days_since_start']), axis=1)
test['pred_residual'] = model.predict(X_test)
test['pred_sales'] = test['baseline'] + test['pred_residual']
```
