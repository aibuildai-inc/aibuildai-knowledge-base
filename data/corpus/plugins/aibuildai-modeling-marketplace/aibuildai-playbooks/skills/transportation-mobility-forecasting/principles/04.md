## Principle 4: Decompose Time into Multiple Granularities and Encode Numerically

*Consensus: 4/5 regression solutions (NYC, Walmart, Geotab, Restaurant)*

Extract multiple temporal features from timestamps: hour, day_of_week, day_of_month, month, day_of_year, and as.numeric(date) (days since epoch). Encode categorical time features (weekday, month) as numeric ordinals (1-7, 1-12) rather than one-hot to reduce feature explosion and allow tree models to blend similar times.

**Why this matters:** Mobility patterns have nested periodicities: hourly (rush hour), daily (weekday vs weekend), monthly (holidays, weather seasons), and long-term trends. Numeric encoding lets tree models group similar times (Saturday and Sunday; June and July) automatically, avoiding combinatorial explosion from one-hot encoding while still capturing patterns. The as.numeric(date) trend feature captures drift: items phased in/out, traffic volume changes over years.

**When to use:** Always extract hour, weekday, is_weekend. Add month, day_of_month if there are seasonal or monthly billing patterns. Include as.numeric(date) to capture trends and abrupt changes (store starts/stops selling an item). Use is_holiday flags for known events (Black Friday, Christmas).

**When NOT to use:** Do not one-hot encode high-cardinality time features (365 days, 8760 hours/year) unless you have massive data. Do not use numeric encoding if order is meaningless (e.g., category IDs) or if linear models need exact day-of-week effects (then use one-hot).

**How to reason about it:**
Start with hour (0-23), day_of_week (0-6 or 1-7), is_weekend (binary). Add month (1-12) and day_of_month (1-31) if you see monthly patterns in EDA. Always include as.numeric(date)—a days-since-start counter—to catch trends and date-specific anomalies. Mark major holidays explicitly. Validate that tree models can split on these numeric features meaningfully.

import pandas as pd

data['hour'] = data['timestamp'].dt.hour
data['day_of_week'] = data['timestamp'].dt.dayofweek  # 0=Monday
data['is_weekend'] = data['day_of_week'].isin([5, 6]).astype(int)
data['month'] = data['timestamp'].dt.month
data['day_of_month'] = data['timestamp'].dt.day
data['day_of_year'] = data['timestamp'].dt.dayofyear
data['days_since_start'] = (data['timestamp'] - pd.Timestamp('2012-01-01')).dt.days
