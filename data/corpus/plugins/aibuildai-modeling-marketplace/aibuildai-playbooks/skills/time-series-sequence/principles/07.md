## Principle 7: Use Target Encoding Carefully to Avoid Leakage

*Consensus: Liverpool 11th credited target encoding as a major boost. Jane Street 1st used supervised autoencoder. But Liverpool also had examples of leakage failures from bad target encoding.*

Target encoding replaces categorical values with the mean target for that category, creating a powerful numeric feature. For time series, this MUST respect temporal order: use only past data to encode values used in future predictions. Add smoothing to prevent overfitting.

**Why this matters:** Global target encoding (using all data) leaks future information in time series—you're telling the model what the average outcome is for a category, including outcomes that happen after your prediction point. This creates massive overfitting. Properly done temporal target encoding captures legitimate patterns (e.g., item X always has higher sales).

**When to use:** When you have high-cardinality categoricals (store_id, item_id) in forecasting tasks. Particularly effective in GBDT models. Combine with other encodings (frequency, embedding). Use cross-validation folds to create out-of-fold target encodings that don't leak within CV.

**When NOT to use:** Skip if categories have very few samples (target encoding becomes noisy). Don't use in signal classification where the category-target relationship isn't meaningful. Avoid if you can use embeddings (neural networks) instead. Never use global target encoding in time series—it WILL leak.

**How to reason about it:**
For each prediction point T, target encoding must use only data from before T. Implementation: sort by time, use expanding window to compute running average. Add smoothing: blend category mean with global mean based on sample size. Validate: check that your target encoding code never looks forward in time. Test: if you shuffle time, does target encoding change? It shouldn't (it should only use local info).

```python
# Temporal target encoding with smoothing (Liverpool pattern)
from category_encoders import TargetEncoder

def temporal_target_encode(df, cat_col, target_col, smoothing=10):
    # Sort by time to ensure no leakage
    df = df.sort_values('time')
    
    # Expanding mean (only past data)
    df[f'{cat_col}_target_enc'] = (
        df.groupby(cat_col)[target_col]
        .transform(lambda x: x.shift(1).expanding().mean())
    )
    
    # Smooth with global mean
    global_mean = df[target_col].mean()
    counts = df.groupby(cat_col).cumcount()
    df[f'{cat_col}_target_enc'] = (
        (df[f'{cat_col}_target_enc'] * counts + global_mean * smoothing) /
        (counts + smoothing)
    )
    
    return df
```
