## Principle 5: Choose Model Architecture Based on Data Structure and Forecasting Horizon

*Consensus: GBDT dominates tabular forecasting (M5, Favorita), RNNs dominate sequence modeling (Sleep), CNNs excel at signal patterns (Liverpool). Top solutions often ensemble across architectures.*

Gradient boosting (LightGBM, XGBoost, CatBoost) wins when data is tabular with engineered features and short horizons. RNNs (LSTM, GRU) win for sequence-to-sequence and long dependencies. CNNs (1D conv, WaveNet, U-Net) win for signal classification with spatial patterns. Transformers win when you have enough data and need long-range dependencies.

**Why this matters:** Wrong architecture wastes compute and underperforms. GBDT can't learn from raw high-frequency signals (no spatial inductive bias). LSTMs overfit on small tabular data and train slowly. CNNs miss long-range dependencies. Each architecture has a sweet spot—matching it to your data structure is a 5-10% performance gain.

**When to use:** GBDT: tabular data, strong feature engineering, short-term patterns, <100K samples. LSTM/GRU: variable-length sequences, need to model order, autoregressive forecasting. 1D CNN/WaveNet: fixed-length signals, local patterns matter, large datasets. Transformers: very large datasets, long-range dependencies, attention over sequence. U-Net: event detection in long sequences with precise localization.

**When NOT to use:** Don't use LSTM if you can express all context as fixed features for GBDT—it's usually faster and better. Don't use GBDT on raw time series without feature engineering. Don't use Transformers without enough data (they overfit on <50K samples). Don't use CNNs if sequence order doesn't matter locally.

**How to reason about it:**
Decision: (1) Is data tabular with time index? → Try GBDT with lag/rolling features first. (2) Is data raw sequences (sensor readings, text)? → Try RNN or CNN. (3) Do you need to predict multi-step ahead with autoregression? → RNN or Seq2Seq. (4) Do patterns occur at multiple scales/frequencies? → CNN with multiple kernel sizes or WaveNet. (5) Are long-range dependencies critical and you have >100K samples? → Transformer. Always ensemble GBDT + neural network—they capture different patterns.
