## Principle 4: Apply Domain-Specific Preprocessing Before Feature Engineering

*Consensus: Signal tasks (Liverpool 1st, Sleep 1st) all preprocess heavily. Market tasks do neutralization. Forecasting tasks do minimal preprocessing.*

Signal classification requires noise removal, drift correction, and frequency filtering. Market prediction needs price normalization and cross-sectional neutralization. Forecasting tasks typically just handle missing values. Preprocessing must be done correctly to avoid leakage and information loss.

**Why this matters:** Raw sensor signals contain device-specific noise, 50Hz electrical interference, baseline drift—none of which generalize to test. Removing them reveals the true signal. Markets have systematic factors that obscure stock-specific alpha. Bad preprocessing destroys signal or leaks information; good preprocessing is often worth 0.01+ on LB.

**When to use:** Signal tasks: always filter noise, check for drift, apply frequency-domain analysis. Market tasks: neutralize returns against market/sector, rank-transform features. Forecasting: handle missing values, detect outliers, log-transform heavy-tailed targets. Check: does test data come from same device/market/distribution as train?

**When NOT to use:** Don't blindly copy preprocessing from other competitions. Liverpool needed 50Hz notch filter (electrical noise in lab equipment); your signal might not. Don't remove 'outliers' in forecasting tasks—they might be real events. Don't normalize away the signal you're trying to predict.

**How to reason about it:**
Ask: what non-generalizable artifacts exist in train that won't be in test? For signals: plot FFT, check for frequency peaks that are device noise. For markets: is there a common factor (market return) driving all stocks? For forecasting: plot train vs validation distributions—are scales/means stable? Preprocessing should remove only what's known to be noise/artifact, never remove variance in the target itself. Validate: does preprocessing improve out-of-sample performance?

```python
# Signal: Remove 50Hz noise + drift (Liverpool pattern)
from scipy import signal

# Auto-tune notch filter to remove electrical noise
def remove_50hz_noise(sig, fs=10000):
    fft = np.fft.fft(sig)
    freqs = np.fft.fftfreq(len(sig), 1/fs)
    # Find peak near 50Hz
    peak_freq = freqs[np.argmax(np.abs(fft[(freqs > 49) & (freqs < 51)]))] 
    # Apply notch filter
    b, a = signal.iirnotch(peak_freq, Q=250, fs=fs)
    return signal.filtfilt(b, a, sig)

# Market: Cross-sectional neutralization (Optiver/Jane Street)
df['target_neutral'] = df['target'] - (
    df.groupby('time')['target'].transform('mean') * df['stock_weight']
).sum() / df['stock_weight'].sum()
```
