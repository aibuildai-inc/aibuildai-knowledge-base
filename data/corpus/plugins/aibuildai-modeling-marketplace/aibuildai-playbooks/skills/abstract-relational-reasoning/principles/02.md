## Principle 2: Represent Roles and Relations, Not Incidental Values

*Consensus: Explicit canonicalization or relational representation appeared in at least 8/12 ARC writeups and 14/16 substantive Foursquare solution writeups.*

Convert raw values into representations that expose stable roles: objects, masks, tiles, relative positions, and color ranks for grids; normalized multilingual fields, geographic displacement, field-wise similarities, and embeddings for records. Preserve raw values alongside canonical forms whenever normalization could erase identity evidence.

**Why this matters:** The same abstract role can be expressed with different colors, scripts, spellings, coordinates, or missing fields. Canonicalization reduces nuisance variation, while relational features let a learner express rules such as “copy the rare object” or “same normalized name at a plausible distance” rather than memorize literal values.

**When to use:** Use role-based encodings when demonstrations vary in superficial symbols, when test records contain unseen tokens or scripts, or when relations depend on relative rather than absolute attributes.

**When NOT to use:** Avoid canonicalization that destroys semantically meaningful distinctions—for example, when a particular color is an instruction token or when transliteration merges different business names. In those cases, retain parallel raw, normalized, and role-based views and let validation determine their use.

**How to reason about it:**
For every field or symbol, ask whether its absolute identity, within-instance rank, geometry, or relationship to another value is likely causal. Build multiple views only when they encode different invariances; redundant normalizations increase cost without expanding the hypothesis class.

```python
def build_views(x):
    return {
        "raw": x,
        "canonical": canonicalize_by_role(x),       # e.g. frequency/object role
        "structure": extract_objects_or_fields(x), # domain-specific units
        "relations": pairwise_or_spatial_features(x),
    }
```
