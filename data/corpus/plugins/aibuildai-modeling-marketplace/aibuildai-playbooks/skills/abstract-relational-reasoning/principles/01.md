## Principle 1: Identify the Relational Regime Before Choosing the Solver

*Consensus: 2/2 competitions exhibited distinct methodological clusters; nearly every substantive writeup followed the cluster implied by its data regime.*

First determine whether the unknown relation is a task-specific transformation inferred from a few demonstrations, or a shared equivalence relation learned from many labeled entities. This choice should govern the representation, learner, validation unit, and inference procedure.

**Why this matters:** Few-shot transformation problems cannot support a high-capacity model trained independently per task; they need strong compositional priors and consistency across demonstrations. Large entity-resolution problems have enough supervision for learned retrieval and pair classification, but their quadratic pair space and transitive output structure make pure end-to-end classification impractical.

**When to use:** Use the few-shot program-induction branch when each test case supplies its own small support set and the rule changes between cases. Use the learned retrieval-and-linking branch when training and test entities differ but the semantics of matching remain stable across the dataset.

**When NOT to use:** Do not force a symbolic search onto a relation whose primitive vocabulary cannot be bounded, and do not train a generic neural predictor per task when only a few demonstrations exist. Hybridize if there is abundant meta-training data but each test task still introduces a new rule.

**How to reason about it:**
Ask: (1) Does the rule itself change from one test case to another? (2) How many independent labeled relation instances are available? (3) Is the output a transformed object, an edge, or an equivalence set? If the rule changes and support is tiny, search over reusable programs. If the rule is stable and labels are abundant, learn retrieval and verification functions, then reason over the resulting graph.

def choose_regime(meta):
    # Customize thresholds to the competition.
    if meta.rule_changes_per_case and meta.examples_per_case <= meta.few_shot_limit:
        return "program_induction"
