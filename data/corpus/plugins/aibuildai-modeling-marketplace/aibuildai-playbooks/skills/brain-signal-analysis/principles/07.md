## Principle 7: Reduce Overfitting with Extreme Regularization When Sample Size Is Tiny

*Consensus: The seizure prediction winner (4 seizures per dog) used a heavily regularized LS ensemble; the Melbourne seizure prediction winner used subject-specific XGB, SVM, KNN, and L2 logistic regression on hand-crafted features; larger datasets such as Parkinson's FOG used deep learning with dropout/augmentation.*

Brain signal datasets often have very few independent events (e.g., 4 seizures per patient, each split into 6 ten-minute clips = 24 samples, but they are autocorrelated). Standard deep learning overfits catastrophically. Regularization strategies: ensemble of simple models, KNN with hand-crafted features, heavy dropout, small model capacity, strong augmentation.

**Why this matters:** The winning seizure prediction solution used 'super regulated iterative LS Ensemble' with 900-1500 hand-crafted features (FFT energy bands, channel correlations, sqrt/pow transforms) because with only 4 seizures per dog, tree-based or deep learning models would memorize the training seizures. The effective sample size is the number of independent events, not rows. For larger datasets with thousands of independent samples, standard deep learning + augmentation suffices. For tiny datasets: feature engineering + regularized linear models or KNN often beats deep learning.

**When to use:** Use extreme regularization (KNN, linear models, feature engineering) when: (1) you have <10 independent events per subject (e.g., <10 seizures), (2) events are temporally clustered (all 6 clips from one seizure are correlated), (3) simple CV suggests deep learning is overfitting (train loss << val loss, high variance across folds). For larger datasets (>1000 independent samples): use standard deep learning with dropout 0.1-0.5, heavy augmentation, and ensemble.

**When NOT to use:** Do NOT abandon deep learning if you have >1000 independent samples (as in FOG). Do NOT use KNN if your signal is high-dimensional and raw (curse of dimensionality)—you need feature extraction first. Do NOT use shallow models if pretrained ImageNet weights are available (2D spectrograms)—the pretraining is a form of regularization.

**How to reason about it:**
Count independent events: how many seizures/FOG episodes/unique annotations per patient? If <10, deep learning is risky. Try: (1) hand-crafted features (FFT energy in bands, correlation between channels, statistical moments) + regularized linear/ensemble model; (2) KNN with DTW distance on aligned segments; (3) very small deep model (1-2 layers, heavy dropout 0.5). If >100 independent events: standard deep learning is fine, use dropout 0.1-0.2, augmentation, cross-validation. If 10-100: try both, compare CV variance.

# Extreme regularization: hand-crafted features + Ridge (tiny dataset)
from scipy.fft import rfft
from sklearn.linear_model import RidgeCV

def extract_features(eeg):
    features = []
    # Energy in frequency bands (0-4Hz, 4-8Hz, 8-12Hz, 12-20Hz) per channel
    for ch in range(eeg.shape[0]):
        fft = np.abs(rfft(eeg[ch]))
        features.extend([fft[0:4].sum(), fft[4:8].sum(), fft[8:12].sum(), fft[12:20].sum()])
    # Correlation between channels
    for i in range(eeg.shape[0]):
        for j in range(i+1, eeg.shape[0]):
            features.append(np.corrcoef(eeg[i], eeg[j])[0, 1])
    return np.array(features)
