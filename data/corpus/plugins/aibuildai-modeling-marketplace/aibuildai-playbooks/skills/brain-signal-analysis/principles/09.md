## Principle 9: Use Positional Bias or Relative Position Encoding for Long-Range Temporal Dependencies

*Consensus: 2/5 transformer solutions bias attention toward local context; FOG 1st place used learnable positional encoding with random roll augmentation; FOG 6th place biased attention with distance masks.*

Standard transformer self-attention is permutation-invariant and struggles with long dependencies in time series. Learned absolute positional encoding (add position embedding to input) helps but can overfit to specific positions. Relative position encoding (bias attention by distance between positions) or local attention masks (restrict attention to nearby timesteps) inject temporal inductive bias.

**Why this matters:** A FOG event spans hundreds of timesteps; the model must learn that timestep t is more related to t±5 than to t±500. Standard self-attention treats all positions equally. A distance-based bias mask (attention_weight *= (1 - |i-j|/L)^2) upweights nearby positions, helping the model predict long events (Walking, seizures). Another approach: learnable positional encoding augmented by random rolling during training (shift the position encoding by ±L timesteps) prevents overfitting to absolute positions.

**When to use:** Use local attention bias or relative position encoding when: (1) your task has strong temporal locality (events span 10-100 timesteps, predictions at t depend most on t±10), (2) you use transformers on long sequences (>500 timesteps), (3) standard positional encoding overfits (CV drops when you permute test sequences). Use random positional encoding roll augmentation if absolute positions are arbitrary (starting position of a recording is random).

**When NOT to use:** Do NOT bias attention toward local positions if your task requires long-range dependencies (e.g., an event whose label depends on a pattern far earlier in the window—use full attention). Do NOT use learned positional encoding without augmentation if your test sequences can start at arbitrary offsets (the model will overfit to training offsets).

**How to reason about it:**
Ask: does my task have temporal locality (predictions at t depend most on nearby t±k)? IF yes: add a distance-based bias to attention scores or use local windowed attention (each position attends to ±W neighbors). IF no (long-range dependencies): use full self-attention with relative position encoding (T5-style) or rotary position encoding (RoPE). For data with arbitrary start positions: augment positional encoding by random rolling (shift by ±L) during training.

```python
# Distance-based attention bias (FOG 6th place)
def get_distance_mask(L, power=2):
    m = torch.zeros((L, L))
    for i in range(L):
        for j in range(L):
            if i != j:
                m[i, j] = (1 - abs(i - j) / L) ** power
            else:
                m[i, i] = 1.0
    return m

# In attention: scores = QK^T + distance_mask, then softmax

# Random positional encoding roll augmentation (FOG 1st place)
class FOGEncoder(nn.Module):
    def __init__(self):
        self.pos_encoding = nn.Parameter(torch.randn(1, seq_len, dim))
    
    def forward(self, x, training=False):
        if training:
            shift = torch.randint(-seq_len, 0, (batch_size,))
            pos_enc = torch.roll(self.pos_encoding.expand(batch_size, -1, -1), 
                                 shifts=shift.tolist(), dims=[1])
        else:
            pos_enc = self.pos_encoding.expand(batch_size, -1, -1)
        return x + pos_enc
```
