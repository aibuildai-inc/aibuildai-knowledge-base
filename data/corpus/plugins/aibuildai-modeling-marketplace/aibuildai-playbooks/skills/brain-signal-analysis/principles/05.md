## Principle 5: Augment Signals to Exploit Domain Symmetries and Regularize Small Datasets

*Consensus: Several Parkinson's FOG solutions augmented accelerometer data (time stretch, Gaussian noise, pitch shift, wave scaling, random low-pass filtering, positional-encoding roll); one applied heavy stretching, cropping, ablation and accumulated noise to every sequence. Diversity in augmentation across models improves ensemble.*

Wearable and brain signal datasets are small (few subjects, few events), so overfitting is severe. Augmentations that keep the label valid generate useful new samples; augmentations that change what the label describes add noise.

**Why this matters:** Gait speed and step force vary between people and between days. Time stretch (the FOG 6th-place solution used rates 0.8 to 1.25) mimics faster and slower walking, wave scaling (multiplying the signal by 0.75 to 1.5) makes the model insensitive to sensor gain and body size, and small Gaussian noise stops the model from memorizing exact waveforms. Cropping and rolling the positional encoding teach the model that an event can start anywhere in the window. These transforms are cheap and add diversity when different ensemble members use different augmentation sets.

**When to use:** Use time stretch, wave scaling, and Gaussian noise for accelerometer and other movement sensors. Use random crops or a random roll of the positional encoding when the model sees fixed-length windows cut from long recordings. For any other transform, including transforms of EEG channels, first check that the label stays true after the transform, then keep it only if CV improves.

**When NOT to use:** Do NOT use a stretch so strong that it changes the event the label describes: a very fast walk is not a normal walk. Do NOT apply image augmentations (rotation, translation) to spectrograms if they break time/frequency alignment. Do NOT add an augmentation because it helped on another signal type—test it on your task.

**How to reason about it:**
For each augmentation, ask: does this transform preserve the label? Time stretch: IF the label depends on rhythm or speed only within a normal range → a mild stretch is OK. IF the label is defined by an absolute speed → NOT OK. Scaling: IF sensor gain or body size varies between subjects → OK. Crop or roll: IF the label applies to every time step or to the whole window → OK. Diversity: train different models with different augmentation sets to diversify the ensemble.
