## Principle 5: Handle Variable-Length Sequences with Masking, Not Padding Alone

*Consensus: 5/5 sequence-based competitions required proper masking. ASL signs 1st place: 'Handling variable-length input correctly was very crucial for train-test consistency.' ASL fingerspelling used variable-length TFLite inference.*

For variable-length sequences, apply masking to all operations (convolution, batch norm, pooling, attention) during training to match inference behavior, rather than treating padded positions as valid data.

**Why this matters:** If the model trains on padded sequences but doesn't mask operations, it learns to use the padding as signal (e.g., BatchNorm statistics include pad values, attention attends to pads). At inference on variable-length inputs, this mismatch degrades performance. Proper masking ensures train-test consistency and speeds up inference (no need to pad short sequences to max_len). ASL 1st place: training with masking allowed fp16 inference without performance drop.

**When to use:** When sequences have variable length. Implement masking at: (1) input layer (tf.keras.layers.Masking or padding_mask in PyTorch), (2) all intermediate operations (BatchNorm, LayerNorm, GlobalAveragePooling must respect mask), (3) attention mechanisms (key_padding_mask). For 1D CNN with causal padding, maintain mask indices through padding. At inference, feed variable-length inputs directly without padding to max_len (where possible under constraints).

**When NOT to use:** If all sequences are the same length (rare). If the competition format requires fixed-size inputs, still use masking during training to prevent the model from learning padding artifacts, even if inference is padded. Do not use masking as a substitute for handling missing data within the sequence (e.g., missing landmarks) — that needs imputation or zero-filling first, then masking applies to sequence length.

**How to reason about it:**
Check if your data has variable-length sequences. If yes: (1) During training, batch sequences by padding to the batch's max length (or a fixed max_len), and create a mask indicating valid positions. (2) Pass the mask through all layers that aggregate across the sequence dimension (convolution with padding, pooling, normalization, attention). (3) At inference, if constraints allow, feed sequences at their true length without padding. If you must pad for inference (TFLite constraints), ensure the model was trained with masking so padding is ignored. Verify train-test consistency: does removing masking during training hurt inference CV?

```python
# TensorFlow: Masking layer propagates mask to downstream ops
inp = tf.keras.Input((max_len, channels))
x = tf.keras.layers.Masking(mask_value=PAD_VALUE)(inp)
x = Conv1D(dim, kernel_size, padding='causal')(x)  # Causal preserves mask indices
x = BatchNormalization()(x)  # Respects mask if propagated
x = GlobalAveragePooling1D()(x)  # Averages only non-masked positions

# PyTorch Transformer: Explicit key_padding_mask
mask = (src == PAD_TOKEN)  # Shape: (batch, seq_len)
output = transformer_encoder(src, src_key_padding_mask=mask)
```
