## Principle 1: Choose Architecture Family Based on Input Modality and Task Structure

*Consensus: All top solutions matched architecture to data type. 7/7 competitions showed clear modality-architecture patterns.*

The input representation (raw video, pre-extracted features, landmarks/pose, or hybrid) determines the foundational architecture choice before any optimization begins.

**Why this matters:** Different data types encode temporal information differently: video has dense pixel correlations across frames, landmarks are sparse structured coordinates, and pre-extracted features are compact representations. Each requires different inductive biases. A CNN excels at local spatiotemporal patterns in video; 1D convolutions handle sequential landmark data efficiently; transformers capture long-range dependencies in feature sequences.

**When to use:** Apply at the start of architecture design. For landmark/pose data (ASL, MABe): 1D CNN or Conv1D+Transformer hybrid. For raw video: 2D CNN + temporal modeling (3D conv, TSM, or separate temporal module). For pre-extracted features (YouTube8M): frame-level or segment-level models with temporal aggregation. For hybrid (video + tracking): encode each modality separately then fuse.

**When NOT to use:** Do not force video models onto landmark data or vice versa. Top ASL solutions that tried 2D CNNs on landmarks (treating them as images) underperformed 1D approaches by ~0.05-0.10. Similarly, pure transformers without convolutional inductive bias struggled on landmark data where strong inter-frame correlation exists (1st place ASL signs: 1D CNN outperformed pure transformer).

**How to reason about it:**
Ask: What is my input? (1) Landmarks/pose → structured sparse coordinates, strong local temporal correlation → 1D CNN backbone, optionally + transformer for global context. (2) Raw video → dense pixels, spatiotemporal patterns → 2D CNN + temporal (3D conv / TSM / temporal transformer). (3) Pre-extracted features → compact representations → aggregation models (NetVLAD, LSTM, transformer). (4) Hybrid (video + tracking) → separate encoders + fusion. Then ask: Is this classification (clip-level head), sequence generation (decoder), or temporal localization (segment proposals)? Match head to task.

```python
# ASL landmark classification: 1D CNN + Transformer
x = Conv1DBlock(dim, kernel_size=17)(x)  # Local patterns
x = Conv1DBlock(dim, kernel_size=17)(x)
x = TransformerBlock(dim, expand=2)(x)   # Global context

# Raw video: 2D CNN + 3D temporal
frames = extract_frames(video, center_frame, window=18)
x = CNN2D(frames)  # Spatial per frame
x = Conv3D(x)      # Temporal aggregation

# YouTube8M features: Frame-level → segment aggregation
x = FrameLevelLSTM(features)
segments = NetVLAD(x)  # Aggregate to segments
```
