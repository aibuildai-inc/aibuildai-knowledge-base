## Principle 6: Tune Post-Processing Thresholds on Validation Data

*Consensus: 5/5 competitions - every top solution tuned confidence/NMS/mask thresholds, often +0.01-0.03 gain*

After training, sweep confidence threshold, NMS IoU threshold, and mask binarization threshold on a validation set to maximize the competition metric. Do not use defaults.

**Why this matters:** Models output continuous scores/masks, but evaluation requires discrete predictions. Default thresholds (0.5 for confidence, 0.5 for NMS, 0.5 for mask) are arbitrary and almost never optimal for your metric/dataset. Fashion 2019 1st place: tuning 4 thresholds improved LB from 0.219 to 0.300 (+37% relative) with zero model changes. The metric you optimize (mAP across IoU thresholds, Dice, etc.) has a specific threshold sweet spot.

**When to use:** Always, after final model training. Critical when: metric is IoU-based (Dice/mAP), class imbalance is high (rare classes may need lower thresholds), or when false positives/negatives have asymmetric cost.

**When NOT to use:** Skip only if you have no validation set. Do not tune on the leaderboard - it overfits to public test set. Do not tune before your model converges - thresholds shift as the model improves.

**How to reason about it:**
1. Identify tunable thresholds:
   - Mask R-CNN: score_thr (confidence), nms_iou_thr, mask_thr_binary, max_per_img
   - U-Net: mask_thr_binary (pixelwise cutoff)
2. Create validation set matching test distribution (stratified by class for multi-class)
3. Grid search or Bayesian optimization:
   - Start coarse: score_thr ∈ [0.3, 0.5, 0.7], nms ∈ [0.3, 0.5, 0.7], mask ∈ [0.4, 0.5, 0.6]
   - Refine around best: if best was 0.5, try [0.45, 0.48, 0.5, 0.52, 0.55]
4. For rare classes, consider per-class thresholds (Fashion 2020: 294×46 attribute thresholds)
5. Common findings: NMS often wants to be looser (0.3-0.4) than default 0.5; mask threshold often 0.45-0.5.

```python
# Threshold tuning grid search
from sklearn.model_selection import ParameterGrid

param_grid = {
    'score_thr': [0.3, 0.4, 0.5, 0.6],
    'nms_iou_thr': [0.25, 0.3, 0.35, 0.4],
    'mask_thr_binary': [0.4, 0.45, 0.5, 0.55],
    'max_per_img': [50, 100, 150, 200]
}

best_score = 0
best_params = None

for params in ParameterGrid(param_grid):
    preds = predict_with_params(val_images, model, **params)
    score = compute_metric(preds, val_labels)  # your competition metric
    if score > best_score:
        best_score = score
        best_params = params

print(f"Best params: {best_params}, score: {best_score}")
```
