## Principle 4: Combine BCE and Dice Loss for Mask Prediction

*Consensus: 4/5 top Carvana solutions used BCE+Dice; Fashion winners used focal loss (BCE variant)*

For binary masks in U-Net, use the sum of binary cross-entropy loss and Dice loss. For multi-class detection-based models, use focal loss for classification and optionally Lovasz-hinge for masks.

**Why this matters:** BCE optimizes pixel-wise accuracy but ignores global mask shape, leading to fragmented predictions on hard examples. Dice loss directly optimizes the evaluation metric (IoU-based) and penalizes disconnected regions, encouraging coherent masks. Combining both gives pixel-level supervision (BCE) and shape-level supervision (Dice). For imbalanced multi-class, focal loss down-weights easy examples, preventing the model from ignoring rare classes.

**When to use:** BCE+Dice: binary or semantic segmentation with U-Net (Carvana 3rd/5th place both used this, +0.0001-0.0002 over Dice alone). Focal loss: multi-class detection with class imbalance >10:1 (Fashion 2020 winner: +0.012 from focal loss on attributes). Lovasz-hinge: when IoU metric is directly optimized (Fashion 16th used symmetric Lovasz).

**When NOT to use:** Do not use Dice alone - it is unstable when masks are very small (division by near-zero). Do not use only BCE for evaluation metrics based on IoU/Dice - the loss-metric mismatch hurts. Avoid focal loss if classes are balanced - the down-weighting adds no value and complicates tuning.

**How to reason about it:**
1. Check class balance: if most examples are easy negatives, use focal loss (gamma=2 is standard). If balanced, use BCE.
2. Check metric: if IoU/Dice-based, add Dice loss term (weight 0.5-1.0 relative to BCE).
3. For Mask R-CNN: classification head uses focal or CE; mask head uses BCE (or Lovasz if you reimplement).
4. Monitor both loss components - if Dice dominates early, reduce its weight.

```python
# Combined loss for U-Net
def bce_dice_loss(pred, target):
    bce = F.binary_cross_entropy_with_logits(pred, target)
    
    pred_sigmoid = torch.sigmoid(pred)
    intersection = (pred_sigmoid * target).sum(dim=(2,3))
    union = pred_sigmoid.sum(dim=(2,3)) + target.sum(dim=(2,3))
    dice = 1 - (2 * intersection + 1) / (union + 1)  # +1 for stability
    
    return bce + dice.mean()

# Focal loss for detection
class FocalLoss(nn.Module):
    def __init__(self, gamma=2, alpha=0.25):
        self.gamma = gamma
        self.alpha = alpha
    
    def forward(self, pred, target):
        ce = F.cross_entropy(pred, target, reduction='none')
        p_t = torch.exp(-ce)
        focal = self.alpha * (1 - p_t) ** self.gamma * ce
        return focal.mean()
```
