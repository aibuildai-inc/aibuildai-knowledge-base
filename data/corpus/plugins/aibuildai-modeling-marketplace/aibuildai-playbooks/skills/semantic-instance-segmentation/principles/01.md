## Principle 1: Choose Architecture Family by Problem Complexity

*Consensus: 5/5 competitions show clear architecture clustering by task type*

Use encoder-decoder networks (U-Net variants) for binary or simple semantic segmentation; use detection-based two-stage approaches (Mask R-CNN family) for multi-class instance segmentation with significant overlap.

**Why this matters:** Encoder-decoder architectures excel at pixel-level precision for single-class or non-overlapping scenarios because they preserve spatial information through skip connections. Detection-based approaches handle overlapping instances better because they explicitly separate detection (where) from segmentation (what shape), allowing the model to reason about each instance independently.

**When to use:** U-Net when: binary segmentation, clean backgrounds, minimal overlap (Carvana: 0.997+ scores with modified U-Net). Mask R-CNN family when: multiple classes (>10), significant instance overlap, hierarchical classes, or attribute prediction needed (Fashion/Open Images: all top-3 used HTC or Cascade Mask R-CNN).

**When NOT to use:** Do not use U-Net for datasets with heavy instance overlap - it cannot naturally separate instances. Do not use Mask R-CNN for simple binary tasks where a lighter U-Net achieves the same quality 10x faster. For tracking+segmentation tasks (NFL), neither architecture alone suffices - combine detection with tracking algorithms.

**How to reason about it:**
Examine your data:
1. How many classes? (<5 favors U-Net, >20 favors detection-based)
2. What is the typical instance overlap? (None/rare → U-Net, frequent → Mask R-CNN)
3. Do you need attributes or hierarchical predictions? (Yes → must use detection-based with extra heads)
4. Is temporal tracking required? (Yes → detector + tracker pipeline)

If the answer to #2-4 is no and #1 is low, start with U-Net; otherwise use Mask R-CNN variants.

# U-Net path (binary/simple)
model = UNet(
    encoder='resnet50',
    encoder_weights='imagenet',
    # Add dilated convolutions in bottleneck for wider receptive field
    decoder_use_batchnorm=True,
    decoder_attention_type='scse'
)

# Mask R-CNN path (multi-class instance)
from mmdet.models import build_detector
model = build_detector(dict(
    type='HybridTaskCascade',  # or 'CascadeMaskRCNN'
    backbone=dict(
        type='ResNeXt',
        depth=101,
        groups=64,
        base_width=4,
        dcn=dict(type='DCNv2', deform_groups=1, fallback_on_stride=False),
        # ... FPN, RPN, roi heads
    )
))
