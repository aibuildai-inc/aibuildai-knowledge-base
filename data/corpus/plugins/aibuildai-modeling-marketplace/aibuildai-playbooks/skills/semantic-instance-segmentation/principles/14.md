## Principle 14: Use Pretrained Weights and Fine-Tune All Layers

*Consensus: 5/5 competitions - every top solution started from COCO or ImageNet pretrained weights*

Initialize encoder/backbone with ImageNet weights (for U-Net) or full model with COCO weights (for Mask R-CNN). Fine-tune all layers with small learning rate, not just the head.

**Why this matters:** Pretraining provides low-level features (edges, textures) from ImageNet and mid/high-level object understanding from COCO. This dramatically reduces data requirements and training time. Fine-tuning all layers (not freezing backbone) adapts these features to your domain specifics (Carvana: car-specific edges, Fashion: fabric textures). Carvana 5th place: ResNet-50 pretrained on ImageNet, fine-tuned all layers, reached 0.997. Fashion 1st: HTC pretrained on COCO, fine-tuned 20 epochs, reached 0.336.

**When to use:** Always when pretrained weights are available for your architecture. Especially when: dataset is <50k images, images are natural photos (ImageNet transfer works), or task overlaps with COCO classes (person, car, clothing → Fashion/Carvana).

**When NOT to use:** Skip pretraining only if: (1) domain is radically different from natural images (medical imaging, satellite) AND ImageNet hurts, (2) architecture is custom and no pretrained weights exist, or (3) you have >500k domain images and training from scratch is feasible. Even then, try pretraining first. Do not freeze backbone layers unless extremely compute-constrained - it caps performance.

**How to reason about it:**
1. For U-Net: load ImageNet encoder (ResNet, EfficientNet), initialize decoder randomly
2. For Mask R-CNN: load full COCO checkpoint (backbone + RPN + heads)
3. Fine-tune strategy:
   - If classes overlap with COCO (person, car, clothing): start LR ~0.01, drop to 0.001 after 10 epochs
   - If classes are new: start LR ~0.02-0.03 (Fashion 1st/2nd both used 0.02-0.03), warm up for 500 iterations
4. Unfreeze all layers, use differential LR (optional): backbone 0.1× head LR
5. For small datasets (<10k), use more aggressive LR schedule (drop earlier) to prevent overfitting
6. BN layers: keep frozen if batch size <4 (Carvana: batch=1, no BN) or use SyncBN/GroupNorm
