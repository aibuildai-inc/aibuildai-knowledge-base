## Principle 7: Rebalance Training Data for Severe Class Imbalance

*Consensus: 2/2 large-scale multi-class competitions (Open Images, Fashion) - top solutions rebalanced*

When class frequencies span >100x range, oversample rare classes and downsample dominant classes to equalize learning attention. Use per-epoch resampling with different random seeds.

**Why this matters:** Extreme imbalance (Open Images: 89k images for top class, 13 for rarest) causes the model to ignore rare classes - the loss is minimized by never predicting them. Rebalancing gives the model sufficient exposure to learn rare class features. Open Images 7th place: oversampled tail classes 10x, downsampled head to 6k, each epoch saw different subset → 450k images/epoch vs 1.7M original, but much better class coverage.

**When to use:** When class imbalance ratio (max_count / min_count) exceeds 100:1. Essential for long-tail datasets (Open Images, iNaturalist) and multi-class detection. Also use when rare classes are equally important (Open Images: all 300 classes weighted equally in metric).

**When NOT to use:** Skip if imbalance is moderate (<10:1) - focal loss handles this. Do not oversample if you have very few examples (<50) of rare class and they are outliers - you will overfit to noise. Do not use static oversampling (repeating same rare images) - always resample per epoch to see different frequent-class subsets.

**How to reason about it:**
1. Count instances per class, sort descending
2. Decide target distribution:
   - Option A: Equalize all classes to median count (conservative)
   - Option B: Tiered (Open Images approach):
     * Tail (count <150): oversample to 1500
     * Mid (150-6k): keep as-is  
     * Head (>6k): downsample to 6k
3. Per epoch: rare classes repeat, frequent classes randomly sample different subset
4. Combine with focal loss for synergy
5. Monitor per-class AP - if tail classes still zero, increase their target count

```python
# Rebalancing sampler (PyTorch)
from collections import Counter
import numpy as np

class BalancedSampler(Sampler):
    def __init__(self, dataset, target_counts):
        self.class_to_indices = defaultdict(list)
        for idx, label in enumerate(dataset.labels):
            self.class_to_indices[label].append(idx)
        
        self.samples = []
        for cls, target_count in target_counts.items():
            indices = self.class_to_indices[cls]
            if len(indices) < target_count:
                # Oversample with replacement
                sampled = np.random.choice(indices, target_count, replace=True)
            else:
                # Downsample without replacement  
                sampled = np.random.choice(indices, target_count, replace=False)
            self.samples.extend(sampled)
        
    def __iter__(self):
        np.random.shuffle(self.samples)  # Different order each epoch
        return iter(self.samples)
    
    def __len__(self):
        return len(self.samples)
```
