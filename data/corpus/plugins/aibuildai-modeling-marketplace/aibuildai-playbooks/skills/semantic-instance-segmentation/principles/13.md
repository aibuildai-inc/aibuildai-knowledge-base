## Principle 13: Build Ensemble Diversity Through Architecture and Scale, Not Just Seeds

*Consensus: 5/5 competitions - top ensembles used different backbones/architectures, not just different random seeds*

Create ensemble diversity by varying architecture (ResNet vs ResNeXt vs SpineNet), backbone depth (R50 vs R101), input resolution, and augmentation policy. Different random seeds alone provide minimal diversity.

**Why this matters:** Ensemble value comes from complementary errors - models that are wrong on different examples. Same architecture with different seeds makes similar mistakes (they have identical inductive bias). Different architectures have different receptive fields, feature hierarchies, and failure modes. Carvana 5th place regretted 'so-so ensemble without good diversity' from using only ResNet-50 at different scales. Open Images 7th: 3 models (X101, R101+DCN, X101+DCN) gave far more diversity than 3× X101.

**When to use:** Always for final ensemble if you have time/compute to train multiple models. Especially when: single model performance plateaus, different architectures are known to excel at different aspects (U-Net for boundaries, Mask R-CNN for overlapping instances), or competition metric averages across diverse scenarios.

**When NOT to use:** Skip ensemble if training one good model already exhausts your compute budget - better to invest in one strong model than three weak ones. Do not ensemble architectures that are too different (U-Net + Mask R-CNN) without careful alignment - their output formats differ. For tracking (NFL), ensembling detectors is fine but do NOT ensemble trackers (breaks temporal consistency).

**How to reason about it:**
1. Plan ensemble at start, not as afterthought - budget compute for 2-4 models
2. Vary in priority order:
   - Architecture family: U-Net vs Mask R-CNN (if both viable) OR backbone: ResNet vs ResNeXt vs EfficientNet
   - Depth: R50 vs R101 vs R152
   - Input resolution: 1280 vs 1600 vs 1920
   - Training: different augmentation strength, different data folds
   - Seed variation last (minimal diversity)
3. Train each model fully - a half-trained diverse model hurts more than helps
4. Merge strategies:
   - U-Net: pixel-wise average of softmax probabilities
   - Mask R-CNN: NMS ensemble at bbox level, then average matched masks (weighted by confidence)
5. Typical gains: 2 models (+0.01), 3-4 models (+0.015), 5+ models (diminishing)

```python
# Ensemble diverse models
models = [
    UNet(encoder='resnet50', input_size=1280),      # Baseline
    UNet(encoder='efficientnet-b4', input_size=1280), # Different backbone
    MaskRCNN(backbone='X101', input_size=1600),     # Different architecture + scale
]

# Ensemble for U-Net (pixel-wise)
predictions = []
for model in models:

    predictions.append(F.softmax(pred, dim=1))  # Calibrate before average

for model in models:

    all_boxes.append(boxes)
    all_masks.append(masks)
    all_scores.append(scores)

# Average masks for instances that matched

    matched_masks = [all_masks[i][j] for i, j in source_indices]
    ensemble_mask = np.mean(matched_masks, axis=0)
```
