## Principle 9: Use Hierarchical or Second-Level Models for Complex Attributes

*Consensus: 3/3 Fashion/Open Images solutions addressed hierarchy/attributes with separate strategies*

For datasets with class hierarchies (parent/child) or per-instance attributes, use separate prediction heads or second-level models rather than forcing everything into the primary mask prediction.

**Why this matters:** Attributes (fashion: color, pattern, sleeve length) and hierarchical classes (Open Images: Tortoise → Turtle → Reptile) have different prediction difficulty than masks. Attributes are often sparse and imbalanced; hierarchies need consistency (if you predict child, must predict parent). Mixing these into one loss confuses the model. Separating them allows: different loss functions (focal loss for attributes), different thresholds per attribute, post-hoc consistency enforcement (child → parent expansion), and second-level filtering (Fashion 3rd place: LGBM to predict if mask IoU >0.5, dropping low-quality predictions).

**When to use:** When dataset has: (1) per-instance attributes beyond class (Fashion: 46 attributes), (2) hierarchical classes where child should imply parent (Open Images: 275 leaf + 25 parent classes), or (3) a need to filter false positives based on prediction quality (Fashion 2020: regression model predicts AP per instance, keeps only top-1).

**When NOT to use:** Skip if classes are flat and no attributes. Do not add second-level model if your first-level model is undertrained - fix the base model first. For simple parent-child (e.g., only 2 levels), just expand predictions: if child detected, add parent with same mask.

**How to reason about it:**
1. Identify extra prediction tasks:
   - Attributes? Add a parallel classification head with focal loss (Fashion 2020)
   - Hierarchy? Decide between:
     * Train only on leaf classes, expand to parents at inference (Open Images 7th: predict 275 leaves, add 25 parents)
     * Train separate parent model and ensemble (Open Images 7th: also did this)
2. For second-level filtering:
   - Extract features: mask area, bbox aspect ratio, class confidence, mask mean/std, category ID
   - Label: IoU with ground truth (or metric-based AP)
   - Train LGBM/XGB to predict quality, threshold to remove low-quality
3. For attributes: tune per-attribute thresholds (Fashion 2020: 13k thresholds for 294 classes × 46 attributes)

```python
# Add attribute head to Mask R-CNN
class MaskRCNNWithAttributes(MaskRCNN):
    def __init__(self, num_classes, num_attributes):
        super().__init__(num_classes)
        # Separate head for attributes
        self.attribute_head = nn.Sequential(
            nn.Linear(1024, 512),
            nn.ReLU(),
            nn.Linear(512, num_attributes)  # Multi-label binary classification
        )
        self.attribute_loss = FocalLoss(gamma=2)  # For imbalance
    
    def forward(self, images, targets=None):
        features, boxes, masks = self.base_forward(images)
        
        # Attribute prediction per instance
        roi_features = self.roi_pool(features, boxes)
        attribute_logits = self.attribute_head(roi_features)
        
        if self.training:
            mask_loss = self.mask_loss(masks, targets['masks'])
            attr_loss = self.attribute_loss(attribute_logits, targets['attributes'])
            return {'mask_loss': mask_loss, 'attr_loss': attr_loss}
        else:
            return boxes, masks, torch.sigmoid(attribute_logits)
```
