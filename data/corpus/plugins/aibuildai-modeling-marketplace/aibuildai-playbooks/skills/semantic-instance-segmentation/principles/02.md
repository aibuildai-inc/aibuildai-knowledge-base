## Principle 2: Add Dilated Convolutions to Bottleneck for U-Net Architectures

*Consensus: 3/5 Carvana top solutions used dilated convolutions; 3rd place specifically ablated +0.0013 improvement*

When using U-Net, replace standard convolutions in the bottleneck (lowest-resolution layer) with dilated/atrous convolutions to expand receptive field without losing resolution.

**Why this matters:** At the bottleneck, the feature map resolution is lowest (e.g., 1/32 of input), so each pixel's receptive field must cover large spatial context to understand object boundaries. Dilated convolutions expand this field without adding parameters or reducing resolution, allowing the model to capture global structure (e.g., car roof curvature) while preserving fine details in the decoder.

**When to use:** Any U-Net architecture for objects with large spatial extent relative to bottleneck resolution. Especially effective when objects have smooth, predictable boundaries (cars, buildings, clothing items) where global shape context improves edge localization.

**When NOT to use:** Skip for very small objects where bottleneck resolution already captures the full object. Also skip if using detection-based architectures - they use RoI pooling instead of global bottleneck, so dilation applies differently (in backbone, not bottleneck).

**How to reason about it:**
Calculate bottleneck resolution: input_size / (2^num_downsamples). If typical object spans >50% of bottleneck spatial dimension, dilated convolutions will help. For Carvana at 1920x1280 input with 5 downsamples: 60x40 bottleneck, car spans ~entire width → high benefit. Stack 2-4 dilated conv layers with rates [1,2,4] or [2,4,8].

```python
# Modify U-Net bottleneck
class DilatedBottleneck(nn.Module):
    def __init__(self, channels):
        super().__init__()
        # Stack dilated convs with increasing rates
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1, dilation=1)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=2, dilation=2) 
        self.conv3 = nn.Conv2d(channels, channels, 3, padding=4, dilation=4)
        
    def forward(self, x):
        # Stacked (not parallel) performed better per Carvana 3rd place
        x = F.relu(self.conv1(x))
        x = F.relu(self.conv2(x))
        x = F.relu(self.conv3(x))
        return x
```
