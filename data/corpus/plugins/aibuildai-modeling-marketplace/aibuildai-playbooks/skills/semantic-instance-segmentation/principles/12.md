## Principle 12: Leverage Pseudo-Labeling When Test Set Is Large

*Consensus: 2/3 simple segmentation tasks (Carvana) where test set ~= train set size*

When the test set is comparable in size to the training set, generate pseudo-labels on test images using your trained model, then retrain including test images with pseudo-labels.

**Why this matters:** Test images expand your training distribution. If train/test come from the same distribution (Carvana: same studio, same cars, just different angles), pseudo-labels are often near-perfect and effectively double your training data. Carvana 3rd place explicitly credited pseudo-labeling as 'one of the best contributors to improving score.' The model learns test-specific patterns (e.g., lighting variations, specific car models) that were underrepresented in train.

**When to use:** When: (1) test set size ≥ 50% of train size (Carvana: 100k test vs 5k train), (2) train/test distributions are similar (same domain, e.g., same camera setup), (3) your baseline model is already strong (>95% accuracy) so pseudo-labels are mostly correct, (4) test labels are not available during training (so this is the only way to use test data).

**When NOT to use:** Skip if test set is small (<10% of train) - the gain is marginal. Do not use if train/test distributions differ significantly (domain shift) - pseudo-labels will be wrong and hurt. Do not pseudo-label if your model is weak (<90% accuracy) - you will amplify errors. Not applicable for most Kaggle competitions where test labels are never revealed. For multi-class with rare classes, pseudo-labeling may miss rare instances entirely.

**How to reason about it:**
1. Train initial model on training data to convergence
2. Generate predictions on test set, apply high confidence threshold (>0.9) or use model ensemble to reduce errors
3. Combine train (real labels) + test (pseudo-labels) into one dataset
4. Retrain from scratch or from checkpoint - options:
   - Simultaneous: train on mixed data each epoch (Carvana 3rd: used this)
   - Pretraining: train on train set, then fine-tune on test set pseudo-labels
5. Optionally iterate: re-generate pseudo-labels with new model, retrain
6. Validation: keep a held-out validation set from original training data (do NOT pseudo-label validation)

```python
# Pseudo-labeling pipeline
# Step 1: Generate pseudo-labels
model.eval()
pseudo_labels = []
for img in test_images:
    pred = model(img)
    # High confidence filtering
    if pred.confidence > 0.9:  # Or use ensemble agreement
        pseudo_labels.append((img, pred.mask))

# Step 2: Combine datasets
train_dataset = Dataset(train_images, train_labels)
pseudo_dataset = Dataset(*zip(*pseudo_labels))
combined_dataset = ConcatDataset([train_dataset, pseudo_dataset])

# Step 3: Retrain
model_v2 = Model()  # Fresh init or load checkpoint
train(model_v2, combined_dataset, epochs=20)

# Carvana 3rd: weighted loss to down-weight pseudo-labels slightly
```
