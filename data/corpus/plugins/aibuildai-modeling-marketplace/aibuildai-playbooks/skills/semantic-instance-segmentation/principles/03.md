## Principle 3: Use Multi-Scale Training and Inference as Default

*Consensus: 5/5 competitions - all top-3 solutions used multi-scale*

Train with random scale augmentation (e.g., short edge 600-1200px) and run inference at 2-4 different scales, averaging predictions.

**Why this matters:** Objects appear at vastly different scales even within one image (foreground vs background) and across images (close-up vs wide shot). Multi-scale training forces the model to learn scale-invariant features. Multi-scale inference combines the fine detail captured at high resolution with the global context captured at low resolution, significantly improving boundary accuracy and small object detection.

**When to use:** Always for instance segmentation. Critical when: objects vary >2x in typical size, small objects are scored equally to large ones, or boundaries matter more than coarse masks. Fashion 2019 winner: +0.01 from 3-scale TTA. Open Images 7th: ensemble 12 scale+flip combinations.

**When NOT to use:** Skip only if inference time is extremely constrained AND objects are consistently sized. Even then, multi-scale training should remain. For U-Net on fixed-camera scenarios (Carvana), 1-2 scales suffice; for detection-based with variable contexts, use 3+ scales.

**How to reason about it:**
1. Measure object size distribution in pixels - if std/mean > 0.5, multi-scale is critical.
2. For training: random scale keeps memory manageable - sample short edge from [0.5x, 1.5x] of base resolution each iteration.
3. For inference: pick 2-4 scales spanning the training range. Merge via:
   - U-Net: average softmax outputs per pixel
   - Mask R-CNN: NMS ensemble at proposal/bbox/mask level (7th place Open Images: NMS at each stage, then average masks)
4. Memory budget determines max scale - if limited, use 1 large scale + 1-2 smaller.
