## Principle 11: Implement Domain-Specific Post-Processing for Systematic Errors

*Consensus: 3/5 competitions - Carvana (antenna merging), Fashion (mask overlap removal), NFL (duplicate label handling)*

After model prediction, apply deterministic rules to fix recurring spatial patterns: merge disconnected components that should be one object, remove small artifacts, close holes, resolve overlapping masks from same class.

**Why this matters:** Models make systematic errors that are predictable from domain knowledge. Carvana: car antennas create small disconnected components above the main mask (model sees them but doesn't connect due to thin structure). Fashion: same-class instances overlap (model predicts both, but metric penalizes overlap). Deterministic post-processing exploits domain structure the model cannot easily learn. Carvana 5th place: +0.0002 (0.9970 → 0.9972) from post-processing alone - a huge gain for a rule-based addition.

**When to use:** After you have a strong baseline model and have visually inspected errors. Identify: (1) systematic spatial patterns (small artifacts always appear near main object), (2) domain constraints the model violates (same-class overlap impossible physically), (3) geometric fixes (holes inside masks should be filled).

**When NOT to use:** Do not implement post-processing before your model is well-trained - you will waste time fixing symptoms. Do not add complex rules for random errors (overfitting to noise). Skip if errors are varied and unpredictable. For overlapping instances of DIFFERENT classes (Fashion: shirt overlaps pants), do not remove - the overlap is real; instead use soft assignment or z-ordering.

**How to reason about it:**
Visually inspect 50-100 predictions, noting recurring errors:
1. Small isolated artifacts? → Remove components <area_threshold pixels, >distance_threshold from main mask
2. Disconnected parts that should connect (antenna)? → Check linearity (R²>0.9), fit linear regression, add points between gaps, convex hull
3. Holes inside main object? → Fill holes with area <threshold OR distance >X from boundary (Carvana 5th: fill holes >50px from edge to avoid closing wheels/windows)
4. Same-class overlap? → Sort by confidence, sequentially subtract higher-confidence masks from lower-confidence (Fashion 1st: hard_overlaps_suppression)
5. For tracking: duplicate labels → reassign based on temporal IoU, cluster voting

```python
# Post-processing examples
import cv2
from scipy.spatial.distance import cdist

# 1. Remove small artifacts far from main mask
def remove_artifacts(mask, area_threshold=100, distance_threshold=50):
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    if len(contours) == 0:
        return mask
    
    # Find main contour (largest)
    main_contour = max(contours, key=cv2.contourArea)
    main_center = np.mean(main_contour.squeeze(), axis=0)
    
    # Remove small + far contours
    mask_clean = np.zeros_like(mask)
    for cnt in contours:
        area = cv2.contourArea(cnt)
        center = np.mean(cnt.squeeze(), axis=0)
        dist = np.linalg.norm(center - main_center)
        
        if area > area_threshold or dist < distance_threshold:
            cv2.drawContours(mask_clean, [cnt], -1, 255, -1)
    return mask_clean

# 2. Same-class overlap suppression (Fashion 1st place)
def hard_overlaps_suppression(masks, scores):
    """masks: [N, H, W] binary, scores: [N]"""
    sorted_idx = np.argsort(scores)[::-1]  # High to low confidence
    non_overlap = []
    
    for i in sorted_idx:
        current = masks[i].copy()
        # Subtract all previously kept masks
        for prev in non_overlap:
            current = np.bitwise_and(current, np.invert(prev))
        non_overlap.append(current)
    
    return np.stack(non_overlap)
```
