## Principle 5: Apply Conservative Augmentation - Strong Transforms Often Hurt

*Consensus: 4/5 competitions - multiple solutions explicitly reported worse scores with aggressive augmentation*

Use only horizontal flips, small rotations (≤10°), and minor scale/shift for training. Avoid strong color jitter, large rotations, or vertical flips unless the domain is truly invariant.

**Why this matters:** Instance segmentation requires precise pixel-level alignment between image and mask. Strong augmentations (large rotations, aggressive crops) degrade this alignment through interpolation artifacts and introduce unrealistic appearances the model must learn to ignore, effectively reducing training data quality. Carvana 5th place explicitly noted: reducing rotation from 30° to 10° improved LB by 0.0001.

**When to use:** Always start conservative. Add augmentation incrementally only if: (1) you have very limited data (<5k images), (2) validation shows clear overfitting, (3) the domain is truly invariant (e.g., aerial imagery for rotation, medical scans for brightness).

**When NOT to use:** Do not add vertical flips for domains with gravity (people, cars, helmets - all have up/down orientation). Do not use large rotations (>15°) for photography datasets where camera is mostly level. Do not use strong color augmentation (AutoAugment full policy) if test conditions are consistent with training (Carvana: studio lighting, no need for color shift).

**How to reason about it:**
1. Check domain invariances: Is rotation meaningful? (Aerial: yes. Cars: no). Are colors arbitrary? (Fashion: no, color is signal. Medical: maybe).
2. Start with: horizontal flip, rotation ±5-10°, scale ±10%, shift ±5%, zoom ±10%. Train 1 epoch.
3. Add one transform at a time and measure validation impact. If it helps, increase strength gradually.
4. For Fashion/Open Images, AutoAugment helped BUT only with careful policy selection (Fashion 2020 winner used 'v3' policy, not full random).
5. TTA is different - use flips + scales liberally at inference (no training alignment issue).

```python
# Conservative augmentation pipeline
import albumentations as A

train_transform = A.Compose([
    A.HorizontalFlip(p=0.5),
    A.ShiftScaleRotate(
        shift_limit=0.05,   # ±5% translation
        scale_limit=0.1,    # ±10% scale
        rotate_limit=10,    # ±10° rotation  
        border_mode=cv2.BORDER_CONSTANT,
        p=0.5
    ),
    # Skip color/brightness for consistent lighting
    # A.RandomBrightnessContrast(p=0.2),  # Only if needed
    A.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
```
