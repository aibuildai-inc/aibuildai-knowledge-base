## Principle 12: Encode Cyclic Time Features as Sine/Cosine Pairs, Not Raw Integers

*Consensus: 5/10 time-series solutions explicitly used cyclic encoding; ASHRAE winner listed it as a key feature*

For periodic features (hour of day, day of year, month), encode as (sin(2π·x/period), cos(2π·x/period)) instead of raw integers. This preserves the circular topology: hour 23 is close to hour 0, not far away.

**Why this matters:** Tree-based models and NNs treat features as ordered numbers. Hour=23 vs. Hour=0 looks like a huge difference (23 units apart), but they're actually 1 hour apart. Cyclic encoding fixes this: sin/cos map the circle correctly. This is critical for energy/weather prediction where diurnal and seasonal cycles drive the target.

**When to use:** For any feature that repeats cyclically: hour (period 24), day of week (period 7), day of year (period 365), month (period 12). Especially important for tree-based models (LightGBM, XGBoost) which can't learn periodicity from raw integers.

**When NOT to use:** When using deep NNs with learned embeddings for time features (the embedding can learn the cycle, though explicit encoding still helps). When the feature isn't actually cyclic (day of month 1-31 is not cyclic — day 31 is not close to day 1 of the next month in terms of same-month patterns).

**How to reason about it:**
1. Identify cyclic features: hour, day_of_week, month, day_of_year.
2. For each, create two features: feature_sin = sin(2π · feature / period), feature_cos = cos(2π · feature / period).
3. Drop the original raw feature (or keep it if you want both — some models benefit from having both the cyclic encoding and the raw value).
4. Validate: train with and without cyclic encoding and check CV. Typically sees 0.01-0.05 improvement in RMSE for energy/weather tasks.

```python
# Cyclic encoding for time features (ASHRAE pattern)
import numpy as np
df['hour_sin'] = np.sin(2 * np.pi * df['hour'] / 24)
df['hour_cos'] = np.cos(2 * np.pi * df['hour'] / 24)
df['month_sin'] = np.sin(2 * np.pi * df['month'] / 12)
df['month_cos'] = np.cos(2 * np.pi * df['month'] / 12)
df['day_of_year_sin'] = np.sin(2 * np.pi * df['day_of_year'] / 365)
df['day_of_year_cos'] = np.cos(2 * np.pi * df['day_of_year'] / 365)
# Now (hour=23, hour=0) are close in (sin, cos) space
```
