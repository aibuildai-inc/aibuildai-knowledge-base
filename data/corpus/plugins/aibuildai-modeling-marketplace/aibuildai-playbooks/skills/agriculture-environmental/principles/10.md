## Principle 10: Apply Group-Specific Post-Processing When Test Has Known Structure

*Consensus: 8/20 solutions used site/state-specific scaling; biomass 2nd-place gained 0.015 R2 from state-based scaling*

If test data has known group labels (site, state, meter type) and you observe systematic bias per group (e.g., predictions for State A are 10% too high), apply group-specific scaling factors. Optimize these on public LB or leaked data if available, or derive from domain knowledge (e.g., 'State WA has zero dead grass — clip dead predictions to 0').

**Why this matters:** Models trained on imbalanced data (some sites have 10x more samples) may underfit minority groups. Post-processing scaling is a fast fix: for State X, multiply predictions by 0.9. This is especially powerful when combined with domain knowledge (WA has no dead grass, so dead=0 for WA samples).

**When to use:** When test samples have group labels (site, state, building type) that were also in training. When public LB feedback shows systematic bias (e.g., your model overpredicts for one meter type). When domain knowledge gives you strong priors (certain groups have restricted ranges for certain targets).

**When NOT to use:** When optimizing scaling factors on public LB leads to overfitting (you tune 50 parameters on 10% of test data, then they don't generalize to the other 90%). When test groups are completely unseen (then scaling factors from train groups won't transfer). When you have a principled fix (e.g., site-specific models) that obviates the need for post-hoc scaling.

**How to reason about it:**
1. Compute mean prediction error per group on validation set: error[group] = mean(pred[group]) - mean(true[group]).
2. Derive scaling factors: scale[group] = mean(true[group]) / mean(pred[group]).
3. At inference: pred_scaled[i] = pred[i] * scale[group[i]].
4. If you have domain constraints (e.g., WA samples must have dead=0), enforce them: if group == 'WA': pred['dead'] = 0.
5. Validate on LB: if scaling helps public but hurts private, you overfit to public distribution.

```python
# Pattern from biomass 2nd-place solution
# Observed: WA state has zero dead grass in training; model predicts small non-zero values
STATE_SCALES = {
    'NSW': {'clover': 1.0, 'dead': 1.0, 'green': 1.03},
    'Tas': {'clover': 1.0, 'dead': 1.0, 'green': 1.0},
    'Vic': {'clover': 0.85, 'dead': 1.0, 'green': 1.0},
    'WA':  {'clover': 0.80, 'dead': 0.0, 'green': 0.97},  # dead forced to 0
}
for i, row in test.iterrows():
    state = predict_state(row['image'])  # classify state from image (98% acc)
    for target in ['clover', 'dead', 'green']:
        if state == 'WA' and target == 'dead':
            pred[i][target] = 0.0  # domain constraint
        else:
            pred[i][target] *= STATE_SCALES[state][target]
```
