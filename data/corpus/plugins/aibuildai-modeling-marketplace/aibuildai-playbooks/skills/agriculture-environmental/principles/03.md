## Principle 3: Exploit Spatial-Environmental Covariates Even When Images Are Primary

*Consensus: 15/20 image-based solutions used ancillary geodata (climate, soil, NDVI, altitude); winner of PlantTraits used structured self-attention over metadata*

Location-derived features (climate normals, soil type, elevation, remote sensing indices) provide free context that images alone cannot capture. For traits/properties influenced by environment (nitrogen content, species distribution), these features are not just 'nice to have' — they're direct causal inputs.

**Why this matters:** An image of a plant leaf doesn't encode the soil pH or 30-year precipitation averages, but those variables directly affect the trait you're predicting. Multi-modal models (image CNN + tabular network) consistently outperform image-only models in agriculture/ecology tasks because the tabular features fill in unobservable context.

**When to use:** When your data includes GPS coordinates or site IDs that can be joined to public geodata (WorldClim for climate, SoilGrids for soil, MODIS/Sentinel for remote sensing). When the target is a property influenced by environment (biomass, plant traits, species presence) rather than purely visual (counting objects in a photo).

**When NOT to use:** When the task is purely visual classification with no environmental dependence (e.g., identifying a diseased leaf would work without knowing the location). When test data comes from completely different geographies not covered by your covariate sources (though this is rare — global climate/soil datasets exist).

**How to reason about it:**
1. Check if the competition provides lat/lon or site IDs. If yes, join to WorldClim (19 bioclim variables), SoilGrids (pH, texture, nutrients), and satellite data (NDVI, LST).
2. Architect a two-stream model: CNN for images, MLP/Transformer for tabular features, then fuse (concatenate + attention, or late fusion via ensemble).
3. If features are high-dimensional (e.g., 50+ climate/soil variables), use attention or learned embeddings rather than raw concatenation — the model should learn which variables matter for which trait.
4. Validate whether metadata helps: train image-only vs. image+metadata and compare CV.

```python
# Multi-modal fusion pattern from PlantTraits winner
class MultiModalModel(nn.Module):
    def __init__(self, image_backbone, metadata_dim):
        self.image_encoder = image_backbone  # e.g., DINOv2
        self.metadata_attention = StructuredSelfAttention(metadata_dim)  # learns feature interactions
        self.fusion = nn.Linear(image_feat_dim + metadata_dim, output_dim)
    
    def forward(self, image, metadata):
        img_feat = self.image_encoder(image)  # (B, D_img)
        meta_feat = self.metadata_attention(metadata)  # (B, D_meta)
        fused = torch.cat([img_feat, meta_feat], dim=1)
        return self.fusion(fused)
```
