## Principle 8: Apply Test-Time Augmentation and Pseudo-Labeling for Small Datasets

*Consensus: 10/20 solutions used TTA; 5/20 used pseudo-labeling or test-time training; biomass winner gained 0.02 R2 from pseudo-labels*

For small datasets (<5000 samples), test-time techniques add robustness. TTA: predict on multiple augmented versions of each test image and average. Pseudo-labeling: use your model to label the test set, retrain on train+test, re-predict. Both reduce variance at the cost of longer inference.

**Why this matters:** With <1000 training images, a single model's predictions are noisy. TTA averages out augmentation-induced variance (a slight rotation shouldn't change the biomass). Pseudo-labeling on test data acts as semi-supervised learning — if test images are similar to train, pseudo-labels capture test distribution shift.

**When to use:** TTA: always for image tasks when inference time allows (5-10x slower). Use horizontal/vertical flips, rotations for overhead images (no canonical orientation). Pseudo-labeling: when train and test are from the same underlying distribution (same sites, same season) but you suspect a small covariate shift; when you have multiple strong models to generate diverse pseudo-labels.

**When NOT to use:** TTA: when test images have a canonical orientation (upright plant photos — vertical flip is unnatural). When inference time is critical (real-time systems). Pseudo-labeling: when train and test are from completely different distributions (train on 2016 data, test on 2017 with different weather) — pseudo-labels will be wrong and hurt the model. When you only have one model (pseudo-labels just reinforce its biases).

**How to reason about it:**
1. TTA: Choose augmentations that preserve the semantics. For overhead pasture images: H/V flips, 90° rotations are safe. For upright plant photos: H flip maybe, V flip no. Average predictions: mean of probabilities (classification) or mean of outputs (regression).
2. Pseudo-labeling: (a) Train multiple diverse models (different backbones, CV folds). (b) Generate pseudo-labels on test set by ensembling these models. (c) Retrain from scratch on train+test with real+pseudo labels. (d) Optionally iterate 2-3 times. (e) Validate on a holdout or via LB — if pseudo-labeling hurts LB, stop.
3. For small datasets, combine TTA + pseudo-labeling: use TTA to generate pseudo-labels (less noisy), then retrain.

# TTA pattern for overhead images (flips + rotations)
def tta_predict(model, image, num_augs=8):
    preds = []
    for _ in range(num_augs):
        aug = random.choice([HFlip(), VFlip(), Rotate90(), Rotate(limit=10)])
        img_aug = aug(image=image)['image']
        pred = model(img_aug)
        preds.append(pred)
    return np.mean(preds, axis=0)
