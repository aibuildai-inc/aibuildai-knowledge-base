## Principle 11: Validate Augmentation Choices Against Physical Realism, Not Just CV Score

*Consensus: 15/20 image solutions used heavy augmentation; multiple noted that certain augs (vertical flip for plant photos, extreme color jitter) hurt despite improving CV*

Use augmentations that preserve the target's physical meaning. For overhead images (pasture, satellite), flips and rotations are safe (no canonical orientation). For upright photos (plant leaves), vertical flip is unrealistic. Brightness/contrast jitter is usually safe; extreme hue shifts may not be if color encodes the target (green = chlorophyll = biomass).

**Why this matters:** An augmentation that changes the target invalidates the label. Flipping a pasture image doesn't change the grass biomass, so it's valid. But if you rotate a plant photo by 180°, the lighting changes in a way that doesn't occur naturally, and the model learns unrealistic invariances. Some augs (CutMix, heavy crops) can improve CV by adding noise but hurt test generalization.

**When to use:** Always for small image datasets (<5000). Start with safe geometric augs (H/V flip, 90° rotations for overhead; H flip only for upright). Add color augs (brightness, contrast, slight hue) that mimic natural lighting variation. For overhead images with varying camera heights, add small random crops or scaling.

**When NOT to use:** When augmentation contradicts physics: don't vertically flip upright plant photos (unnatural). Don't apply extreme hue shifts if color is a direct signal (greenness for vegetation indices). CutMix/MixUp can hurt if the task requires spatial coherence (biomass is distributed across the image; cutting and pasting regions breaks this).

**How to reason about it:**
1. Ask: does this augmentation produce an image that could occur naturally? Overhead pasture rotated 90°: yes (camera angle varies). Upright plant flipped upside-down: no.
2. For color augs: mimic lighting variation (brightness, contrast) but avoid changing wavelengths if they're meaningful (NDVI uses NIR, don't shift it).
3. For spatial augs: random crops are safe if the target is an average density (biomass per area), unsafe if it's a total count in the frame (then cropping changes the count).
4. Validate on CV: if an aug improves CV by 0.01 but you suspect it's unrealistic, check LB — often it hurts LB.

```python
# Safe augmentations for overhead pasture images (no canonical orientation)
train_transform = A.Compose([
    A.HorizontalFlip(p=0.5),
    A.VerticalFlip(p=0.5),  # safe for overhead, not for upright plants
    A.RandomRotate90(p=0.5),  # 90° rotations safe for overhead
    A.RandomBrightnessContrast(brightness_limit=0.2, contrast_limit=0.2, p=0.7),  # lighting variation
    A.HueSaturationValue(hue_shift_limit=10, sat_shift_limit=20, val_shift_limit=20, p=0.5),  # mild color
    A.RandomResizedCrop(size=(1024, 1024), scale=(0.8, 1.0), p=0.3),  # simulates camera height variation
])
# Avoid: CutMix, extreme hue shifts (hue_shift_limit=180), vertical flip for upright plants
```
