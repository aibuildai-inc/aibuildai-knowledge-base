## Principle 1: Route the Problem by Input–Output Geometry Before Choosing a Model

*Consensus: The 12 polymer writeups spanned SMILES language models, graph neural networks, 3D conformer models, and descriptor-based tabular models; the winning solution combined three of these families rather than committing to one.*

First classify what the input really contains and what receives the label: a molecule or polymer repeat unit given only as a string, a graph with reliable connectivity, trustworthy 3D conformers, or a table of descriptors, with labels at the molecule level or at a substructure level. Choose the model family and prediction granularity from that interface rather than from the broad “molecular” label.

**Why this matters:** The useful inductive bias changes with the information path. String models learn from notation and benefit from pretraining on large unlabeled corpora; graph models see connectivity directly and are invariant to atom order by construction; 3D models see geometry but depend on conformer generation that can fail or exhaust memory; descriptor-based tabular models are strong in small-data regimes but see only what the features encode.

**When to use:** Always, before feature engineering. Inspect the raw input, target granularity, label sparsity per target, metric weighting, data volume per target, and whether coordinates, connectivity, or repeat-unit markers are authoritative.

**When NOT to use:** Do not force a fashionable GNN or 3D model onto a small, sparse-label dataset without comparing it against a descriptor-based tabular baseline, and do not assume a chemistry-specific pretrained model beats a general one. In the polymer writeups, a tabular AutoML model, a code-pretrained BERT, and a 3D conformer model each earned a place in the winning ensemble, while chemistry-specific language models scored worse than general-purpose ones and a D-MPNN did not work as well.

**How to reason about it:**
Ask in order: (1) What entity receives a label—a whole molecule, a repeat unit, or a substructure? (2) What transformations should leave that label unchanged? (3) How many labels does each target have, and which targets are missing for which molecules? (4) Where can information be lost before the model sees it: string parsing, graph construction, conformer generation, or fingerprint hashing? Route only after answering all four, and keep at least one model from a different family as a control.

```python
def candidate_routes(dataset, target):
    routes = ["descriptor_fingerprint_tabular"]  # Strong baseline for small or sparse targets.
    if dataset.smiles_parse_ok:
        routes += ["smiles_language_model_with_enumeration", "graph_neural_network"]
    if dataset.conformers_ok and dataset.molecules_fit_memory:
        routes.append("3d_conformer_model")
    if target.level != "molecule":
        routes.append("readout_at_target_granularity")  # Keep the labeled substructure explicit.
    return routes  # Compare every route under the same grouped folds.
```
