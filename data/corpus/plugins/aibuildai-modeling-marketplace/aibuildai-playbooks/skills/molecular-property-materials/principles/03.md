## Principle 3: Model Whole-Molecule Context at the Target’s Native Granularity

*Consensus: Several polymer writeups encoded context beyond local substructures: a global graph node, repeat-unit chain extension, attachment-point position features, or 3D shape descriptors.*

Encode local chemical environments first, then let information flow across the whole molecule or repeat unit before reading out at the level the label belongs to. For global polymer properties, pool only after local environments, attachment points, and repeat-unit topology have been encoded; for a label attached to a substructure, keep that substructure explicit in the readout instead of pooling it away.

**Why this matters:** A property is rarely set by one functional group alone: backbone rigidity, sidechain placement, the separation of attachment points, and overall shape all change it, and a monomer string understates the chain the property belongs to. Short-range message passing or early pooling can miss this context, while pooling a substructure-level label into one molecule vector destroys the state needed to tell queries apart.

**When to use:** Use for properties whose mechanism combines local motifs with chain topology, overall shape, or packing, such as the size, free-volume, and thermal properties of polymers, and for any label attached to a substructure rather than to the whole molecule.

**When NOT to use:** Extra global structure can overfit small datasets: one polymer solution found that more than one global node, or descriptors injected into the global node or the GNN layers, overfit. A descriptor-based tree model can remain competitive when engineered topology features already capture the relevant context.

**How to reason about it:**
Make the target level explicit: a molecule readout, a repeat-unit readout, or a query embedding for a substructure. Then test increasing receptive fields: local fingerprint only, deeper message passing, one global node, and extended repeat units. Stop when more distant context ceases to improve grouped validation.

def add_global_node(graph):
    hub = graph.add_node(features=graph.zero_node_features())
    for atom in graph.atom_ids():
        graph.add_edge(hub, atom, features=graph.virtual_edge_features())
    return graph  # One shortcut node lets distant atoms exchange information.
