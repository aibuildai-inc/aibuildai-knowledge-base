## Principle 4: Treat Invariance as a Testable Inductive Bias, Not a Dogma

*Consensus: Polymer solutions handled notation invariance in different ways: SMILES language models used randomized SMILES in training and test-time averaging, graph models were invariant by construction, and some notation variants gave no gain.*

Identify label-preserving transformations—atom renumbering, alternate SMILES enumeration, Kekulé versus aromatic notation, conformer choice, or rigid motion of 3D coordinates—and decide whether to encode invariance architecturally, learn it through augmentation, or leave a transform out because it changes the chemistry.

**Why this matters:** Correct invariance reduces sample complexity and improves robustness, but enforcing more invariance than the data-generating process warrants can remove relevant information. A graph network is invariant to atom order by construction, while a string model sees one arbitrary spelling of the molecule and must learn that other spellings mean the same thing; both reached strong polymer results, which shows the invariance mechanism is a choice to test, not a default.

**When to use:** Use hard invariance when deployment can arbitrarily reorder or rotate inputs and the physics guarantees unchanged labels. Use augmentation-based invariance when the model reads an order-dependent representation, such as a SMILES string, and the same molecule can be written many ways.

**When NOT to use:** Avoid transformations that alter the label or create unrealistic inputs. Removing stereochemistry or changing explicit hydrogens is not a neutral rewrite, and a different isomer is not an alternate notation of the same molecule.

**How to reason about it:**
For each proposed transform, ask: Is the molecule identical? Is the target identical? Can the test data contain this variation? Compare no transform, augmentation, and an invariant architecture under a validation set deliberately transformed at test time.

```python
def invariance_test(model, x, transforms):
    base = model(x)
    return {
        name: (model(fn(x)) - base).abs().mean().item()
        for name, fn in transforms.items()
    }
# Include only chemically label-preserving transforms in this test.
```
