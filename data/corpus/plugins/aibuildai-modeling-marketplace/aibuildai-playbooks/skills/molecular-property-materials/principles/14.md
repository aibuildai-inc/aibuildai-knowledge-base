## Principle 14: Use Chemical Validity as a Routing Constraint, Not as Proof of Correctness

*Consensus: Polymer writeups deduplicated data by canonical SMILES, and one 3D-model solution routed molecules that failed conformer generation to a descriptor model, which its authors called key to their result.*

Parse and canonicalize every structure, record which representations fail for which molecules, and route each molecule to a model that can actually read it. Keep validity separate from accuracy: a structure that parses, canonicalizes, and yields a conformer can still be predicted badly.

**Why this matters:** Representation failures are not random: conformer generation and memory-limited 3D models tend to fail on larger or unusual molecules, so silently dropping them biases both training data and test coverage. Canonicalization is a low-cost check that also finds duplicate structures written in different notations.

**When to use:** Use whenever a pipeline depends on RDKit parsing, conformer generation, or a model with input-size limits. Measure failures before training, route failed test molecules to a fallback model, and use canonical forms to find duplicates within and across datasets.

**When NOT to use:** Do not treat a valid parse as evidence that a prediction is right, and do not over-invest in the fallback slice: the same solution found that further tuning of its fallback model had a negligible effect on the overall score. Do not canonicalize away information the target depends on, such as stereochemistry or attachment points.

**How to reason about it:**
For each representation, list the molecules it cannot handle and their share of each target. Compare dropping, fallback prediction, and a simpler representation for that slice under grouped OOF, and scale the effort to the slice’s share of the metric.

```python
def route_prediction(smiles, primary, fallback, chemistry):
    mol = chemistry.parse(smiles)
    if mol is None:
        return fallback.predict_from_string(smiles)
    conformer = chemistry.embed_3d(mol)
    if conformer is None or mol.num_atoms > primary.max_atoms:
        return fallback.predict(chemistry.descriptors(mol))
    return primary.predict(conformer)  # Validity routes the input; it does not certify the output.
```
