## Principle 9: Use Augmentation to Match Real Nuisance Variation Without Changing Chemistry

*Consensus: Polymer writeups used randomized SMILES enumeration, repeat-unit chain extension, or targeted substituent changes, while other notation variants and a mixture-model augmentation from public notebooks gave no gain.*

Choose augmentations from the task’s equivalence class and observed error: non-canonical SMILES for string models, repeat-unit extension when a monomer string understates the chain, and controlled substituent changes only where their effect on the label is understood.

**Why this matters:** Augmentation is most valuable when it removes reliance on accidental representation choices or adds coverage where the model fails. Generic augmentation can instead distort bond topology, stereochemistry, or the physical meaning of a polymer repeat unit.

**When to use:** Use after measuring invariance violations or error concentrations. Couple training-time augmentation with matching test-time augmentation only when predictions are stable and aggregation improves held-out data; the winning string model took the median over many randomized SMILES at test time.

**When NOT to use:** Avoid isomer generation when labels are not guaranteed unchanged, stereochemistry removal when stereochemistry affects the property, or random atom deletion when omitted atoms alter the property. In the polymer writeups, extra SMILES variants gave no gain for a graph model, Kekulé, stereo-removal, and explicit-hydrogen variants did not help a string model, and a mixture-model augmentation from public notebooks did not work.

**How to reason about it:**
For every transform, document identity preservation, realism, and expected failure mode. Run an ablation on clean validation and on the slice of molecules the transform targets; retain it only if the combined error improves.

def augment(sample, mode):
