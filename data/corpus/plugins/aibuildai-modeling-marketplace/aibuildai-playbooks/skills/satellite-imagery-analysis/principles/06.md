## Principle 6: Apply Test-Time Augmentation with Metric-Compatible Averaging

*Consensus: Most solutions used TTA; reported gains were small but consistent*

At inference, predict on flipped/rotated versions of the image and average predictions. For segmentation, average probabilities before thresholding. TTA is nearly free (just extra inference time) and consistently improves scores.

**Why this matters:** Satellite imagery has no canonical orientation—ships/clouds can appear at any angle. TTA reduces prediction variance and captures patterns the model missed in one orientation. The 3rd-place Planet Amazon solution averaged predictions over 32 variations of each image. The 48th-place cloud solution gained +0.005 on the public LB from 6-way TTA.

**When to use:** Almost always use TTA for segmentation/detection in satellite imagery. Use at minimum: horizontal flip + vertical flip (4 combinations). Better: add rot90 (8 combinations). For very large images or tight time limits, use 4-way instead of 8-way.

**When NOT to use:** Skip TTA only if inference time is critical (e.g., speed competition). The 1st-place speed prize for ship detection skipped TTA to maximize throughput.

**How to reason about it:**
Implementation: (1) For each test image, generate augmented versions (flip/rotate). (2) Predict on each. (3) Apply inverse transform to predictions. (4) Average probabilities (not binary masks). (5) Threshold. The averaging should be arithmetic mean for probabilities, not geometric mean (worse for Dice).

```python
def tta_predict(model, img, tta_transforms):
    preds = []
    for transform, inv_transform in tta_transforms:
        img_aug = transform(img)
        pred_aug = model(img_aug)
        pred = inv_transform(pred_aug)  # undo transformation
        preds.append(pred)
    return torch.stack(preds).mean(dim=0)  # average probabilities

# 8-way TTA
tta_transforms = [
    (identity, identity),
    (hflip, hflip),
    (vflip, vflip),
    (rot90, rot270),
    # ... all 8 combinations of flip × rot90
]
y_pred = tta_predict(model, test_img, tta_transforms)
```
