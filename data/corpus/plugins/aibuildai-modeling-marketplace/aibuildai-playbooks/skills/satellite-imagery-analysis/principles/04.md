## Principle 4: Use Two-Stage Pipeline for Severely Imbalanced Segmentation: Classifier First, Then Segmenter

*Consensus: Most top ship-detection solutions and many top cloud solutions used separate empty-image classifiers*

When most images contain no target (e.g., 75% of ship images are empty ocean), train a binary classifier to filter empty images before running the expensive segmenter. This reduces false positives and speeds up inference.

**Why this matters:** Segmentation models on imbalanced data tend to predict empty masks everywhere to minimize loss. The metric (F2, Dice) heavily penalizes false positives on empty images. A dedicated classifier learns the empty vs non-empty boundary better than the segmenter's indirect signal. The 1st-place cloud solution trained segmentation models only on non-empty labels, using a separate classifier to decide which images to segment.

**When to use:** Use two-stage when: >50% of images are empty, the metric penalizes false positives heavily (F2, Dice), inference time matters (skip segmentation on 75% of images). The ship detection winners used classifiers with 0.5-0.7 threshold; images below got blank predictions.

**When NOT to use:** Skip if class imbalance is mild (<30% empty) or if the segmenter already handles it well (some U-Nets with focal loss do). The 14th-place ship solution used the classifier at the END of the pipeline, not the start—sieving out uncertain small ships post-segmentation rather than pre-filtering.

**How to reason about it:**
Decision tree: (1) What fraction of images are empty? If >60% → two-stage is critical. (2) Does the segmenter overpredict (seeing ships in empty ocean)? If yes → classifier helps. (3) Can you afford to run segmentation on all images? If no → classifier speeds up inference. (4) Does your metric have asymmetric penalties (FP worse than FN)? If yes → classifier reduces costly FPs. Optionally: use segmenter's max-probability as a soft classifier (top-K pixel values).

```python
# Two-stage pipeline
classifier = train_classifier(images, has_ship_labels)  # ResNet34
segmenter = train_segmenter(non_empty_images, masks)   # U-Net

# Inference
for img in test_images:
    prob = classifier.predict(img)
    if prob < 0.6:  # tuned threshold
        submit_empty_mask(img)
    else:
        mask = segmenter.predict(img)
        # Optionally: filter mask by classifier confidence
        if prob < 0.95 and mask.sum() < 100:  # small uncertain ship
            submit_empty_mask(img)
        else:
            submit(mask)
```
