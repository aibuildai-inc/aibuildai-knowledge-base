## Principle 12: Understand and Optimize for the Metric's Specific Behavior, Not Just Training Loss

*Consensus: Several solutions explicitly discussed metric vs loss misalignment and tuned decisions separately for the metric*

The training loss (BCE, Dice on training set) optimizes pixel-level or batch-level objectives. The evaluation metric (global Dice, F2, mean IoU) often aggregates differently and has different sensitivities. Threshold, post-processing, and ensemble weights should be tuned to the actual metric, not training loss.

**Why this matters:** A global Dice metric (sum all pixels across all images, then compute Dice) is not mean Dice (per-image Dice, then average). Global Dice is dominated by images with many positives; mean Dice treats all images equally. Training with mean Dice (easier) doesn't optimize the right objective. The ship detection F2 metric weights recall 2× more than precision, so under-segmenting is worse than over-segmenting—but training loss doesn't know this.

**When to use:** Always tune final decisions (threshold, ensemble weights, post-processing) on the real metric. If the metric is global Dice, aggregate predictions globally before computing Dice. If it's F2, optimize recall more than precision. If it's mean IoU per class, ensure small classes aren't drowned by large classes.

**When NOT to use:** If the metric is simple pixel accuracy or log-loss, training loss aligns well—no special tuning needed. If you have no validation data, you can't tune for the metric, only rely on training loss.

**How to reason about it:**
Steps: (1) Read the metric definition carefully. Is it global or per-image? Does it weight classes equally? (2) Simulate the metric on validation: compute it exactly as the leaderboard does. (3) Tune decisions (threshold, pruning) to maximize this simulated metric, not training loss. (4) Check: does local metric correlate with LB? If not, revisit metric implementation or validation split.

```python
# Global Dice: aggregate first, then compute
def global_dice(preds, targets):
    preds_flat = preds.flatten()  # all images concatenated
    targets_flat = targets.flatten()
    intersection = (preds_flat * targets_flat).sum()
    return (2 * intersection) / (preds_flat.sum() + targets_flat.sum())

# vs mean Dice: compute per-image, then average
def mean_dice(preds, targets):
    dices = [dice_per_image(p, t) for p, t in zip(preds, targets)]
    return np.mean(dices)

# F2 score: recall weighted 2x
def f2_score(pred, target, beta=2):
    tp = (pred * target).sum()
    fp = (pred * (1 - target)).sum()
    fn = ((1 - pred) * target).sum()
    precision = tp / (tp + fp + 1e-8)
    recall = tp / (tp + fn + 1e-8)
    return (1 + beta**2) * precision * recall / (beta**2 * precision + recall + 1e-8)

for th in np.arange(0.3, 0.7, 0.05):
```
