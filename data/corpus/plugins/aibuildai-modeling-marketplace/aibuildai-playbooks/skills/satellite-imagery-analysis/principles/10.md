## Principle 10: Exploit Metadata Features When Available, Especially for Group-Based Patterns

*Consensus: Top chronology solutions grouped images by location and by acquisition day before solving each group*

Satellite imagery often comes with metadata: viewing geometry, acquisition timestamp, sensor type, lat/lon. This metadata can be highly predictive, especially when samples cluster by metadata values. Use it as input features, for stratification, or for post-processing.

**Why this matters:** When samples cluster into groups (same location, same acquisition pass), the group carries information that a single image does not show. The 1st-place chronology solution split the data by location, matched the pictures taken on the same day, and then solved each location with clues from every set in it. Group statistics (group size, group label rate) and per-group thresholds turn such structure into features, but confirm that the pattern also holds in test.

**When to use:** Always inspect metadata when available. Use it if: samples cluster by metadata (date, location), metadata correlates with label (plot distribution), or metadata reveals train-test shift. Common uses: (1) stratify CV by metadata, (2) add metadata as input feature (concatenate to CNN features), (3) post-process by metadata (threshold per group).

**When NOT to use:** If metadata is random or uncorrelated with labels, it adds noise. The Planet Amazon competition had lat/lon but top solutions didn't use it because deforestation patterns were local (within-image), not global. If metadata has missing values (NA), handle carefully—missing values can be distributed differently in train and test.

**How to reason about it:**
Exploration: (1) Plot label distribution vs metadata (e.g., positive rate vs a metadata value). (2) Check if metadata clusters samples (find modes). (3) Check correlation with predictions. If correlation is strong, add metadata to model or use for post-processing. If weak, skip.

# Add metadata as model input
class CNNWithMeta(nn.Module):
    def __init__(self):
        self.cnn = ResNet34()
        self.fc = nn.Linear(512 + 1, 2)  # +1 for one metadata value
    
    def forward(self, img, meta):
        x = self.cnn(img)  # (B, 512)
        x = torch.cat([x, meta.unsqueeze(1)], dim=1)  # (B, 513)
        return self.fc(x)
