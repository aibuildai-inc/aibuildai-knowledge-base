## Principle 2: Handle Multi-Spectral Bands by Deciding Whether to Use Them All or Filter by Task

*Consensus: Most solutions in the multi-band competitions (DSTL, Planet Amazon) chose bands per class or per model rather than always using all bands*

Satellite data often has 4-16+ spectral bands (RGB, NIR, SWIR, thermal, etc.). Top solutions either (1) use all bands for coarse classes, (2) use only RGB+NIR for fine detail classes, or (3) train separate models per band combination and ensemble.

**Why this matters:** Different bands capture different information: NIR distinguishes vegetation from water, thermal shows heat signatures, SWIR penetrates clouds. But using all bands increases model complexity and can hurt performance on classes where extra bands add noise. The 12th-place DSTL solution used all bands for buildings/roads but only RGB+Panchromatic for vehicles because vehicle detection needs maximum spatial resolution, not spectral diversity.

**When to use:** Use all bands for: land cover classification (agriculture, forests, water), atmospheric phenomena (clouds), when class differences are spectral not spatial. Use RGB+NIR only for: small object detection (vehicles, small ships), when you need fine spatial detail, when training speed matters.

**When NOT to use:** Don't default to using all bands without checking if they help. The Planet Amazon 3rd place used only JPEG (RGB) despite TIFF having 4 bands because they had preprocessing issues with TIFFs and RGB was sufficient. Don't use NIR for urban structure detection if your pretrained encoder expects 3 channels—either retrain from scratch or duplicate RGB channels.

**How to reason about it:**
Inspect the bands: (1) Plot each band separately to see what it shows. (2) Check if pretrained weights expect 3 channels—if yes, either adapt first layer or select 3 most informative bands. (3) Train small experiments: RGB-only vs all-bands, measure difference. (4) Consider task: does this class differ spectrally (vegetation vs water → use NIR) or spatially (vehicle shape → RGB enough)?
