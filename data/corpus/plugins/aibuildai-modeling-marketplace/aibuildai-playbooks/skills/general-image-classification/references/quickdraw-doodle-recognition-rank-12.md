# 12th place code release

Competition: quickdraw-doodle-recognition
Rank: #12
Source: https://www.kaggle.com/c/quickdraw-doodle-recognition/discussion/74132

Hi everyone, we are releasing our solution to the Doodle challenge. It's located under the [ml-arsenal-public][1] repository, where in the future you may find the code to all of my high scoring-solutions. The solution journal will be released in the future, but in short, we used various models, encoding methods, input sizes, and a careful ensemble (done by @ShenTao) to stabilize the score.
