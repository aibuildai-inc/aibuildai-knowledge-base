## Principle 7: Apply Test-Time Augmentation with Geometric Averaging for Robustness

*Consensus: 5/8 QuickDraw solutions used TTA*

At inference, predict on multiple augmented versions of each test image (horizontal flip, rotations, crops) and aggregate predictions via geometric mean. This smooths prediction noise and improves robustness.

**Why this matters:** TTA exploits test-time invariances (flips, small rotations) to reduce variance in predictions. Geometric mean is more robust to outlier predictions than arithmetic mean. Consistently provided 0.01-0.03 improvement in top solutions.

**When to use:** Always as a final boost when inference time is not severely constrained. Especially valuable for tasks with natural augmentations (horizontal flip for most images, rotation for sketches). TTA with 4x augmentation (flip + no flip, original + crop) is a good default.

**When NOT to use:** When inference must be very fast (real-time applications). Also skip augmentations that break the task (vertical flip for driver detection, where up/down matters). One Inclusive Images solution used flip only (no rotation/crop) due to inference time limits.

**How to reason about it:**
Choose augmentations that preserve label: horizontal flip (almost always valid), small crops (±10%), rotation (±10° if orientation-invariant). Avoid: vertical flip (breaks many tasks), large rotations (unless task is rotation-invariant like doodles). For each test sample: generate K augmented versions, predict on each, aggregate via geometric mean (multiply probabilities, take Kth root). Alternatively, arithmetic mean or max. Measure on validation: does TTA improve by >0.01? If not, skip.

```python
# Test-time augmentation with geometric mean
def predict_with_tta(model, image, n_augmentations=4):
    preds = []
    
    # Original
    preds.append(model.predict(image))
    
    # Horizontal flip
    preds.append(model.predict(np.fliplr(image)))
    
    # Central crop + resize
    crop = center_crop(image, crop_pct=0.9)
    preds.append(model.predict(resize(crop, image.shape[:2])))
    
    # Flip + crop
    preds.append(model.predict(np.fliplr(resize(crop, image.shape[:2]))))
    
    # Geometric mean (more robust to outliers)
    preds = np.array(preds)  # (4, num_classes)
    geom_mean = np.exp(np.mean(np.log(preds + 1e-8), axis=0))
    return geom_mean
```
