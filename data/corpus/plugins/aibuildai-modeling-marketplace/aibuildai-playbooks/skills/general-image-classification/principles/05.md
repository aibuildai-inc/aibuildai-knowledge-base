## Principle 5: Tune Class-Specific Thresholds for Multi-Label Tasks

*Consensus: 3/4 Inclusive Images solutions tuned per-class thresholds; winner gained ~0.15*

For multi-label classification, optimize a separate probability threshold for each class rather than using a global threshold. This accounts for class imbalance and differing model confidence per class.

**Why this matters:** Classes have vastly different frequencies (Inclusive Images: 800K instances of one label, 1 instance of another). A global threshold biases toward common classes. Per-class thresholds improved F2 score from 0.35 to 0.50 on the same model predictions.

**When to use:** Multi-label tasks with imbalanced classes AND a tuning set with ground truth. Inclusive Images provided 1K labeled images for threshold tuning. Essential when the metric is threshold-sensitive (F-beta, precision-recall trade-offs).

**When NOT to use:** Single-label classification (use softmax argmax). Also skip if you lack a tuning set or if test distribution is very different from train (threshold overfits to tuning distribution). One Inclusive Images solution used fixed threshold=0.04 assuming stage 2 distribution would differ.

**How to reason about it:**
For each class: sweep threshold from 0.01 to 0.99 and select the value that maximizes the metric (F2, F1) on the tuning set. Iterate 2-3 times: optimize class 1's threshold, then class 2's (holding class 1 fixed), repeat. Hyperparameters: min/max threshold range, minimum samples per class to trust optimization (e.g., only optimize classes with ≥5 tuning samples). Risk: overfitting to tuning set if distributions shift.

```python
# Inclusive Images 3rd place threshold optimization
thresholds = {c: 0.5 for c in classes}  # Initialize

for iteration in range(3):  # Iterate to convergence
    for cls in classes:
        best_thr, best_f2 = 0.5, 0
        for thr in np.arange(0.01, 0.99, 0.01):  # Sweep
            thresholds[cls] = thr
            preds = (probs > pd.Series(thresholds)).astype(int)
            f2 = fbeta_score(y_tuning, preds, beta=2, average='samples')
            if f2 > best_f2:
                best_thr, best_f2 = thr, f2
        thresholds[cls] = best_thr

# Apply to test
test_preds = (test_probs > pd.Series(thresholds)).astype(int)
```
