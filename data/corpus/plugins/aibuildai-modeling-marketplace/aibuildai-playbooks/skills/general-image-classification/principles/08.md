## Principle 8: Weight Loss or Sample to Address Severe Class Imbalance

*Consensus: 2/4 Inclusive Images solutions, 1/8 QuickDraw solutions used class weighting*

When classes are extremely imbalanced (800K:1 ratios), apply per-class loss weights or weighted sampling to prevent the model from ignoring rare classes. This forces learning on long-tail categories.

**Why this matters:** Unweighted training on imbalanced data causes models to predict only common classes (maximizes accuracy but fails on rare classes). Weighting rare classes more heavily (or sampling them more often) provides stronger gradient signal for them. Critical for multi-label tasks where positive labels are sparse.

**When to use:** When class imbalance is severe (>100:1) AND rare classes matter for the metric (F-beta, mAP). Inclusive Images had 7K classes with ratios up to 800,000:1. Also useful when positive labels are sparse in multi-label settings.

**When NOT to use:** Moderate imbalance (<10:1) where standard training handles it. Also skip if weighting destabilizes training (rare class gradients dominate, common classes degrade).

**How to reason about it:**
Measure per-class frequency: `counts = df['label'].value_counts()`. Compute weights: `weights = 1 / counts` or `weights = 1 / sqrt(counts)` (less aggressive). For multi-label: also weight positive vs negative labels (e.g., pos_weight=20 to emphasize sparse positives). Alternative: weighted sampling (sample rare classes more often). Monitor: rare class recall and common class precision. If rare recall improves but common precision drops too much, reduce weighting.

```python
# Inclusive Images weighted BCE for multi-label
class_counts = df['labels'].explode().value_counts()  # Per class
class_weights = 1 / np.sqrt(class_counts)  # Less aggressive than 1/count
class_weights = class_weights / class_weights.sum() * len(class_weights)

# Positive label weighting (sparse multi-label)
def weighted_bce(outputs, targets, pos_weight=20):
    w = targets * pos_weight + 1  # Emphasize positive labels
    loss = F.binary_cross_entropy_with_logits(outputs, targets, weight=w)
    return loss

# Or weighted sampling
from torch.utils.data import WeightedRandomSampler
sample_weights = [class_weights[label] for label in labels]
sampler = WeightedRandomSampler(sample_weights, num_samples=len(labels))
loader = DataLoader(dataset, sampler=sampler, batch_size=64)
```
