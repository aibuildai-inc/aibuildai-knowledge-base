## Principle 4: Leverage Temporal or Spatial Correlations with Nearest Neighbor Aggregation

*Consensus: 2/2 State Farm top solutions used nearest neighbor features*

When samples are correlated (video frames, sequential captures), compute embeddings and aggregate predictions from K-nearest neighbors in feature space. This exploits temporal/spatial smoothness.

**Why this matters:** Video frames or sequential images have high correlation: adjacent frames show the same subject under similar conditions (lighting, pose, background). Nearest neighbor averaging smooths prediction noise and improved State Farm winner's score by 0.10-0.12 alone.

**When to use:** When data has inherent sequential structure (video frames, time-lapse, same subject across images). State Farm: images are video frames, so nearest neighbors are almost always the same driver/class. QuickDraw: temporally correlated strokes within a drawing.

**When NOT to use:** When samples are independent (different objects, different people); nearest neighbors then carry no shared label signal. Also skip if computing embeddings for the entire test set is infeasible (memory/time).

**How to reason about it:**
Extract embeddings from a late layer (e.g., pool5 features, 512×7×7 spatial). For each test sample, find K=10-20 nearest neighbors in embedding space (cosine or L2 distance). Weighted average: distance-weighted or equal-weight average of neighbor predictions. Check: nearest neighbor class hit rate on validation. If >95%, strong signal. Also compute segment-level consistency: if a group has confident, consistent predictions, apply to all members.

```python
# State Farm winner's K-NN averaging
from sklearn.neighbors import NearestNeighbors

# Extract pool5 features (last MaxPool layer)
feature_extractor = Model(inputs=model.input, 
                           outputs=model.get_layer('pool5').output)
test_features = feature_extractor.predict(X_test)  # (N, 512, 7, 7)
test_features = test_features.reshape(len(X_test), -1)  # Flatten

# Find K=10 nearest neighbors
knn = NearestNeighbors(n_neighbors=10, metric='cosine')
knn.fit(test_features)
distances, indices = knn.kneighbors(test_features)

# Weighted average of predictions
for i in range(len(X_test)):
    neighbor_preds = predictions[indices[i]]  # (10, num_classes)
    weights = 1 / (distances[i] + 1e-8)  # Inverse distance
    weighted_pred = np.average(neighbor_preds, weights=weights, axis=0)
    final_predictions[i] = weighted_pred
```
