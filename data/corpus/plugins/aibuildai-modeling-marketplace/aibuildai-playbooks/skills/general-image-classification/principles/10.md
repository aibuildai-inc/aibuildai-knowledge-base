## Principle 10: Exploit Known Test Set Structure with Post-Processing Constraints

*Consensus: 1/8 QuickDraw solutions (winner); "secret sauce" gave +0.7%*

If the test set has a known structural constraint (e.g., equal class distribution), iteratively adjust predictions to satisfy that constraint. This is valid when the constraint is guaranteed, not inferred.

**Why this matters:** QuickDraw test set had exactly 330 samples per class (112,200 total / 340 classes = 330). Enforcing this via iterative probability reduction improved every model by ~0.7%. Without the constraint, models over-predict common classes.

**When to use:** ONLY when the test set structure is explicitly stated or mathematically guaranteed (e.g., equal distribution, known total per class, stratified sampling). QuickDraw organizers confirmed equal distribution. This is NOT data leakage if the constraint is public knowledge.

**When NOT to use:** When the test distribution is unknown or only estimated. Applying this to Inclusive Images (where the test distribution is unknown and potentially different from train) would overfit. Also skip if the constraint is not exact (e.g., 'approximately balanced').

**How to reason about it:**
Confirm constraint: does the competition explicitly state test set structure? For equal distribution: predict normally, then iteratively adjust. For each iteration: find the most over-predicted class, reduce all its probabilities by a small constant delta until it's no longer the most popular. Repeat until all classes have equal counts (or target counts). This is a form of calibration, not learning—it doesn't change model parameters, only post-processes predictions.

```python
# QuickDraw winner's equal-distribution post-processing
def balance_predictions(probs, target_per_class=330):
    """Iteratively reduce over-predicted classes to enforce equal distribution."""
    preds = np.argmax(probs, axis=1)
    n_classes = probs.shape[1]
    
    while True:
        counts = np.bincount(preds, minlength=n_classes)
        if counts.max() == counts.min():  # All equal
            break
        
        # Find most over-predicted class
        max_class = counts.argmax()
        
        # Reduce all probabilities for this class by small delta
        delta = 0.0001
        probs[:, max_class] -= delta
        preds = np.argmax(probs, axis=1)  # Re-assign
    
    return preds

# Apply to test predictions
balanced_preds = balance_predictions(test_probs, target_per_class=330)
# Gave ~0.7% boost on QuickDraw for every model
```
