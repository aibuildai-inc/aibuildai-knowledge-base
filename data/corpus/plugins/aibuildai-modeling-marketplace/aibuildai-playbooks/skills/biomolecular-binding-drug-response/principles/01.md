## Principle 1: Diagnose the Observation Modality, Output Structure, and Metric First

*Consensus: 7/7 BELKA writeups followed the molecular-structure branch; all detailed MoA solutions followed the cellular-profile branch. Every successful solution was shaped by its competition’s ranking-versus-probability metric.*

Before selecting a model, classify the task along three axes: molecular structure versus cellular response features, single/panel binding versus multi-label mechanism prediction, and ranking metric versus proper probability loss. These axes determine the useful inductive bias, validation diagnostics, and safe post-processing.

**Why this matters:** SMILES and molecular graphs encode connectivity, so locality and long-range structural interactions matter. Gene-expression and viability columns are an unordered assay vector, while columnwise log loss additionally punishes miscalibration; treating these regimes as interchangeable wastes model capacity and can optimize the wrong statistical objective.

**When to use:** Always. Use the molecular branch when inputs are SMILES, building blocks, fingerprints, or graphs; use the assay branch when each row is a perturbational profile with gene/cell measurements and treatment metadata.

**When NOT to use:** Do not choose a branch merely because the domain is called drug discovery. If both molecular structure and cellular profiles are available, benchmark separate encoders and late fusion rather than forcing both modalities through one tokenizer or one tabular stack.

**How to reason about it:**
Ask in order: (1) What physical object does one row represent? (2) Is feature order meaningful or arbitrary? (3) Are outputs independent labels, correlated labels, or molecule–target pairs? (4) Does the metric reward ordering, calibrated probabilities, or both? (5) What entity is novel at test time? The answers define the rest of the pipeline.

```python
from dataclasses import dataclass

@dataclass
class TaskSpec:
    modality: str          # "molecule" or "cellular_profile"
    metric: str            # "average_precision" or "log_loss"
    novelty_unit: str      # e.g. "building_block", "drug_id", "random_row"
    n_targets: int

if spec.modality == "molecule":
    representation = "smiles_or_graph"  # benchmark both if resources permit
else:
    representation = "normalized_assay_vector"

needs_calibration = spec.metric == "log_loss"
needs_rank_stability = spec.metric == "average_precision"
```
