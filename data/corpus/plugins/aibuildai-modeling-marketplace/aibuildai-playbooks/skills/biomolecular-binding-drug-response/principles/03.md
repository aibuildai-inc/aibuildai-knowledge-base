## Principle 3: Match the Backbone to the Representation Instead of Chasing Generic Complexity

*Consensus: 7/7 BELKA writeups used molecular sequence, fingerprint, or graph models, with simple SMILES sequence models repeatedly competitive. At least 12/14 MoA writeups used shallow MLP, residual MLP, TabNet, or learned convolutions over assay features.*

For molecular inputs, benchmark compact SMILES CNNs/Transformers against fingerprint MLPs and graph networks; for cellular profiles, start with strong normalized MLP/ResNet and TabNet baselines before imposing artificial spatial structure. Increase complexity only when it improves the relevant novelty stratum.

**Why this matters:** Architecture helps when its bias matches the data-generating structure. Character-level SMILES models can learn local chemistry cheaply while attention captures distant interactions; assay matrices often benefit more from stable dense feature mixing than from a deep sequence model because column order has no natural semantics.

**When to use:** Use sequence encoders when raw SMILES scale makes graph preprocessing expensive, graph networks when explicit atom/bond invariance produces validated gains, and dense/residual tabular models when inputs are fixed assay columns. Learned reshaping or DeepInsight-style CNNs are most valuable as diverse complements after proving CV value.

**When NOT to use:** Do not assume a chemistry-specific tokenizer, a very deep encoder, a large pretrained model, or a GNN must win. BELKA’s winner used a small four-layer Transformer, character-like tokenization repeatedly beat more elaborate tokenizers, and several graph or multi-input systems failed to improve. Likewise, MoA image conversions could overfit and were not required by most top teams.

**How to reason about it:**
Build a cost–quality frontier by representation and by novelty stratum. Compare a cheap local model, a global-context model, and one structurally explicit model. Prefer the simplest model on the frontier unless the more complex model adds either extrapolation quality or low-error-correlation ensemble value.

```python
def build_backbone(modality, kind, input_dim, n_targets):
    if modality == "molecule" and kind == "local":
        return SmilesCNN(vocab_size=VOCAB, n_targets=n_targets)
    if modality == "molecule" and kind == "global":
        return SmilesTransformer(vocab_size=VOCAB, n_targets=n_targets)
    if modality == "molecule" and kind == "graph":
        return MolecularGNN(n_targets=n_targets)
    if modality == "cellular_profile" and kind == "dense":
        return ResidualMLP(input_dim, n_targets)
    if modality == "cellular_profile" and kind == "tabnet":
        return TabularAttentionModel(input_dim, n_targets)
    raise ValueError("Benchmark only modality-compatible candidates")
```
