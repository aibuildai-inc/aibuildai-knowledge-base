## Principle 6: Separate Memorization and Extrapolation When the Test Set Mixes Both

*Consensus: 4/7 BELKA writeups explicitly built different shared/non-shared pipelines. In MoA, the 5th-place solution explicitly gated models for seen versus unseen drugs; several others blended random-split and drug-group-split models to cover both regimes.*

If test rows contain both familiar identities/components and novel ones, treat interpolation and extrapolation as different prediction regimes. Train or select models under matching validation schemes, then route or smoothly blend them using overlap or similarity evidence.

**Why this matters:** The bias–variance trade-off reverses across regimes: a high-capacity model or identity statistic can profitably memorize shared building blocks or repeated compounds, while the same shortcut collapses on unseen chemistry. A single regularization level often compromises both.

**When to use:** Use regime-specific models when overlap can be determined from metadata, molecular components, scaffold similarity, or a validated learned identity score. BELKA-style exact building-block overlap supports hard routing; uncertain compound identity supports soft gating.

**When NOT to use:** Do not gate on an unreliable novelty classifier or on information unavailable at inference. If the test set is uniformly novel, optimize only extrapolation; if uniformly repeated, a separate generalization model adds complexity without benefit. A strong single model may also be preferable when regime-specific CV gains do not survive repeated folds.

**How to reason about it:**
Estimate overlap and similarity before modeling. Measure each candidate on a 2×2 table: trained for interpolation/extrapolation versus evaluated on interpolation/extrapolation. Route only when diagonal specialization exceeds the variance introduced by the gate; otherwise blend robustly.
