## Principle 7: Handle Ordinal Relevance Targets with Binary or Classification Decomposition

*Consensus: Rare in the source writeups: one Home Depot top solution stacked regression-via-classification models among its level-1 models*

When targets are numeric grades with only a few discrete levels (for example relevance ratings on a 1-3 or 1-4 scale, or averages of a few such ratings), binary or ordinal encoding can beat direct regression, or at least add diversity to a stack. Convert the target into multiple binary tasks (t > threshold) and reconstruct via expected value.

**Why this matters:** Cross-entropy loss on binary tasks is better calibrated than MSE on continuous targets when underlying data is discrete. Encoding the target as one binary task per level (t > level_i) and using BCE loss, then computing expected value, keeps the ordering structure that pure regression ignores. A Home Depot top solution trained about 200 level-1 models, and some of them used regression via classification with extra-trees classifiers, which added model types beside its regressors for the stacker.

**When to use:** When targets have only a few distinct values, and the metric is rank-based or rewards the correct grade. Check training target histograms: if you see discrete levels, try ordinal encoding. Also useful when rare grades exist - binary encoding lets you weight rare events.

**When NOT to use:** Skip if targets are truly continuous (smooth distribution, 100+ unique values). For RMSE/MAE metrics, do not use it as the only model; add it to a stack beside regressors. Skip if training data is large and smooth (> 10k samples, well-distributed) - regression works fine.

**How to reason about it:**
Plot the target distribution. If you see clear peaks at discrete levels: encode as binary (t > level_i) for each level. Train with BCE loss. At inference: get probabilities p_i for each threshold, compute expected value: E[t] = sum(level_i * (p_{i-1} - p_i)). Alternatively: simpler approximation is mean(probabilities) when levels are evenly spaced.

```python
# Ordinal encoding for graded targets
import torch
import torch.nn as nn

class OrdinalRegressionHead(nn.Module):
    def __init__(self, input_dim, levels):
        super().__init__()
        self.levels = levels
        # N-1 binary classifiers for N levels
        self.threshold_layers = nn.ModuleList([
            nn.Linear(input_dim, 1) for _ in range(len(levels) - 1)
        ])
    
    def forward(self, x):
        # Predict P(t > level_i) for each threshold
        probs = [torch.sigmoid(layer(x)) for layer in self.threshold_layers]
        # Compute expected value
        expected = self.levels[0] * (1 - probs[0])
        for i in range(len(probs) - 1):
            expected += self.levels[i+1] * (probs[i] - probs[i+1])
        expected += self.levels[-1] * probs[-1]
        return expected, probs  # Return both for loss computation

# Loss: BCE on each threshold
def ordinal_loss(probs, target, levels):
    losses = []
    for i, p in enumerate(probs):
        binary_target = (target > levels[i]).float()
        losses.append(nn.BCELoss()(p, binary_target))
    return sum(losses) / len(losses)
```
