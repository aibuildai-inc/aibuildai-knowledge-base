## Principle 6: Ensemble Diverse Architectures, Not Just Different Seeds

*Consensus: Common in the source writeups - LLM Science, MAP and Home Depot top solutions ensemble multiple model families*

Ensembling models from different architectures or families (for example DeBERTa and Longformer encoders, or Llama, Mistral, Qwen and Phi decoders) or different input strategies dramatically outperforms ensembling the same model with different seeds. Diversity in what the models see and how they process it is key.

**Why this matters:** Different architectures have different inductive biases: masked bidirectional encoders read the whole input at once, while autoregressive decoders carry different pretraining knowledge. Different tokenizers (WordPiece vs SentencePiece) segment text differently. LLM Science 1st place ensembled Llama-2 and Mistral models; LLM Science 21st place combined DeBERTa-v3 and Longformer; a MAP top solution trained its models with different seeds and slightly different data formats. An ensemble that mixes model families, input formats and tokenizers corrects errors that extra seeds of one model repeat.

**When to use:** Always in the final stage. Start with single best model; once you plateau, add architecturally diverse models. Prioritize: (1) Different model families (encoder-only BERT vs encoder-decoder BART vs decoder-only GPT). (2) Different tokenizers (byte-pair vs WordPiece vs character). (3) Different input formats (prompt templates, context lengths, retrieved contexts). Then try different hyperparameters/seeds within each family.

**When NOT to use:** Don't ensemble 10 BERT-base models with different seeds as your first move - you'll get 0.001 gain. Don't add models that are highly correlated with existing ensemble (check prediction correlation; if > 0.95, skip). Don't add models if inference time is constrained and the marginal gain is < 0.003.

**How to reason about it:**
Measure diversity: calculate pairwise prediction correlation between candidate models. Target: add models with correlation < 0.90 to your best model. Blend methods: simple average works well; weighted average tuned on validation adds 0.001-0.003; rank averaging for ranking metrics. Check if different models excel at different subsets (e.g., one model better on short text, another on long) - blend conditionally or train a meta-model.
