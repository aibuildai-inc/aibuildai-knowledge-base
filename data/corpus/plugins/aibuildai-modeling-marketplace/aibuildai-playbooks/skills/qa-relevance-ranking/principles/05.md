## Principle 5: Post-Process Predictions to Match Target Distribution and Metric

*Consensus: Large impact in Eedi (rescaling seen versus unseen misconceptions) and MAP (filtering labels by question)*

For bounded targets or label sets with known structure, post-processing raw predictions to match the training distribution or to apply rules learned from training data is a cheap, measurable gain. Common techniques: clipping to the valid range, candidate filtering by known label structure, rescaling seen versus unseen labels.

**Why this matters:** Models produce raw scores, but the targets and labels have structure the model does not enforce. For Eedi, rescaling the scores of misconceptions seen in training against unseen ones sharply raised the score, because the hidden test held many unseen misconceptions. For MAP - Charting Student Math Misunderstandings, several top solutions kept only the labels that appeared for the same QuestionId in training. Post-processing is low-risk (reversible) and often the difference between silver and gold.

**When to use:** Always try for: (1) Bounded targets (for example relevance on a fixed scale) - clip predictions to the valid range. (2) Label sets where training data shows which labels each question or group can take - filter or rescale candidates. (3) Test sets that hold labels never seen in training - rescale seen versus unseen candidates. (4) When annotator guidelines are known.

**When NOT to use:** Don't apply aggressive post-processing if CV and LB have different distributions (you'll overfit public LB). Don't discretize for RMSE/MAE metrics (continuous predictions are correct). Don't over-tune with 100+ rules (each rule is a risk for private LB shift).

**How to reason about it:**
Start by analyzing training target distributions: plot histograms, check the valid range, identify rare events. For bounded targets: clip predictions to the valid range, then test tighter bounds on out-of-fold predictions. For label prediction: build the set of labels seen for each question or group in training, and check how often test predictions fall outside it. For multi-label: check if certain labels co-occur or are mutually exclusive. Validate every post-processing on held-out data or public LB.

# Clip bounded targets; tune the bounds on out-of-fold predictions
def best_clip(y_true, oof_pred, lo_valid, hi_valid, metric, steps=20):
    best = (lo_valid, hi_valid)
    best_score = metric(y_true, np.clip(oof_pred, lo_valid, hi_valid))
    for lo in np.linspace(lo_valid, np.quantile(oof_pred, 0.05), steps):
        for hi in np.linspace(np.quantile(oof_pred, 0.95), hi_valid, steps):
            score = metric(y_true, np.clip(oof_pred, lo, hi))
            if score > best_score:
                best, best_score = (lo, hi), score
    return best
