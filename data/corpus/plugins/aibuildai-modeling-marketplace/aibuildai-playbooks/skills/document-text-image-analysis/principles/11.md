## Principle 11: Validate Structured Outputs with Auxiliary Models or Checks

*Consensus: Seen in several top graph solutions. Used auxiliary point-count models or geometry checks to filter/correct predictions.*

Use auxiliary models or rule checks to validate primary predictions: a separate model that counts objects (for example scatter points) to correct the primary output, geometry-consistency checks for graphs, or agreement checks across ensemble members.

**Why this matters:** Primary models make systematic errors detectable by auxiliary signals: graph points outside the plot area or not aligned to axes, a number of predicted points that disagrees with a point-count model, predictions inconsistent across ensemble members. Auxiliary models catch these cheaply without retraining primary model.

**When to use:** When primary model has a specific failure mode (false positives, geometric inconsistencies, low-confidence ambiguous cases), when you can extract features characterizing failure (overlap, spacing, multi-model agreement), or when you have validation data showing failure patterns.

**When NOT to use:** When failure modes are not systematic or featurizable, when you lack validation data to train auxiliary models, or when primary model errors are rare (<1%) and auxiliary model would overfit to noise.

**How to reason about it:**
Analyze validation errors: is there a pattern? For detection: remove boxes that break layout rules (for example data points outside the detected plot area, axis labels on the wrong side of the plot). For sequence outputs: compare the predicted number of items with a separate counting model (for example a point segmentation model with NMS), then trim extra items or fill missing ones. For graphs: check geometric constraints (points should interpolate between tick labels, categorical values should match tick labels).

```python
# Geometry check: drop detected points outside the plot area
def filter_points(points, plot_bbox):
    x1, y1, x2, y2 = plot_bbox
    return [(px, py) for px, py in points if x1 <= px <= x2 and y1 <= py <= y2]

# Count check: reconcile a generated data series with a point-count model
def reconcile_series(values, point_mask):
    n_points = len(nms_peaks(point_mask))  # points found by a segmentation model + NMS
    if len(values) > n_points:
        values = values[:n_points]  # too many values: drop the last ones
    elif len(values) < n_points:
        values = values + [np.mean(values)] * (n_points - len(values))  # too few: fill with the mean
    return values
```
