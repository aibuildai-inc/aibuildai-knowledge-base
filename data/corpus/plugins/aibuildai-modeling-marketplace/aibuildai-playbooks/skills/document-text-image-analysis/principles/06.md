## Principle 6: Use Multi-Stage Training: Domain Adaptation then Task Specialization

*Consensus: Recurring in top Benetech solutions. Two-phase training (synthetic→real, coarse→fine, or general→specialized) consistently outperformed single-stage.*

Train in multiple stages with different objectives or data distributions. Stage 1: broad/synthetic data for general features. Stage 2: narrow/real data for task-specific adaptation. Optionally stage 3: fine-tune on extracted/hard samples.

**Why this matters:** Models overfit to training distribution. Multi-stage training lets you leverage large synthetic data for diversity then adapt to real data's style without overfitting to its limited size. Also enables specialization: train separate models for scatter vs bar charts after shared initialization.

**When to use:** When you have abundant synthetic + scarce real data, when task has subtypes requiring specialization (scatter vs line graphs), when you can afford multi-stage training time, or when single-stage overfits to synthetic or underutilizes real data.

**When NOT to use:** When training time is constrained and single-stage works, when real data is abundant (>100k samples), when synthetic→real transfer is poor (validate this first), or when task is homogeneous (no subtypes needing specialization).

**How to reason about it:**
Stage 1: Train on large synthetic dataset (100k-1M samples) for 5-10 epochs with normal LR. Stage 2: Fine-tune on real data (1k-10k samples) for 2-5 epochs with 10× lower LR, optionally oversampling real data. Stage 3 (optional): Specialize—train separate models for subtypes (e.g., Benetech 1st: one model for scatter, another for bars/lines) or fine-tune on hardest samples. Validate that each stage improves on a held-out real validation set.

```python
# Stage 1: Train on synthetic data
model = Model(backbone='efficientnet-b5')
train(model, synthetic_data, epochs=8, lr=1e-4)

# Stage 2: Fine-tune on real extracted data with lower LR
# Oversample real data to balance with synthetic
real_oversampled = real_data * 8  # repeat real data
combined = synthetic_data + real_oversampled
train(model, combined, epochs=5, lr=1e-5)

# Stage 3: Specialize for subtypes (e.g., scatter only)
scatter_model = deepcopy(model)
scatter_data = filter_by_type(combined, chart_type='scatter')
train(scatter_model, scatter_data, epochs=3, lr=5e-6)

# At inference: route by chart type to specialized models
if chart_type == 'scatter':
    output = scatter_model(image)
else:
    output = model(image)
```
