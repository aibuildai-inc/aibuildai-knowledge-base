## Principle 12: Leverage External Datasets with Careful Annotation Alignment

*Consensus: 8/10 graph solutions. ICDAR, WikiTables, and domain-specific corpora helped, but required annotation cleaning/reformatting.*

Incorporate external datasets (ICDAR for graphs/documents, WikiTables for data, domain-specific corpora) after aligning annotations to competition format and manually cleaning errors.

**Why this matters:** External data adds diversity beyond competition data. ICDAR has real-world graph styles, WikiTables has realistic data distributions. But annotation formats differ (percentages, tick conventions, label notation) and contain errors. Using raw external data hurts; cleaned external data helps significantly.

**When to use:** When competition data is limited (<10k samples), when you can find domain-matched external data (ICDAR for graphs), when you have time to clean/realign annotations, or when external data has higher diversity than competition synthetic data.

**When NOT to use:** When competition data is abundant (>100k samples), when external data is mismatched (different task or quality), when annotation cleaning cost exceeds benefit, or when competition prohibits external data.

**How to reason about it:**
Find domain-matched external datasets. Download a sample (100-500 images). Manually check annotations against competition format: do tick labels match? Are percentages formatted correctly? Are bounding boxes accurate? If <90% match, write conversion logic OR manually clean. After cleaning, validate external data improves validation score before scaling up. # Example: Align ICDAR graph annotations to competition format
def align_icdar_to_benetech(icdar_annotation):
    # ICDAR uses percentages as 0-100, competition uses 0-1 → no, uses X not X/100
    # But convention: '21.5%' label → store as 21.5 not 0.215
    
    x_values = icdar_annotation['x_values']
    y_values = icdar_annotation['y_values']
    
    # Remove '%' suffix if present, keep as numeric
    x_values = [float(v.rstrip('%')) for v in x_values]
    y_values = [float(v.rstrip('%')) for v in y_values]
    
    # Interpolate line/bar values to match tick labels (competition requirement)
    if icdar_annotation['chart_type'] == 'line':
        x_ticks = icdar_annotation['x_tick_labels']
        # Only keep y-values where x aligns with a tick
        aligned_y = [y for x, y in zip(x_values, y_values) if x in x_ticks]
        y_values = aligned_y
    
    return {'x': x_values, 'y': y_values, 'chart_type': icdar_annotation['chart_type']}
