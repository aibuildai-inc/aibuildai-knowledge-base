## Principle 5: Predict at Component Level When Output Space is Compositional

*Consensus: 5/8 Bengali top solutions. Component-level prediction outperformed direct grapheme prediction for compositional outputs.*

Decompose the output into components and predict each separately when the output is compositional. For Bengali: predict root/vowel/consonant rather than full grapheme.

**Why this matters:** Compositional prediction reduces output space and improves generalization to unseen combinations. Bengali has 168 roots × 11 vowels × 8 consonants = 14,784 graphemes but only 1,295 appear in train. Predicting components requires learning 168+11+8=187 classes vs 14,784, enabling zero-shot composition.

**When to use:** When outputs decompose into independent or semi-independent components, when many valid combinations are absent from training, when components have unequal frequencies (rare combinations penalized by macro-average metrics), or when you can derive composition rules (Bengali unicode composition).

**When NOT to use:** When components are tightly coupled (predicting one requires knowing others), when composition rules are complex/ambiguous, when end-to-end sequence models (transformers) can learn implicit composition, or when you lack clear decomposition logic. End-to-end sequence generation combined with candidate reranking can be competitive with component approaches.

**How to reason about it:**
Map output space: can you decompose into <1000 components each? Are composition rules well-defined? If yes, predict components. For Bengali, use multi-head model (3 heads for root/vowel/consonant) or separate models, then compose via unicode rules. For complex cases (graph data series), end-to-end transformers (Deplot/Matcha) may implicitly learn composition better than manual decomposition.

```python
# Multi-head component prediction
class ComponentClassifier(nn.Module):
    def __init__(self, backbone, n_root=168, n_vowel=11, n_consonant=8):
        self.backbone = backbone  # ResNet, EfficientNet
        self.root_head = nn.Linear(backbone.out_features, n_root)
        self.vowel_head = nn.Linear(backbone.out_features, n_vowel)
        self.consonant_head = nn.Linear(backbone.out_features, n_consonant)
    
    def forward(self, x):
        features = self.backbone(x)
        return {
            'root': self.root_head(features),
            'vowel': self.vowel_head(features),
            'consonant': self.consonant_head(features)
        }
```
