## Principle 4: Apply Task-Specific Augmentations That Match Test Distribution

*Consensus: Recurring in top solutions. Cutmix/fmix for Bengali, noise/blur/compression for scanned or photographed ECG printouts, color/blur for graphs. Generic augmentations (flips, rotates) often hurt.*

Use augmentations that reflect real-world variation in your domain. Analyze train-test differences and augment to close the gap. Avoid augmentations that create invalid samples.

**Why this matters:** Generic augmentations can create unrealistic samples that harm learning (vertical flip breaks text reading order, rotation invalidates graph axes). Domain-specific augmentations teach invariances that actually exist: cutmix simulates overlapping/connected characters; noise, blur, and compression match scanner and phone-camera artifacts; color jitter handles lighting variation.

**When to use:** Always. Start with domain analysis: what varies in real data? For text: mixing (overlaps, ligatures), occlusion, noise. For graphs: style/color diversity, annotation patterns. For scanned documents: noise type (gaussian vs salt-and-pepper), blur, contrast. Match augmentation to observed train-test gap.

**When NOT to use:** Avoid augmentations that violate domain constraints: no vertical/horizontal flip for text unless symmetry exists (digits, some symbols), no rotation beyond minor angles for charts with axes, no color augmentation for grayscale-only tasks.

**How to reason about it:**
Analyze test samples (if available) or EDA: Is noise gaussian or impulse? Do characters overlap/connect? Are graphs styled diversely? Then match: (1) For overlapping elements → cutmix/fmix. (2) For scan or photo artifacts → noise/blur/compression. (3) For style diversity → color jitter/contrast. (4) For orientation variation → small rotation only if domain-valid. Validate each augmentation ablates positively on held-out data.

# Mixing augmentation (fmix) for overlapping characters
import fmix  # https://github.com/ecs-vlc/FMix
def fmix_augment(images, labels, alpha=4):
    mask = fmix.sample_mask(alpha, decay_power=3, shape=images[0].shape[:2])
    mixed_image = mask * images[0] + (1 - mask) * images[1]
    mixed_label = alpha * labels[0] + (1-alpha) * labels[1]  # soft labels
    return mixed_image, mixed_label

# Scanned or photographed pages: sensor noise, blur, and compression artifacts
