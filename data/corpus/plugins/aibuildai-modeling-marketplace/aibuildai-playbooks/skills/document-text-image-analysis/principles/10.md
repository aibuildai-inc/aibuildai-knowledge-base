## Principle 10: Use Pseudo-Labeling on Test Data for Writer/Style Adaptation

*Consensus: 4/6 Kannada-MNIST top solutions pseudo-labeled test data; the top 3 graph solutions pseudo-labeled extra unlabeled chart images. Confident predictions added to train improved the leaderboard score.*

Generate pseudo-labels for test data using confident predictions (keep only samples above a confidence threshold checked on validation), add to training set, and retrain. Especially effective when test has different style/writer/domain than train.

**Why this matters:** Each data source has its own style (handwriting, font, rendering, graph styling). Pseudo-labeling lets the model adapt to test distribution's style without labeled test data. Works because high-confidence predictions are almost always correct, so the added labels carry little noise.

**When to use:** When test distribution differs in style (not label distribution), when model confidence is well-calibrated (high confidence → high accuracy), when you can afford retraining, or when test set is large enough to provide diverse pseudo-labels (>1000 samples). Particularly effective for writer adaptation, domain adaptation.

**When NOT to use:** When model confidence is poorly calibrated (overconfident on mistakes), when test set is tiny, when pseudo-label accuracy is <95% (noise hurts more than adaptation helps), or when train and test are already well-matched (no adaptation needed).

**How to reason about it:**
After training initial model (or an ensemble), predict on test with confidence scores. Keep predictions above a probability threshold (for example 0.95 on the ensemble average), and check the accuracy of the kept samples on held-out train data before you use them. Add pseudo-labeled test data to training set. Retrain with two options: (1) Fine-tune existing model with a lower LR. (2) Train from scratch with combined train+pseudo data. Validate that LB improves. Iterate: regenerate pseudo-labels with new model, retrain.

```python
# Generate pseudo-labels
test_preds = model.predict_proba(X_test)
confidences = test_preds.max(axis=1)
pseudo_labels = test_preds.argmax(axis=1)

# Filter to high-confidence predictions
confidence_threshold = 0.95  # probability threshold; check it on validation
high_conf_mask = confidences > confidence_threshold

X_pseudo = X_test[high_conf_mask]
y_pseudo = pseudo_labels[high_conf_mask]

# Validate pseudo-label quality on held-out train
val_preds = model.predict_proba(X_val)
val_conf = val_preds.max(axis=1)
val_filtered = val_conf > confidence_threshold
val_acc = (val_preds.argmax(axis=1)[val_filtered] == y_val[val_filtered]).mean()
print(f'Pseudo-label accuracy estimate: {val_acc:.3f}')  # Should be close to 1.0

# Retrain: fine-tune with combined data
X_combined = np.vstack([X_train, X_pseudo])
y_combined = np.hstack([y_train, y_pseudo])
train(model, X_combined, y_combined, lr=lower_lr)
```
