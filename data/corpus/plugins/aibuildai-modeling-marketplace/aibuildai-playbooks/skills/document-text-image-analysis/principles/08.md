## Principle 8: Analyze and Close Train-Test Distribution Gaps Early

*Consensus: Most top solutions explicitly mentioned gap analysis. CV-LB correlation was the primary validation signal.*

Systematically compare train and test distributions before deep modeling. Probe public LB to identify which subgroups hurt. Match CV to LB by stratified splitting or targeted augmentation.

**Why this matters:** Hidden test distribution shifts (unseen graphemes, noisier scans, different graph styles) cause large CV-LB gaps and shakeups. Early gap analysis guides augmentation, synthetic data generation, and validation strategy. Bengali had 0.998 CV vs 0.987 LB due to unseen graphemes.

**When to use:** Always, at competition start. Compare: (1) Label distributions (are test labels balanced differently?). (2) Visual features (noise, resolution, style). (3) Probe LB by ablating subgroups (submit only class X, measure drop). (4) Stratify validation to match test (if test has more rare classes, oversample them in validation).

**When NOT to use:** This is foundational—skip only if train and test are guaranteed i.i.d. (rare in real competitions).

**How to reason about it:**
Week 1: Probe public LB to identify weak subgroups (submit predictions with specific classes zeroed out, measure impact). Visualize train vs test samples—are test images noisier, rotated, styled differently? Create validation split stratified by identified gaps (e.g., group validation folds by source document, validate on extracted-only for graphs). Monitor CV-LB correlation: if CV improves but LB doesn't, you're overfitting to train distribution. Adjust augmentation or data generation to close observed gaps.
