# SUMMARY
Similar to other solutions, our pipeline also consists of object detection for scatter points and end-to-end plot prediction by deplot for other graphs.
**Scatter plots**: plot-bb detection with YOLOX + scatter point detection with YOLOX + OCR of max/min axis labels with matcha
**Other graphs**: deplot trained with original synthetic data

# Scatter point detection
We used the following two steps object detection to detect scatter points and determined the coordinates of scatter points from the axis labels read by matcha.

Step 1. plot-bb detection by YOLOX (model size : x, image size : 640)
Step 2. scatter points detection with "plot-bb cropped" image by YOLOX (model size : x, image size : 960)

Training data for step.2 is the competition data (generated, extracted)+ 538 scatter plots from ICDAR dataset.

Public LB : Private LB = 0.09 : 0.29

# Bar graph, line graph, dot graph

We used a variety of graph data sources for training deplot,

1. generated graph (competition data)
2. extracted graph (competition data)
3. ICDAR dataset (1185 single series + 2992 multiple series)
4. @brendanartley 's 500k dataset (except scatter)
5. original synthetic dataset (vertical bar: 40000, horizontal bar: 40000, line: 40000)
6. original synthetic dataset (histogram : 10000)

## original dataset (generated by matplotlib)
Our key focus of this competition is data generation.
We generated graphs with various patterns to make our model robust against unknown private dataset.
The generated graphs were evaluated using the competition dataset (extracted) and the ICDAR dataset.
Continuous graph modification and feedback from error analysis allowed predictions to be made on difficult data.
Our data was especially helpful in improving the accuracy of line graphs (so it is very important whether the line is on the tick label or not!).

Some attempts for improving common mistakes:
- line plot with no value on some tick labels
- JPG compression to lower quality (simulate low resolution and blurred characters)
- add symbols ($ % , .) to distinguish numbers and symbols (like 8 and $)
- extended predicted digits for small values (like < 0.0001)
- separate labels into multiple lines
- etc..

## Training (deplot)
### training data configuration
| source | # of samples per epoch | total graphs |
| --- | --- |
| generated | 1000| 50000 |
| extracted | 953 | 953 |
| ICDAR | 1000 | 4177 |
| 500k dataset | 1000 | 400000 |
| original synthetic data | 2000 | 120000 | 
| original synthetic data (histogram) | 100 | 10000 | 

For each epoch, we randomly sampled the graphs for each source at the above ratios.

### training conditions
epochs: 50
learning rate: 2e-4
scheduler: cosine annealing
batch (accumulation): 64
