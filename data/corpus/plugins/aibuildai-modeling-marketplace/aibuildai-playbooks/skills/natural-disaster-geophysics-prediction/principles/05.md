## Principle 5: Use Multi-Stage Pseudo-Labeling on Unlabeled Test Data

*Consensus: 4 waveform inversion solutions (1st/10th/14th/24th) built pseudo-labeled pairs from test predictions through the forward model; ClimSim 10th also trained on pseudo-labeled test data*

Train a strong baseline on labeled data, predict the unlabeled test inputs, turn those predictions into extra training pairs, then retrain or fine-tune on the combined set. Repeat for 2-3 rounds, and predict the test set again with the improved model before each new round.

**Why this matters:** Test inputs often differ slightly from the training distribution. Training on pseudo-labeled test samples adapts the model to that distribution. When a forward simulator exists, the pseudo-labels carry no label noise: run the simulator on each predicted target to regenerate its input, and the new pair (regenerated input, predicted target) is exactly consistent. Each round gives a better model, which gives better pseudo-labels for the next round.

**When to use:** For: (1) tasks where the unlabeled test inputs are available, (2) a baseline that is already strong on validation, (3) a test distribution that differs slightly from train, (4) tasks with a forward simulator, or with a reliable confidence measure for each prediction. Most effective when an ensemble of diverse models produces the pseudo-labels, which limits confirmation bias.

**When NOT to use:** Skip for: (1) tasks where test data is not accessible (some competitions hide it), (2) a baseline that already overfits (val score << train score), (3) tasks with no simulator and no confidence measure, where wrong pseudo-labels reinforce themselves, (4) classification tasks where adding high-confidence predictions directly is simpler.

**How to reason about it:**
**Round 1**: Train diverse models on labeled data with K-fold CV. Ensemble their predictions on test. **Build pseudo-labels**: With a forward simulator, run it on each predicted target and keep the pair (regenerated input, predicted target). Without a simulator, keep only the test samples where the ensemble is confident. **Round 2**: Retrain or fine-tune on train + pseudo-labeled pairs. Validate only on held-out real labeled data, never on pseudo-labels. **Round 3+**: Predict the test set again with the Round 2 models, rebuild the pseudo-labels, and repeat while the validation score improves. **Final**: Ensemble the models from the last rounds.

```python
import numpy as np

def build_pseudo_pairs(models, test_inputs, forward_model=None, confidence_fn=None, min_confidence=None):
    preds = np.mean([m.predict(test_inputs) for m in models], axis=0)

    if forward_model is not None:
        # Physics-consistent pairs: the regenerated input matches the predicted target exactly
        regenerated = np.stack([forward_model(p) for p in preds])
        return regenerated, preds

    # Without a simulator: keep only confident samples
    confidence = confidence_fn(preds)          # one score per sample
    keep = np.where(confidence >= min_confidence)[0]
    print(f"Kept {len(keep)} pseudo-labels ({len(keep) / len(test_inputs) * 100:.1f}% of test)")
    return test_inputs[keep], preds[keep]
```
