## Principle 12: Use Test-Time Augmentation (TTA) for Invariant Predictions

*Consensus: 6/10 waveform inversion solutions used TTA.*

At inference, apply valid augmentations (horizontal flip, small crops) to each test sample, predict on all versions, and average the predictions. For image-shaped outputs, flip the prediction back before averaging. This reduces variance and exploits symmetries.

**Why this matters:** Deep models have residual variance - the same input can get slightly different predictions due to floating-point noise or dropout (if enabled at test). Averaging over augmented versions smooths this out. For tasks with true invariances (horizontal symmetry in seismic images), TTA enforces this and often gives a small but consistent gain.

**When to use:** When: (1) your task has physical invariances (horizontal symmetry in seismic images), (2) you have inference time budget (TTA doubles/quadruples compute), (3) your model has some variance (check by predicting same sample twice - if results differ, TTA helps). Standard for image-to-image tasks such as waveform inversion. Less useful for time-series regression where temporal order breaks symmetry.

**When NOT to use:** Skip when: (1) no true invariances (earthquake time-series has temporal direction), (2) inference time is constrained (real-time applications), (3) your model is already deterministic and predictions are identical on repeat, (4) validation shows TTA doesn't help (test it first!).

**How to reason about it:**
1. **Identify valid augmentations**: For seismic images, horizontal flip is valid when the target structure is symmetric. Vertical flip is NOT (gravity direction). 2. **Inference**: For each test sample, generate K augmented versions (original, h-flip, maybe small shifts). 3. **Predict**: Pass each version through the model → get K predictions. 4. **Invert augmentations**: If you flipped the input, flip the prediction back to original orientation. 5. **Average**: Arithmetic mean of K predictions. For thresholded outputs, average probabilities then threshold, not average masks. 6. **Validate**: Check TTA on validation set - it should improve the score. If not, the augmentations aren't valid or model is already stable.

```python
import numpy as np

def predict_with_tta(model, image, num_augmentations=2):
    """
    Test-time augmentation for an image-to-image seismic task.
    Augmentations: original + horizontal flip
    """
    predictions = []
    
    # 1. Original image
    pred_original = model.predict(image)  # Shape: (H, W)
    predictions.append(pred_original)
    
    # 2. Horizontal flip
    image_flipped = np.fliplr(image)
    pred_flipped = model.predict(image_flipped)
    pred_flipped_back = np.fliplr(pred_flipped)  # Flip prediction back
    predictions.append(pred_flipped_back)
    
    # Average the continuous predictions (probabilities, not thresholded masks)
    avg_prediction = np.mean(predictions, axis=0)
    
    return avg_prediction
```
