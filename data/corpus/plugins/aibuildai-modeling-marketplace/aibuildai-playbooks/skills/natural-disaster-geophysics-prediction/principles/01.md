## Principle 1: Align Train and Test Distributions Before Building Models

*Consensus: 10/15 earthquake solutions, 3/5 rainfall solutions explicitly mentioned this*

Geophysical data often has temporal drift or sampling bias. Use statistical tests (KS statistics, adversarial validation) to identify distribution mismatches, then subsample training data or engineer features that are robust to the shift.

**Why this matters:** Raw sensor measurements often contain time-dependent trends (baseline drift, instrument calibration changes) that make mean/quantile features unstable. Models trained on the full distribution overfit to artifacts that don't exist in test data, while models trained on distribution-aligned subsets generalize better.

**When to use:** When: (1) adversarial validation AUC > 0.6 between train and test, (2) feature distributions visibly differ between train/test on EDA, (3) public LB has low correlation with CV. Particularly critical for continuous-recording sensors (seismic, weather radar) where temporal position matters.

**When NOT to use:** Skip when train and test are from the same experimental run or when the task is segmentation/classification where position doesn't affect the target. Also skip if you have < 10 complete event cycles - not enough data to subsample reliably.

**How to reason about it:**
1. Calculate a small set of candidate features on both train and test. 2. For each feature, run a two-sample KS test or build a binary classifier (train vs test). 3. If KS p-value < 0.05 or AUC > 0.55 for many features, you have drift. 4. **Subsample strategy**: Sample different earthquake cycles (or time windows) from training data, compute KS statistics between each subsample and full test, select the subsample with lowest average KS across features. 5. **Robust feature strategy**: Add noise to raw signals (e.g., N(0, 0.5)), subtract segment median, use only features with KS p > 0.05. 6. Validate that your final train subset has similar target distribution to what you expect in test (compare histograms).
