## Principle 4: Minimize Feature Count Through Aggressive Selection

*Consensus: 5/15 earthquake solutions emphasized this (1st: 4 features, 7th: 7+4, 15th: 7 features)*

With limited geophysical data (often <5000 independent events), fewer features generalize better. Use statistical significance testing (p-value on CV improvement, KS test between train/test) to keep only features that robustly improve your metric, not just on one CV fold.

**Why this matters:** Overfitting is the primary failure mode when you have 10-20 earthquake cycles but can generate 2000+ features. Each noisy feature adds variance without information. Top solutions used 4-15 features, not 400. The discipline of discarding features that don't meet a significance threshold prevents CV-test divergence.

**When to use:** When: (1) you have < 5000 independent samples (event cycles, not time windows), (2) you can generate >100 candidate features, (3) public LB has weak correlation with CV. Critical for regression tasks with continuous targets where feature correlation is complex. Less critical for classification or when you have >100k samples.

**When NOT to use:** Not needed for: (1) deep learning end-to-end (the model learns feature importance), (2) problems with >50k independent samples where regularization handles it, (3) tree-based models with strong regularization (XGBoost with high min_child_weight), (4) when you have <20 features total.

**How to reason about it:**
1. **Generate a large candidate pool** (200-2000 features from multiple signal representations). 2. **Statistical pre-filter**: For each feature, run a KS test between train and test distributions. Drop any with p < 0.05 (distribution shift → likely to fail on test). 3. **Forward selection with significance**: Start with 0 features. For each candidate, add it, train a simple model (SVR or LGBM), compute CV score. Keep it only if CV improves by more than 0.5*std(CV) across folds. Repeat until no feature meets the threshold. 4. **Permutation importance**: On your final feature set, permute each feature and check CV drop. Remove any with importance < threshold. 5. **Correlation pruning**: If two features are correlated > 0.95, keep only the one with better individual importance. 6. Typical endpoint: 5-20 features.

```python
from scipy.stats import ks_2samp
import lightgbm as lgb
import numpy as np

def select_features_with_significance(train_features, test_features, train_target, cv_folds, threshold_pvalue=0.05):
    # Step 1: Filter features with train-test distribution shift
    valid_features = []
    for col in train_features.columns:
        stat, pvalue = ks_2samp(train_features[col], test_features[col])
        if pvalue > threshold_pvalue:  # No significant shift
            valid_features.append(col)
    
    print(f"Kept {len(valid_features)}/{len(train_features.columns)} features after KS filter")
    
    # Step 2: Forward selection with CV significance
    selected = []
    baseline_scores = []
    
    while True:
        best_feature = None
        best_improvement = 0
        
        for candidate in valid_features:
            if candidate in selected:
                continue
            
            # Train with selected + candidate
            features = selected + [candidate]
            cv_scores = []
            
            for train_idx, val_idx in cv_folds:
                model = lgb.LGBMRegressor(n_estimators=100, learning_rate=0.05)
                model.fit(train_features.iloc[train_idx][features], train_target.iloc[train_idx])
                val_pred = model.predict(train_features.iloc[val_idx][features])
                mae = np.mean(np.abs(val_pred - train_target.iloc[val_idx]))
                cv_scores.append(mae)
            
            # Check if improvement is significant (> 0.5 * std)
            if len(baseline_scores) > 0:
                improvement = np.mean(baseline_scores) - np.mean(cv_scores)
                std_cv = np.std(cv_scores, ddof=1)
                if improvement > 0.5 * std_cv and improvement > best_improvement:
                    best_feature = candidate
                    best_improvement = improvement
                    best_cv = cv_scores
        
        if best_feature is None:
            break
        
        selected.append(best_feature)
        baseline_scores = best_cv
        print(f"Added {best_feature}, CV: {np.mean(best_cv):.4f}")
    
    return selected
```
