## Principle 10: Ensemble Diverse Model Families, Not Just Multiple Seeds

*Consensus: 15/15 earthquake solutions, 10/10 waveform solutions - all ensembled*

Blend predictions from structurally different models: GBDT + neural network + SVR, or ResNet + ResNeXt + DenseNet. Diversity in architecture, input representation, or training approach captures complementary patterns and reduces overfitting more than averaging 10 runs of the same model.

**Why this matters:** Ensembling reduces variance, but only if models make different errors. Ten LightGBM models with different seeds are highly correlated; they all share the same inductive bias. A blend of LightGBM (tree-based) + SVR (kernel-based) + LSTM (sequential) makes uncorrelated errors and averages them out. Top solutions consistently had 3-5 model families, not 10 copies of one.

**When to use:** Always for final submissions in competitions. Most effective when: (1) you have time to train multiple model types, (2) different models have similar validation scores (within 5% of each other), (3) their predictions have correlation <0.9. For geophysics tasks, the canonical trio is: GBDT on engineered features + CNN on spectrograms/images + neural net on raw signals.

**When NOT to use:** Skip if: (1) one model dominates by >10% and others add noise, (2) you have <1000 test samples (ensembling can overfit to test distribution via leaderboard probing), (3) inference time is critical and you can't afford multiple models. In production, a single well-tuned model often beats a complex ensemble.

**How to reason about it:**
1. **Train base models**: Pick 3-5 structurally different families. For tabular: LightGBM, XGBoost, CatBoost, SVR, KNN. For images: ResNet, ResNeXt, DenseNet, EfficientNet. For time-series: LSTM, GRU, 1D-CNN, Transformer. 2. **Check diversity**: Compute pairwise correlation of predictions on validation set. If all >0.95, you need more diversity (try different feature sets or architectures). 3. **Blending strategy**: (a) Simple average (equal weights), (b) Weighted average (optimize weights on validation via grid search or hill climbing), (c) Stacking (train a meta-model on base predictions). For geophysics, weighted average with 2-5 models usually wins. 4. **Typical weights**: Best single model gets 40-50%, next 2-3 get 20-30% each, weakest models get 5-10% (they still help!). 5. **Validate**: Ensemble should improve validation by 2-5% over best single model. If not, check for leakage or overfitting.

import numpy as np
from scipy.optimize import minimize

# Train diverse models
lgb_pred = train_lightgbm(train_features, train_target)
xgb_pred = train_xgboost(train_features, train_target)
svr_pred = train_svr(train_features, train_target)
nn_pred = train_neural_net(train_features, train_target)

# Stack predictions
val_preds = np.column_stack([lgb_pred, xgb_pred, svr_pred, nn_pred])

# Check correlation
import pandas as pd
corr_matrix = pd.DataFrame(val_preds).corr()
print("Prediction correlations:")
print(corr_matrix)
# If all >0.95, need more diversity!

# Optimize blend weights on validation set
def blend_loss(weights):
    weights = weights / weights.sum()  # Normalize to sum=1
    blended = val_preds @ weights
    mae = np.mean(np.abs(blended - val_target))
    return mae

# Find optimal weights
initial_weights = np.ones(4) / 4
result = minimize(blend_loss, initial_weights, bounds=[(0, 1)]*4, method='L-BFGS-B')
optimal_weights = result.x / result.x.sum()

print(f"Optimal weights: LGB={optimal_weights[0]:.2f}, XGB={optimal_weights[1]:.2f}, "
      f"SVR={optimal_weights[2]:.2f}, NN={optimal_weights[3]:.2f}")

# Apply to test set
test_preds = np.column_stack([lgb_test, xgb_test, svr_test, nn_test])
