## Principle 9: Use Multi-Task Learning with Auxiliary Targets to Regularize Predictions

*Consensus: 3/5 earthquake top solutions (1st place NN, 12th place RNN), 1/1 ClimSim 1st place*

For complex regression tasks, predict auxiliary targets alongside the main target: time-since-failure (inverse of time-to-failure), binary 'near-failure' class, or spatial/temporal metadata. Weight auxiliary losses lower than main loss, but use them to regularize the model.

**Why this matters:** Auxiliary tasks provide additional supervision signals that share underlying structure with the main task. Predicting time-since-failure alongside time-to-failure helps the model learn a consistent temporal representation. Predicting earthquake phase (early/middle/late) as a classification task stabilizes regression predictions at extreme values. The model learns more robust features.

**When to use:** When: (1) you can define auxiliary targets that correlate with but aren't identical to the main target, (2) your main target has difficult regimes (very high/low values, sharp transitions), (3) you have metadata (time, location) that's available in train but not test - use it as auxiliary loss. Most effective for neural networks (easy to add heads); less for GBDTs.

**When NOT to use:** Skip if: (1) you can't define meaningful auxiliary targets, (2) you're using pure GBDT (no multi-output), (3) your dataset is tiny (<1k samples) and auxiliary loss adds too much complexity, (4) single-task model already performs well and you're short on time.

**How to reason about it:**
1. **Identify auxiliary targets**: For time-to-failure, add time-since-failure (simple: max_ttf - ttf). For regression, add binary 'extreme' class (ttf < 0.5 or ttf > 10). For geospatial data with lat/lon in train, add lat/lon prediction. 2. **Architecture**: Add separate prediction heads (one per auxiliary task) branching from the shared backbone. 3. **Loss weighting**: Main task weight = 1.0, auxiliary weights = 0.1-0.3 each. Tune on validation. 4. **Training**: Compute total loss = main_loss + sum(aux_weight * aux_loss). Backprop on total. 5. **Inference**: Use only main task prediction; auxiliary heads are discarded. 6. **Validation**: Check that auxiliary tasks are actually learning (aux loss should decrease). If an auxiliary task flatlines, it's not helping - remove it.

import torch
import torch.nn as nn

class MultiTaskSeismicModel(nn.Module):
    def __init__(self, input_dim=400, hidden_dim=256):
        super().__init__()
        # Shared backbone
        self.backbone = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Main task: time-to-failure regression
        self.head_ttf = nn.Linear(hidden_dim, 1)
        
        # Auxiliary task 1: time-since-failure regression
        self.head_tsf = nn.Linear(hidden_dim, 1)
        
        # Auxiliary task 2: binary 'near failure' classification
        self.head_binary = nn.Linear(hidden_dim, 1)
    
    def forward(self, x):
        features = self.backbone(x)
        ttf = self.head_ttf(features)
        tsf = self.head_tsf(features)
        near_failure = torch.sigmoid(self.head_binary(features))
        return ttf, tsf, near_failure
