## Principle 2: Design Cross-Validation to Respect Physical Event Boundaries

*Consensus: 15/15 earthquake solutions used event-aware CV*

Never split within a continuous physical event (earthquake cycle, storm system). Group-based CV that respects event boundaries prevents leakage and produces reliable validation scores when events have variable characteristics.

**Why this matters:** Adjacent time windows within the same event are highly autocorrelated - a model can 'cheat' by learning the event's signature rather than the underlying physics. Shuffled CV on overlapping segments gives artificially optimistic scores that don't transfer to unseen events. Event-grouped CV with stratification by event duration/intensity ensures folds have similar difficulty.

**When to use:** Always for time-series tasks where data comes from discrete physical events (earthquakes, storms). Critical when training data has 5-20 complete events and test has 2-5 unseen events. Also when events have variable duration (5s to 16s earthquakes) - stratify folds by duration AND target distribution to get stable CV.

**When NOT to use:** Not needed for: (1) spatial tasks without temporal autocorrelation, where each image is independent, (2) very large datasets with thousands of events (ClimSim with 40M samples), (3) inverse problems where each sample is a separate experiment (waveform inversion).

**How to reason about it:**
1. **Identify event boundaries** in your training data (e.g., 17 earthquake cycles). 2. **Characterize each event**: compute mean target, duration, and sample count. 3. **Cluster events** by these characteristics (manually or via k-means) into 3-5 groups of similar events. 4. **Split by group**: Use StratifiedKFold on event groups, NOT individual samples. Each fold gets entire events in or out. 5. **Check fold similarity**: Verify that each fold has similar target distribution (mean, variance) and sample count (within 20%). 6. For extra robustness, repeat with multiple grouping schemes and average the CV scores.

```python
# Example: event-aware stratified CV for earthquakes
from sklearn.model_selection import StratifiedKFold
import numpy as np

# Group events by duration into 3 classes
event_stats = []
for eq_id in range(17):  # 17 earthquake cycles
    duration = earthquake_durations[eq_id]
    mean_ttf = train_data[train_data.eq_id == eq_id].ttf.mean()

# Cluster into short/medium/long events
event_classes = []
for stat in event_stats:
    if stat['duration'] < 9:
        event_classes.append(0)
    elif stat['duration'] < 12:
        event_classes.append(1)
    else:
        event_classes.append(2)

# 5-fold stratified by event class
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for fold, (train_eq, val_eq) in enumerate(skf.split(range(17), event_classes)):
```
