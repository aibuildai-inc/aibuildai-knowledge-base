## Principle 6: Allocate Model Capacity Across the Long Tail Deliberately

*Consensus: 6/9 CAFA writeups explicitly varied frequency cutoffs, target counts, or label universes; several winning systems paired a strong frequent-label model with a much wider linear model.*

Choose label coverage jointly with model class and metric. Use high-capacity models for frequent terms and computationally cheap wide models, priors, retrieval, or graph inference for rare terms rather than applying one arbitrary cutoff to every component.

**Why this matters:** GO labels have an extreme long tail. Restricting to common labels stabilizes learning but discards high-information rare functions; predicting every term with an expensive model wastes capacity and increases false positives. Different cutoffs also create useful ensemble diversity.

**When to use:** Apply this to large multilabel vocabularies with sparse positives and output limits. Inspect support and information-accretion mass by aspect, not only raw term counts, because BP, MF, and CC have very different scales.

**When NOT to use:** This principle does not apply directly to scalar regression. Do not remove unscored or zero-IA labels automatically if they provide a useful auxiliary task to a shared representation; one top CAFA solution retained such labels in its neural model while excluding them from other learners.

**How to reason about it:**
Plot cumulative positive count and cumulative metric weight versus vocabulary size. For each model family, ask how many labels it can estimate reliably and affordably. Blend models trained with different cutoffs only if they improve complementary support ranges.

```python
def select_terms(counts, ia, min_count, keep_auxiliary=False):
    selected = counts.index[counts >= min_count].tolist()
    if not keep_auxiliary:
        selected = [t for t in selected if ia.get(t, 0.0) > 0]
    return selected

# Example pattern: narrow nonlinear expert + wide linear expert
terms_gbdt = select_terms(counts, ia, min_count=200)
terms_linear = select_terms(counts, ia, min_count=20)
```
