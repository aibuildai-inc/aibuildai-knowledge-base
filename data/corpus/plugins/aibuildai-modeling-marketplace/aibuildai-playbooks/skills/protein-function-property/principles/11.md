## Principle 11: Ensemble Across Mechanisms, Not Cosmetic Variants

*Consensus: 14/14 final solutions used multiple models, seeds, representations, physical scores, or external prediction sources.*

Blend experts with genuinely different failure modes: learned sequence models, homology transfer, structure retrieval, annotation evidence, and physical energy calculations. Estimate weights from out-of-fold or historical validation and use rank normalization when only order matters.

**Why this matters:** The largest repeated gain across all three competitions came from combining complementary mechanisms. Near-duplicate models produce little benefit, while public-leaderboard weight tuning was repeatedly described as risky and caused private shake-ups in stability prediction.

**When to use:** Ensemble after each component has a defined role and validated coverage. Use multi-stage blends when internal model diversity and external evidence diversity operate at different levels.

**When NOT to use:** Do not add a weak, correlated model solely because it nudges a small public leaderboard. Subtractive or extreme weighting can accidentally help one slice and fail elsewhere; if no trustworthy validation exists, prefer conservative equal or regularized weights.

**How to reason about it:**
Measure out-of-fold residual correlations, per-stratum performance, and missing coverage. Optimize nonnegative weights with regularization toward equal weighting, then stress-test across folds, dates, protein families, and knowledge states.

```python
from scipy.stats import rankdata
import numpy as np

def blend_for_metric(pred_list, weights, metric):
    P = np.column_stack(pred_list)
    if metric == "spearman":
        P = np.column_stack([rankdata(P[:, j]) / len(P) for j in range(P.shape[1])])
    w = np.maximum(np.asarray(weights), 0)
    w = w / w.sum()
    return P @ w
```
