## Principle 4: Fuse Orthogonal Evidence, but Gate It by Coverage and Failure Mode

*Consensus: 13/14 detailed solutions combined multiple feature families or prediction sources; every competition's leading writeups relied on complementary evidence.*

Combine sequence, taxonomy, literature, existing annotations, structure, interaction networks, and physics only when each supplies distinct information. Preserve missingness and renormalize over available experts instead of treating absent predictions as confident zeros.

**Why this matters:** No single source covers protein space uniformly. PLMs generalize broadly, homology is precise near known families, structure survives sequence divergence, literature and GOA reveal accumulated knowledge, and energy functions target mutation mechanics; their errors are therefore partly complementary.

**When to use:** Use multimodal fusion when coverage, provenance, and timestamps can be audited. Separate experts or branches are especially useful when a source is sparse, aspect-specific, or potentially leaky.

**When NOT to use:** Skip a modality when it adds no out-of-distribution value, is merely a duplicate of another source, or would be unavailable at inference. Top solutions reported that STRING did not always help, PPI gains could be BP-only, fine-tuning did not necessarily help, and more embeddings could reduce performance.

**How to reason about it:**
For every source, record coverage, temporal availability, biological scope, and standalone/conditional gain. Prefer sources that improve difficult strata or ensemble diversity, not merely the public leaderboard. Add a source cautiously if it can directly encode post-cutoff outcomes.

```python
import numpy as np

def nan_aware_blend(preds, weights):
    # preds: [n_models, n_items], NaN means the expert has no evidence.
    p = np.asarray(preds, float)
    w = np.asarray(weights, float)[:, None]
    valid = np.isfinite(p)
    num = np.nansum(np.where(valid, p * w, 0.0), axis=0)
    den = np.sum(valid * w, axis=0)
    return num / np.maximum(den, 1e-12)
```
