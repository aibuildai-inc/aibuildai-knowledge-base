## Principle 2: Build the Representation Around the Relevant Biological Invariance

*Consensus: 9/9 function writeups used sequence-derived information or homology; 4/5 stability writeups explicitly centered local mutation environments or mutant-minus-wild-type features.*

For whole-protein function, represent global sequence semantics and evolutionary similarity. For mutation properties, represent what changed and the local structural environment, ideally as mutant-minus-wild-type features with rotation- and translation-safe geometry.

**Why this matters:** Function often reflects domains and global evolutionary history, so pooled protein-language-model embeddings and homologs are informative. A single mutation changes only a small part of a protein; absolute protein features can swamp the causal signal, while paired differences cancel parent-specific baselines.

**When to use:** Use pooled PLM embeddings, sequence search, and domain/family features for annotation. Use residue identity changes, BLOSUM-like substitution scores, solvent accessibility, residue depth, nearby atoms/residues, energy differences, and paired PLM or structure deltas for mutation effects.

**When NOT to use:** Do not over-localize when the property depends on global sequence context or large conformational changes. Do not spend heavily on mutant structure generation if confidence is poor or a sequence-only model validates equally well; several stability writeups found elaborate equivariant networks weaker than simpler descriptors and energy scores.

**How to reason about it:**
For each feature, identify the invariance it should obey. Whole-protein predictions should not depend on arbitrary residue indexing conventions; structural predictions should not change under rigid rotation or translation; swapping WT and mutant should approximately negate a mutation-effect prediction when the assay permits it.

```python
def mutation_features(wt, mut, wt_struct, mut_struct, pos):
    # Customize radius and descriptors for the assay.
    local_wt = structural_descriptors(wt_struct, center=pos, radius=8.0)
    local_mut = structural_descriptors(mut_struct, center=pos, radius=8.0)
    return {
        "local_delta": local_mut - local_wt,
        "plm_delta": embed(mut) - embed(wt),
        "substitution": substitution_features(wt[pos], mut[pos]),
    }
```
