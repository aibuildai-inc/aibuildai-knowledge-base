## Principle 1: Branch First on the Target's Mathematical and Biological Structure

*Consensus: 14/14: the 9 CAFA writeups and 5 stability writeups used fundamentally different formulations.*

Determine whether the target is a hierarchy-constrained set of functions or a scalar property/change. Use aspect-wise multilabel or structured prediction for GO annotations; use mutation-effect regression or ranking for variant properties.

**Why this matters:** The target geometry controls almost every later choice. GO labels are sparse, dependent nodes in a DAG and are incompletely observed, whereas thermostability is a continuous property whose metric preserves only order and whose test cases may all be variants of one parent protein.

**When to use:** Always make this decision before selecting representations or models. Indicators include an ontology file, multiple labels per protein, and weighted F-max for the structured branch; or wild-type/variant pairs, a continuous assay, and Spearman correlation for the property branch.

**When NOT to use:** Do not force a unified generic classifier across both regimes. A flat independent-label model discards GO implications, while an ontology architecture adds no value to a single scalar stability target; stability solutions instead used mutation deltas, structural energies, and ranking.

**How to reason about it:**
Ask: (1) Is absence of a label a verified negative or merely unknown? (2) Does the metric care about calibrated probabilities, thresholded sets, absolute values, or rank? (3) Is the prediction for a whole protein or the effect of changing a reference protein? These answers define the task branch.

```python
def choose_task(cfg):
    if cfg.has_ontology and cfg.multilabel:
        return {"mode": "structured_multilabel", "split_by_aspect": True}
    if cfg.has_reference_variant and cfg.metric == "spearman":
        return {"mode": "mutation_effect_ranking", "predict_delta": True}
    return {"mode": "scalar_regression", "predict_delta": False}
```
