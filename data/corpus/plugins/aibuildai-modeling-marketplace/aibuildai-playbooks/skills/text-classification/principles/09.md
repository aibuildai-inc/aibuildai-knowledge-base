## Principle 9: Train Language-Specific Models for Multilingual Tasks, Then Ensemble

*Consensus: 2/2 multilingual winners - 1st place trained 6 separate monolingual models*

For multilingual classification, bootstrap with a multilingual model (XLM-RoBERTa), then train separate monolingual models (CamemBERT for French, BERTurk for Turkish, etc.) on their respective languages using pseudo-labels from the multilingual model. Iteratively refine pseudo-labels and retrain.

**Why this matters:** Multilingual models (XLM-R) spread capacity across all languages, so per-language performance is lower than a monolingual specialist. The 1st place multilingual toxic comment solution scored 0.942 with pure XLM-R, jumped to 0.951 by adding monolingual models, and reached 0.9556 with iterative refinement. Each monolingual model outperformed XLM-R on its target language by 0.01-0.02 AUC.

**When to use:** When test data spans multiple languages and you know the language distribution (e.g., 6 languages specified). When monolingual pretrained models exist for your target languages. When you have compute budget to train multiple models. When translating test data to a single language hurts performance (language-specific signals matter).

**When NOT to use:** When test languages are unknown or cover 50+ languages (can't train a specialist for each). When no quality monolingual models exist for your languages. When language-specific signals don't matter (e.g., named entity recognition where entities are language-agnostic). When your dataset is too small per language (< 1k samples) to fine-tune a specialist.

**How to reason about it:**
Start with XLM-R on all languages to establish a baseline. Check per-language performance - if variance is high (> 0.05 AUC gap), language-specific models help. For each language, train a monolingual model using (1) translated training data in that language + (2) pseudo-labels for test data in that language from XLM-R. Predict only same-language samples (don't translate across languages). Iteratively improve: use monolingual predictions to refine pseudo-labels, retrain XLM-R, repeat.

# Multilingual to monolingual refinement
# Step 1: Bootstrap with multilingual model
xlm_model = AutoModelForSequenceClassification.from_pretrained('xlm-roberta-large')

# Step 2: Train language-specific models

    'fr': 'camembert-base',

    'tr': 'dbmdz/bert-base-turkish-cased',
    'ru': 'DeepPavlov/rubert-base-cased',
    'it': 'dbmdz/bert-base-italian-cased',
    'pt': 'neuralmind/bert-base-portuguese-cased'
}

for lang, model_name in monolingual_models.items():
    # Filter to language-specific data
    lang_train = translated_train_data[translated_train_data['lang'] == lang]
    lang_test = test_data[test_data['lang'] == lang]
    lang_pseudo = test_pseudo_labels[test_data['lang'] == lang]

        lang_train,
        lang_test.assign(label=lang_pseudo)  # Add pseudo-labeled test data
    ])

    predictions[lang] = model.predict(lang_test)
