## Principle 14: Train with Statistical and Linguistic Features for Robustness

*Consensus: Several Quora solutions used auxiliary statistical features - 2nd place Quora gained 0.00097 from 92 statistical features*

Complement neural models with hand-crafted features: word/character counts, unique word ratios, POS tag distributions, readability scores, bag-of-character n-grams. These features capture patterns neural models might miss and add robustness to adversarial examples.

**Why this matters:** Neural models can overfit to spurious correlations. Statistical features provide orthogonal signal. The 2nd place Quora solution added 92 statistical features (word counts, unique words, character counts, bag-of-characters) to their GRU model and gained 0.00097 CV - small but significant in a tight competition. The features helped on edge cases where RNN failed (very short texts, unusual character patterns).

**When to use:** When you have domain knowledge about distinguishing patterns (e.g., toxic comments use more caps, LLM text has different readability scores). When your neural model plateaus and you need marginal gains. When you want robustness to adversarial perturbations (character-level features catch obfuscations). When model interpretability matters (features are human-readable).

**When NOT to use:** When using large transformers that already capture these patterns through attention (BERT learns capitalization, length, etc.). When features are derived from the text the model sees (redundant signal). When feature engineering time exceeds potential gain (diminishing returns after ~20 features). The 1st place Quora solution saw no improvement from extra features such as sentiment or bag-of-words variables.

**How to reason about it:**
Start with basic counts (text length, word count, unique word ratio, caps ratio). Add domain-specific features based on EDA: do toxic comments have more punctuation? Do LLM texts have different sentence length variance? Test feature importance: train a simple model on features alone - if AUC > 0.6, they're informative. Add to neural model as auxiliary inputs. Monitor CV: if gain < 0.0005, not worth the complexity.

# Statistical and linguistic features
import textstat
from collections import Counter
import string

def extract_statistical_features(text):
    words = text.split()
    chars = list(text)
    
    features = {
        # Basic counts
        'num_words': len(words),
        'num_unique_words': len(set(words)),
        'num_chars': len(chars),
        'num_upper_chars': sum(1 for c in chars if c.isupper()),
        'num_punctuation': sum(1 for c in chars if c in string.punctuation),
        
        # Ratios
        'unique_word_ratio': len(set(words)) / max(len(words), 1),
        'caps_ratio': sum(1 for c in chars if c.isupper()) / max(len(chars), 1),
        
        # Readability (useful for LLM detection)
        'flesch_reading_ease': textstat.flesch_reading_ease(text),
        'flesch_kincaid_grade': textstat.flesch_kincaid_grade(text),

class HybridModel(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_stat_features):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.rnn = nn.GRU(embed_dim, hidden_dim, bidirectional=True, batch_first=True)
        
        # Statistical features branch
        self.stat_dense = nn.Sequential(
            nn.Linear(num_stat_features, 32),
            nn.ReLU(),
            nn.Linear(32, 16),
            nn.ReLU()
        )
        
        # Combine RNN and statistical features
        self.final = nn.Linear(hidden_dim * 2 + 16, 1)
    
    def forward(self, text_ids, stat_features):
        # Text branch
        embed = self.embedding(text_ids)
        rnn_out, _ = self.rnn(embed)
        text_features = rnn_out[:, -1, :]  # Last hidden state
        
        # Statistical branch
        stat_out = self.stat_dense(stat_features)
        
        # Concatenate and classify
        combined = torch.cat([text_features, stat_out], dim=1)
        return self.final(combined)
