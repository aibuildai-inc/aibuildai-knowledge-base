## Principle 2: Maximize Embedding Coverage to Minimize Out-of-Vocabulary Impact

*Consensus: Several embedding-based Quora solutions emphasize this - 1st place Quora reduced OOV from 50k to near-zero*

For embedding-based models, aggressively reduce out-of-vocabulary (OOV) tokens through multiple lookup strategies: check singular/plural, lowercase variants, remove special characters, use multiple embedding sources. Each 1% reduction in OOV can yield 0.001-0.002 score improvement.

**Why this matters:** Pre-trained embeddings capture semantic relationships, but only for words in their vocabulary. The 1st place Quora solution found embeddings for >90% of their vocabulary through cascading lookups, while a baseline approach left 50k/250k tokens as OOV. Those OOV tokens get random embeddings, destroying signal. With 1.3M training samples, small per-token improvements compound massively.

**When to use:** When using pre-trained embeddings (FastText, GloVe, word2vec). When your domain vocabulary differs from embedding training corpus (e.g., social media text with slang, code-switching, typos). When you've exhausted architectural improvements and need marginal gains.

**When NOT to use:** When using transformers with subword tokenization (BERT, DeBERTa) - they handle OOV through wordpiece/BPE. When training embeddings from scratch on your domain. The 2nd place Quora solution trained 64-dim FastText embeddings on train+test and saw gains, bypassing OOV entirely.

**How to reason about it:**
Count OOV rate first. If > 5%, it's worth addressing. Build a cascading lookup: (1) exact match, (2) lowercase, (3) singular/plural, (4) strip special chars, (5) check alternative embedding sources. Weight embeddings by source quality (GloVe 840B > FastText crawl > domain-trained). Track OOV reduction vs CV score to know when to stop.

```python
def get_embedding(word, embed_dict_1, embed_dict_2):
    # Cascading lookup strategy
    if word in embed_dict_1:
        return embed_dict_1[word]
    
    # Try lowercase
    word_lower = word.lower()
    if word_lower in embed_dict_1:
        return embed_dict_1[word_lower]
    
    # Try alternative source
    if word in embed_dict_2:
        return embed_dict_2[word]
    
    # Try singular/plural (simple heuristic)
    if word.endswith('s') and word[:-1] in embed_dict_1:
        return embed_dict_1[word[:-1]]
    
    # Try removing special chars
    word_clean = re.sub(r'[^a-zA-Z0-9]', '', word)
    if word_clean in embed_dict_1:
        return embed_dict_1[word_clean]
    
    return None  # Will get random embedding
```
