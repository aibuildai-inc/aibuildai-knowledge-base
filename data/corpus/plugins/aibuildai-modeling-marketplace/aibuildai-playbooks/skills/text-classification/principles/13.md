## Principle 13: Leverage Domain Adaptation at Test Time for Unknown Distributions

*Consensus: 1/5 LLM detection solutions - 5th place used student models trained on test pseudo-labels*

When test distribution is unknown, use a strong long-context teacher model to pseudo-label test data, then train short-context student models to mimic teacher predictions on random chunks of test documents. Students learn test-specific patterns the teacher found, improving generalization.

**Why this matters:** The 5th place LLM detection solution trained DeBERTa with 1024 token context and scored 0.970. They then pseudo-labeled test data with this teacher and trained 128/256-character context student models on random chunks to mimic the teacher. Students scored 0.977 (without Mamba) - beating the teacher by 0.007. The short context forced students to learn local statistical quirks correlated with teacher judgments, adapting to test distribution.

**When to use:** When you suspect test distribution differs from training (adversarial validation AUC > 0.6). When you have a strong base model but weak CV-LB correlation. When test data is available during model training (semi-supervised setting, or competition with test data released). When inference time allows for multi-stage prediction.

**When NOT to use:** When test data is unavailable until inference (real-time production systems). When your teacher model is weak (< 0.7 accuracy) - student will learn wrong patterns. When test distribution matches training (standard cross-validation holds). The technique adds complexity and requires careful validation to avoid overfitting.

**How to reason about it:**
Train a strong teacher model on full training data. Generate soft pseudo-labels for test data. Create a student task: predict teacher's labels (not true labels) on short random chunks of test documents. The student learns to identify local patterns that correlate with the teacher's global judgment. This is similar to knowledge distillation but adapted to test distribution. Use shorter context than teacher to force pattern learning over memorization.

```python
# Test-time domain adaptation
# Step 1: Train long-context teacher
teacher = AutoModelForSequenceClassification.from_pretrained('microsoft/deberta-v3-large')
teacher.fit(train_data, context_length=1024)

# Step 2: Pseudo-label test data with teacher
test_pseudo_labels = teacher.predict_proba(test_data)[:, 1]  # Soft labels

# Step 3: Create student training data from test set
def create_student_chunks(test_texts, pseudo_labels, chunk_size=128, stride=64):
    student_data = []
    for text, label in zip(test_texts, pseudo_labels):
        # Random chunks of the test document
        for start in range(0, len(text) - chunk_size, stride):
            chunk = text[start:start + chunk_size]
            # Student learns to predict teacher's label from local chunk
            student_data.append((chunk, label))
    return student_data

student_train_128 = create_student_chunks(test_data, test_pseudo_labels, chunk_size=128)
student_train_256 = create_student_chunks(test_data, test_pseudo_labels, chunk_size=256)

# Step 4: Train short-context students on pseudo-labeled chunks
student_128 = AutoModelForSequenceClassification.from_pretrained('microsoft/deberta-v3-large')
student_128.fit(student_train_128, context_length=128, epochs=1)  # 1 epoch, long warmup

student_256 = AutoModelForSequenceClassification.from_pretrained('microsoft/deberta-v3-large')
student_256.fit(student_train_256, context_length=256, epochs=1)

# Step 5: Inference - students predict on overlapping chunks, average
def predict_with_students(text, student_128, student_256, chunk_size_128=128, chunk_size_256=256):
    preds_128 = []
    for start in range(0, len(text), chunk_size_128 // 2):  # 50% stride
        chunk = text[start:start + chunk_size_128]
        preds_128.append(student_128.predict_proba(chunk)[0, 1])
    
    preds_256 = []
    for start in range(0, len(text), chunk_size_256 // 2):
        chunk = text[start:start + chunk_size_256]
        preds_256.append(student_256.predict_proba(chunk)[0, 1])
    
    # Weighted average: more weight on smaller chunks (more specialized)
    return 0.6 * np.mean(preds_128) + 0.4 * np.mean(preds_256)
```
