## Principle 6: Optimize Thresholds Using Cross-Fold Stability, Not Single-Fold Optima

*Consensus: 3/3 imbalanced-class competitions - 1st place Quora found stable threshold across 10 folds*

For imbalanced classification with F1/custom metrics, don't optimize threshold separately per fold. Instead, find the fixed threshold that minimizes deviation from optimal F1 across all folds. This threshold generalizes better to test data where you can't optimize post-hoc.

**Why this matters:** The optimal threshold varies wildly across folds due to class imbalance fluctuations. The 1st place Quora solution found that optimizing per fold gave CV F1 of 0.71 but LB F1 of 0.685 (catastrophic overfitting). Finding a stable fixed threshold (0.927 in their case) gave CV F1 of 0.709 but LB F1 of 0.705 - much tighter and more trustworthy.

**When to use:** When your metric is threshold-dependent (F1, precision@recall, custom metrics) and you can't optimize threshold on test data. When class imbalance varies across folds. When you're training on full data without a validation set (so you need a predetermined threshold).

**When NOT to use:** When using AUC/log-loss (threshold-free metrics). When you have a large stable validation set where you can safely optimize threshold once. When class balance is stable across folds (optimal threshold won't vary much anyway).

**How to reason about it:**
For each fold, compute F1 across a grid of thresholds (0.1 to 0.9 in 0.01 steps). For each fixed threshold, measure the deviation from the optimal F1 across folds. Choose the threshold with minimum mean deviation (or minimum max deviation if you're conservative). Visualize: x-axis = threshold, y-axis = mean absolute F1 drop from optimal, pick the valley. Then use that fixed threshold on test.

```python
# Find stable threshold across folds
thresholds = np.arange(0.1, 0.9, 0.01)
fold_f1_scores = []  # Shape: (n_folds, n_thresholds)

for fold in range(n_folds):
    y_true = val_labels[fold]
    y_pred_proba = val_predictions[fold]
    
    fold_thresholds_f1 = []
    for threshold in thresholds:
        y_pred_binary = (y_pred_proba > threshold).astype(int)
        f1 = f1_score(y_true, y_pred_binary)
        fold_thresholds_f1.append(f1)
    fold_f1_scores.append(fold_thresholds_f1)

fold_f1_scores = np.array(fold_f1_scores)  # (n_folds, n_thresholds)

# For each threshold, compute deviation from optimal F1 per fold
optimal_f1_per_fold = fold_f1_scores.max(axis=1, keepdims=True)
deviations = optimal_f1_per_fold - fold_f1_scores  # How much worse than optimal

# Find threshold with minimum mean deviation
mean_deviation = deviations.mean(axis=0)
best_stable_threshold = thresholds[mean_deviation.argmin()]

print(f"Best stable threshold: {best_stable_threshold:.3f}")
print(f"Mean F1 deviation: {mean_deviation.min():.4f}")
```
