## Principle 4: Use Back-Translation for Multilingual Robustness

*Consensus: Half of the Jigsaw multilingual writeups (8/16) trained on translated data; 3 also averaged predictions over translated test text*

Translate text to intermediate languages and back to English (or target language) both as training augmentation and test-time augmentation (TTA). Average predictions across original and translated versions. This corrects translation artifacts, handles code-mixing, and improves robustness to non-native text.

**Why this matters:** Many datasets contain non-English text mislabeled as English, or English written by non-native speakers. Translation through several languages normalizes these variations while preserving semantic meaning. In the Jigsaw multilingual competition, the 8th place solution called translating the training data into the test languages the only really important thing.

**When to use:** When training data contains multilingual text or text from non-native speakers. When you suspect test set has more language mixing than training. When CV shows high variance across folds (translation smooths fold-specific artifacts). When you have translation API budget or can use offline models.

**When NOT to use:** When your task is language-specific (e.g., detecting French toxic comments - translation would destroy language-specific signals). When test distribution is monolingual native text and translation would just add noise. The 1st place multilingual toxic comment solution found that translating test samples to non-native languages hurt performance; only native language predictions helped.

**How to reason about it:**
First, check if train and test differ in language distribution (adversarial validation on language features). If yes, translation helps. Decide: train-time only (cheaper, less robust), test-time only (expensive, works on pretrained models), or both. For TTA, keep translations within the same fold during CV to prevent leakage. Weight original text at least as high as each translation, and tune the weight on validation.

```python
# Train-time augmentation (keep original + translation in same fold)
for text, label in train_data:
    # Original
    train_samples.append((text, label, fold_id))
    
    # Back-translate through multiple languages
    for lang in pivot_languages:
        translated = translate(text, src='en', tgt=lang)
        back_translated = translate(translated, src=lang, tgt='en')
        # Keep in SAME fold as original to prevent leakage
        train_samples.append((back_translated, label, fold_id))

# Test-time augmentation
def predict_with_tta(model, text, languages=pivot_languages):
    preds = [model.predict(text)]  # Original
    
    for lang in languages:
        translated = translate(text, src='en', tgt=lang)
        back_translated = translate(translated, src=lang, tgt='en')
        preds.append(model.predict(back_translated))
    
    # Average predictions (can also use weighted average)
    return np.mean(preds, axis=0)
```
