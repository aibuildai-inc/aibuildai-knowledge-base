## Principle 5: Bridge Train-Test Distribution Gaps with Pseudo-Labeling

*Consensus: Top solutions in 3 of the 11 competitions used this (Jigsaw multilingual, LLM detection, Jigsaw community rules) - 11th place community rules gained +0.00155 private score*

When train and test distributions differ (confirmed by adversarial validation or organizer hints), use your best model to generate soft labels for test data, add them to training data, and retrain. Use soft labels (continuous probabilities) not hard labels (0/1), and optionally upsample pseudo-labeled data.

**Why this matters:** The train-test distribution gap is a documented issue in many competitions. Pseudo-labeling forces the model to learn the test distribution directly. The 10th place multilingual solution used all test samples as soft-labeled training data (KL-divergence loss) and got its best performance that way. It works because even imperfect predictions on test data provide signal about test distribution patterns that pure train data lacks.

**When to use:** When adversarial validation AUC > 0.6 (train and test are distinguishable). When competition description mentions train-test differences. When CV-LB correlation is weak (suggests distribution shift). When you have a strong base model (otherwise you're just amplifying errors).

**When NOT to use:** When train and test are from the same distribution (AV AUC ~ 0.5). When your base model is weak (< 0.7 CV) - pseudo-labels will be mostly wrong and hurt performance. The 1st place Quora solution explicitly tried pseudo-labeling and found it didn't help, likely because train-test distributions were similar.

**How to reason about it:**
Run adversarial validation first - if a simple model can't distinguish train from test (AUC < 0.55), skip pseudo-labeling. Generate predictions from your best ensemble, not a single model. Use soft labels to preserve uncertainty. Start with low weight (10-20%) on pseudo-labeled samples and tune up if CV improves. Iterative refinement (predict → add to train → retrain → predict again) can help for large distribution gaps.

```python
# Check if pseudo-labeling is worth it
from sklearn.ensemble import RandomForestClassifier
train['is_test'] = 0
test['is_test'] = 1
adv_val_data = pd.concat([train[features], test[features]])
adv_val_labels = pd.concat([train['is_test'], test['is_test']])
auc = cross_val_score(RandomForestClassifier(), adv_val_data, adv_val_labels, cv=5).mean()
print(f"Adversarial validation AUC: {auc}")
if auc < 0.55:
    print("Train and test are similar, pseudo-labeling likely won't help")

# Pseudo-labeling with soft labels
best_model = ensemble_of_top_models
test_soft_labels = best_model.predict_proba(test_data)[:, 1]  # Keep probabilities

# Create augmented training set
train_augmented = pd.concat([
    train_data.assign(weight=1.0),
    test_data.assign(label=test_soft_labels, weight=0.2)  # Lower weight on pseudo-labels
])

# Retrain with sample weights
model.fit(train_augmented[features], train_augmented['label'], 
          sample_weight=train_augmented['weight'])
```
