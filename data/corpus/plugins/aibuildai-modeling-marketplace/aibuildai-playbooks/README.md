# aibuildai-playbooks

Domain-specific ML playbooks for competition and research tasks. Each playbook contains battle-tested principles distilled from top-solution writeups. No playbook reads the writeups of an MLE-bench competition, so the playbooks carry no solution to a task of that benchmark.

## Skills

44 domain playbooks covering:

- **Vision**: image classification, object detection, segmentation, fine-grained categorization
- **NLP**: text classification, sentiment analysis, text similarity, entity extraction
- **Tabular**: time series, recommendation, rating prediction
- **Scientific**: molecular/biochemical prediction, medical imaging, brain signals, agriculture
- **Specialized**: satellite imagery, video understanding, multimodal, reasoning
- **Meta**: ensemble optimization, playground series

## Installation

Copy this directory into your plugins folder, or pass `--plugins-dir` pointing to the parent directory.
