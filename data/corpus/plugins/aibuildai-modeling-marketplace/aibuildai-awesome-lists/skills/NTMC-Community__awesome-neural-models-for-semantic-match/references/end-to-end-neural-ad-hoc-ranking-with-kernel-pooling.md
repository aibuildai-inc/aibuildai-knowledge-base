# End-to-End Neural Ad-hoc Ranking with Kernel Pooling.

**Source**: [https://arxiv.org/pdf/1706.06613.pdf](https://arxiv.org/pdf/1706.06613.pdf)

**Code**: [https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/knrm.py](https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/knrm.py)

**Year**: 2017 | **Venue**: SIGIR 2017 | **Category**: Ad-hoc Information Retrieval

## Description

KNRM uses a translation matrix that models word-level similarities via word embeddings, a kernel-pooling technique that uses kernels (i.e., RBF kernel) to extract multi-level soft match features, and a learning-to-rank layer that combines those features into the final ranking score.
