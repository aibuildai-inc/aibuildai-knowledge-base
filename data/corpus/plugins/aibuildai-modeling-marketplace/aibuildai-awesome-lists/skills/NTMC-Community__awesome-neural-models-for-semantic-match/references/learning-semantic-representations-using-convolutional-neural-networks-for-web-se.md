# Learning Semantic Representations Using Convolutional Neural Networks for Web Search.

**Source**: [https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/www2014_cdssm_p07.pdf](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/www2014_cdssm_p07.pdf)

**Code**: [https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/cdssm.py](https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/cdssm.py)

**Year**: 2014 | **Venue**: WWW 2014 | **Category**: Ad-hoc Information Retrieval

## Description

CDSSM contains a word hashing layer that transforms each word into a letter tri-gram input representation, a convolutional layer to extract local contextual features, a max-pooling layer to form a global feature vector, and a final semantic layer to represent the high-level semantic feature vector of the input word sequence.
