# Text Matching as Image Recognition.

**Source**: [https://arxiv.org/pdf/1602.06359.pdf](https://arxiv.org/pdf/1602.06359.pdf)

**Code**: [https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/match_pyramid.py](https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/match_pyramid.py)

**Year**: 2016 | **Venue**: AAAI 2016 | **Category**: Paraphrase Identification

## Description

MatchPyramid model text matching as the problem of image recognition. Firstly, a matching matrix whose entries represent the similarities between words is constructed and viewed as an image. Then a convolutional neural network is utilized to capture rich matching patterns in a layer-by-layer way.
