# Learning to Match using Local and Distributed Representations of Text for Web Search.

**Source**: [https://www.microsoft.com/en-us/research/wp-content/uploads/2016/10/wwwfp0192-mitra.pdf](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/10/wwwfp0192-mitra.pdf)

**Code**: [https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/duet.py](https://github.com/NTMC-Community/MatchZoo/blob/master/matchzoo/models/duet.py)

**Year**: 2017 | **Venue**: WWW 2017 | **Category**: Ad-hoc Information Retrieval

## Description

Duet is composed of two separate DNNS that model query-document relevance using local and distributed representations, respectively. The two DNNS, refered to henceforth as the *local model* and the *distributed model*. The local model takes an interaction matrix of query and document terms as input, whereas the distributed model learns embeddings of the query and document text before matching.
