# pyEMMA

**Source**: [http://www.emma-project.org/latest/](http://www.emma-project.org/latest/)

## Source Description

Library for the estimation, validation and analysis Markov models of molecular kinetics and other kinetic and thermodynamic models from molecular dynamics data.
