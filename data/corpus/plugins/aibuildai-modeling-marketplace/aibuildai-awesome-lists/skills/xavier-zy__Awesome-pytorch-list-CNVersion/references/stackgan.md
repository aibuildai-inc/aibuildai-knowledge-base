# StackGAN

**Source**: [https://arxiv.org/abs/1710.10916](https://arxiv.org/abs/1710.10916)

**Code**: [https://github.com/akanimax/T2F](https://github.com/akanimax/T2F)

## Description

使用深度学习进行Text-to-Face生成。该项目结合了[StackGAN](https://arxiv.org/abs/1710.10916)和[ProGAN](https://arxiv.org/abs/1710.10196)，这两个模型可以基于文字描述合成人脸。
