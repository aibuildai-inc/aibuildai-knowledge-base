# ToT (Tree-of-Thought)

**Source**: [https://arxiv.org/abs/2305.10601](https://arxiv.org/abs/2305.10601)

**Category**: 2.3 Extensive Exploration | **Subcategory**: 2.3.3 External Exploration

## Description

Expands the traditional "left-to-right" token generation reasoning process into a "tree structure exploration," where each node represents a thought unit. This supports multi-path attempts, backtracking, forward reasoning, and self-evaluation within the reasoning process.
