# MemPO: Self-Memory Policy Optimization for Long-Horizon Agents

**Source**: [https://arxiv.org/pdf/2603.00680](https://arxiv.org/pdf/2603.00680)

**Category**: Framework & Methods

## Description

• Long-horizon agents passively depend on external RAG retrieval and lack autonomous mechanisms for assessing the value of historical information and managing what should be retained. • Proposes the Self-Memory Policy Optimization algorithm (MemPO), which introduces an improved credit assignment mechanism to grant the model the ability to proactively summarize and filter high-value memories. • By precisely removing redundant information, the method significantly reduces token consumption while comprehensively outperforming prior approaches in both F1 score and overall task performance.
