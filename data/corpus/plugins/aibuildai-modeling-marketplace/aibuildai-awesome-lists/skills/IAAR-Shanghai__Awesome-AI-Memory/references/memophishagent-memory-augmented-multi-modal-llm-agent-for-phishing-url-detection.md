# MemoPhishAgent: Memory-Augmented Multi-Modal LLM Agent for Phishing URL Detection

**Source**: [https://arxiv.org/pdf/2602.21394.pdf](https://arxiv.org/pdf/2602.21394.pdf)

**Category**: Systems & Models

## Description

• Proposes the MPA agent, which leverages episodic memory of past reasoning trajectories to guide decision-making against both recurring and novel phishing threats. • Achieves a 13.6% improvement in recall over state-of-the-art baselines on public datasets, with gains of up to 20% in real-world scenarios. • Analysis shows that episodic memory contributes approximately 27% of the recall improvement without introducing additional computational overhead.
