# MemCoT: Test-Time Scaling through Memory-Driven Chain-of-Thought

**Source**: [https://arxiv.org/abs/2604.08216](https://arxiv.org/abs/2604.08216)

**Category**: Framework & Methods

## Description

• Proposes MemCoT, a test-time memory scaling framework that recasts long-context reasoning as iterative, stateful information search. • Uses multi-view long-term memory perception to surface evidence and a task-conditioned short-term memory module to track search history and refine subsequent queries. • Achieves state-of-the-art results across several long-memory reasoning benchmarks.
