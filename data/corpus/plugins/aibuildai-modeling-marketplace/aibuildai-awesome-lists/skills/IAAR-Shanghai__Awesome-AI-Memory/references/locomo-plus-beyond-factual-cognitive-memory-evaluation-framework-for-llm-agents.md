# Locomo-Plus: Beyond-Factual Cognitive Memory Evaluation Framework for LLM Agents

**Source**: [https://arxiv.org/pdf/2602.10715](https://arxiv.org/pdf/2602.10715)

**Category**: Datasets & Benchmark

## Description

• It introduces the LoCoMo-Plus benchmark to evaluate "cognitive memory" in LLM agents, focusing on their ability to retain and apply implicit constraints like user goals and values across long conversational contexts. • It constructs scenarios with "cue–trigger semantic disconnect," requiring models to apply latent information even when downstream queries lack surface-level similarity to the original memory cues. • It establishes an evaluation framework based on "constraint consistency," revealing through extensive experiments that current LLMs and memory systems struggle significantly with complex cognitive memory tasks.
