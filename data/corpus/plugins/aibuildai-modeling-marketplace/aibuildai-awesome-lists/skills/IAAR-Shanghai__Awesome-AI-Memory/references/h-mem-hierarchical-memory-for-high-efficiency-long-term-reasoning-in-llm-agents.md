# H-MEM: Hierarchical Memory for High-Efficiency Long-Term Reasoning in LLM Agents

**Source**: [https://arxiv.org/abs/2507.22925](https://arxiv.org/abs/2507.22925)

**Category**: Systems & Models

## Description

• Proposes H-MEM, a hierarchical memory architecture that organizes memory into four semantic levels with positional index encoding, enabling efficient layer-by-layer retrieval without exhaustive similarity computation. • Introduces a dynamic memory update mechanism that adjusts memory weights based on user feedback to reflect changing user interests and psychological states. • Experimental results on the LoCoMo dataset demonstrate that H-MEM consistently outperforms baselines in long-term dialogue tasks while significantly reducing computational cost and retrieval latency.
