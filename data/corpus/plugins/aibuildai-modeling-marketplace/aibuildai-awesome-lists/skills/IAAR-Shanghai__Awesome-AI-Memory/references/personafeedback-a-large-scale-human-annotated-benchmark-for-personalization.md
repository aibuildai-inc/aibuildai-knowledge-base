# PersonaFeedback: A Large-scale Human-annotated Benchmark For Personalization

**Source**: [https://arxiv.org/pdf/2506.12915](https://arxiv.org/pdf/2506.12915)

**Category**: Datasets & Benchmark

## Description

• Proposes the PersonaFeedback benchmark for evaluating large language models (LLMs) in personalized response generation. • The study shows that while LLMs have made progress in producing personalized content, they still face limitations in complex scenarios. • By leveraging dynamic user attribute inference, personalized profiles, and reward models, the researchers aim to improve the effectiveness of personalized question answering.
