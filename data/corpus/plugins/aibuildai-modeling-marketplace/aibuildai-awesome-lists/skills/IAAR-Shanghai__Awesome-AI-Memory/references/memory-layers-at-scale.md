# Memory Layers at Scale

**Source**: [https://arxiv.org/pdf/2412.09764](https://arxiv.org/pdf/2412.09764)

**Category**: Systems & Models

## Description

• Studied trainable key–value “memory layers” as a sparse lookup module to add capacity without proportionally increasing FLOPs. • Presented a fully parallelizable implementation and explored scaling behavior with very large memory parameter counts. • Reported downstream improvements (notably on factual tasks) compared to dense and MoE baselines under matched budgets.
