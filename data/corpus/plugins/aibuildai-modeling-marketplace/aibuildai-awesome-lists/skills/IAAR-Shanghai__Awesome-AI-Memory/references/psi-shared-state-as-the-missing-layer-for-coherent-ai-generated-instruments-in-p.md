# PSI: Shared State as the Missing Layer for Coherent AI-Generated Instruments in Personal AI Agents

**Source**: [https://arxiv.org/abs/2604.08529](https://arxiv.org/abs/2604.08529)

**Category**: Systems & Models

## Description

• Proposes PSI, a shared-state architecture that connects separately generated personal AI modules into a coherent tool ecosystem. • Exposes current state through a personal context bus and supports writeback so modules can reason across each other and stay synchronized. • Demonstrates that the system can automatically integrate later-generated tools in a three-week personal AI deployment.
