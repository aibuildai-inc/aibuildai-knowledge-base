# MemAdapter: Fast Alignment across Agent Memory Paradigms via Generative Subgraph Retrieval

**Source**: [https://arxiv.org/pdf/2602.08369](https://arxiv.org/pdf/2602.08369)

**Category**: Framework & Methods

## Description

• It proposes MemAdapter, a framework that unifies heterogeneous agent memory paradigms (explicit, parametric, and latent) using a paradigm-agnostic generative subgraph retrieval approach. • It employs a two-stage training strategy: distilling a generative retriever from a unified memory space and then efficiently adapting it to new paradigms via lightweight alignment modules and contrastive learning. • MemAdapter consistently outperforms existing baselines, completing paradigm alignment in just 13 minutes and enabling effective zero-shot fusion across different memory types.
