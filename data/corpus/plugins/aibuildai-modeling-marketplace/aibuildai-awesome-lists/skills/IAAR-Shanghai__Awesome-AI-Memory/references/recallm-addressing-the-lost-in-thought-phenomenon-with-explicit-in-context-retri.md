# RecaLLM: Addressing the Lost-in-Thought Phenomenon with Explicit In-Context Retrieval

**Source**: [https://arxiv.org/abs/2604.09494](https://arxiv.org/abs/2604.09494)

**Category**: Framework & Methods

## Description

• Proposes RecaLLM, which interleaves explicit in-context retrieval with reasoning to address the lost-in-thought problem. • Uses constrained decoding to copy evidence spans and trains on both lexical and semantic retrieval tasks. • Outperforms baselines on long-context benchmarks such as RULER and HELMET and scales to 128K contexts with relatively modest training data.
