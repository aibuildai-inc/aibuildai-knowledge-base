# AutoAgent: Evolving Cognition and Elastic Memory Orchestration for Adaptive Agents

**Source**: [https://arxiv.org/pdf/2603.09716v1](https://arxiv.org/pdf/2603.09716v1)

**Category**: Framework & Methods

## Description

• It structures the agent’s cognition into “internal cognition” and “external cognition.” This cognition, treated as an updatable state of the agent, is continuously self-corrected and evolved based on the actual outcomes of task interactions, thereby providing a more accurate and less biased knowledge foundation for decision-making. • It adopts a dynamic “select–execute–update” loop for problem solving. The action space is uniformly divided into “emic actions” (self-driven) and “etic actions” (collaborative), enabling the agent to adaptively plan its next step entirely based on the current context and real-time cognition. • To tackle context redundancy and token consumption in long-sequence reasoning, the system designs an Elastic Memory Orchestrator (EMO) that dynamically compresses historical trajectories, filters redundant information, and extracts reusable episodic memories.
