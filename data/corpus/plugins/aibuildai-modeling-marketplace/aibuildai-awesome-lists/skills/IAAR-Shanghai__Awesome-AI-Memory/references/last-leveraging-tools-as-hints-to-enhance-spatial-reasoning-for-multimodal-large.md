# LAST: Leveraging Tools as Hints to Enhance Spatial Reasoning for Multimodal Large Language Models

**Source**: [https://arxiv.org/abs/2604.09712](https://arxiv.org/abs/2604.09712)

**Category**: Framework & Methods

## Description

• Proposes LAST, a tool-as-hints framework for improving multimodal spatial reasoning. • Packages heterogeneous tool invocations into reusable spatial skills through LAST-Box and returns multimodal prompts that can be consumed directly by the model. • Uses a three-stage curriculum to teach adaptive tool use and significantly improves performance on four spatial reasoning datasets.
