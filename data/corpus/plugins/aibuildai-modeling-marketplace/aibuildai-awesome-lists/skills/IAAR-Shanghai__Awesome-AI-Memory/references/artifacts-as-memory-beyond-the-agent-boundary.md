# Artifacts as Memory Beyond the Agent Boundary

**Source**: [https://arxiv.org/abs/2604.08756](https://arxiv.org/abs/2604.08756)

**Category**: Framework & Methods

## Description

• Formalizes the idea that the environment itself can serve as external memory for an agent. • Introduces artifacts as observations that reduce the information needed to represent history and connects the idea to reinforcement learning theory. • Shows that observing spatial paths can lower the internal memory needed to learn strong policies and motivates future environment-backed memory designs.
