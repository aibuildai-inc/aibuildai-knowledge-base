# Towards Lifelong Aerial Autonomy: Geometric Memory Management for Continual Visual Place Recognition in Dynamic Environments

**Source**: [https://arxiv.org/abs/2604.09038](https://arxiv.org/abs/2604.09038)

**Category**: Framework & Methods

## Description

• Introduces a geometric memory management framework for continual visual place recognition in dynamic environments. • Decomposes knowledge into static satellite anchors and a dynamic replay buffer, then allocates limited storage with spatially constrained sampling. • Improves long-term retention and spatial generalization, and establishes a 21-task benchmark for evaluation.
