# Cognitive Memory in Large Language Models

**Source**: [https://arxiv.org/pdf/2504.02441](https://arxiv.org/pdf/2504.02441)

**Category**: Survey

## Description

• Provides a comprehensive examination of memory mechanisms in large language models (LLMs), with a particular focus on different types of memory and their roles within the models. • While LLMs excel at information retrieval and interaction summarization, their long-term memory remains unstable. • Integrating memory into AI systems is crucial for delivering context-rich responses, reducing hallucinations, improving data processing efficiency, and enabling the self-evolution of AI systems.
