# MMA: Multimodal Memory Agent

**Source**: [https://arxiv.org/pdf/2602.16493.pdf](https://arxiv.org/pdf/2602.16493.pdf)

**Category**: Systems & Models

## Description

• Proposes the Multimodal Memory Agent (MMA), which addresses overconfidence errors in RAG by assigning dynamic reliability scores to retrieved items, incorporating source credibility, temporal decay, and conflict awareness. • Introduces the MMA-Bench benchmark to control speaker reliability and evaluate belief dynamics under text–vision contradictions. • Reveals the “visual reassurance effect,” where agents tend to inherit latent visual biases from the underlying models.
