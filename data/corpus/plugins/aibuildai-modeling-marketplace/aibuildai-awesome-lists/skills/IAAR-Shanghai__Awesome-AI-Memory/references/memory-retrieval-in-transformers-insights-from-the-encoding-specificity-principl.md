# Memory Retrieval in Transformers: Insights from The Encoding Specificity Principle

**Source**: [https://arxiv.org/pdf/2601.20282](https://arxiv.org/pdf/2601.20282)

**Category**: Systems & Models

## Description

• Investigated memory mechanisms in Transformer attention layers drawing on the "Encoding Specificity Principle" from psychology. • Proposed that Q encodes retrieval context, K indexes memory traces, and V stores content, identifying that contextual cues are encoded as keywords. • Identified specific attention neurons whose activations facilitate keyword retrieval, providing a theoretical basis and extraction method for downstream tasks like unlearning.
