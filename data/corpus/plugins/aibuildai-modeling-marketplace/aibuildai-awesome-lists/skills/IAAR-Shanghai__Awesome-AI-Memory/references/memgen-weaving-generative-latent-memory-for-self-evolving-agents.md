# MemGen Weaving Generative Latent Memory for Self-Evolving Agents

**Source**: [https://arxiv.org/abs/2509.24704](https://arxiv.org/abs/2509.24704)

**Category**: Framework & Methods

## Description

• MemGen is a dynamic generative memory framework designed to enhance the reasoning and decision-making capabilities of agents based on large language models (LLMS). • MemGen simulates human cognitive patterns by interweaving memory with the reasoning process. • This framework consists of two parts: memory triggers and memory weavers, which can dynamically determine when to invoke potential memories and integrate them into the reasoning process.
