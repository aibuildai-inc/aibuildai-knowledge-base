# ClawVM: Harness-Managed Virtual Memory for Stateful Tool-Using LLM Agents

**Source**: [https://arxiv.org/abs/2604.10352](https://arxiv.org/abs/2604.10352)

**Category**: Framework & Methods

## Description

• Proposes ClawVM, a harness-managed virtual memory layer for stateful tool-using LLM agents. • Organizes agent state as typed pages with multi-resolution representations and validates writeback at lifecycle boundaries to avoid stale or destructive state updates. • Significantly reduces controllable failures while adding very little policy-engine overhead.
