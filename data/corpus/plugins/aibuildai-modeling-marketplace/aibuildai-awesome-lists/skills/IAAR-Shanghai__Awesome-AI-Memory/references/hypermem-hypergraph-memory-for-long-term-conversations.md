# HyperMem: Hypergraph Memory for Long-Term Conversations

**Source**: [https://arxiv.org/abs/2604.08256](https://arxiv.org/abs/2604.08256)

**Category**: Framework & Methods

## Description

• Introduces HyperMem, a hypergraph-based memory architecture for long-term conversation. • Models higher-order relations through hyperedges, organizes memory into topic, event, and fact layers, and couples lexical-semantic indexing with coarse-to-fine retrieval. • Improves recall and consistency on long-conversation tasks and achieves the best results on LoCoMo.
