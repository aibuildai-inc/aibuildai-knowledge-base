# Toward Multi-Session Personalized Conversation: A Large-Scale Dataset and Hierarchical Tree Framework for Implicit Reasoning

**Source**: [https://aclanthology.org/2025.emnlp-main.580.pdf](https://aclanthology.org/2025.emnlp-main.580.pdf)

**Category**: Datasets & Benchmark

## Description

• Introduces the IMPLEXCONV dataset and the TACITREE framework for studying implicit reasoning in personalized dialogue. • IMPLEXCONV consists of 2,500 examples focused on implicit reasoning scenarios, capturing subtle syntactic and semantic relationships within conversations. • TACITREE enhances large language models (LLMs)’ ability to perform implicit contextual reasoning in long dialogues by hierarchically organizing dialogue history.
