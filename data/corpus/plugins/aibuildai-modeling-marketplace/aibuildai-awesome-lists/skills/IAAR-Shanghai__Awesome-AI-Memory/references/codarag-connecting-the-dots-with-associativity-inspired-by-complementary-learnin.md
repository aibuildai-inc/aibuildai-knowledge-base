# CodaRAG: Connecting the Dots with Associativity Inspired by Complementary Learning

**Source**: [https://arxiv.org/abs/2604.10426](https://arxiv.org/abs/2604.10426)

**Category**: Framework & Methods

## Description

• Presents CodaRAG, an associative retrieval framework inspired by complementary learning for RAG systems. • Consolidates fragmented knowledge, navigates semantic and functional links to recover evidence chains, and suppresses distractors during retrieval. • Improves both retrieval recall and generation accuracy over prior methods.
