# Evaluating the Long-term memory of large language models

**Source**: [https://aclanthology.org/2025.findings-acl.1014.pdf](https://aclanthology.org/2025.findings-acl.1014.pdf)

**Category**: Datasets & Benchmark

## Description

• This paper investigates the memory capabilities of large language models (LLMs) in long-term tasks, with a particular focus on dialogue systems. • By constructing the Long-Order Chronological Conversation (LOCCO) dataset, the study provides a quantitative evaluation of LLMs’ long-term memory performance. • Experimental results show that while LLMs can retain historical conversational information to some extent, their memory gradually degrades over time.
