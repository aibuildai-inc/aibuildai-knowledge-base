# PASK: Toward Intent-Aware Proactive Agents with Long-Term Memory

**Source**: [https://arxiv.org/abs/2604.08000](https://arxiv.org/abs/2604.08000)

**Category**: Framework & Methods

## Description

• Introduces the DD-MM-PAS paradigm and the Pask system for intent-aware proactive agents with long-term memory. • Combines IntentFlow for latent-need detection, a hybrid workspace-user-global memory design, and a full perception-memory-action infrastructure. • Achieves deeper user-intent recognition under low-latency constraints and releases LatentNeeds-Bench.
