# Codebase-Memory: Tree-Sitter-Based Knowledge Graphs for LLM Code Exploration via MCP

**Source**: [https://arxiv.org/abs/2603.27277](https://arxiv.org/abs/2603.27277)

**Category**: Framework & Methods

## Description

• CODEBASE-MEMORY provides a persistent, Tree-Sitter-based knowledge graph architecture supporting 66 languages through a multi-phase parallel build pipeline and incremental synchronization. • The system introduces an MCP-based tool interface exposing 14 structural query tools, such as call-path tracing and impact analysis, with sub-millisecond query latency. • Empirical evaluation across 31 repositories demonstrates that the approach achieves competitive answer quality while reducing token consumption by ten times and tool calls by 2.1 times compared to traditional file-exploration agents.
