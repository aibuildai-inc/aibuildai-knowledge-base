# From Experience to Strategy: Empowering LLM Agents with Trainable Graph Memory

**Source**: [https://arxiv.org/pdf/2511.07800](https://arxiv.org/pdf/2511.07800)

**Category**: Systems & Models

## Description

• Introduced a trainable graph-structured memory to store experiences and support strategy formation over time. • Learned how to weight/route experiences in the memory graph to inform future decisions and planning. • Reported improvements on agent tasks requiring multi-step reuse of prior experience.
