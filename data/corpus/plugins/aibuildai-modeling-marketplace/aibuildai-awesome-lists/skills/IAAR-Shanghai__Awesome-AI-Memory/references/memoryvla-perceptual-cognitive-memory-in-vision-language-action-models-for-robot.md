# MemoryVLA Perceptual-Cognitive Memory in Vision-Language-Action Models for Robotic Manipulation

**Source**: [https://arxiv.org/abs/2508.19236](https://arxiv.org/abs/2508.19236)

**Category**: Framework & Methods

## Description

• MemoryVLA is a newly developed robot operation framework, aiming to enhance the performance of robots in complex tasks by integrating visual, language, and perception-cognitive mechanisms. • This framework adopts an architecture similar to the human dual memory system, enhancing the robot's ability to handle long-sequence tasks. • MemoryVLA introduces perception-cognitive memory banks (PCMB), which can effectively integrate historical information with current decisions, thereby enhancing the success rate of robots in responding to complex scenarios.
