# MemBench: Towards More Comprehensive Evaluation on the Memory of LLM-based Agents

**Source**: [https://aclanthology.org/2025.findings-acl.989.pdf](https://aclanthology.org/2025.findings-acl.989.pdf)

**Category**: Datasets & Benchmark

## Description

• MemBench is designed to comprehensively evaluate the memory capabilities of LLM-based agents. • By constructing datasets that cover both factual memory and reflective memory, the study addresses limitations of existing evaluation approaches. • The paper provides a detailed description of memory mechanism construction—including user relationship graphs and multi-layer memory designs—and emphasizes the importance of evaluation metrics such as accuracy, efficiency, and capacity.
