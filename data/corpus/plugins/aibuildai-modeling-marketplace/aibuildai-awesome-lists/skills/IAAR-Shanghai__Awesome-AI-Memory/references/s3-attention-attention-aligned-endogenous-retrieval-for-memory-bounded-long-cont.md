# S3-Attention: Attention-Aligned Endogenous Retrieval for Memory-Bounded Long-Context Inference

**Source**: [https://arxiv.org/pdf/2601.17702](https://arxiv.org/pdf/2601.17702)

**Category**: Systems & Models

## Description

• Proposed S3-Attention (Sparse & Semantic Streaming Attention), achieving O(1) GPU memory for long-context inference. • Uses Sparse Autoencoders (SAE) to decode attention states into sparse features, building a CPU-based inverted index and discarding the KV cache. • Retained near-full-context performance (e.g., 99.4% on Llama-3-8B) on LongBench via endogenous retrieval based on feature co-activation.
