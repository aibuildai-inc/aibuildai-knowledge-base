# MemLong: Memory-Augmented Retrieval for Long Text Modeling

**Source**: [https://openreview.net/pdf?id=AxBgIF4Xva](https://openreview.net/pdf?id=AxBgIF4Xva)

**Category**: Framework & Methods

## Description

• Proposed MemLong, a memory-augmented retrieval approach for long-context language modeling by fetching historical chunks externally. • Combined a retrieval/memory module with a partially trainable decoder-only LM, plus controllable retrieval attention over retrieved chunks. • Evaluated on long-context language modeling benchmarks to show improved generation quality and longer effective context.
