# Memory3: Language modeling with explict memory

**Source**: [https://doi.org/10.4208/jml.240708](https://doi.org/10.4208/jml.240708)

**Category**: Systems & Models

## Description

• Memory3 is a novel large language model that introduces explicit memory to reduce training and inference costs. • The study proposes a memory circuit theory that describes the process of memory externalization, clarifies the definition of knowledge, and highlights the model’s advantages in handling long contexts. • Memory3 effectively manages the costs of knowledge writing and reading, and employs compression techniques to significantly reduce the storage requirements of explicit memory.
