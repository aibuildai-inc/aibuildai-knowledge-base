# Echo: A Large Language Model with Temporal Episodic Memory

**Source**: [https://arxiv.org/pdf/2502.16090](https://arxiv.org/pdf/2502.16090)

**Category**: Systems & Models

## Description

• Introduced an LLM design that explicitly incorporates temporal episodic memory to store time-indexed events. • Targeted improved recall of event sequences and time-sensitive dependencies for downstream reasoning. • Evaluated on episodic-memory-focused tests to demonstrate gains over baselines without explicit episodic memory.
