# StreamMeCo: Long-Term Agent Memory Compression for Efficient Streaming Video Understanding

**Source**: [https://arxiv.org/abs/2604.09000](https://arxiv.org/abs/2604.09000)

**Category**: Framework & Methods

## Description

• Proposes StreamMeCo for long-term memory compression in streaming video understanding. • Compresses memory graphs through edge-aware pruning and isolated-node sampling, and adds time-decayed retrieval to offset compression loss. • Delivers large memory savings and faster retrieval while maintaining or improving accuracy on multiple benchmarks.
