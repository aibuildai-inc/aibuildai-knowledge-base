# LongMemEval: Benchmarking chat assistants on long-term interactive memory

**Source**: [https://arxiv.org/pdf/2410.10813](https://arxiv.org/pdf/2410.10813)

**Category**: Datasets & Benchmark

## Description

• The paper introduces LONGMEMEVAL, a comprehensive benchmark for evaluating the long-term memory capabilities of chat assistants. • The benchmark assesses five core memory abilities, capturing key challenges faced by existing systems. • LONGMEMEVAL adopts a unified three-stage framework—indexing, retrieval, and reading—and proposes several design optimizations to improve memory recall and question-answering accuracy.
