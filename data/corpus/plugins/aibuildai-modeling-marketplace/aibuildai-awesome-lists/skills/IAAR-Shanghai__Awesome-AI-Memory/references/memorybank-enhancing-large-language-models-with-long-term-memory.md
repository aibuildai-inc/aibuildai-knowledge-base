# MemoryBank: Enhancing Large Language Models with Long-Term Memory

**Source**: [https://ojs.aaai.org/index.php/AAAI/article/view/29946](https://ojs.aaai.org/index.php/AAAI/article/view/29946)

**Category**: Framework & Methods

## Description

• MemoryBank is a long-term memory mechanism designed for large language models (LLMs) to address memory limitations in continuous interactions. • By enabling models to effectively recall, update, and adapt user memories, MemoryBank enhances contextual understanding and user experience. • Experimental results and analyses demonstrate MemoryBank’s effectiveness in improving emotional support and personalized interactions.
