# When to Memorize and When to Stop: Gated Recurrent Memory for Long-Context Reasoning

**Source**: [https://arxiv.org/pdf/2602.10560](https://arxiv.org/pdf/2602.10560)

**Category**: Framework & Methods

## Description

• It proposes GRU-Mem, a gated recurrent memory framework that processes long context chunk-by-chunk to overcome performance degradation and context window limits in LLMs. • It introduces two text-controlled gates, an update gate and an exit gate, to selectively update memory and enable early termination, effectively preventing memory explosion and reducing redundant computation. • Optimized via end-to-end reinforcement learning, GRU-Mem significantly outperforms existing methods in reasoning tasks and achieves up to 400% inference speed acceleration compared to vanilla recurrent memory agents.
