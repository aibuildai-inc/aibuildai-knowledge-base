# Learning Hierarchical Procedural Memory for LLM Agents through Bayesian Selection and Contrastive Refinement

**Source**: [https://arxiv.org/pdf/2512.18950](https://arxiv.org/pdf/2512.18950)

**Category**: Framework & Methods

## Description

• A Bayesian procedural memory (experience) framework: MACLA. • Overall still a rule-based algorithm; operations include extraction, retrieval/storage, and refinement (Bayesian posterior calibration). • On unseen tasks in ALFWorld, performance (90.3%) exceeded that on seen tasks (87.2%), achieving +3.1% positive generalization.
