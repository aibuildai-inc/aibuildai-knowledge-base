# LogAct: Enabling Agentic Reliability via Shared Logs

**Source**: [https://arxiv.org/abs/2604.07988](https://arxiv.org/abs/2604.07988)

**Category**: Framework & Methods

## Description

• Proposes LogAct, a shared-log execution framework that turns agents into state machines over an explicit log. • Makes planned actions visible before execution, enabling intervention, recovery, semantic replay, and LLM-based introspection from historical traces. • Improves reliability, fault recovery, and debugging for agentic systems.
