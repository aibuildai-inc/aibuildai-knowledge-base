# CodeComp: Structural KV Cache Compression for Agentic Coding

**Source**: [https://arxiv.org/abs/2604.10235](https://arxiv.org/abs/2604.10235)

**Category**: Framework & Methods

## Description

• Introduces CodeComp, a structural KV-cache compression method for agentic coding tasks. • Combines static program analysis with code property graphs to preserve structurally critical tokens that attention-only pruning often removes. • Outperforms attention-based compression under the same memory budget and integrates into the SGLang pipeline without changing the model.
