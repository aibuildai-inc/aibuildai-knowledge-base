# Memoro: Using Large Language Models to Realize a Concise Interface for Real-Time Memory Augmentation

**Source**: [https://dl.acm.org/doi/10.1145/3613904.3642450](https://dl.acm.org/doi/10.1145/3613904.3642450)

**Category**: Systems & Models

## Description

• Memoro is a wearable audio-based memory assistant designed to minimize disruption during social interactions by utilizing Large Language Models (LLMs) for concise memory retrieval. • The system introduces a "Queryless Mode" that proactively infers user memory needs based on real-time conversational context, alongside a traditional "Query Mode" for explicit natural language requests. • User studies indicate that Memoro increases recall confidence and reduces device interaction time while effectively preserving the quality of ongoing conversations.
