# Pretraining with hierarchical memories: separating long-tail and common knowledge

**Source**: [https://arxiv.org/pdf/2510.02375](https://arxiv.org/pdf/2510.02375)

**Category**: Framework & Methods

## Description

• Proposes a "pretraining-with-memories" architecture that decouples reasoning capabilities (anchor model) from long-tail world knowledge (hierarchical memory bank). • The system dynamically retrieves and attaches context-dependent parameter blocks from a massive memory bank to a small anchor model during inference, enabling efficient scaling. • Experiments demonstrate that a 160M model augmented with memories matches the performance of a standard model with over twice the parameters, specifically excelling at long-tail knowledge tasks.
