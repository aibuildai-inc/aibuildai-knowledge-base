# FadeMem: Biologically-Inspired Forgetting for Efficient Agent Memory

**Source**: [https://arxiv.org/pdf/2601.18642](https://arxiv.org/pdf/2601.18642)

**Category**: Framework & Methods

## Description

• Proposed FadeMem, a memory architecture inspired by the Ebbinghaus forgetting curve, introducing active forgetting mechanisms to prevent information overload. • Implemented a dual-layer hierarchy with adaptive exponential decay governed by semantic relevance, access frequency, and temporal patterns. • Combined with LLM-guided conflict resolution, FadeMem achieved superior multi-hop reasoning on Multi-Session Chat and LoCoMo while reducing storage by 45%.
