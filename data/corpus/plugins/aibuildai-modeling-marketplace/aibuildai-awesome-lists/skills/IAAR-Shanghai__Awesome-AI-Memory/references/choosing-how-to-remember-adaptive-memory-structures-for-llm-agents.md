# Choosing How to Remember: Adaptive Memory Structures for LLM Agents

**Source**: [https://arxiv.org/pdf/2602.14038.pdf](https://arxiv.org/pdf/2602.14038.pdf)

**Category**: Framework & Methods

## Description

• Proposes the FluxMem framework, which enables LLM agents to adaptively select different memory structures based on interaction characteristics. • Introduces a three-layer memory hierarchy and employs probabilistic gating based on a Beta mixture model to enhance the robustness of memory fusion. • FluxMem demonstrates outstanding performance in handling heterogeneous interaction patterns, achieving significant performance gains across multiple long-term benchmarks.
