# LongGenBench: Benchmarking long-form generation in long context LLMs

**Source**: [https://arxiv.org/pdf/2409.02076](https://arxiv.org/pdf/2409.02076)

**Category**: Datasets & Benchmark

## Description

• LongGenBench is a benchmark designed to evaluate large language models (LLMs) in generating high-quality long-form text, with a particular emphasis on following complex instructions. • Unlike existing benchmarks, LongGenBench focuses specifically on long-text generation scenarios, covering tasks such as diary writing and menu design. • Despite strong performance on other evaluations, LLMs face significant challenges on the LongGenBench benchmark.
