# Verify Before You Commit: Towards Faithful Reasoning in LLM Agents via Self-Auditing

**Source**: [https://arxiv.org/abs/2604.08401](https://arxiv.org/abs/2604.08401)

**Category**: Framework & Methods

## Description

• Introduces SAVeR, a self-auditing framework for faithful reasoning in LLM agents. • Generates diverse candidate beliefs, audits them adversarially to locate violations, and applies minimal constrained edits before the agent commits to action. • Reduces behavior drift caused by unfaithful reasoning while preserving task performance.
