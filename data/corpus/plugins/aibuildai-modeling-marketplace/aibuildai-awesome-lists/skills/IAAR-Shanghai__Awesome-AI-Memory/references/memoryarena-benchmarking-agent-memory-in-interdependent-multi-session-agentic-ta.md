# MemoryArena: Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks

**Source**: [https://arxiv.org/pdf/2602.16313.pdf](https://arxiv.org/pdf/2602.16313.pdf)

**Category**: Datasets & Benchmark

## Description

• Introduces MemoryArena, a unified evaluation platform for benchmarking agent memory in multi-session tasks. • The benchmark covers tasks such as web navigation, planning, information search, and reasoning, requiring agents to continuously learn and utilize memory during execution. • The study reveals limitations of existing long-context memory benchmarks in evaluating real-world interactive scenarios and emphasizes the necessity of jointly evaluating memory and action.
