# Towards Efficient and Effective Unlearning of Large Language Models for Recommendation

**Source**: [https://arxiv.org/pdf/2403.03536](https://arxiv.org/pdf/2403.03536)

**Category**: Framework & Methods

## Description

• Introduces E2URec, a recommendation data unlearning method specifically designed for LLM-based recommender systems (LLMRec). • E2URec significantly improves unlearning efficiency while preserving recommendation performance by updating only Low-Rank Adaptation (LoRA) parameters. • Experimental results show that E2URec outperforms existing baseline methods on real-world datasets.
