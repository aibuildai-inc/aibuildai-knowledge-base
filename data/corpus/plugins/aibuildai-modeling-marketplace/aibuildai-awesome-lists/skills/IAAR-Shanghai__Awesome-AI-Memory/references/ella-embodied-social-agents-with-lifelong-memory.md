# Ella: Embodied Social Agents with Lifelong Memory

**Source**: [https://arxiv.org/pdf/2506.24019](https://arxiv.org/pdf/2506.24019)

**Category**: Systems & Models

## Description

• Introduces Ella, an embodied social agent equipped with a structured long-term multimodal memory system comprising name-centric semantic memory and spatiotemporal episodic memory. • By integrating this lifelong memory system with foundation models, Ella can retrieve relevant information for decision-making, plan daily activities, and build social relationships in a 3D open world. • Experimental results in a dynamic environment demonstrate Ella's ability to influence, lead, and cooperate with other agents, highlighting the potential of combining structured memory with foundation models.
