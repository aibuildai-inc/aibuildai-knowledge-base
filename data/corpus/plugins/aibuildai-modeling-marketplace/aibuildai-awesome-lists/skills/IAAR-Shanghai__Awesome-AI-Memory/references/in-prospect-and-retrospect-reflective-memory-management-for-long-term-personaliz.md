# In Prospect and Retrospect: Reflective Memory Management for Long-term Personalized Dialogue Agents

**Source**: [https://aclanthology.org/2025.acl-long.413/](https://aclanthology.org/2025.acl-long.413/)

**Category**: Framework & Methods

## Description

• Proposes Reflective Memory Management (RMM), a novel framework for long-term dialogue agents that addresses the limitations of rigid memory granularity and fixed retrieval mechanisms. • Integrates Prospective Reflection to dynamically organize dialogue history into topic-based memories, and Retrospective Reflection to iteratively refine retrieval using online reinforcement learning guided by LLM attribution signals. • Experimental results on MSC and LongMemEval benchmarks demonstrate that RMM significantly outperforms strong baselines, achieving over 10% improvement in accuracy and enhancing response personalization.
