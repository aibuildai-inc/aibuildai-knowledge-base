# L-CiteEval: A Long-Context Citation Evaluation Benchmark

**Source**: [https://arxiv.org/pdf/2410.02115](https://arxiv.org/pdf/2410.02115)

**Category**: Datasets & Benchmark

## Description

• L-CiteEval is a multi-task evaluation benchmark for long-context models (LCMs), designed to measure their abilities in understanding and citation. • The benchmark covers 11 tasks, supports context lengths ranging from 8K to 48K, and provides a comprehensive evaluation framework. • The study shows that closed-source models outperform open-source models in citation quality and generation accuracy, while retrieval-augmented generation (RAG) techniques effectively improve citation quality.
