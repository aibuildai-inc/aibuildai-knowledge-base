# HippoRAG: Neurobiologically Inspired Long-Term Memory for Large Language Models

**Source**: [https://arxiv.org/pdf/2405.14831](https://arxiv.org/pdf/2405.14831)

**Category**: Framework & Methods

## Description

• HippoRAG is a novel retrieval framework inspired by the hippocampal indexing theory of human long-term memory, designed to enable deeper and more efficient knowledge integration for LLMs. • By orchestrating LLMs, knowledge graphs, and Personalized PageRank (PPR) to mimic the neocortex and hippocampus, it enables effective single-step multi-hop retrieval. • The method outperforms state-of-the-art retrieval-augmented generation (RAG) methods on multi-hop QA tasks by up to 20% and is significantly faster and cheaper than iterative retrieval approaches.
