# Human-inspired Perspectives: A Survey on AI Long-term Memory

**Source**: [https://arxiv.org/pdf/2411.00489](https://arxiv.org/pdf/2411.00489)

**Category**: Survey

## Description

• This paper systematically examines the interplay between human long-term memory mechanisms and AI long-term memory, and proposes an adaptive long-term memory cognitive architecture (SALM). • It introduces the structure of human memory, including sensory memory, working memory, and different types of long-term memory (episodic, semantic, and procedural memory). • The paper analyzes the classification of AI long-term memory—parametric and non-parametric memory—as well as their storage and retrieval mechanisms.
