# Clustering-driven Memory Compression for On-device Large Language Models

**Source**: [https://arxiv.org/pdf/2601.17443](https://arxiv.org/pdf/2601.17443)

**Category**: Framework & Methods

## Description

• Proposed a clustering-based memory compression strategy designed for on-device personalization under limited context windows. • Groups similar memories and merges them within clusters (instead of simple concatenation), reducing redundancy while preserving semantic coherence. • Demonstrated significant reduction in token usage and improved personalized generation quality compared to naive concatenation baselines.
