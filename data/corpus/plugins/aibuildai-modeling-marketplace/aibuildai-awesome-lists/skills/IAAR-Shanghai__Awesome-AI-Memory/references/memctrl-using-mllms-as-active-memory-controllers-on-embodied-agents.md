# MemCtrl: Using MLLMs as Active Memory Controllers on Embodied Agents

**Source**: [https://arxiv.org/pdf/2601.20831](https://arxiv.org/pdf/2601.20831)

**Category**: Framework & Methods

## Description

• Proposed MemCtrl, a framework using MLLMs as active memory controllers to filter redundant observations online for embodied agents. • Introduced a trainable memory head ($\mu$) acting as a gate to dynamically determine whether to retain, update, or discard observations during exploration. • Trained via offline supervision and online RL, MemCtrl improved task completion rates by ~16% for small MLLMs on EmbodiedBench, with >20% gains on specific instruction subsets.
