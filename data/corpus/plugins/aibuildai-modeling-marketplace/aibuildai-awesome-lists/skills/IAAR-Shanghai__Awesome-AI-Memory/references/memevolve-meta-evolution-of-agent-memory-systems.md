# MemEvolve: Meta-Evolution of Agent Memory Systems

**Source**: [https://arxiv.org/pdf/2512.18746](https://arxiv.org/pdf/2512.18746)

**Category**: Framework & Methods

## Description

• An OPPO-affiliated paper proposes a two-layer framework that, in RL settings, separates learning to extract memories (level-1) from learning the memory-extraction method itself (level-2). • Experiments using Flash-Searcher and GPT-5-Mini achieve SOTA on benchmarks including GAIA.
