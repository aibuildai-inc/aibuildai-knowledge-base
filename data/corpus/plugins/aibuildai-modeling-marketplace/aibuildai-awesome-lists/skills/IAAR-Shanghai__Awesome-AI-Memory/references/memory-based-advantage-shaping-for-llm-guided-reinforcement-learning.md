# Memory-Based Advantage Shaping for LLM-Guided Reinforcement Learning

**Source**: [https://arxiv.org/pdf/2602.17931v1.pdf](https://arxiv.org/pdf/2602.17931v1.pdf)

**Category**: Framework & Methods

## Description

• This study proposes an innovative “memory-based advantage shaping” approach aimed at improving the sample efficiency of reinforcement learning (RL) guided by large language models (LLMs) in sparse or delayed reward environments. • By constructing a memory graph and introducing a utility function, the method effectively integrates external guidance to optimize the learning process of RL models. • Experimental results demonstrate high sample efficiency and strong performance across multiple benchmark environments.
