# Towards Compressive and Scalable Recurrent Memory

**Source**: [https://arxiv.org/pdf/2602.11212](https://arxiv.org/pdf/2602.11212)

**Category**: Framework & Methods

## Description

• It proposes Elastic Memory, a novel recurrent memory architecture grounded in the HiPPO framework that encodes long-range history into fixed-size states via optimal online function approximation. • It develops a parallelized block-level update and a flexible "polynomial sampling" mechanism for efficient retrieval, enabling the reconstruction of history summaries from compressed states without extra trainable parameters. • Experiments demonstrate that it outperforms SOTA baselines on 32k+ context tasks with superior efficiency, while its decoupled design allows for injecting inductive biases at test-time without retraining.
