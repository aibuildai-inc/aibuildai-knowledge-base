# Formal Architecture Descriptors as Navigation Primitives for AI Coding Agents

**Source**: [https://arxiv.org/abs/2604.13108](https://arxiv.org/abs/2604.13108)

**Category**: Framework & Methods

## Description

• Studies formal architecture descriptors as navigation primitives for AI coding agents. • Shows that structured architecture context can reduce aimless repository exploration and improve behavioral consistency across agent runs. • Compares JSON, YAML, and S-expression formats, and introduces intent.lisp and the Forge toolchain.
