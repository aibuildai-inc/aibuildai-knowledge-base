# HiMeS: Hippocampus-inspired Memory System for Personalized AI Assistants

**Source**: [https://arxiv.org/pdf/2601.06152](https://arxiv.org/pdf/2601.06152)

**Category**: Framework & Methods

## Description

• HiMeS is a memory framework for AI assistants that emulates the hippocampus–neocortex interaction by integrating short-term dialogue compression with long-term user profile storage. • It utilizes a short-term memory extractor trained via reinforcement learning to proactively pre-retrieve knowledge, and a partitioned long-term memory network to re-rank results based on historical user interactions. • Evaluations on real-world industrial datasets demonstrate that HiMeS significantly outperforms traditional RAG baselines in personalized question-answering tasks.
