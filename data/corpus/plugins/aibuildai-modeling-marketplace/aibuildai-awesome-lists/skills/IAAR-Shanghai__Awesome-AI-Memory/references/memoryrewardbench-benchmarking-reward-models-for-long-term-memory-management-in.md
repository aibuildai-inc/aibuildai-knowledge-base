# MemoryRewardBench: Benchmarking Reward Models for Long-Term Memory Management in Large Language Models

**Source**: [https://arxiv.org/pdf/2601.11969](https://arxiv.org/pdf/2601.11969)

**Category**: Datasets & Benchmark

## Description

• Proposed MemoryRewardBench, the first benchmark to systematically evaluate the ability of Reward Models (RMs) to assess long-term memory management. • Covers 10 settings across reasoning, dialogue, and generation tasks with contexts from 8K to 128K tokens. • Designed Outcome-based and Process-based evaluation criteria, revealing a generational advantage in newer models for evaluating memory capabilities.
