# SimpleMem: Efficient Lifelong Memory for LLM Agents

**Source**: [https://arxiv.org/pdf/2601.02553](https://arxiv.org/pdf/2601.02553)

**Category**: Framework & Methods

## Description

• Introduces SimpleMem, an efficient memory framework tailored for lifelong LLM agents based on semantic lossless compression. • The system operates via a three-stage pipeline: Semantic Structured Compression to filter low-entropy noise, Recursive Memory Consolidation to synthesize abstract representations, and Adaptive Query-Aware Retrieval to minimize token usage. • Experiments on the LoCoMo benchmark demonstrate a 26.4% improvement in F1 score and up to 30× reduction in inference token consumption compared to full-context models, significantly outperforming baselines like Mem0.
