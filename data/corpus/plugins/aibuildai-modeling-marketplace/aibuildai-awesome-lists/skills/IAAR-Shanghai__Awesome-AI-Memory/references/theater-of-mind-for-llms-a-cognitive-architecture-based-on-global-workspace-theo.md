# "Theater of Mind" for LLMs: A Cognitive Architecture Based on Global Workspace Theory

**Source**: [https://arxiv.org/abs/2604.08206](https://arxiv.org/abs/2604.08206)

**Category**: Framework & Methods

## Description

• Introduces Global Workspace Agents, a cognitive architecture for LLM agents inspired by global workspace theory. • Combines a central broadcast hub with heterogeneous agents, plus entropy-driven intrinsic motivation and a two-tier memory branching strategy. • Improves semantic diversity and long-term cognitive continuity in multi-agent execution.
