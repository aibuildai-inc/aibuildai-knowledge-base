# Look Back to Reason Forward: Revisitable Memory for Long-Context LLM Agents

**Source**: [https://arxiv.org/pdf/2509.23040](https://arxiv.org/pdf/2509.23040)

**Category**: Framework & Methods

## Description

• Addressed long-context reasoning where relevant evidence is dispersed across very long inputs. • Proposed a “revisitable” memory design that allows the agent to look back and selectively retrieve from the broader history. • Evaluated on long-context QA settings to show improved evidence recovery and reasoning accuracy.
