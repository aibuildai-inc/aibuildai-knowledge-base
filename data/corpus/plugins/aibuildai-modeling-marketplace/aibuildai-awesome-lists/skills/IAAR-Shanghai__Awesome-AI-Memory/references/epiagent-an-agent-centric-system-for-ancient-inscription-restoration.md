# EpiAgent: An Agent-Centric System for Ancient Inscription Restoration

**Source**: [https://arxiv.org/abs/2604.09367](https://arxiv.org/abs/2604.09367)

**Category**: Systems & Models

## Description

• Proposes EpiAgent, an agent-centric system for ancient inscription restoration. • Uses an Observe-Conceive-Execute-Reevaluate loop in which a central LLM planner coordinates multimodal analysis, historical experience, tools, and self-reflection. • Outperforms prior methods on real restoration tasks and improves both quality and generalization.
