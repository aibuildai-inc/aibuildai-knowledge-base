# Live-Evo: Online Evolution of Agentic Memory from Continuous Feedback

**Source**: [https://arxiv.org/pdf/2602.02369](https://arxiv.org/pdf/2602.02369)

**Category**: Framework & Methods

## Description

• Formulated memory as an evolving object updated online from dense/continuous feedback signals rather than sparse endpoints. • Proposed an update/evolution loop that revises stored memories based on feedback to improve future behavior. • Demonstrated online improvement over time in agent tasks under continuous supervision.
