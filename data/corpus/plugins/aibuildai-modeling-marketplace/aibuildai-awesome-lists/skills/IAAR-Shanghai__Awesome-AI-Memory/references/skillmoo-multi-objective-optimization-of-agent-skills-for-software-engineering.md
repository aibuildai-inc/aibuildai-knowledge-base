# SkillMOO: Multi-Objective Optimization of Agent Skills for Software Engineering

**Source**: [https://arxiv.org/abs/2604.09297](https://arxiv.org/abs/2604.09297)

**Category**: Framework & Methods

## Description

• Introduces SkillMOO, a multi-objective optimization framework for software engineering agent skills. • Combines LLM-generated edits with NSGA-II selection to evolve skill bundles based on task failures and cost-performance trade-offs. • Improves pass rates while lowering cost, and shows that replacing or pruning instructions can outperform simply accumulating them.
