# Aligning Progress and Feasibility: A Neuro-Symbolic Dual Memory Framework for Long-Horizon LLM Agents

**Source**: [https://arxiv.org/abs/2604.02734](https://arxiv.org/abs/2604.02734)

**Category**: Framework & Methods

## Description

• Identifying long-horizon agent failures as arising from two coupled but distinct objectives: global progress alignment and local feasibility alignment. • Proposing the Neuro-Symbolic Dual Memory Framework that instantiates a neural Progress Memory for stage-aware semantic guidance and a symbolic Feasibility Memory for executable action verification. • Demonstrating superior performance across diverse benchmarks including ALFWorld, WebShop, and TextCraft while significantly reducing invalid action rates and trajectory lengths.
