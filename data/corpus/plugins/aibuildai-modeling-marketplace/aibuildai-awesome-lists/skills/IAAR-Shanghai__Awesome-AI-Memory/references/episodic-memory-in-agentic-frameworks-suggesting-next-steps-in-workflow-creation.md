# Episodic Memory in Agentic Frameworks: Suggesting Next Steps in Workflow Creation

**Source**: [https://arxiv.org/pdf/2511.17775](https://arxiv.org/pdf/2511.17775)

**Category**: Systems & Models

## Description

• Proposed an episodic memory store for workflow traces, enabling retrieval of similar historical workflows. • Used retrieved workflow episodes to suggest plausible “next steps” during workflow creation, reducing hallucination pressure on the LLM. • Evaluated next-step recommendation quality in agentic workflow settings.
