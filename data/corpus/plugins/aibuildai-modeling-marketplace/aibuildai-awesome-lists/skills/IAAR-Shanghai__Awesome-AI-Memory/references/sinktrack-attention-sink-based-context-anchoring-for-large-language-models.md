# SinkTrack: Attention Sink based Context Anchoring for Large Language Models

**Source**: [https://arxiv.org/abs/2604.10027](https://arxiv.org/abs/2604.10027)

**Category**: Framework & Methods

## Description

• Introduces SinkTrack, a training-free context anchoring method that exploits the model's attention sink at <BOS> to preserve critical context. • Injects key information into the <BOS> representation so the model can retain initial context throughout generation instead of gradually forgetting it. • Delivers consistent gains on text and multimodal tasks while reducing hallucination and context forgetting.
