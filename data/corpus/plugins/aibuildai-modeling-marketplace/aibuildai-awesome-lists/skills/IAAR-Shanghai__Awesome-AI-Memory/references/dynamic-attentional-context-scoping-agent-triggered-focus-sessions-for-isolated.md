# Dynamic Attentional Context Scoping: Agent-Triggered Focus Sessions for Isolated Per-Agent Steering in Multi-Agent LLM Orchestration

**Source**: [https://arxiv.org/abs/2604.07911](https://arxiv.org/abs/2604.07911)

**Category**: Framework & Methods

## Description

• Introduces DACS, a dynamic attentional context scoping mechanism for multi-agent LLM orchestration. • Keeps only lightweight state summaries in registry mode and switches into a focus mode that injects full context for the selected agent while compressing others. • Improves steering accuracy and reduces interference from irrelevant agents.
