# KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation

**Source**: [https://arxiv.org/abs/2604.08455](https://arxiv.org/abs/2604.08455)

**Category**: Datasets & Benchmark

## Description

• Introduces KnowU-Bench, an online benchmark for interactive, proactive, and personalized mobile agents in Android simulation. • Hides user profiles and provides only behavioral traces, requiring agents to infer preferences through interaction and decide when to intervene, ask consent, or stay silent. • Reveals large performance drops for frontier models when preference inference and intervention calibration are required.
