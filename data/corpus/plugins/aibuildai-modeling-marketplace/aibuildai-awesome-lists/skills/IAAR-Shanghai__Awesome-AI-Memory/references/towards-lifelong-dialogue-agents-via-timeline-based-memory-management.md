# Towards Lifelong Dialogue Agents via Timeline-based Memory Management

**Source**: [https://aclanthology.org/2025.naacl-long.435.pdf](https://aclanthology.org/2025.naacl-long.435.pdf)

**Category**: Systems & Models

## Description

• Proposes THEANINE, a framework for lifelong dialogue agents that utilizes a relation-aware memory graph to store memories without deletion, preserving temporal and cause-effect connections. • Introduces a timeline-augmented response generation approach that retrieves and refines entire memory timelines, ensuring rich contextual cues are maintained for long-term interaction. • Presents TeaFarm, a counterfactual-driven evaluation pipeline designed to stress-test dialogue agents' ability to correctly reference past conversations, where THEANINE demonstrates superior performance over existing baselines.
