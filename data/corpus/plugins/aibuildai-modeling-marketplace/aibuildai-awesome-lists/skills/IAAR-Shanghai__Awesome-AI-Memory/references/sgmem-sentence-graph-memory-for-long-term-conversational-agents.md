# SGMEM: Sentence Graph Memory for Long-Term Conversational Agents

**Source**: [https://arxiv.org/abs/2509.21212](https://arxiv.org/abs/2509.21212)

**Category**: Framework & Methods

## Description

• SGMem is a hierarchical memory management framework designed to address memory fragmentation in long-term conversational agents by organizing dialogue into sentence-level graphs. • It explicitly models associations across turns, rounds, and sessions, and uses a multi-hop retrieval mechanism to integrate raw dialogue history with generated memory such as summaries, facts, and insights. • Extensive experiments on LongMemEval and LoCoMo benchmarks demonstrate that SGMem consistently improves retrieval coherence and outperforms strong baselines in question answering accuracy.
