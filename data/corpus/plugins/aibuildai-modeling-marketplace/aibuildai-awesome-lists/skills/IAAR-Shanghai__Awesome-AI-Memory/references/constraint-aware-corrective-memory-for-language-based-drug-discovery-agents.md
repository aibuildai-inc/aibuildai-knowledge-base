# Constraint-Aware Corrective Memory for Language-Based Drug Discovery Agents

**Source**: [https://arxiv.org/abs/2604.09308](https://arxiv.org/abs/2604.09308)

**Category**: Framework & Methods

## Description

• Introduces a constraint-aware corrective memory framework for language-based drug discovery agents. • Audits protocols and diagnoses constraint violations, then writes compact corrective feedback into static, dynamic, and correction memory channels. • Significantly improves task success rates by keeping planning context compact and actionable.
