# MEMENTO: Teaching LLMs to Manage Their Own Context

**Source**: [https://arxiv.org/abs/2604.09852](https://arxiv.org/abs/2604.09852)

**Category**: Framework & Methods

## Description

• Introduces MEMENTO, which teaches LLMs to manage their own context by summarizing long reasoning traces into dense intermediate mementos. • Splits reasoning into blocks, generates compact summaries for each block, and continues reasoning from the summaries instead of the full trace. • Reduces context length, KV cache usage, and compute cost while preserving reasoning quality, and releases the OpenMementos dataset.
