# Conflict-Aware Soft Prompting for Retrieval-Augmented Generation

**Source**: [https://arxiv.org/abs/2508.15253](https://arxiv.org/abs/2508.15253)

**Category**: Framework & Methods

## Description

• The "Conflict-Aware Retrieval Enhancement Generation" (CARE) model aims to address the context-memory conflict problem that occurs in Retrieval Enhancement Generation (RAG). • CARE optimizes the performance of large language models (LLMs) by introducing context evaluators, especially in dealing with conflicts between external and internal knowledge. • This method significantly enhances the accuracy and reliability of the model in multiple tasks through techniques such as conflict-aware fine-tuning, soft prompts, and adversarial soft prompts.
