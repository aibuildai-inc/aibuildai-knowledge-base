# Improving Code Localization with Repository Memory

**Source**: [https://arxiv.org/pdf/2510.01003](https://arxiv.org/pdf/2510.01003)

**Category**: Systems & Models

## Description

• Modeled long-term “repository memory” from commit history, linked issues, and evolving code regions. • Added tools to retrieve historical changes and summarize active code areas to support localization decisions. • Demonstrated improved localization performance for software engineering agents on SWE-bench-style benchmarks.
