# Episodic Memory Benchmark: Episodic Memories Generation and Evaluation Benchmark for Large Language Models

**Source**: [https://arxiv.org/abs/2501.13121](https://arxiv.org/abs/2501.13121)

**Category**: Datasets & Benchmark

## Description

• Explores the importance of episodic memory in large language models (LLMs) and proposes the construction of new benchmarks to evaluate models’ reasoning capabilities. • The authors develop a comprehensive framework with newly designed tasks and evaluation protocols, emphasizing the need for novel training strategies to effectively integrate episodic memory. • The framework provides a promising solution for evaluating episodic memory in LLMs.
