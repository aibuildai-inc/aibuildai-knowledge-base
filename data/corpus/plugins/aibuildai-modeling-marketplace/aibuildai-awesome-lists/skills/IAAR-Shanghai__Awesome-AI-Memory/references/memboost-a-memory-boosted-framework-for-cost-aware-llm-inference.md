# MemBoost: A Memory-Boosted Framework for Cost-Aware LLM Inference

**Source**: [https://arxiv.org/html/2603.26557v1](https://arxiv.org/html/2603.26557v1)

**Category**: Framework & Methods

## Description

• Proposes MemBoost, a memory-boosted LLM serving framework that integrates an Associative Memory Engine, a Meta Controller, and a Large-LLM Oracle to optimize the cost-quality trade-off. • Introduces a retrieve-or-escalate decision loop combined with a continuous write-back mechanism to enable efficient semantic answer reuse and memory growth. • Demonstrates through experiments on the MMLU-Pro dataset that the framework significantly reduces inference costs and latency while achieving accuracy comparable to or exceeding the oracle model.
